# YuLiangToolkit（凉雨工具集）

> **一个 Windows 上的自用小工具集：39 个常用工具装进同一个窗口。**
>
> 99.99% AI Coding · .NET 9 + WPF · 绿色免安装 · Unlicense

音视频处理、文档 / 图片 / PDF 阅读、音游辅助、联机棋牌、系统维护都收在里面；
主页是可搜索 / 排序 / 筛选的卡片墙，六套界面风格 + 深 / 浅 / 跟随系统 + 自定义配色 + 可拖拽布局。
日常办点小事、折腾音视频、玩 osu!、和朋友联机，或者拿来当 WPF 工具集模板都行。

## 快速开始

```powershell
.\build.ps1                                  # 一键还原 + 构建（离线可用，走本机 NuGet 缓存）
dotnet run --project YuLiangTookit.csproj    # 运行；也可以直接用 Rider / Visual Studio 打开
.\publish.ps1                                # 发布到 dist\YuLiangToolkit\（-SelfContained 打独立包）
```

需要 **Windows 10 2004（build 19041）及以上** + **.NET 9 SDK**（`global.json` 锁定 9.0.317）。

- **FFmpeg**（音频工具 / 录屏 / 剪辑）：自动找 `PATH` 里的 `ffmpeg.exe`，也可以在工具里手动指定；
- **WebView2 Runtime**（网页浏览器）：Win10 2004+ 一般随 Edge 自带，缺失时工具会提示安装，不随本项目打包；
- **Word / Excel / PPT 阅读器**不需要安装 Office / WPS，**Live2D 桌宠**也不需要额外组件（仅 Windows x64）；
  Live2D 的「AI 聊天」要自己填 DeepSeek API Key（按 token 计费，可全程不用——不填就只走离线兜底）；
- 从源码构建**首次需要联网**还原一次 NuGet 包（OsuParsers / WebView2 / AvalonEdit / SharpCompress / SkiaSharp / MailKit 等），之后走本机缓存。

## 界面与体验

- **卡片墙主页**：搜索（名称 / 分类 / 标签 / 描述）、标签快速筛选、排序（最近使用 / 名称 / 分类）；功能多了按多级分类收进**类别页**，顶部面包屑每一层都能点回去。
- **深色 / 浅色 / 跟随系统 + 六套界面风格**：默认纯色 / 液态玻璃 / 毛玻璃 / 亚克力 / 道系（墨金）/ 云间天上（白天云海 + 暖阳，夜晚星空 + 月亮），「主页设置」里一键切换、立即生效；默认风格另有 **7 套配色（含默认深蓝）+ 自定义主色 / 深浅底色**；可上传窗口背景图（半透明风格下透出、自适应窗口不拉伸，模糊度 0~60 px 按风格各记），换图 / 清除都保留历史。
- **云间天上可调**：选中该主题选项下方会直接出现「云朵速度」（0~150×，默认 1.5×）和「云朵密度」（1~100 个，默认 8 个）两条滑块；云朵按窗口高度上下均匀分布，只影响这套主题。
- **渲染显卡可选**：云朵 / 光晕 / 粒子动画由 WPF 画，「主页设置 → 渲染与性能」可以让本程序优先使用**高性能独显**（也可以选节能核显 / 软件渲染排查），选项会同步进 Windows「图形设置」里本程序的图形性能首选项，重启本程序后生效；设置页同时显示检测到的显卡与「当前是硬件加速还是软件渲染」。
- **应用内光标**：可隐藏系统光标、用程序自绘光标；有跟随主题 / 经典 / 液态玻璃 / 毛玻璃 / 亚克力 / 道系 / 云间天上 / 自定义图片多套样式，**每套都有深 / 浅两套配色，浅色界面自动换成深色系，也可以在「光标深浅」里单独强制**；上传的小图会复制进 `Data\shell\cursor\` 并保留历史；光标在粒子 / 点击特效下面，不会挡住它们。
- **鼠标特效**：粒子拖尾 / 鼠标散光 / 粒子爆炸 / 散光扩散 / 光晕闪烁 / 反色圆环；自动效果与点击效果互相独立、可多选，数量 / 范围 / 半径都有滑块，粒子颜色可自定义。
- **自定义外壳**：自绘标题栏（最大化时按住标题栏往外拖会先还原再跟手）、托盘小图标（× 可设为最小化到托盘）、浏览器式「← 后退 / → 前进」。
- **可拖拽布局**：工具页区块之间的分隔条可左右 / 上下拖动，松手自动记住、双击恢复这一处；左侧「功能列表」栏也能拖宽 / 收起。
- **左侧快捷功能栏**：可把左侧栏切成自定义快捷栏——从主页把功能卡片拖到左边加入，⋮ 上下拖动排序，✕ 移除；关掉恢复完整功能列表（主页设置里开关，内容会记住）。
- **工具页状态保留**：切去别的工具再切回来，打开的文件 / 文件夹、阅读位置、列表、游戏局面都会原样恢复（缓存最近 12 个工具页）。
- **配置导入导出**：主页设置里一键把所有设置 + 表情包收藏图片打成 zip，换电脑 / 备份 / 分享给别人时用；导入覆盖式还原、立即生效，含账号凭据的三份配置不进包。

## 数据与配置

**运行时目录就在 exe 旁边**（`bin\Debug\...` 或 `dist\YuLiangToolkit\`），首次运行自动生成：

- `Data\<功能Id>\` —— 用户数据（下载的游戏、聊天记录、播放列表快照……），**删了会丢**；
- `Config\<功能Id>\config.json` —— 各功能的选项，**改一下自动保存，没有「保存」按钮**；
- `Cache\<功能Id>\` —— 缓存（缩略图 / 临时文件之类），**随时可删**，「主页设置 → 清理缓存」可一键清。

数据跟着 exe 走，**整个程序目录拷走即可迁移 / 发布**；反过来 `dotnet clean`、手删 `bin` / `dist` 会连用户数据一起删掉。仓库根的 `Data/`、`Config/`、`Cache/` 里只有说明文件，**不是**运行时目录。细节见 [docs/shell.md](docs/shell.md#数据与配置都在-exe-旁边)。

## 如何添加一个新工具

实现 `ITool`（`Id / Name / Description / EmojiIcon / Category / Order` + `CreateView()`），启动时会被 `ToolDiscovery` 自动发现；
要分类就加 `CategoryPath`（支持任意层级）。配置继承 `ToolConfig`、ViewModel 继承 `ToolViewModelBase`，
Data / Config 路径与持久化由框架接管；编译好的 dll 也可以放进程序目录的 `plugins\` 当外部插件。

最省事的做法是复制 `src\YuLiangToolkit.Tools.Sample` 当模板，完整步骤见 [AGENTS.md](AGENTS.md)。
