# 主页与外壳

> 窗口外壳本身的功能：主页的搜索 / 排序 / 标签、**多级分类导航（类别页 + 面包屑）**、主页设置
> （**界面风格：默认 / 液态玻璃**、鼠标粒子开关）、自定义标题栏，以及**数据存在哪**（Data / Config）。
> 这几个是所有工具共用的，所以单独放一页。

[← 工具一览](../README.md) ｜ [文档索引](README.md)

## 多级分类导航（类别页 · 面包屑）

功能变多之后主页不再是一整面卡片墙：工具可以声明**任意层级**的类别路径（`ITool.CategoryPath`），
外壳会自动建一棵目录树。

- **主页**：搜索框下面**先**显示「全部分类」卡片（emoji + 描述 + **N 个工具**计数），
  然后才是快速筛选标签条和没有分类的根层工具卡片 —— 功能一多也能第一眼看到大类入口。
  当前内置一个大类 **🎵 音游工具**（osu! 谱面转换、LN 处理、等级计算与下图），
  点它进类别页，再点里面的工具卡片打开功能。
- **类别页**：显示分类的图标 / 名称 / 描述 / 工具统计，下面列出**子分类卡片**（可以继续往下钻，层数不限）
  和**直接属于该分类的工具卡片**；页面里的搜索框只搜这个分类（含子分类）里的工具。
- **面包屑**：顶部工具条显示可点击的分层路径，例如 `🏠 主页 › 🎵 音游工具 › 🎧 osu! 下图器`。
  点前面的祖先层级就能跳回去；当前层级高亮、不可点。工具条左边是**浏览器式「← 后退 / → 前进」**：按访问顺序回退 / 前进（主页、类别页、工具页都算一次访问），跳错页面可以快速回去。
- **侧边栏**：首页 + 根层分类 + 根层工具；进入某个分类子树时，侧边栏选中它的根分类（不会迷路）。
- **搜索不受分类影响**：主页搜索是在**全部工具**里扁平过滤，被收进分类的工具照样能按名称 / 标签 /
  描述 / 类别名搜到；标签条、排序、最近使用、空状态也都保留。

> 给工具加分类只需要一行代码（其它什么都不用改）：
>
> ```csharp
> public IReadOnlyList<string> CategoryPath => new[] { "音游工具" };                       // 一级
> public IReadOnlyList<string> CategoryPath => new[] { "音游工具", "谱面处理" };            // 任意层级
> ```
>
> 不写就是回到主页根层（老工具行为不变）；类别名想配 emoji / 描述，在
> `Models/ShellCategories.cs` 里加一条 `ToolCategoryInfo` 即可。

## 主页设置（⚙ 按钮）

主页标题右上角的「⚙ 主页设置」打开一个无边框小窗（`Owner` = 主窗口、居中、不占任务栏，`Esc` 关闭）：

- **界面风格**：**默认（深色）** / **液态玻璃（实验）** 二选一，**点一下立即换肤、不用重启**（设置窗口自己也跟着变）。
  - 默认 = 第一套 UI：经典深色纯色面板，最省资源（外观与升级前完全一样）。
  - 液态玻璃 = 第二套 UI：半透明玻璃面板 + 流动的彩色光晕背景 + 亮边 / 高光 + 大圆角，
    参考 [Glassium](https://github.com/Kerxs/glassium) 的 Liquid Glass 观感（WPF 版，不依赖 Win11 的 Mica，Win10 也有效果）。
    会多渲染一层动画光晕，低配机器觉得费电 / 掉帧就切回默认。
  - 存 `Config\shell\config.json` 的 `uiTheme`（`"Default"` / `"LiquidGlass"`）；旧配置没有这一项时按「默认」处理，重启后保持。
- **显示鼠标粒子效果**（默认开）：粒子跟随鼠标移动，左键爆一簇、右键来更多；关掉后立刻停止绘制。
  开关自动保存到 `Config\shell\config.json` 的 `showParticles`，重启后保持。
- **粒子颜色**：勾选「启用自定义颜色」后可以选 1~2 种颜色 —— 颜色 1 / 颜色 2 各有一个启用勾选框；
  只勾一种 = 单色粒子，勾两种 = 每颗粒子在两种颜色之间随机渐变；两种都不勾 = 回到默认淡紫白。
  色块点开是预设色板 + 手填 `#RRGGBB`。存 `particleCustomColors` / `particleColor1Enabled` /
  `particleColor2Enabled` / `particleColor1` / `particleColor2`。
- **窗口与托盘**：「点击右上角 × 时」可以选 **关闭应用**（默认）或 **最小化到托盘**。
  选托盘后，× / Alt+F4 只把窗口藏到任务栏右侧的小图标里，应用继续在后台运行
  （单击 / 双击托盘图标恢复窗口；右键托盘图标可以「显示主窗口 / 主页设置 / 退出」）。
  存 `Config\shell\config.json` 的 `closeAction`（`Exit` / `MinimizeToTray`），重启后保持。
- 设置窗口只影响外壳本身；各功能自己的选项仍然在对应功能页面里。

## 主页：搜索 · 排序 · 标签

功能多了也不用翻找：

- **搜索**：直接打字即可（进主页自动聚焦搜索框，`Ctrl+F` 聚焦、`Esc` 清空）。
  按**名称、分类、标签、描述、Id** 匹配，大小写不敏感；空格分隔多个关键词时需**全部命中**（例如 `视频 mp3`）。
- **标签**：卡片上那行蓝色小字就是标签（分类 + 工具自带的 `Tags`）。主页有一排「快速筛选」标签，
  **点一下就筛**；搜不到时也有空状态提示。
- **排序**：默认顺序 / **最近使用**（刚打开过的排最前，卡片上会标“x 分钟前用过”）/ 名称 A→Z / 名称 Z→A / 按分类。
- 排序偏好、使用时间与粒子开关都记在 `Config\shell\config.json`，重启后保持；
  **搜索结果本身不保留**（免得下次打开以为功能丢了）。

## 侧边栏

启动时自动扫描程序目录里所有实现了 `ITool` 的类（`YuLiangToolkit.*.dll` 与 `plugins\*.dll`），
按 `Order` 排序列出来。侧边栏 = 首页 + 根层分类 + 根层工具；分类里的工具在类别页里。
加一个新工具不用改外壳（见 [AGENTS.md 第 4 节](../AGENTS.md)）。

## 自定义标题栏

- 采用 `WindowStyle=None` + `WindowChrome`（`CaptionHeight=0`，整窗都是客户区），边缘缩放由 `ResizeBorderThickness` 提供；
- 窗口按钮（— □ ×）画在界面右上角，关闭按钮悬停变红；
- × 的行为可在「主页设置 → 窗口与托盘」里改成**最小化到托盘**（默认仍是关闭应用）；
  托盘图标在**任务栏右侧通知区域**：单击 / 双击恢复主窗口，右键菜单「显示主窗口 / 主页设置 / 退出」；
- 拖拽移动与双击最大化是代码里手动实现的（点按钮区域不会误触发拖拽）；
  **最大化时按住标题栏往外拖，窗口会先还原成最大化前的大小/位置再跟着鼠标走**（就是普通 Windows 窗口那种
  「拖出来变窗口」的手感）—— 光标抓住标题栏的那一点在还原后保持不动；只点一下（或只抖几个像素、没超过系统
  拖拽判定距离）不会退出最大化；
- 最大化时把窗口钳制到工作区，不会盖住任务栏；
- 顶栏下面那条工具条就是**面包屑导航**（见上）；左边是浏览器式的**← 后退 / → 前进**按钮（没有可回退 / 前进的页面时变灰）；
- **整窗全屏**（目前只有播放器会要）：藏掉标题栏 / 工具条 / 侧边栏 / 状态栏，把窗口铺满**整块显示器**
  （连任务栏那块也占），退出后原样还原。做法是临时改掉 `WM_GETMINMAXINFO` 再最大化 ——
  直接设 `Left/Top/Width/Height` 会被窗口管理器夹回工作区（踩过）；
- **左下角迷你播放条**（播放器开着「后台播放」时出现）也是外壳画的一层浮窗：
  它只在“那个工具不在前台”时显示，点标题回到该工具。
- **鼠标粒子覆盖层**（`Core/Controls/ParticleOverlay`）铺在窗口最上层但不吃鼠标；
  只在主页设置里开关打开时绘制。全屏时界面被藏掉，粒子层照常跟随鼠标。

## 数据与配置：都在 exe 旁边

**运行时目录 = exe 所在目录**（`bin\Debug\net9.0-windows\`、`bin\Release\…`、`publish.ps1` 出来的
`dist\YuLiangToolkit\`）。首次运行 exe 时自动生成 `Data` 与 `Config`，并各带一份「怎么用这两个文件夹.md」：

```
<exe 旁边>\
├─ Data\
│  ├─ <功能Id>\…            ← 功能自己的资源（下载的游戏、会话记录、播放列表快照…）
│  └─ 怎么用这两个文件夹.md  ← 首次运行写入，只写缺失的，不覆盖你改过的
└─ Config\
   ├─ <功能Id>\config.json  ← 该功能所有选项的值（改一下自动保存，没有「保存」按钮）
   ├─ shell\config.json     ← 外壳自己的：主页排序偏好 + 各功能上次使用时间 + 粒子开关 / 颜色 + **界面主题 uiTheme** + 关闭按钮行为
   └─ 怎么用这两个文件夹.md
```

找目录的顺序（先命中先用）：

1. 环境变量 `YLT_HOME`（自检 / 特殊部署用）；
2. **exe 同级**（默认）；
3. `%AppData%\YuLiangToolkit`——只有 exe 目录不可写时（比如装在 `C:\Program Files`）才退到这里。

状态栏最右边一直显示当前实际用的目录。

### 几件要记住的事

- **配置是纯 JSON**（camelCase、带缩进、中文不转义），可以直接用记事本改，改完重开功能即生效；
  枚举按字符串存（`"RepeatOne"`），加字段不影响老文件（缺失字段用代码里的默认值）。
- **删掉 `Config\<功能Id>\*.json` = 那个功能的选项恢复默认**（下次打开自动重建）。
- 文件写坏会自动备份成 `xxx.bad-20250101-120000.json`，然后回退默认值继续跑，不崩。
- 因为数据跟着 exe 走，**整个程序目录拷走就能迁移 / 发布**；反过来 `dotnet clean`、手删 `bin`/`dist`
  会**连用户数据一起删掉**，重要内容自己备份。
- 仓库根的 `Data/`、`Config/` 里只有说明文件，**不是**运行时目录。

## 开发调试用的环境变量

| 变量 | 作用 |
| --- | --- |
| `YLT_NAV_TOOL=<工具Id>` | 启动后直接打开指定工具（如 `media-player`） |
| `YLT_NAV_CATEGORY=<类别路径>` | 启动后直接进类别页（如 `音游工具`，多层用 `/` 分隔：`音游工具/谱面处理`） |
| `YLT_OPEN_SETTINGS=1` | 启动后打开「主页设置」窗口（配合 `YLT_SHOT` 截那个窗口本身） |
| `YLT_SHOT=<png路径>` + `YLT_SHOT_TOOL=<工具Id>` | 渲染界面成 PNG 后退出（不抢焦点，可后台跑） |
| `YLT_HOME=<目录>` | 覆盖数据根目录，测试时隔离用 |
| `YLT_NO_SERVER=1` | 不自动起本地服务器 / 不开房间（自检与无头构造时用） |
| `YLT_PARTICLE_DEMO=1` | 粒子覆盖层按固定轨迹自动生成粒子（截图验收粒子效果用，不设就是正常鼠标模式） |
| `YLT_PARTICLE_TRACE=<文件>` | 把粒子覆盖层收到的鼠标事件坐标、每 20 帧的发射点与存活数写进文件（排查「粒子从错误位置冒出来」用） |
| `YLT_THEME=default\|liquid-glass` | 启动时临时指定界面主题（默认深色 / 液态玻璃），**不写配置**、只影响本次运行；截图对比两套 UI 用 |

其余（各功能专属的调试开关、自检、发布）见 [AGENTS.md 第 0、6 节](../AGENTS.md)。
