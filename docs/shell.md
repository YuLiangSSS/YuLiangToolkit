# 主页与外壳

> 窗口外壳本身的功能：主页的搜索 / 排序 / 标签、**多级分类导航（类别页 + 面包屑）**、**主页设置页面**
> （界面风格与窗口背景图、主页显示、自动 / 点击特效、粒子颜色、关闭行为，以及页面底部的**清理缓存 / 重建配置（恢复默认）**）、
> 自定义标题栏，以及**数据存在哪**（Data / Config / Cache）。这几个是所有工具共用的，所以单独放一页。

## 多级分类导航（类别页 · 面包屑）

功能变多之后主页不再是一整面卡片墙：工具可以声明**任意层级**的类别路径（`ITool.CategoryPath`），
外壳会自动建一棵目录树。

- **主页**：搜索框下面**先**显示「全部分类」卡片（emoji + 描述 + **N 个工具**计数），
  然后才是快速筛选标签条和没有分类的根层工具卡片 —— 功能一多也能第一眼看到大类入口。
  当前内置一个大类 **🎵 音游工具**（osu! 谱面转换、LN 处理、等级计算与下图），
  点它进类别页，再点里面的工具卡片打开功能。
- **类别页**：显示分类的图标 / 名称 / 描述 / 工具统计，下面列出**子分类卡片**（可以继续往下钻，层数不限）
  和**直接属于该分类的工具卡片**；页面里的搜索框只搜这个分类（含子分类）里的工具。
- **面包屑**：顶部工具条显示可点击的分层路径，例如 `🏠 主页 › 🎵 音游工具 › 🎧 osu! 下图器`。
  点前面的祖先层级就能跳回去；当前层级高亮、不可点。工具条左边是**浏览器式「← 后退 / → 前进」**：按访问顺序回退 / 前进（主页、类别页、工具页、主页设置页都算一次访问），跳错页面可以快速回去。
- **侧边栏**：首页 + 根层分类 + 根层工具；进入某个分类子树时，侧边栏选中它的根分类（不会迷路）。
- **搜索不受分类影响**：主页搜索是在**全部工具**里扁平过滤，被收进分类的工具照样能按名称 / 标签 /
  描述 / 类别名搜到；标签条、排序、最近使用、空状态也都保留。

> 给工具加分类只需要一行代码（其它什么都不用改）：
>
> ```csharp
> public IReadOnlyList<string> CategoryPath => new[] { "音游工具" };                       // 一级
> public IReadOnlyList<string> CategoryPath => new[] { "音游工具", "谱面处理" };            // 任意层级
> ```
>
> 不写就是回到主页根层（老工具行为不变）；类别名想配 emoji / 描述，在
> `Models/ShellCategories.cs` 里加一条 `ToolCategoryInfo` 即可。

## 主页设置（⚙ 页面）

主页标题右上角的「⚙ 主页设置」进入**设置页面**（v0.26.0 起从独立小窗改成页面）：
面包屑显示 `🏠 主页 › ⚙ 主页设置`，浏览器式的「← 后退 / → 前进」也能回到这一页，页面底部还有「返回主页」按钮。

- **界面风格**（v0.43.0 起四选一）：**默认（深色）** / **液态玻璃** / **毛玻璃** / **亚克力**，
  **点一下立即换肤、不用重启**（这一页自己也跟着变）：
  - 默认 = 第一套 UI：经典深色纯色面板，最省资源（外观与升级前完全一样）；
  - 液态玻璃 = 半透明玻璃面板 + 流动的彩色光晕背景 + 亮边 / 高光 + 大圆角，
    参考 [Glassium](https://github.com/Kerxs/glassium) 的 Liquid Glass 观感（WPF 版，不依赖 Win11 的 Mica，Win10 也有效果）；
    会多渲染一层动画光晕，低配机器觉得费电 / 掉帧就换默认或毛玻璃；
  - 毛玻璃 = 奶白磨砂面板 + **重模糊背景**（上传背景图时模糊约 28px）、冷色调、没有动画光晕，安静省电；
  - 亚克力 = 深色紫蓝着色玻璃 + **轻模糊**（约 20px）+ 细颗粒噪点，类似 Win11 的 Acrylic；
  - 后三套都是**半透明界面**，能透出下面「背景图」里上传的图片；默认（深色）是纯色面板，不显示背景图；
  - 存 `Config\shell\config.json` 的 `uiTheme`（`"Default"` / `"LiquidGlass"` / `"FrostedGlass"` / `"Acrylic"`）；
    旧配置没有这一项时按「默认」处理，重启后保持。
- **背景图**（v0.43.0，「界面风格」卡片下面那张「背景图」卡）：
  - 点「**选择图片…**」上传一张图片（PNG / JPG / BMP / GIF / TIFF），它会**复制一份**到
    `Data\shell\background\`——只存文件名在配置里，所以整个程序目录搬走 / 换盘符都不失效，之后原图被移动、删除也不影响；
  - **自适应窗口、不拉伸**：默认「铺满窗口」（保持比例，多出来的部分裁掉，窗口怎么拉都不变形）；
    勾「**完整显示整张图（不裁剪，可能留边）**」则整张图完整显示、四周可能留边，同样不拉伸；
  - **只有半透明风格（液态玻璃 / 毛玻璃 / 亚克力）才会显示**背景图（从半透明面板后面透出来，还会按风格自动模糊 /
    加暗色压暗层保证白字可读）；默认（深色）风格下背景图不会显示——设置页里会提示当前风格会不会显示；
  - **背景图模糊度可调**（v0.43.1）：在「界面风格」里选中某个半透明风格后，**它下面会出现「背景图模糊度」滑块**
    （和下面自动 / 点击效果的参数滑块同一种样式），拖动立即生效并自动保存。范围 0~60 px（0 = 清晰、越大越朦胧），
    三套风格**各记各的值**；默认液态玻璃 0 / 毛玻璃 28 / 亚克力 20（= v0.43.0 写死的外观，旧配置升级后不变）。
    模糊只加在静态背景图上，面板和文字永远清晰；没有背景图时拖动看不出效果；
  - 换图会自动删掉上一张副本；「**清除背景图**」删掉数据目录里的副本、恢复纯色背景。配置字段是
    `backgroundImage`（文件名，缺省 = 没设置）、`backgroundImageFitWhole`（`true` = 完整显示 / `false` = 铺满）、
    以及三套风格的模糊度 `liquidGlassBlurRadius` / `frostedGlassBlurRadius` / `acrylicBlurRadius`（缺省 = 0 / 28 / 20）；
    图片文件不在了会当成“没设置”，不影响启动。
- **主页显示**：**显示 / 隐藏主页标签快捷筛选条**（默认显示，v0.33.0）。
  标签有一百多个，默认只排 3 行 + 横向滚动条；不需要这个功能的人可以整块隐藏它
  （隐藏后搜索框仍然能按标签搜到功能，标签本身不会被删）。存 `Config\shell\config.json` 的 `showHomeTags`。
- **自动效果**（可多选，也可以全部不勾）：鼠标移动时持续生效的特效：
  - **粒子拖尾**：鼠标位置持续冒出小粒子（就是以前的「鼠标粒子效果」；左键 / 右键会让粒子短时间变多）；
  - **鼠标散光**：鼠标位置一圈微弱的圆形发散光，跟随鼠标。
  - 全部不勾 = 没有任何自动效果；**和下面的点击效果互不影响**。
- **点击效果**（可多选，可以同时勾好几个）：鼠标按下时触发一次的特效：
  - **粒子爆炸**：点击处炸开一簇粒子；
  - **散光扩散**：点击处扩散一圈彩色色散光环（Glassium 风格散光）；
  - **光晕闪烁**：点击处柔光亮一下再淡出；
  - **反色圆环**（v0.36.0）：点击处一块**颜色反转**的圆形区域，先快速扩大、再收缩到看不见
    （easeOutCubic 缓动：变大时一开始半径涨得快、越往后越慢，缩小时一开始掉得慢、最后掉得快；
    只反色窗口里的界面内容，鼠标指针 / 粒子特效不参与反色）。
    **可以连点**：每点一个位置就新起一圈，上一圈不会被打断（同时最多叠 8 圈，超过才丢最旧的）。
    **两圈撞一起**：默认重叠处会**再反一次 → 变回正色**（像橡皮互相抵消，3 圈及以上按覆盖次数的奇偶算）；
    不想要这个效果可以关掉「反色圆环：两圆重叠时变回正色」复选框（关掉后后触发的圆直接盖住先前的）。
  - **自动效果全部关掉也照样生效**（比如只勾「粒子爆炸」，平时没有拖尾，点一下照样爆炸）。
- **特效参数（v0.37.0，v0.37.3 起嵌在勾选项下面）**：勾选某个特效后，它自己的参数滑块会直接显示在
  那个勾选项的**正下方**（没勾选时参数块整个不显示，不占地方），拖动立即生效并自动保存；
  范围比以前大、精度也调细了：
  - 粒子拖尾：**数量**（1~20 个/帧，0.5 一档）、**大小**（0.4~2.5×）；
  - 鼠标散光：**半径**（20~300 DIP）；
  - 粒子爆炸：**数量**（4~160 颗）、**范围**（0.3~3.0×，射程倍率）；
  - 散光扩散：**半径**（20~400 DIP）；光晕闪烁：**半径**（10~240 DIP）；反色圆环：**半径**（20~400 DIP）；
    反色圆环参数下面还有一个**「两圆重叠时变回正色」**复选框（默认勾选，见上）。
  - 默认值就是 v0.36.x 的固定外观（拖尾 1 个/帧、爆炸 24 颗、反色半径 150 DIP 等）；
    老配置没有这些字段时自动用默认值，升级后外观不变。
- **粒子颜色**：勾选「启用自定义颜色」后可以选 1~2 种颜色 —— 颜色 1 / 颜色 2 各有一个启用勾选框；
  只勾一种 = 单色，勾两种 = 每颗粒子在两种颜色之间随机渐变；两种都不勾 = 回到默认淡紫白。
  色块点开是预设色板 + 手填 `#RRGGBB`。存 `particleCustomColors` / `particleColor1Enabled` /
  `particleColor2Enabled` / `particleColor1` / `particleColor2`。
  颜色对「粒子拖尾 / 粒子爆炸」生效；散光与闪光取颜色 1 作为主色调。只勾散光 / 闪光 / 反色这类非粒子效果时这一卡会置灰。
- **窗口与托盘**：「点击右上角 × 时」可以选 **关闭应用**（默认）或 **最小化到托盘**。
  选托盘后，× / Alt+F4 只把窗口藏到任务栏右侧的小图标里，应用继续在后台运行
  （单击 / 双击托盘图标恢复窗口；右键托盘图标可以「显示主窗口 / 主页设置 / 退出」）。
  存 `Config\shell\config.json` 的 `closeAction`（`Exit` / `MinimizeToTray`），重启后保持。
- **清理缓存 / 重建配置 / 界面布局**：页面最下面（「窗口与托盘」之后、底部小字说明之前）的三张卡 ——
  一个清掉各功能的缓存和「最近浏览」这类记录，一个把勾选功能的选项**恢复默认**（删掉配置文件并立即写回一份默认值），
  最后一个把各工具页拖出来的区块大小**恢复默认布局**。
  会删什么 / 不会删什么、目录约定见下面「[清理缓存与重建配置](#清理缓存与重建配置)」。
- 设置页只影响外壳本身（只有底部的「清理缓存 / 重建配置 / 界面布局」会动到各功能）；各功能自己的选项仍然在对应功能页面里。

> **配置字段**：`autoEffects` / `clickEffects` 是两个字符串数组（可多选、可为空），例如
> `"autoEffects": ["particle-trail", "cursor-glow"]`、`"clickEffects": ["particle-burst", "dispersion", "invert-circle"]`。
> `trailParticleCount` / `trailParticleSize` / `cursorGlowRadius` / `burstParticleCount` / `burstRange` /
> `dispersionRadius` / `glowFlashRadius` / `invertCircleRadius` 是滑块的数值（缺字段 = 默认值）。
> 窗口背景图是 `backgroundImage`（`Data\shell\background\` 里的文件名）+ `backgroundImageFitWhole`（铺满 / 完整显示），
> 模糊度是 `liquidGlassBlurRadius` / `frostedGlassBlurRadius` / `acrylicBlurRadius`（0~60 px，各风格独立）。
> 老版本的 `showParticles` 布尔开关会在升级后**自动迁移**（开 = 粒子拖尾 + 粒子爆炸，关 = 两个都空），
> 之后以两个数组为准；未知 Id 会被忽略，不会崩。

## 清理缓存与重建配置

「主页设置」页最下面、「窗口与托盘」卡片之后（底部小字说明之前）有**清理缓存**和**重建配置**两张卡：
一张管「可以随时删的临时东西」，一张管「把选项恢复默认」。动作都要**先勾选、再点按钮、弹确认**之后才执行。

### 清理缓存

把可清理的缓存列成清单（每项一行、右侧显示占用大小 / 数量），每项一个勾选框，上方有「**全选 / 全不选**」；
**只列出当前确实有东西的项**，没有可清的就不会出现：

- **各功能的缓存文件夹** —— 就是 `Cache\<功能Id>\`（缩略图、解压出来的临时文件之类）。
  这些随时可删，删了最多下次重新生成、慢一点；
- **存在配置里的「记录类」缓存**，由功能自己报告：**图片阅读器的「最近浏览记录」**、
  **PDF 阅读器的「最近打开记录」**、**聊天室的「最近会话列表」**等。
  这些只清记录本身，**不动设置**，也不删你电脑上的原始文件 / 聊天记录；
- `Cache` 里已经没有对应功能的**残留文件夹**、以及直接丢在 `Cache\` 根目录的散落文件（插件删了 / 工具改名留下的）。

点「**清理选中缓存**」会先弹确认，确认后才清；清的是**内容**、保留文件夹本身，下次照常写入。
旁边的「**打开缓存文件夹**」直接在资源管理器打开 `Cache\`，想自己看 / 自己删也行。

**不会删**：`Data\` 里的用户数据（下载的游戏、聊天记录、播放列表…）；也**不改**各功能的设置、不动你原本的图片 / PDF 等文件。
清理只碰 `Cache\` 与被勾选的记录项（想把选项恢复默认，用下面那张「重建配置」）。

`Cache` 和 `Data` / `Config` 在同一个根目录：默认就在 **exe 旁边**（`...\Cache\<功能Id>\`），
设了 `YLT_HOME` 以它为准，exe 目录不可写（比如装在 `C:\Program Files`）才退到 `%AppData%\YuLiangToolkit`
（找目录的顺序见下面「[数据与配置](#数据与配置都在-exe-旁边)」）。

### 重建配置

列出**每个功能**的 `Config\<功能Id>\` 状态（第一项是「**主页 / 外壳设置**」，也就是设置页自己的配置）：
**已有配置文件** / **还没有配置文件**。同样可以勾选、「全选 / 全不选」，点「**重建选中配置**」并确认后：

1. 删掉这些功能配置目录里的 `*.json`；
2. 把**内存里已经加载**的配置对象原地改回默认值（不用重启，页面上的选项立刻回默认）；
3. 已加载的配置会**立刻写回一份默认 JSON**（所以重启后仍然是默认）；从没打开过的功能，下次打开时自然就是默认值。

效果等于「**恢复默认设置**」——**自定义过的选项会丢失**，介意的话先去 `Config\` 里备份。
勾第一项「主页 / 外壳设置」的话，主题、背景图设置、特效、标签墙、关闭行为这些外壳选项也会一起回默认
（背景图设置回默认 = 不再显示；已经复制进 `Data\shell\background\` 的图片文件属于用户数据，重建配置不会删它）。
文件写坏时留下的损坏备份 `*.bad-时间戳.json` **不会被删**，还能从里面手动把设置抄回来。

> 两张卡的分工：**清理缓存** = 清 `Cache` 与「最近记录」这类临时数据；**重建配置** = 恢复默认设置。
> 两者都**不动 `Data\` 里的用户数据**。

### 界面布局（区块可拖拽 / 恢复默认布局）

v0.41.0 起，「有多个区块的工具页」区块之间都能拖动调整大小（跟画图软件拉图形一样）：

- 鼠标移到区块之间的缝隙上 → 亮起一条**蓝色竖线 / 横线**，光标变成 ↔ / ↕，按住拖动即可；
  鼠标**不在**缝隙上时默认只留一条很淡的「提示线」帮你找缝隙——同一张卡里也可以拖滑块
  「**分隔条提示线（鼠标不在上面时）**」调它的透明度：`0%` = 平时完全看不见、`18%` = 默认淡淡一条、
  `100%` = 一直显示实心蓝线；改一下所有工具页立即生效并自动保存；
- 松手后**自动记住**（存在 `Config\layout.json`，外壳级，不在任何功能目录里），下次打开还是调好的样子；
- **双击**某一条分隔条 = 只恢复这一处的默认大小；
- 页面最下面第三张卡「**界面布局**」会显示「已记住几处 / 涉及哪些页面」，点「**恢复默认布局**」并确认后：
  一次清掉所有页面记住的尺寸（只影响区块大小，不动设置 / 缓存 / 数据；以后拖分隔条会重新记住）。

实现 / 新页面约定见 [`docs/dev/layout.md`](dev/layout.md)；用到的控件是 `Core/Mvvm/PaneSplitter`，
样式在 `App.xaml`（`PaneSplitterVerticalStyle` / `PaneSplitterHorizontalStyle`）。`Config\layout.json` 被删或写坏时，
页面自动回到默认尺寸（损坏文件会按惯例备份成 `layout.bad-时间戳.json`）。


### 新功能怎么自动进这两张卡（约定）

```
<exe 旁边>\
├─ Data\<功能Id>\      ← 用户数据，删了会丢（下载的游戏、聊天记录…）
├─ Config\<功能Id>\    ← 选项配置（「重建配置」管这里）
└─ Cache\<功能Id>\     ← 缓存，随时可删（「清理缓存」管这里）
```

- **新功能把缓存写进 `Cache\<功能Id>\`，就自动出现在「清理缓存」列表里**，不用改设置页
  （推荐用框架的 `ToolCache.For(<功能Id>)` 拼路径 / 读写，路径就是 `Cache\<功能Id>\`）。
- 如果缓存**混在 `Config\` 里**（「最近浏览」这种记录），让工具类实现
  `YuLiangToolkit.Core.Maintenance.IToolCacheSource`，在 `DescribeCacheItems()` 里报告
  「显示名 + 数量提示 + 清理动作」即可；没有可清内容时返回空列表，设置页就不会列出这一项。
- **「重建配置」的清单来自所有已发现的功能，新工具自动有一行**，同样不用改设置页。

> 以后别的 AI 写新工具也按这个约定来，两个功能都自动生效；实现细节看
> `src/YuLiangToolkit.Core/Maintenance/` 里的源码注释。

## 主页：搜索 · 排序 · 标签

功能多了也不用翻找：

- **搜索**：直接打字即可（进主页自动聚焦搜索框，`Ctrl+F` 聚焦、`Esc` 清空）。
  按**名称、分类、标签、描述、Id** 匹配，大小写不敏感；空格分隔多个关键词时需**全部命中**（例如 `视频 mp3`）。
- **标签**：卡片上那行蓝色小字就是标签（分类 + 工具自带的 `Tags`）。主页有一排「快速筛选」标签，
  **点一下就筛**；搜不到时也有空状态提示。
  标签有一百多个，所以默认**只排 3 行 + 一条横向滚动条**（v0.33.0）：三行按「行宽尽量均匀」自动分行，
  行内**紧密排列**（标签保持自然宽度、一个挨一个，不按列对齐）；
  左右拖滚动条、或者按住 `Shift` 滚滚轮就能横向看更多；点标题行右边的 **「展开全部 ▾」** 会按原来的换行方式把全部标签铺开，
  再点 **「收起 ▴」** 回到 3 行。不需要标签墙可以在「主页设置 → 主页显示」里整块隐藏。
  鼠标停在标签条上时，普通滚轮仍然滚整个主页页面（不会被标签条吃掉）。
- **排序**：默认顺序 / **最近使用**（刚打开过的排最前，卡片上会标“x 分钟前用过”）/ 名称 A→Z / 名称 Z→A / 按分类。
- 排序偏好、使用时间与光标特效配置都记在 `Config\shell\config.json`，重启后保持；
  **搜索结果本身不保留**（免得下次打开以为功能丢了）。

## 侧边栏

启动时自动扫描程序目录里所有实现了 `ITool` 的类（`YuLiangToolkit.*.dll` 与 `plugins\*.dll`），
按 `Order` 排序列出来。侧边栏 = 首页 + 根层分类 + 根层工具；分类里的工具在类别页里。
加一个新工具不用改外壳（见 [AGENTS.md](../AGENTS.md)）。

## 自定义标题栏

- 采用 `WindowStyle=None` + `WindowChrome`（`CaptionHeight=0`，整窗都是客户区），边缘缩放由 `ResizeBorderThickness` 提供；
- 窗口按钮（— □ ×）画在界面右上角，关闭按钮悬停变红；
- × 的行为可在「主页设置 → 窗口与托盘」里改成**最小化到托盘**（默认仍是关闭应用）；
  托盘图标在**任务栏右侧通知区域**：单击 / 双击恢复主窗口，右键菜单「显示主窗口 / 主页设置 / 退出」；
- 拖拽移动与双击最大化是代码里手动实现的（点按钮区域不会误触发拖拽）；
  **最大化时按住标题栏往外拖，窗口会先还原成最大化前的大小/位置再跟着鼠标走**（就是普通 Windows 窗口那种
  「拖出来变窗口」的手感）—— 光标抓住标题栏的那一点在还原后保持不动；只点一下（或只抖几个像素、没超过系统
  拖拽判定距离）不会退出最大化；
- 最大化时把窗口钳制到工作区，不会盖住任务栏；
- 顶栏下面那条工具条就是**面包屑导航**（见上）；左边是浏览器式的**← 后退 / → 前进**按钮（没有可回退 / 前进的页面时变灰）；
- **整窗全屏**（目前只有播放器会要）：藏掉标题栏 / 工具条 / 侧边栏 / 状态栏，把窗口铺满**整块显示器**
  （连任务栏那块也占），退出后原样还原。做法是临时改掉 `WM_GETMINMAXINFO` 再最大化 ——
  直接设 `Left/Top/Width/Height` 会被窗口管理器夹回工作区（踩过）；
- **左下角迷你播放条**（播放器开着「后台播放」时出现）也是外壳画的一层浮窗：
  它只在“那个工具不在前台”时显示，点标题回到该工具；要关掉它并停掉声音就点右上角的 **×**
  （谁停播由工具自己处理，外壳只负责收起这层浮窗）。
- **光标特效覆盖层**（`Core/Controls/ParticleOverlay`）铺在窗口最上层但不吃鼠标：
  自动效果（粒子拖尾 / 鼠标散光）与点击效果（粒子爆炸 / 散光扩散 / 光晕闪烁 / 反色圆环）都在主页设置页里勾选，
  两套互相独立、各自可多选；只有「确实有特效要画」时才跑渲染循环（空闲零开销）。全屏时界面被藏掉，特效层照常跟随鼠标。
  反色圆环要先把窗口内容取景再逐像素反色，所以覆盖层与内容根节点（`MainWindow.xaml` 的 `RootGrid`）是**兄弟节点**，
  取景不会把覆盖层自己画进去。

## 数据与配置：都在 exe 旁边

**运行时目录 = exe 所在目录**（`bin\Debug\net9.0-windows10.0.19041.0\`、`bin\Release\…`、`publish.ps1` 出来的
`dist\YuLiangToolkit\`）。首次运行 exe 时自动生成 `Data`、`Config` 与 `Cache` 三个文件夹
（`Data` / `Config` 里各带一份「怎么用这两个文件夹.md」）：

```
<exe 旁边>\
├─ Data\
│  ├─ <功能Id>\…            ← 功能自己的资源（下载的游戏、会话记录、播放列表快照…），删了会丢
│  ├─ shell\background\…    ← 窗口背景图（主页设置里上传的那张，复制一份进来；删掉 = 背景图不显示）
│  └─ 怎么用这两个文件夹.md  ← 首次运行写入，只写缺失的，不覆盖你改过的
├─ Config\
│  ├─ <功能Id>\config.json  ← 该功能所有选项的值（改一下自动保存，没有「保存」按钮）
│  ├─ shell\config.json     ← 外壳自己的：主页排序偏好 + 各功能上次使用时间 + 自动/点击特效（`autoEffects` / `clickEffects`）+ 粒子颜色 + 界面主题（`uiTheme`）+ 背景图（`backgroundImage` / `backgroundImageFitWhole` / 三套风格的 `*BlurRadius`）+ 标签墙显示（`showHomeTags`）+ 关闭按钮行为
│  └─ 怎么用这两个文件夹.md
└─ Cache\
   └─ <功能Id>\…            ← 缩略图 / 临时文件之类，随时可删（「主页设置 → 清理缓存」清这里）
```

**三个文件夹的分工**：`Data` = 用户数据（删了会丢）、`Config` = 选项配置、
`Cache` = 随时可删的缓存；清理缓存 / 恢复默认设置见 [清理缓存与重建配置](#清理缓存与重建配置)。

找目录的顺序（先命中先用）：

1. 环境变量 `YLT_HOME`（自检 / 特殊部署用）；
2. **exe 同级**（默认）；
3. `%AppData%\YuLiangToolkit`——只有 exe 目录不可写时（比如装在 `C:\Program Files`）才退到这里。

状态栏最右边一直显示当前实际用的目录。

### 几件要记住的事

- **配置是纯 JSON**（camelCase、带缩进、中文不转义），可以直接用记事本改，改完重开功能即生效；
  枚举按字符串存（`"RepeatOne"`），加字段不影响老文件（缺失字段用代码里的默认值）。
- **删掉 `Config\<功能Id>\*.json` = 那个功能的选项恢复默认**（下次打开自动重建）；
  「主页设置 → 重建配置」就是批量做这件事，而且**立即生效、不用重开**（损坏备份 `*.bad-*.json` 不删）。
- 文件写坏会自动备份成 `xxx.bad-20250101-120000.json`，然后回退默认值继续跑，不崩。
- 因为数据跟着 exe 走，**整个程序目录拷走就能迁移 / 发布**；反过来 `dotnet clean`、手删 `bin`/`dist`
  会**连用户数据一起删掉**，重要内容自己备份。
- 仓库根的 `Data/`、`Config/`、`Cache/` 里只有说明文件，**不是**运行时目录。

| 变量 | 作用 |
| --- | --- |
| `YLT_NAV_TOOL=<工具Id>` | 启动后直接打开指定工具（如 `media-player`） |
| `YLT_NAV_CATEGORY=<类别路径>` | 启动后直接进类别页（如 `音游工具`，多层用 `/` 分隔：`音游工具/谱面处理`） |

| `YLT_HOME_TAGS=hidden\|expanded` | 启动时临时隐藏 / 展开主页标签墙（截图验证用，**不写配置**；什么都不设 = 按配置里的 `showHomeTags`） |

| `YLT_SHOT=<png路径>` + `YLT_SHOT_TOOL=<工具Id>` | 渲染界面成 PNG 后退出（不抢焦点，可后台跑） |
| `YLT_HOME=<目录>` | 覆盖数据根目录，测试时隔离用 |
| `YLT_NO_SERVER=1` | 不自动起本地服务器 / 不开房间（自检与无头构造时用） |
| `YLT_PARTICLE_DEMO=1` / `YLT_EFFECT_DEMO=1` | 特效演示模式：不用鼠标、按固定轨迹自动产生拖尾并周期性触发点击特效（截图验收「自动效果 + 点击效果」用，不设就是正常鼠标模式） |
| `YLT_PARTICLE_TRACE=<文件>` | 把粒子覆盖层收到的鼠标事件坐标、每 20 帧的发射点与存活数写进文件（排查「粒子从错误位置冒出来」用） |

| `YLT_SPUG_DEMO=1` | 「Spug 验证码测试」演示模式：界面塞入假的发送 / 验证状态（给截图冒烟用，**不联网、不写配置**） |
