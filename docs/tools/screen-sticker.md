# 📌 屏幕贴纸

> 工具 Id：`screen-sticker` ｜ 自检组：`screen-sticker` ｜ 配置：`Config\screen-sticker\config.json` ｜ 剪贴板位图存 `Data\screen-sticker\clipboard\`（不写 `Cache\`）

> 把任意图片贴到桌面上：**每张贴纸都是一个独立的透明小窗口**，可以自由拖动、滚轮缩放、调层级、
> 单独强制置顶；工具页负责选图（多选）/ 拖入图片 / 剪贴板贴图、最近使用和所有贴纸的统一管理。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **多选一次贴一批**：点「🖼 选择图片…」可以一次选多张（png / jpg / jpeg / bmp / gif / tif / tiff / ico / webp），
  每张图都会变成一个独立的桌面贴纸。
- **把图片（可多张、含 GIF）拖进页面即贴到桌面**：从资源管理器拖一张或多张图片到工具页任意位置松手，
  就逐张贴到桌面（GIF 拖进来照样完整播放）；夹带的文件夹 / 非图片 / 不存在的文件会被忽略，
  状态栏和日志会说明忽略了几个，不会误贴。
- **从剪贴板直接贴**：复制了一张图（截图 / 网页右键复制 / 聊天工具）或在资源管理器里复制了多张图片文件，
  点「📋 粘贴剪贴板」或按 **Ctrl+V** 就能贴到桌面，不用先存文件。
- **GIF 会完整播放**：GIF 贴纸不再只显示第一帧，会按文件自带的帧延时循环播放；可以设默认播放速度，
  也能对每张贴纸单独调速（右键菜单选倍速，或工具页列表里点倍速按钮循环切换）。
- **每张贴纸各自独立**：能拖动、能缩放，还能**单独**勾「强制置顶」——一张盖在所有窗口上面，另一张待在普通窗口层，互不影响。
- **随手缩放**：鼠标滚轮以**光标为中心**缩放（一格 1.12 倍）；鼠标移到贴纸上会出现右下角手柄，按住拖可以等比缩放。
  右键「重置缩放」一键回到默认宽度，「居中显示」放回主屏工作区正中。
- **调层级**：右键菜单或工具页列表里的 ↑ / ↓ 调整谁在上面、谁在下面；也可以直接「置于最上层 / 最下层」。
- **最近使用**：贴过的图片自动进「🕘 最近使用」列表，点一下缩略图就再贴一张；最多保留到设定的上限。
- **下次还认识**：程序关掉时贴纸会记住（位置 / 大小 / 置顶 / 层级），默认下次启动自动恢复；
  工具页「🖼 桌面上的贴纸」卡片可以逐个开关置顶、调层级、关闭，也能「全部关闭」。
- **完全本地**：不联网、不上传图片；贴纸窗口只是把本地图片显示在桌面上。

## 怎么用

1. **选图**：点顶部「🖼 选择图片…」，在文件对话框里可以按住 Ctrl / Shift **多选**。
   每张图会变成一个独立的贴纸窗口，默认放在主屏工作区中间；连续贴多张时按 28 像素层叠错开
   （12 张一循环，不会一路跑到屏幕外）。
2. **拖入贴图**：也可以直接从资源管理器把图片**拖进工具页**（可以多张一起拖），松手即贴——
   落点覆盖整个页面（空白处、卡片上都能放），和「选择图片…」走同一条批量贴图流程，
   同样会记住这次拖入的文件夹。拖入的内容里没有支持的图片时，只会在状态栏 / 日志提示，
   不会贴出任何东西。
3. **从剪贴板贴**：复制图片后，点顶部「📋 粘贴剪贴板」或按 **Ctrl+V**（焦点在工具页、不在输入框里时）。
   一次可以贴一张位图，或一次贴多张「复制的图片文件」（见下面「从剪贴板贴图」）。
4. **每张贴纸都是独立窗口**：可以单独拖动、单独缩放、单独置顶。切去别的工具页、把主窗口最小化，
   贴纸都继续留在桌面上；只有关闭程序（或手动关掉它们）才会消失。
5. **右键菜单**：在贴纸上点右键 → 强制置顶 / 层级上移下移置顶置底 / 重置缩放 / 居中显示 /
   打开图片所在文件夹 / 把主窗口叫到前面 / 关闭这张贴纸。
6. **鼠标操作**：**左键按住拖动**移动位置；**滚轮**以鼠标所在点为中心缩放；鼠标移到贴纸上出现
   **右下角手柄**，按住拖 = 等比缩放（左上角不动）。
7. **最近使用**：左侧「🕘 最近使用」里点任意一张缩略图 = 把这张图再贴一张到桌面。
   缩略图上右键还能「再贴一张 / 移除这条记录 / 在资源管理器中显示」；图片被移走 / 删除后记录会变灰。
8. **在工具页统一管理**：右侧「🖼 桌面上的贴纸」卡片列出当前每一张：勾「置顶」开关是否强制置顶，
   ↑ / ↓ 调层级，✕ 关闭这一张；底部还有「全部置顶 / 全部取消置顶 / 恢复上次贴纸 / 全部关闭」。
   顶部工具条也有「↩ 恢复上次贴纸」，把配置里保存、但当前没显示的贴纸放回桌面。

> **布局**：工具页上半区（最近使用 ‖ 桌面上的贴纸）与下面的设置区可以上下拖；
> 最近使用与贴纸管理之间可以左右拖。拖完自动记住，双击分隔条只恢复这一处，
> 全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 从剪贴板贴图

工具页顶部「📋 粘贴剪贴板」按钮，或按 **Ctrl+V**（焦点在工具页、不在输入框里时）会读一次剪贴板：

| 剪贴板里是什么 | 效果 |
| --- | --- |
| 截图 / 网页右键「复制图片」/ 聊天工具复制的一张图 | 贴一张。优先读 PNG 格式（保留透明通道），没有就按标准 DIB / BITMAP 读 |
| 在资源管理器里复制的**多张图片文件** | 一次贴多张（每张一个贴纸），直接用原文件，不复制、不重新压缩 |
| 文本 / 其它非图片内容 | 状态栏提示「剪贴板里没有图片」，不做任何事 |

- 剪贴板位图没有文件路径，所以会先编码成 PNG 存进 **`Data\screen-sticker\clipboard\`**，
  文件名是 `clipboard-<内容哈希前 16 位>.png`：**同一张图反复粘贴只存一份**，最近使用里也不会重复。
- 落盘后的剪贴板图片和普通选图完全一样：进「最近使用」、可重启恢复、可单独置顶 / 调层级 / 关闭。
- 剪贴板被别的程序占用时会自动重试 5 次（每次间隔 40ms），仍失败就提示稍后再试。
- 文件对话框里选的原图与「复制的图片文件」不会被复制进 Data，只有**剪贴板位图**需要落盘。

> Windows 剪贴板同一时刻只有**当前一项**：想一次贴多张，请在资源管理器里多选图片后复制；
> Win+V 剪贴板历史里选一项后，App 读到的也只是选中的那一项。

## GIF 动画与播放速度

GIF 贴纸会按文件里每帧自带的延时循环播放（帧延时 0 / 10ms 这种按浏览器的惯例用 100ms，最长 10 秒）。

| 想改速度 | 怎么操作 |
| --- | --- |
| **以后新贴的 GIF 默认速度** | 工具页「⚙ 设置 → GIF 默认播放速度」滑块（0.25× ~ 3×，1× = 文件自带速度） |
| **某一张 GIF 单独改** | 右键贴纸 →「GIF 播放速度」→ 选 0.25× / 0.5× / 0.75× / 1× / 1.25× / 1.5× / 2× / 3×；也可以选「用设置里的默认速度」 |
| **快速换档** | 工具页「🖼 桌面上的贴纸」列表里，GIF 行会多一个倍速按钮（例如 `1.5×`），点一下换到下一档，循环 |

- 速度只改变「换帧间隔」= 原始帧延时 ÷ 速度，**不会改变贴纸大小 / 层级 / 位置**；拖动、缩放、置顶都照常。
- 每张贴纸的速度单独保存在配置里，重启恢复后仍然生效；静态图片不受影响。
- 帧数太多 / 内存占用过大的 GIF 会退回「静态第一帧显示」并在日志里提示（避免一个贴纸吃掉几百 MB 内存）；
  单帧宽度超过 1280 的动画会先等比缩小再缓存。

## 贴纸窗口操作

### 右键菜单

| 菜单项 | 作用 |
| --- | --- |
| **强制置顶（覆盖其它窗口）** | 勾上 = 这张贴纸始终盖在普通窗口上面；再点一次取消。已置顶的贴纸永远在所有非置顶窗口之上（Windows 窗口带规则） |
| **GIF 播放速度** | 只对会动的 GIF 有效；子菜单里选 0.25× ~ 3×，或「用设置里的默认速度」。静态图这一项是灰的 |
| **层级：上移一层 / 下移一层** | 和别的贴纸交换一层（最上层 / 最下层时无变化） |
| **层级：置于最上层 / 置于最下层** | 一步放到所有贴纸的最上面 / 最下面 |
| **重置缩放（默认宽度）** | 宽度恢复成设置里的「新贴纸默认宽度」，**中心点不动** |
| **居中显示** | 移到主屏工作区正中（大小不变） |
| **打开图片所在文件夹** | 在资源管理器里选中这张图片 |
| **把主窗口叫到前面（管理贴纸）** | 激活主窗口；贴纸管理页在侧边栏「桌面 → 屏幕贴纸」 |
| **关闭这张贴纸** | 关掉这张贴纸，并**从配置里删掉它的记录**（下次启动不会恢复；图片文件不受影响） |

### 鼠标

| 操作 | 效果 |
| --- | --- |
| **左键按住拖动** | 移动贴纸；鼠标下面的那一点始终跟着鼠标 |
| **滚轮** | 以鼠标所在位置为不动点缩放，一格 1.12 倍；宽度范围 48 ~ 2400（到顶 / 到底就不再变） |
| **右下角手柄拖动** | 等比缩放，左上角固定；鼠标移出贴纸时手柄自动隐藏 |
| **单击（激活贴纸）** | 它会被抬到其它普通窗口上面，工具页列表里的层级也会同步到最上层 |
| **右键** | 打开上面的菜单 |

> 贴纸的窗口大小就是图片显示大小，**图片透明像素所在的区域也算窗口**，所以会挡住那一块的鼠标点击
> （见「已知限制」）。

## 设置说明

设置区在工具页下方「⚙ 设置」，改一下立即生效并自动保存，**没有保存按钮**。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| **启动程序时自动恢复上次的贴纸** | 开 | 程序启动时把上次保存的贴纸放回桌面；关掉只是不自动恢复，记录还在，随时可以点「恢复上次贴纸」 |
| **新贴纸默认置顶** | 关 | 打开后，以后新贴的图片默认「强制置顶」；已经贴好的贴纸不受影响 |
| **新贴纸默认宽度** | 320 | 单位 DIP（和窗口宽高同一套坐标），范围 48 ~ 2400；图片特别高时还会按屏幕高度的 90% 再缩小一次 |
| **GIF 默认播放速度** | 1× | 0.25× ~ 3×；只影响以后新贴的 GIF，已经贴上的在贴纸右键菜单 / 列表里单独调 |
| **最近使用上限** | 50 | 0 ~ 100；**0 = 不记录并清空列表**；调小会立刻裁掉最旧的记录 |
| **恢复默认设置** | — | 只把上面这些偏好恢复默认；**不动桌面上的贴纸和最近使用记录**（那是用户当下的成果） |
| **打开配置文件夹** | — | 在资源管理器里打开 `Config\screen-sticker\` |

## 数据与状态

- **配置**：`Config\screen-sticker\config.json`（相对 **exe 所在目录**），保存：
  - 偏好设置（启动自动恢复 / 默认置顶 / 默认宽度 / GIF 默认速度 / 最近上限 / 上次选图文件夹）；
  - **最近使用**记录（图片路径 + 时间，新的在前，同一路径只留一条）；
  - **贴纸记录**（每张的图片路径、位置、大小、是否置顶、GIF 播放速度；列表顺序就是层级，下标 0 最靠下）。
- 改任何设置 / 拖动缩放贴纸都会**自动保存**（粘贴 / 拖窗口时做了防抖，不会每动一下写一次盘）。
- **关程序时贴纸会记住**：窗口关闭但记录保留，下次启动按「启动时自动恢复」放回桌面。
  右键「关闭这张贴纸」和工具页的 ✕ 会删掉这一张的记录；「全部关闭」会先确认，然后关掉全部贴纸并**清空记录**。
- 「最近使用」只保存**图片路径**，不复制图片文件：图片被移动 / 删除后，那条记录会变灰、
  启动恢复时也会自动清理找不到的贴纸记录。
- **剪贴板位图**会落到 `Data\screen-sticker\clipboard\` 下（按内容哈希命名、自动去重）——这是贴纸要用的
  图片本体，所以放 Data 不放 Cache；「清理缓存」不会删它，否则桌面上的贴纸会变空白。
- 本工具**不写 `Cache\`**；如果最近使用里有记录，「主页设置 → 清理缓存」会多出
  「最近使用的图片」一项，只清最近列表，不动桌面贴纸、设置和已经落盘的剪贴板图片。

## 已知限制

- **独占全屏游戏 / 全屏应用盖不住**：普通窗口无法显示在独占全屏（DirectX 独占）的上面；
  无边框全屏 / 窗口化全屏一般可以，但也取决于游戏。
- **透明像素仍然占窗口区域**：贴纸窗口是矩形的，图片透明的地方也会挡住鼠标点击。想点下面的东西：
  把贴纸移开、取消置顶、缩小它，或暂时关掉这张贴纸。
- **格式支持取决于系统 WIC 解码器**：png / jpg / bmp / gif / tif / ico / webp 是按后缀允许的，
  真正能不能解码由 Windows 自带的 WIC 决定（新版 Windows 一般都能解 webp）。**GIF 会完整循环播放**；
  但 APNG / 动图 WebP 目前只显示第一帧；帧数过多或内存占用过大的 GIF 会退回静态第一帧（日志里会提示）。
- **GIF 播放会占用一点 CPU**：每张贴纸有自己的帧定时器，很多张同时动时 CPU / 内存会上升；
  不需要动的贴纸关掉即可。帧尺寸不一致的极端优化 GIF 会按静态第一帧显示（避免看起来扭曲）。
- **多显示器 / 分辨率变化会拉回可见区域**：拔显示器、改分辨率后，保存的坐标可能落在屏幕外；
  恢复时会被夹回可见区域（至少留 48 × 48 可抓），位置会变但不会「丢」。
- **每张贴纸是一个独立透明窗口**：贴很多张会占内存 / 图形资源（几十张以内一般没问题）；
  用完建议关掉不需要的贴纸。
- **强制置顶会盖住所有普通窗口**（包括本程序自己的界面）；不想挡操作就取消置顶或关闭这张贴纸。
- 最近使用记录里**不保存图片副本**，删掉 / 移走原图后就贴不回来了（剪贴板位图例外：它本来就存在
  `Data\screen-sticker\clipboard\` 里）。
- **剪贴板只读「当前一项」**：没法一次读 Win+V 历史里的多张；一次贴多张请复制图片文件。
  个别程序复制图片时只给 EMF / 元文件格式（WPF 读不了位图），会提示剪贴板里没有图片。

## 开发调试

截图 / 验收用的环境变量（都在启动 exe 前设置）：

| 环境变量 | 作用 |
| --- | --- |
| `YLT_STICKER_DEMO=<图片路径>` | 启动后自动贴这一张（方便截图 / 验收），并且**不恢复**上次保存的旧贴纸 |
| `YLT_STICKER_CLIPBOARD=1` | 启动后直接读一次剪贴板并贴图（验收剪贴板功能；和 `YLT_STICKER_SHOT` 一起用可截图后退出） |
| `YLT_STICKER_SHOT=<png 路径>` | 第一张贴纸窗口出现约 0.8 秒后，把窗口画面（透明底垫深色）保存成 PNG，然后退出程序 |

```powershell
$env:YLT_STICKER_DEMO = "D:\pics\demo.png"
$env:YLT_STICKER_SHOT = "shots\sticker.png"
Start-Process .\bin\Debug\net9.0-windows10.0.19041.0\YuLiangTookit.exe -Wait
Remove-Item Env:YLT_STICKER_DEMO, Env:YLT_STICKER_SHOT
```

## 自检

`screen-sticker` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/ScreenStickerChecks.cs`）：**120 条纯逻辑断言**——
工具元数据、配置默认值与夹取、最近使用（去重 / 排序 / 上限裁剪 / 清空 / 无效路径）、
贴纸记录与「恢复默认设置」的边界、贴纸几何（宽度比例 / 放进工作区 / 层叠落点 / 恢复位置 /
以鼠标为锚点缩放 / 滚轮倍率 / 角点等比缩放 / 重置宽度 / 夹回屏幕，含负坐标多显示器）、
层级顺序、图片格式识别与 1×1 PNG 解码、剪贴板文件过滤 / 内容哈希文件名 / PNG 落盘去重、
拖入判定（存在图片 / 非图片 / 文件夹 / 不存在 / 空路径）与「过滤后为空」的状态提示、
GIF 动画识别（真写 2 帧 GIF 再加载）/ 单帧 GIF 按静态 / 帧延时归一 / 速度夹取与倍速循环 / 帧预算守卫、配置 JSON 持久化。
**不创建贴纸窗口、不渲染、不碰真实 Data/Config、不读写系统剪贴板**（位图解码 / 编码 / GIF 编码放在独立 STA 线程里跑；
拖入判定只构造 ViewModel 校验过滤，不调用 `AddSticker`）。
