# 🐟 Live2D 桌宠

> 工具 Id：`live2d` ｜ 自检组：`live2d` ｜ 配置：`Config\live2d\config.json` ｜ 数据：`Data\live2d\`

内置一套 Live2D Cubism 模型（`大肥鱼`，随程序一起发布），既能当**模型测试台**逐项调试
参数 / 部件 / 动作 / 表情 / 物理 / 眼睛跟随，也能把模型放成**桌面宠物**：透明置顶、
可拖动、滚轮缩放、右键菜单、眼睛跟着鼠标看、点透明区域能穿透；还支持**摄像头面部动捕**
（转头 / 眨眼 / 张嘴）和**身体晃动测试**（看物理链带动头发 / 裙子 / 尾巴）。

渲染由本程序自己完成（官方 Cubism Core 原生库负责模型变形 + 手写 C# 软件光栅器负责画像素），
**不联网、不上传、不需要显卡、不依赖 WebView**；模型文件全部在本地，动捕用 Windows 自带摄像头与
FaceAnalysis API（不录像、不存画面）。

## 能做什么

- **模型测试台**：实时渲染内置模型，509 个参数、147 个部件、8 个动作、23 个表情逐项可调，
  改一下立刻在预览里看到效果；物理 / 眼睛跟随 / 调试视图都有开关和滑杆。
- **😛 面部测试**：眼睛位置 / 开闭、嘴、**舌头三参数**（伸舌头 / 上下 / 宽窄）直接拧 + 常用表情预设，
  适合调表情、截图、检查网格；手动调的脸不会被关掉的功能每帧重置。
- **鼠标跟随可调**：除了平滑 / 头眼身幅度，还有**横向灵敏度 / 抬头灵敏度 / 低头灵敏度 / 纵向偏移**，
  治「跟得不够 / 向下看跟不到」。
- **桌面宠物**：把模型放成透明置顶的小窗，鼠标按住拖动、滚轮缩放、右键菜单改设置；
  眼睛 / 头 / 身体跟着鼠标转，待机时眨眼 / 呼吸 / 头发和尾巴按物理摆，双击还会随机来个表情或动作。
- **摄像头面部动捕**（可选，默认关）：用电脑摄像头 + Windows 自带人脸检测驱动角色**转头 / 眨眼 / 张嘴**，
  头部转动会温和带动一点身体；有脸时动捕接管头部（鼠标眼控自动让位），没脸时自动回落，不僵住。
- **身体晃动测试**：让身体主轴 / 物理输入做正弦晃动，实时曲线直接展示
  「身体晃 → 角度参数 → physics3 钟摆物理 → 头发 / 裙子 / 尾巴 / 飘带跟摆」这条链。
- **整身轻倾（常态）**：模型平时会以脚为支点整身左右轻倾（日常 0.6°/4 秒），**有音乐时加快到约 2.6 秒、
  幅度略大**；渲染层整体倾斜、不扭模型参数，可在「物理与眼睛跟随」卡关掉。
- **🎵 音乐跟唱 / 律动**（可选，默认关）：用 Windows 回环采集**系统正在播放的声音**（不是麦克风），
  自动识别「带歌词 / 纯音乐」——带歌词时跟唱嘴型，纯音乐不跟唱；两种都会整身轻倾（有歌加快）、跟着点头。
  不录音、不存音频、不联网。
- **🖐 手臂 & 姿势**：左右手臂 / 肩膀参数直接拖；**8 个手势**（抱胸致意 / 竖起食指 / 拿起狗尾草 /
  举手打招呼 / 比心 / 叉腰 / 抱头 / 放下手）、**6 个多步表演**、**4 种舞蹈**（可调速度）、随机动作、
  停止所有演示；待机时会随机来个小动作（更生动）。
- **💬 说话 / 轻对话**：微软 Edge 在线神经网络语音（默认「晓伊 · 少女音」软妹音 / 断网自动回退本地 TTS），
  嘴型跟发音、头顶聊天气泡、**声音 / 口型 / 气泡同步**；可打字轻对话（离线关键词匹配）、预设台词、
  空闲随机自言自语；在线只发送文字，不保存音频、不申请麦克风。
- **自定义模型**：支持 Cubism 3 ~ 5 的 `.moc3` 模型文件夹，选一下文件夹就能换成你自己的模型
  （放法见 [自定义模型](#自定义模型)）。
- **完全本地**（动作 / 模型 / 音乐分析都本地；仅「在线语音」需要联网发送文字；）**不读账号、不上传模型、不录像**；
  关掉程序桌宠就消失。

## 快速上手

1. 主页搜「Live2D」或进「桌面」分类，打开「🐟 Live2D 桌宠」；
2. 第一次打开会**自动加载内置模型**（5 张纹理，最大 8192×8192，要解码 + 降采样，约 1~3 秒，加载期间有进度条）；
3. 预览区出现角色后就可以拖参数 / 播动作 / 点表情；
4. 点「桌面宠物」卡里的「**显示桌宠**」把角色放到屏幕右下角；再点一次隐藏；
5. 桌宠在桌面时：**鼠标在屏幕任意位置移动，角色都会转头看鼠标**（全屏跟随，不需要把鼠标移到桌宠窗口上）；
   按住角色拖动位置，滚轮缩放大小；
6. 想用摄像头：打开下排「📷 摄像头面部动捕」卡里的**启用摄像头动捕**开关（首次会弹 Windows 摄像头权限）；
   想验证物理：打开「🌊 身体晃动测试」卡里的**开启身体晃动**，或点「摇一摇（3 秒）」直接看效果；
7. 想手动捏表情 / 检查五官网格：用「😛 面部测试」卡（先关掉动捕 / 眼睛跟随 / 自动眨眼、停动作、清表情，
   手动值才不会被每帧覆盖）；
8. 想听歌跟唱：放一首歌，勾选「🎵 音乐跟唱 · 律动」卡里的**启用音乐跟唱 / 律动**（不用麦克风权限）；
9. 想让角色动起来：到「🖐 手臂 & 姿势」卡点手势 / 表演 / 「跳个舞」，或点「🎲 随机动作」；
10. 想听她说话：到「💬 说话 / 轻对话」卡点预设台词或输入一句 →「说出来」（默认在线软妹音，断网会自动回退本地）。

> 整页分成「预览 + 右侧模型信息 / 参数 / 部件」「下排：动作 / 表情 / 物理与眼睛跟随 / 桌面宠物」
> 「📷 摄像头面部动捕」「🌊 身体晃动测试」「😛 面部测试」「🎵 音乐跟唱 · 律动」「🖐 手臂 & 姿势」
> 「💬 说话 / 轻对话」「底部日志」几块，**区块之间都能拖拽调大小**（双击分隔条恢复这一处），布局会被记住。

## 模型测试台（各区块）

### 顶部标题与预览工具条

- 页面右上角是 **显示桌宠 / 重新加载模型** 两个按钮；预览工具条上依次是：**适应窗口**（恢复默认缩放 / 位置）、
  **棋盘格**（透明背景显示棋盘格，关掉就是纯色）、**统计**（左下角 FPS / 网格数 / 三角形数 / 耗时）、
  **帧率**上限、**渲染倍率**；
- 预览区操作：**滚轮缩放**、**左键拖动平移**、鼠标移动 = 眼睛跟随、**单击模型 = 命中的网格信息**
  （命中后预览下方出现提示，可用「清除高亮」取消）；
- 模型按「整张画布等比缩放」显示（适应窗口），窗口怎么拉伸都不会变形。

### 模型信息卡

- 显示当前模型名 / 路径、画布尺寸、参数 / 部件 / 网格（含当前可见数）/ 纹理 / 三角形数量、
  moc3 版本与 Cubism Core 版本、物理配置数量、加载耗时；
- 按钮：**重新加载**（改过模型文件后点）、**选择文件夹…**（切到自定义模型）、**用内置模型**（切回内置）、
  **打开模型目录**；
- **纹理上限**下拉（2048 / 4096）：改完点「重新加载」生效。

### 参数区

- 列出模型**全部参数**（内置模型 509 个），按 cdi3 里的中文分组显示
  （开关 / 身体轴 / 控制器 / 眼睛 / 嘴 / 前发物理 / 侧发物理 / 后发物理 / 手臂 / 裙子上衣 …），
  分组可以折叠；
- 每个参数一条滑杆：范围就是模型自己声明的最小值 ~ 最大值，右侧显示当前值；
- 拖滑杆立刻写入模型；**「一键全部重置」**把全部参数恢复默认（动作 / 表情也一起停掉）；
- 搜索框可以按参数 Id 或中文名过滤（例如搜 `Angle` / `角度`）；
- 被动作 / 表情 / 物理 / 眼睛跟随接管的参数会跟着被驱动（这时手动拖会被覆盖，想自己调请先停动作、
  清表情、关物理和眼睛跟随）。

### 部件区

- 列出模型**全部部件**（内置模型 147 个），显示 cdi3 里的中文名，可折叠；
- 每个部件一条 0 ~ 100% 的不透明度滑杆：拉到 0 就整块隐藏（例如单独看「头」「裙子」）；
- **「全部显示」**把所有部件不透明度恢复 1；搜索框同上，按 Id / 中文名过滤；
- 部件不透明度只在本次会话内有效，重开工具页会恢复默认。

### 动作区

- 列出模型文件夹 `Animation\` 下的全部 `.motion3.json`（内置模型 8 个：IDLE、脱捕、举手相关动作 …）；
- 点「▶」**立即播放**：动作会接管它涉及的参数（做举手动作时手会抬起来），下方有**进度条**；
- 点播默认**不循环**（播完淡出、回到待机动作）；每条动作可以单独勾**循环**；
- 顶部有**停止**按钮和**淡入淡出**时长（秒，控制动作切换的淡入淡出）；
- **待机动作**下拉：待机动画开着时，没在播别的动作就会循环播这个（默认自动选 IDLE）；
- 想安静地手动调参数时，先「停止」当前动作。

### 表情区

- 列出模型文件夹 `Exp3\` 下的全部 `.exp3.json`（内置模型 23 个：黑脸、落泪、圈圈眼、爱心眼、
  兔牙、脸红、眼镜、裙子切换 …）；
- 点一个表情**施加到模型上**（带淡入，时长可调）：表情只改它声明的那几个参数，其它参数不受影响；
- **同一时间只有一个表情生效**（Cubism 官方的表达式语义）：点另一个表情会**交叉淡入淡出**切换过去，
  旧表情没被新表情引用的参数会淡回默认值；
- 再点一次当前生效的表情 = 取消它（回默认）；**「全部清除」**一次清掉；
- 表情在动作之后生效：动作驱动参数的同时，表情改的参数也会生效。

### 物理与眼睛跟随区

- **物理演算**总开关：关掉后头发 / 尾巴 / 衣服不再摆动（方便对比和截图）；
- **物理强度**滑杆 0 ~ 1：0 = 不摆，1 = 模型作者调好的默认强度；
- 物理靠模型文件夹里的 `.physics3.json` 驱动（内置模型 131 组物理、299 路输入、292 路输出）；
  模型没带物理文件时这一区没有效果；
- **待机动画**（呼吸 / 轻微摇摆 + 待机动作）、**自动眨眼**两个开关；
- **眼睛跟随鼠标**开关 + **平滑度**（0.05 ~ 1，越大越跟手）：预览区跟随光标；桌宠是**跟随全屏鼠标**
  （鼠标在屏幕任意位置都会看过去，不需要停在桌宠窗口上）；
- **头转幅度 / 眼球幅度 / 身体幅度**三个滑杆（0 ~ 1.5），分别调「头转多少」「眼珠转多少」「身体跟着侧多少」；
- **灵敏度（手感）四个滑杆**（本轮新增，默认 1/1/1/0 = 原来手感）：
  | 滑杆 | 范围 | 作用 |
  | --- | --- | --- |
  | **横向灵敏度** | 0.3 ~ 3 | 鼠标左右离中心多近就让头 / 眼转到最大角度；调大更跟手 |
  | **抬头灵敏度** | 0.3 ~ 3 | 鼠标在角色**上方**时的跟随幅度 |
  | **低头灵敏度** | 0.3 ~ 3 | 鼠标在角色**下方**时的跟随幅度；**觉得「向下看跟不到」就先调大这个** |
  | **纵向偏移** | -0.5 ~ 0.5 | 跟随的纵向中性点整体上下挪一点（模型上下不对称 / 总像在低头时用） |
- **推荐调法**：觉得幅度小 → 先加大「头转幅度」和「横向灵敏度」；觉得向下看跟不到 → 加大「低头灵敏度」
  （还不行就把「纵向偏移」往负方向调一点）；觉得太灵敏 / 抖 → 加「平滑度」、降灵敏度；
- **全身轻晃（以脚为轴）** 开关（本轮新增，默认开）：模型平时以脚底为支点整身左右轻倾（日常 0.6°/4 秒，
  有音乐时加快到约 2.6 秒）；关掉会平滑归零，详情见「🌊 身体晃动测试」里的「整身轻倾」说明；
- 这套设置**桌宠共用**（桌宠的眼睛跟随也读它）。

### 😛 面部测试

> 一个「直接拧脸」的调试卡：眼睛 / 嘴 / **舌头**三组参数各有滑杆 + 一排常用表情**预设按钮**。
> 它不经过动作 / 表情 / 物理，直接把值写进 Cubism 模型参数（滑杆范围 = 参数自身的 Min/Max），
> 所见即所得，适合调表情、截图、检查五官网格。位置在 🌊 身体晃动卡下面（再下面是 🎵 音乐跟唱卡）。

- **👁 眼睛（5 个）**：`ParamEyeBallX / ParamEyeBallY`（眼球左右 / 上下）、
  `ParamEyeLOpen / ParamEyeROpen`（左右眼开闭，默认 1 = 睁开，0 = 闭眼）、`EyeSmile`（眯眼笑）；
- **👄 嘴（13 个）**：`ParamMouthOpenY`（张嘴 0~1）、`ParamMouthForm`（嘴形 -1~1）、`JawOpen`（下巴张开）、
  `Mouthpucker` / `MouthFunnel` / `MouthPuckerWiden`（撅嘴 / 漏斗嘴 / 嘴宽窄）、
  `MouthPressLipOpen` / `MouthRollUpper` / `MouthRollLower`（压唇 / 上唇卷 / 下唇卷）、
  `MouthSmile_L / MouthSmile_R`（左右嘴角上扬）、`PoutOffsetXL / PoutOffsetXR`（努嘴位移）；
- **👅 舌头（3 个，重点）**：`TongueOut`（伸舌头 0~1）、`ParamTongueUpDown`（舌头上下）、
  `ParamTongueWidth`（舌头宽窄）；
- **预设按钮（7 个）**：
  | 按钮 | 效果 |
  | --- | --- |
  | 😛 吐舌头 | `TongueOut=1` + 嘴张开 0.7 + 下巴 0.4 + 嘴形 0.5（重点验证舌头参数） |
  | 😲 张嘴 | `ParamMouthOpenY=1` + `JawOpen=1` |
  | 😗 撅嘴 | `Mouthpucker=1` + 嘴形 0.3 |
  | 😊 微笑 | 左右嘴角上扬 + `EyeSmile=1` + 嘴形 1 |
  | 😉 眨眼 | 左眼 0.05 / 右眼 1（单眼眨） |
  | 🙄 翻白眼 | 眼球上移 `ParamEyeBallY=1` + 双眼半闭 |
  | 😐 重置面部 | 把这一卡所有参数恢复默认值 |
- 每个滑杆双击可回默认值；顶部状态文本会显示「可调参数 N 个（眼睛 X / 嘴 Y / 舌头 Z）」和上一次预设结果；
- **什么时候会被接管**：这些值会被每帧驱动它们的系统覆盖——动捕开启且检测到脸（眨眼 / 张嘴 / 眼珠）、
  表情生效（嘴形 / 眼睛表情参数）、动作曲线涉及这些参数、待机自动眨眼、鼠标眼控开启时的眼珠方向。
  想安静调脸：先关掉「动捕」「眼睛跟随」「自动眨眼」、停掉动作、清除表情；**关掉这些功能后，它们原本每帧
  复位的参数也不会再被重置**，手调的值会一直保留（直到你打开对应功能 / 点「一键全部重置」/「重置面部」）；
- 舌头没伸出来时：先确认动捕 / 眼控 / 表情没在接管（或直接点「😛 吐舌头」预设看效果）。

### 🎵 音乐跟唱 · 律动

> 采集**系统正在播放的声音**（WASAPI 回环 = 扬声器 / 耳机混音，**不是麦克风**），实时分析后让模型
> **跟着唱（嘴型）+ 整身以脚为支点轻倾（有歌时加快）**；自动识别「带歌词」还是「纯音乐」：
> 纯音乐不跟唱、只整身轻倾。不录音、不存音频、不联网。**默认关闭**。位置在「😛 面部测试」卡下面、日志上面。

**怎么开**

1. 勾选卡片右上角「**启用音乐跟唱 / 律动**」（默认关；打开后开始采集系统声音，不申请麦克风）；
2. 用任意播放器 / 浏览器放歌 → 右侧状态行显示「静音 / 识别中 / 纯音乐 / 带歌词」+ 置信度；
3. 桌宠也能用：右键桌宠 →「**音乐跟唱：开 / 关**」，状态与测试页共用配置；
4. 不用时取消勾选（会立刻释放音频回环设备）；关掉工具页 / 隐藏桌宠时也会停止采集。

**卡片上有什么**

- 状态行 / 置信度 / 媒体信息（歌名 · 歌手 · 播放器，来自 Windows SMTC；播放器不支持 SMTC 时显示 —）；
- 实时条：响度 RMS、人声分数 VocalScore、置信度 Confidence、节拍强度 BeatStrength、中心声道占比 CenterRatio，
  另有音高 / BPM 文本（每 100ms 刷新；没在放音乐时显示静音，采集本身仍在正常运行）；
- **身体倾斜实时值**：卡片里显示当前「身体倾斜 +0.62°」——这就是预览 / 桌宠整身轻倾的角度；
- 「**识别模式**」：`自动识别`（推荐）/ `强制跟唱`（跟唱 + 整身轻倾）/ `强制纯音乐`（只整身轻倾）——
  自动识别不准时手动指定；
- 「**识别灵敏度**」0.3 ~ 3：越大越容易判成「带歌词」（识别不出来调大；总误判成带歌词就调小）；
- 「**跟唱嘴型幅度**」「**身体摇晃幅度**」两个滑杆（0 ~ 1.5；后者只作用于「整身轻倾」的倾斜角度）；
- 「**摇晃**」「**点头**」两个开关：整身轻倾是否跟音乐加快 / 轻轻点头
  （动捕或鼠标眼控正在用头部时不抢头部参数）。

**整身轻倾（本轮变化）**

- 模型会**以脚底为支点整身左右轻倾**（不是扭腰 / 不是扭身体参数）：**日常 0.6°、4 秒一个来回**；
- **有音乐在播且「摇晃」开着时**：倾斜**加快到约 2.6 秒一个来回**、幅度变成 **1.0° × 身体摇晃幅度**
  （所以调「身体摇晃幅度」能调大幅度）；
- 这是渲染层的整体倾斜（预览和桌宠都适用），不会写坏模型参数；「物理与眼睛跟随」卡里的
  「**全身轻晃（以脚为轴）**」开关可以**关掉整身轻倾**（关掉后角度平滑归零，不跳变）。

**原理（不是音量阈值）**

- **采集**：WASAPI **回环**（loopback）抓系统默认播放设备的混音（48k 立体声浮点；立体声中心声道 = 主唱位置）；
  分析在内存里做，**不申请麦克风、不录像、不写任何音频文件**；
- **分析**（本轮按真实混音重新调过，不再依赖单帧清晰基频）：重采样到 16k → 1024 点 Hann 窗 FFT
  （hop 256，≈62.5 帧/秒），然后：
  - **人声显著度**：mid 声道带通 200~3500Hz 的**带限自相关周期显著度**（人声有准周期、鼓点/噪声没有）、
    **HPS 谐波显著度**（谐波梳齿）、谱平坦度 / **共振峰**打分（频谱平滑后数宽峰）、
    **3~7Hz 包络调制**（念字 / 咬字的起伏）、**voice-band mid/side 比**（主唱在中间，乐器 / 和声偏两侧）——
    多特征**加权融合 + 自适应分位 + 时序滞后**，比单帧 YIN 清晰度更适合真实混音；
  - **YIN** 现在只用来**输出音高显示**（不再当「是不是人声」的硬门槛）；
  - 人声频带 300~3400Hz 的**包络 → 唇形张开度**（attack 15ms / release 90ms、按最近 10 秒 p90 归一化），
    谱质心 → 嘴型明暗；
  - **音节调制**（4~8Hz 包络起伏）+ **颤音深度**辅助判断「像不像在唱」；
  - 分类带**时序滞后**（带歌词持续 1.2s / 纯音乐持续 2.5s 才确认，避免闪断）——**不是音量阈值**，
    音量只用于判断「有没有在播」和唇形包络；
  - **节拍**：起音（时域电平差）onset → 自相关估 BPM（60~180）→ 相位 PLL 校正 → 驱动点头 / 决定轻倾快慢；
    估不出可靠 BPM 时（钢琴曲 / 纯人声 / 环境音乐）相位退化成 0.5Hz 舒缓摆动（有强度保底），
    同时整身轻倾仍按「有音乐」的节奏轻倾；
- **延迟**：采集缓冲 100ms + 分析窗 64ms + 确认滞后 1.2~2.5s（状态切换是「逐渐确认」，不是瞬时的）；
- **带歌词 / 纯音乐都会整身轻倾**：区别只在嘴型——带歌词跟唱（嘴动），纯音乐不跟唱（嘴不动）。

**怎么调**

| 现象 | 调法 |
| --- | --- |
| 不跟唱 / 嘴不动 | 看状态是不是「带歌词」；识别不出来先用「强制跟唱」 |
| 嘴型太大 / 太小 | 调「跟唱嘴型幅度」 |
| 整身轻倾太夸张 / 太轻 | 调「身体摇晃幅度」（只影响倾斜角度）或关「摇晃」；想彻底不倾就在「物理与眼睛跟随」卡关「全身轻晃（以脚为轴）」 |
| 点头太频繁 / 不想点头 | 关「点头」 |
| 钢琴曲 / 纯人声时节奏不对 | 这种歌估不出 BPM，点头 / 轻倾的节拍会退化成 0.5Hz 舒缓摆动（整身轻倾仍会加快到约 2.6s）；想更明显调大「身体摇晃幅度」 |
| 纯音乐被误判成带歌词 | 用「强制纯音乐」或把灵敏度调小 |
| 和「🌊 身体晃动测试」一起开 | 可以共存：手动晃动测试是**扭身体参数**（看物理链），音乐 / 整身轻倾是**渲染层整体倾斜**，互不覆盖 |

**限制 / 排查**

- **独占模式**播放器（ASIO / WASAPI 独占）的声音可能绕过系统混音 → 回环抓不到 → 状态一直静音：换共享模式播放；
- 切换播放设备（拔耳机 / 切蓝牙）会自动重启采集，失败时卡片里显示原因；
- **SMTC 不可用 / 播放器不支持** → 只是看不到歌名歌手，不影响跟唱功能；
- 纯器乐、人声采样、说唱、Live 版等可能误判（自动识别只是启发式）→ 用强制模式；
- **隐私**：不申请麦克风、不读麦克风、不录音、不存音频；debug 自检日志（`YLT_LIVE2D_MUSIC_SELFTEST`）
  会记 SMTC 的媒体标题 / 文件名（在 exe 旁边的 `Data\live2d\` 下，**排错用，别公开贴出来**）；
- 系统静音 / 音量极低时等于没声音（回环抓到的是静音帧）。

### 🖐 手臂 & 姿势

> 位置：音乐跟唱卡下面、「💬 说话 / 轻对话」卡上面。左边是手臂 / 肩膀参数滑杆，右边是手势 / 表演 / 舞蹈 /
> 待机灵动。所有演示都走运行时动作系统，会覆盖手动拖的手臂参数；想手动调先点「⏹ 停止所有演示」。

**手动摆姿势**

- **左臂 / 右臂 / 肩膀**三组滑杆（范围取模型参数自身 Min/Max）：从参数列表里挑出的常用关节
  （`LArm / LForearm / LWrist / LHand / LHand2`、`RArm / …`、`ShoulderX / Y / Z / Yy` 等）；
- 动作播放时会覆盖手动值（动作 / 手势 / 表演 / 舞蹈都在写这些关节）；想安静手动摆就先停止所有演示。

**手势（点一下就播，8 个）**

- **作者原生手势**（用模型作者做的进入 / 退出动作，姿势最自然）：**抱胸致意 / 竖起食指 / 拿起狗尾草**——
  播进入动作后保持姿势（自动接住手臂，不会掉回 IDLE），停止时播作者退出动作回默认；
- **参数姿势**：**举手打招呼 / 比心 / 叉腰 / 抱头 / 放下手**——直接摆手臂参数（0.35 秒平滑淡入），
  停止 0.25 秒淡出回默认；想微调幅度可以先播姿势再拖左边滑杆（停止演示前有效）。

**表演（多步小剧情，6 个）**

`开心挥手` / `俏皮比心` / `好奇→思考→恍然大悟` / `骄傲展示` / `害羞低头` / `晚安道别`——
时间线里组合了手势、看、点头、说话口型等动作，像一小段剧情（9~15 秒）；播完自动结束回默认，
点「⏹ 停止所有演示」可随时停。

**舞蹈（4 模式 + 速度）**

- 模式：**轻快摇摆 / 挥手舞 / 摇摆转圈 / 酷炫抖肩**；点「跳个舞」开始、「停」结束（0.25 秒淡出）；
- **舞蹈速度** 0.5 ~ 2.0 倍（滑杆）：舞蹈是程序化算出来的（不是模型里的动作文件），任意速度都顺、
  也不需要额外资源；
- 舞蹈会写身体 / 手臂 / 头部参数，和物理叠加（头发 / 裙子照样甩）。

**待机灵动**

- 「**待机随机小动作（更生动）**」开关（默认开）：待机时每隔一段时间随机做个小动作（手势或表演）；
- 「**间隔（秒）**」8 ~ 60（默认 22；实际每次在 0.55~1.6 倍之间随机，所以不会太规律）；
- 说话 / 放音乐 / 正在播用户动作 / 跳舞 / 表演时**不抢**（等条件空闲再触发）。

**按钮与状态**

- **🎲 随机动作**：随机播一个手势或表演；
- **⏹ 停止所有演示**：停掉手势 / 表演 / 舞蹈 / 当前动作，把身体交还手动参数与物理；
- 卡片头部会显示当前状态（正在播什么 / 待机灵动的倒计时）。

### 📷 摄像头面部动捕

> 用电脑摄像头 + **Windows 自带**的人脸检测（MediaCapture / FaceAnalysis，不是第三方库）驱动角色
> **转头 / 眨眼 / 张嘴**：不录像、不存画面、不联网。**默认关闭**，只有你打开开关才会请求摄像头。
>
> 这个卡片在测试页的下排（「物理与眼睛跟随」下面、「身体晃动测试」上面），和相邻区块之间都能拖拽调大小。

**开启步骤**

1. 勾选卡片右上角的「**启用摄像头动捕**」（默认关；打开后 Windows 才会弹摄像头权限）；
2. 首次使用会弹系统权限提示 → 允许；如果之前拒绝过：
   **Windows 设置 → 隐私和安全性 → 摄像头 → 允许桌面应用访问摄像头**（本程序是桌面应用，不是 UWP）；
3. 在「**摄像头**」下拉里选设备：默认优先内置摄像头（如 `HD User Facing`）；装了 **DroidCam / OBS 虚拟摄像头**
   等会多出设备，**选错会黑屏 / 一直没人脸**，手动选内置摄像头那一项即可；点「**刷新设备**」重新枚举
   （只枚举设备，不会打开摄像头）；
4. 右侧**预览小窗**会显示摄像头画面（按「镜像」设置翻转）和人脸框；下面状态行会显示
   「正在跟踪 / 未检测到人脸 / 摄像头未运行（原因）」；
5. 对着摄像头正常转头 / 眨眼 / 张嘴，角色会跟着动。

**卡片上的设置**

| 设置 | 作用 |
| --- | --- |
| **镜像画面**（默认开） | 像照镜子：自己往右转头 = 画面右侧 = 模型往右看。关掉则左右相反（后置 / 非前置摄像头时可能需要关） |
| **显示摄像头预览**（默认开） | 右侧预览小窗；关掉省 CPU / 内存（动捕本身不受影响） |
| **帧率** 10 / 15 / 24 | 默认 15；越高越顺、CPU 越高（检测一帧约 8~10ms） |
| **平滑** 0 ~ 0.9 | 越大越稳、延迟越高（默认 0.45） |
| **驱动头部 / 驱动眨眼 / 驱动张嘴** | 三个开关可以单独关（例如戴眼镜眨眼不准就只关眨眼） |
| **头部强度**（0 ~ 1.5） | 转头幅度倍率（默认 1.0） |
| **眼球强度**（0 ~ 1.5） | 眼球方向（由转头方向近似）的幅度倍率 |
| **张嘴幅度**（0 ~ 1.5） | 张嘴参与程度（对应模型 `ParamMouthOpenY`） |

**校准**

- **重新校准表情**：把眨眼 / 张嘴的自动基准清零（换环境 / 光线 / 戴摘眼镜后点一下）。
  自动校准需要你**正常眨眼 + 张嘴几次**（系统靠滚动分位数找「睁 / 闭」两端），刚点完时开合度会短暂回到中性值；
- **校准中性位**：把**当前**有脸的位置当成「正前方」（换座位 / 换摄像头后角色总是歪着看时用）。
  存进配置 `mocapNeutralFaceX / mocapNeutralFaceY`，下次打开继续用。

**优先级与回落**

- 有脸时**动捕接管**头部 / 眼珠 / 眨眼 / 张嘴（自动眨眼暂停，避免和动捕抢同一批参数）；
  此时鼠标眼控让位（不会两边打架）；
- 没脸、或摄像头帧过期超过 0.6 秒（相机卡住）时，自动回落到**鼠标眼控 + 自动眨眼**，角度平滑回正，不僵住；
- 关掉动捕开关 = 立即释放摄像头；切走工具页且桌宠没开动捕时也会释放（见「隐私」）。

**常见问题**

| 现象 | 怎么办 |
| --- | --- |
| 打开开关后一直「正在启动摄像头…」/ 报错 | 看卡片里的错误文本：多半是没给 Windows 摄像头权限，或被别的程序占用（微信 / QQ / 钉钉 / 直播软件 / 浏览器视频会议可能独占摄像头）→ 关掉那些程序后点「刷新设备」再开关一次 |
| 有画面但一直「未检测到人脸」 | 人离镜头太远 / 太近、只露侧脸、光线太暗；把脸放到画面中间、保持 40~80cm、开灯或面向光源 |
| **预览颜色不对（偏绿 / 偏紫 / 错色）** | 旧版本在某些摄像头的 Bgra8 Straight 帧上做了二次格式转换，**更新到最新版本**即可修复；仍异常就换内置摄像头、关掉其它占用摄像头的程序（详见文末「[故障排查](#故障排查)」） |
| 太暗 / 逆光时眨眼张嘴乱跳 | 光照不足时启发式不稳：补光后点「重新校准表情」；也可关掉眨眼/张嘴驱动 |
| 戴眼镜 / 刘海挡眼，眨眼不准 | 关掉「驱动眨眼」；或换个角度、点重新校准 |
| 转头幅度不够 / 太灵敏 | 调「头部强度」「平滑」；偏移多少算满角度是经验值（左右 ±20% 画面宽 ≈ 30°、上下 ±16% ≈ 22°） |
| 设备列表里有 DroidCam 等虚拟摄像头 | 选内置摄像头那一项（名字通常是 `HD User Facing` / `Integrated Camera` / 品牌名）；虚拟摄像头可能不出画面或帧率不稳 |
| 角色总是歪向一边看 | 点「校准中性位」把当前脸位置设为正前方；或检查「镜像画面」是否该反过来 |
| 桌宠也想动捕 | 右键桌宠 →「摄像头动捕：开 / 关」；状态与测试页共用配置（关掉立即释放摄像头，隐私） |

> ⚠ 动捕只驱动**头部 + 眨眼 + 张嘴**：没有精确眼球追踪（眼球方向由头方向近似）、没有身体关键点 / 手势。
> 摄像头画面只在内存里做检测，**不录像、不存图、不上传**；预览只在测试页窗口里显示。

### 🌊 身体晃动测试

> 让角色按正弦规律持续晃动，直观看到「身体主轴 → 物理输入 → physics3 钟摆物理 → 头发 / 裙子 / 尾巴跟摆」
> 这条链。不是播放动画，**晃动是实时算出来的**。

**这个模型的身体是怎么晃的**（看曲线前先理解这条链）：

1. **身体主轴**：`ParamBodyAngleX / Y / Z`（左右 / 前后 / 扭转）直接驱动身体网格变形；
2. **物理输入**：`PositionX / Y / Z` 是 physics3.json 的输入，物理设置（Setting 4 / 14 / 9 等）会把它们
   变成 `ParamBodyAngle*`，再带动下游一大串物理输出；
3. **物理链**：内置模型里 **28 组物理设置**的输入含 `ParamBodyAngleX/Z`，输出包括
   `ShoulderZ`（肩）、`HipAngle*` / `HipZ*`（胯）、`ChestX*`（胸）、`SkirtX*`（裙）、`LArm/RArm`、
   `LSleeve*/RSleeve*`（袖）、`LRibbon*/RRibbon*`（飘带）、`Lace*`（花边）、`Param_Angle_Rotation84~89`
   （尾巴的 [0]~[5] 段）等；`ParamAngleX` 还会经 Setting 50 / 54 / 59 等带动 `FrontHairX1~4` /
   `SideHairX1~4` / `LateHairX1~5`（头发）。
4. **头**：`ParamAngleX/Y/Z` 直接驱动头部；`AngleX/Y/Z` 是头部物理输入（Setting 1~3 把 `AngleX` 变成
   `ParamAngleX`）。所以「头部补偿」两套都写；
5. **腰腿**：`HipAngleX/Y/Z`、`ParamHipAngleZ`、`LEGAngleZ2`（勾「连腰部 / 腿部一起晃」才写）。

→ 所以身体一晃，头发 / 裙子 / 尾巴 / 飘带会**慢半拍地甩**——那是物理在算，不是动画预设。

**怎么玩**

- 勾右上角「**开启身体晃动**」持续晃动，或点「**摇一摇（3 秒）**」临时演示（不改变开关配置）；
- **晃动模式**（5 种）：
  - **左右摇**：X 主轴左右摆（附带少量侧倾 Z），最常用；
  - **前后摇**：Y 轴前后点头式晃动；
  - **扭腰**：Z 轴扭转为主（附带少量 X），像扭腰；
  - **椭圆**：X / Z 相位差 90°，身体画椭圆（能明显看出腰腿反向）；
  - **自然晃**：多个频率 / 相位叠加，最像真人站着轻微晃；
- **幅度** 0 ~ 30°（默认 12）；**速度** 0.1 ~ 2 Hz（默认 0.5 ≈ 2 秒一个来回）；
- **头部补偿** 0 ~ 1：0 = 头完全跟着身体晃；1 = 头尽量保持朝前（反向补偿）；默认 0.35；
- **连腰部 / 腿部一起晃**（默认开）：关掉只看身体主轴 + 物理输入（对比物理链是否有区别）；
- 点「**停**」= 立刻停止演示并关闭晃动开关。

**整身轻倾（常态，和上面的测试晃动不是一回事）**

- 模型平时会**以脚底为支点整身左右轻倾**：日常 **0.6°、4 秒一个来回**；
- **有音乐在播**（唱 / 纯音乐都算）且「摇晃」开着时：**加快到约 2.6 秒一个来回、幅度 1.0° × 身体摇晃幅度**；
- 这是**渲染层的整体倾斜**（预览和桌宠都按同一个角度转），不写模型参数，所以和上面的「身体晃动测试」
  （扭身体参数 / 看物理链）**可以同时开、互不覆盖**；
- 不想看到倾斜：在「**物理与眼睛跟随**」卡里关掉「**全身轻晃（以脚为轴）**」（配置 `bodyLeanEnabled`）——
  关掉后角度会平滑归零，不会突然跳正。

**右侧曲线怎么读**（最近 5 秒，四条线同一 ±30° 尺度）：

| 曲线 | 参数 | 含义 |
| --- | --- | --- |
| 蓝 | `ParamBodyAngleX` | 身体主轴（正弦驱动） |
| 绿 | `AngleX` | 头部物理输入（与身体反向的补偿量） |
| 红 | `ParamAngleX` | 头部最终角度（补偿后，方向与身体相反） |
| 灰 | `FrontHairX1` | 前发物理输出——**比身体慢半拍 / 有起伏**，正是物理链在算的证据 |

下方参数实时值每 100ms 刷新一次。切到「椭圆」能看出 X / Z 两条正交曲线；切到「自然晃」曲线不再规则。
晃动关闭时不写任何参数（无副作用）；物理演算关掉时，身体仍会晃，但头发 / 裙子不会跟摆（对比用）。

> ⚠ 和摄像头动捕**同时**开启时：头部优先跟脸（动捕），晃动只驱动身体 / 腰身 / 物理，**不做头部反向补偿**
> ——想认真看动捕（自己转头）就关掉晃动；想专注看身体 / 物理链就关掉动捕。界面上也有这条提示。

| **点透明区域** | 直接穿透到下面的窗口（默认开启）；角色本体部分仍然能拖动 |
| **待机** | 自动眨眼 + 呼吸 + 物理摆动（头发 / 尾巴 / 衣服）+ 整身轻倾；每隔 8~18 秒随机来个小动作（换脚 / 东张西望 / 伸懒腰 / 挥挥手 / 戴铁盆） |

  打开后桌宠会跟随真实摄像头里的头部转动 / 眨眼 / 张嘴（**会请求摄像头权限**，关掉立即释放摄像头）；
- 桌宠**也能开音乐跟唱**：右键菜单「音乐跟唱：开 / 关」，勾选状态与测试页共用配置；
  打开后放歌，桌宠会自己跟唱嘴型 / 跟节拍摇（采集系统声音，不碰麦克风；关掉立即释放回环设备）；
- 桌宠右键还能直接**说句话 / 换个姿势 / 跳个舞 / 停止动作**（说句话会用当前语音设置说一句随机软妹台词，
  同时在桌宠头顶弹气泡；换个姿势 = 随机手势或表演；跳个舞 = 按上次选的舞蹈模式跳）；

  音乐跟唱同理：不录音、不存音频，只做实时分析；
- 桌宠**置顶显示**（可右键关掉；和其他置顶窗口的层级由系统决定）；

  想整块都挡住鼠标就在右键菜单 / 测试页关掉点击穿透；
- 桌宠窗口**不抢焦点**、不进任务栏 / Alt+Tab；
- 关掉程序桌宠一起消失；桌宠开着时切去别的工具页 / 回主页它继续在桌面上跑。

## 🐭 鼠标互动玩法

> 桌宠现在能像撸猫一样**摸**：点到角色不同部位有不同反应（动作 + 表情 + 说话 + 气泡），拖起来头发 / 裙子会跟着甩。
> 互动只在**桌宠窗口**里生效（测试页预览不响应摸头）；不想被摸 / 想安静挂着可以关掉互动。

**完整玩法表**

| 操作（鼠标在桌宠上） | 反应 |
| --- | --- |
| **左键按住角色拖动** | 搬动桌宠窗口（位置记住）；同时**拖拽物理**：头发 / 裙子 / 身体按拖动速度甩起来，松手后自然衰减 |
| **左键轻点角色** | **点击互动**（按下 <200ms 且几乎没移动 <6px 算轻点；移动超过 6px 就是搬窗口，不会误触发互动） |
| **单击（不拖动）头部** | **摸头**：角色说话 + 小表情（＞＜ 眯眼笑 / 脸红之类）约 0.8 秒后恢复 |
| **单击额头** | **三态表情循环**：每点一次在「常态 → 爱心眼 → 单片眼镜/黑框眼镜 → 常态」之间切换 |
| **按住脸左 / 右半侧拖动** | **捏脸**：对应半边脸鼓起（CheeckPuff）+ 嘴形变化，耳朵 / 身体轻轻抖；松手约 0.3 秒复位 |
| **摸脚 / 摸腰** | **怕痒**：身体 / 耳朵高频抖动约 1.2 秒 + 说话（「别挠啦～」之类） |
| **摸胸 / 摸胯** | **护住 + 黑脸**：护住手势 + 黑脸表情约 1.5 秒后恢复，同时说一句 |
| **点左手 / 右手** | **竖食指**：点一下竖起食指，再点一下放下（切换） |
| **双击角色** | 随机表情 / 动作彩蛋（原有玩法） |
| **待机（不打扰）** | 自动眨眼 / 呼吸 / 整身轻倾；每隔 **8~18 秒**随机来个小动作：**重心换脚 / 东张西望 / 伸懒腰 / 挥挥手 / 戴铁盆**（部分带小表情） |

**互动时的规则**

- **有互动就停掉当前待机小动作并复位**（不会出现「摸头时还在伸懒腰」）；
- 互动结束后 **3 秒内不再自动恢复**待机小动作，之后继续；
- 互动**会说话 + 弹气泡**（走「💬 说话 / 轻对话」的语音设置；不想要可关「互动语音」）；
- 正在播放动作 / 手势 / 表演 / 舞蹈 / 说话时，互动反应会和它们叠加 / 打断（以运行时状态为准），
  点「⏹ 停止所有演示」可回到安静状态。

**快捷键**

| 快捷键 | 作用 |
| --- | --- |
| **Ctrl + Alt + L** | 切换**鼠标穿透**（穿透后鼠标点不到桌宠，也不会误挡操作；再按一次恢复可互动） |
| **Ctrl + Alt + 0** | **退出程序**（桌宠一起关闭） |

> 快捷键默认开启；如果和其它软件冲突 / 不想用，可在「桌面宠物」卡 / 桌宠右键菜单里关掉「全局快捷键」。

**开关与配置**

> 开关都在「桌面宠物」卡内部往下滚（或右键角色 →「⚙ 设置（打开工具页）」跳过去），改了立即生效。

- **鼠标互动玩法**：关掉后鼠标点到桌宠不再触发摸头 / 捏脸 / 表情循环等（但拖动搬窗口 / 滚轮缩放仍可用）；
- **互动时说话**：关掉后互动只做动作 / 表情 / 气泡，不说话；
- **拖拽物理**：关掉后拖动只搬窗口，头发 / 裙子不甩；
- **待机随机表情**：关掉后待机小动作不再附带随机小表情（动作本身还在）；
- **待机间隔**：滑杆 8~30 秒（默认 12；实际每次会浮动）；
- **全局快捷键**：关掉后 Ctrl+Alt+L / Ctrl+Alt+0 不生效。

配置键（`Config\live2d\config.json`，程序退出后改；运行中改会被内存值覆盖）：

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `petInteractionEnabled` | `true` | 鼠标互动总开关（摸头 / 捏脸 / 表情循环 / 挠痒 / 护住 / 手势） |
| `petInteractionVoiceEnabled` | `true` | 互动时是否说话（走 TTS 语音设置） |
| `petDragPhysicsEnabled` | `true` | 拖动时是否施加拖拽物理（头发 / 裙子甩） |
| `petIdleActionIntervalSeconds` | `12` | 待机小动作间隔（秒，夹取 8 ~ 30；实际会浮动） |
| `petIdleExpressionEnabled` | `true` | 待机小动作是否附带随机小表情 |
| `petHotkeysEnabled` | `true` | 全局快捷键（Ctrl+Alt+L 穿透 / Ctrl+Alt+0 退出） |

**隐私**

- 互动本身完全本地（无需联网 / 不读麦克风 / 不保存任何东西）；
- 互动语音沿用「说话」的语音引擎：默认在线软妹音需联网（只发送要说的文字），离线回退本地 TTS（见说话章）；
- 互动台词 / 气泡都在内存里，不写日志文件（除调试模式）。

**故障排查**

| 现象 | 处理 |
| --- | --- |
| 点角色没反应（摸头 / 捏脸都不触发） | ① 检查「互动」开关是否关掉；② 检查是否按了 Ctrl+Alt+L 进入**鼠标穿透**（穿透时点不到桌宠，再按恢复）；③ 点在透明区域会穿透，要点角色本体 |
| 想轻点却变成搬窗口 / 想拖却触发了互动 | 判定：按下后 **<200ms 且移动 <6px = 点击互动**，**>6px = 搬窗口**；快速轻点 / 按住再拖区分一下即可 |
| 拖角色时头发 / 裙子不甩 | 「拖拽物理」开关被关掉了 |
| 待机小动作太频繁 / 太安静 | 调「待机小动作间隔」（8~30 秒）或直接关掉待机小动作 |
| Ctrl+Alt+L / Ctrl+Alt+0 没反应 | ① 检查「全局快捷键」开关；② 被其它软件占用（输入法 / 游戏平台 / 录屏工具常用这组键）→ 关掉冲突软件或关本工具快捷键；③ 个别游戏全屏独占时全局热键可能被拦 |
| 互动有动作但没声音 | 「互动语音」关了，或语音引擎失败（看「说话」卡状态 / 错误；在线失败会自动回退本地） |
| 互动表情 / 姿势卡住不恢复 | 互动有超时自动复位；如果卡住点「⏹ 停止所有演示」或让角色播一个表情 / 动作即可恢复 |

## 动作 / 表情 / 物理 / 动捕 / 晃动 / 音乐 / 调试视图怎么用

**看动作效果**：动作区点「▶」→ 预览里手抬起来 → 看进度条 / 等它播完；循环动作（如 IDLE）会一直播。
动作之间切换会自动淡入淡出（淡入淡出时长可调）。

**看表情效果**：表情区点「爱心眼」→ 角色眼睛变成爱心；再点一次取消。换表情时自动交叉淡入淡出
（同一时间只有一个表情生效，旧表情的参数会淡回默认）。

**看物理效果**：头转得快时头发 / 尾巴会甩；把「物理强度」拖到 0 就完全不动，对比一下就能看出
哪些是物理驱动的（主要是前发 / 侧发 / 后发 / 尾巴 / 裙子 / 飘带）。

**看动捕效果**：打开动捕开关、等状态变成「正在跟踪」→ 自己左右转头 / 点头 / 眨眼 / 张嘴，
角色的头、眼睛和嘴会跟着动；把鼠标移到预览区，有脸时角色只跟摄像头（鼠标眼控让位），
捂一下摄像头或走开，角色会平滑回落到鼠标眼控。

**看身体晃动**：打开晃动 → 右侧四条曲线开始滚动；调大「幅度」看甩得更狠，切「椭圆」看腰腿反向，
把「物理强度」拖到 0 再晃 → 身体还会动，但头发 / 裙子不跟摆了（说明跟摆来自物理链）。

**看音乐跟唱**：先放一首歌（任意播放器）→ 勾「启用音乐跟唱 / 律动」→ 状态从「静音」变「识别中」，
约 2~4 秒后判定「带歌词」或「纯音乐」：带歌词 → 嘴跟唱（可调跟唱幅度），纯音乐 → 不跟唱、只跟节拍晃身体；
「摇晃」「点头」可以单独关。识别不准时用「强制跟唱 / 强制纯音乐」。

**排查渲染问题**（一般是自定义模型才有）：
1. 先开「网格包围盒」看整体位置对不对；
2. 花屏 / 破面 → 在预览里单击疑似网格看信息 / 高亮，确认是不是 UV / 纹理张数对不上；
3. 某个部位该显示的地方被裁掉 → 开「蒙版范围（染红）」看蒙版网格有没有画出来；
4. 蒙版完全错位 → 开「蒙版缓冲可视化」看蒙版缓冲本身是黑还是白。

## 自定义模型

### 支持哪些模型

- **Cubism 3 / 4 / 5 的 `.moc3` 模型**（官方 Cubism Core 5.0 支持 moc3 格式版本 1~5）；
- 不支持 Cubism 2 的 `model.json` / `moc`（那是上一代格式）；
- 模型可以带动作、表情、物理、cdi3（显示名）；**都是可选的**，没有就只是没得播 / 没物理。

### 文件夹怎么放

选一个文件夹，里面至少要有 `model3.json` + `moc3` + 纹理，典型结构：

```
我的模型\
├── 我的模型.model3.json          ← 必须：FileReferences 指向 Moc / Textures / Physics / DisplayInfo
├── 我的模型.moc3                 ← 必须：模型数据
├── 我的模型.4096\
│   ├── texture_00.png            ← 必须：纹理（张数 = model3.json 的 Textures 数组）
│   ├── texture_01.png
│   └── ...
├── 我的模型.physics3.json        ← 可选：物理（头发 / 尾巴摆动）
├── 我的模型.cdi3.json            ← 可选：参数 / 部件的中文名与分组（没有就显示英文 Id）
├── Animation\                    ← 可选：动作
│   ├── IDLE.motion3.json
│   └── 其它动作.motion3.json
└── Exp3\                         ← 可选：表情
    ├── 爱心眼.exp3.json
    └── 其它表情.exp3.json
```

- 纹理放哪个子目录都行，跟着 `model3.json` 的 `FileReferences.Textures` 走；
- **动作**：`Animation\` 下所有 `*.motion3.json` 都会被扫出来，文件名当动作名；
- **表情**：`Exp3\` 下所有 `*.exp3.json` 都会被扫出来，文件名当表情名；
- 没有 `model3.json` 时会按约定兜底猜：文件夹里**唯一**的 `.moc3` + 唯一含 `texture_00.png` 的子目录；
- 换模型：在预览工具条点「选择模型文件夹…」选文件夹 → 自动重新加载；想切回内置点「用内置模型」。

### 放模型时的注意事项

- **不要放 PSD 源文件**（一个 PSD 可能上百 MB，程序完全不读它，白占空间）；
- 纹理建议 2 的幂（1024 / 2048 / 4096），单张最长边建议 ≤ 4096（最大不要超过 8192）；
- 换模型后如果报「moc3 复活失败」，一般是 moc3 比 Cubism Core 新（用更高版本编辑器导出）或文件不完整；
- 自定义模型路径会存进配置（`modelFolder`），下次打开自动加载；路径失效时会退回内置模型并在日志里提示；
- 模型版权由你自己负责：只放你有权使用的模型，**不要分发别人的付费模型**。

### 数据：`Data\live2d\`

- `Data\live2d\screenshots\`：测试页「截图」按钮保存的预览 PNG；
- **动捕不落盘**：摄像头画面只在内存里做检测，不录像、不存图（开发调试开关 `YLT_LIVE2D_MOCAP_SELFTEST`
  才会写 `Data\live2d\mocap-selftest.log`，里面只有数字和设备名，没有画面）；
- 其余没有必须放在这里的文件：模型本体跟着程序（内置）或跟着你选的文件夹（自定义），不会被复制到 Data。
- 「主页设置 → 清理缓存」不会动 Data\live2d（截图属于用户数据，不自动清）。

### 内置模型在哪

内置模型随程序发布在 **exe 旁边的 `Live2D\Models\DeepSeek\`**（开发时构建自动拷贝，
发布包 `dist\YuLiangToolkit\` 里也有）；Cubism Core 原生库是 exe 旁边的 `Live2DCubismCore.dll`。
这两个东西别手动移动，移动了程序就找不到模型。

## 性能建议

- **首选默认值**（纹理 2048 / 30 帧 / 渲染倍率 1.0）：一般台式机 CPU 占用很低，笔记本也够用；
- **纹理上限**：内置模型原图 5 张（最长边 8192），2048 档解到内存约 50~60 MB、4096 档约 200 MB；
  除非要截高清大图，否则 2048 看不出差别；小内存机器（8 GB）建议保持 2048；
- **帧率**：15 帧明显省电（桌宠挂着当装饰够用），30 帧默认，60 帧更顺滑但 CPU 占用更高；
- **渲染倍率**：2K / 4K 屏上桌宠显示面积大，调到 0.75 能明显省 CPU 且肉眼几乎无差；
  反过来觉得边缘糊可以调到 1.25 / 1.5；
- **桌宠宽度**：越大越吃 CPU（像素按面积涨），420 宽是默认；
- **摄像头动捕**：只在启用时耗 CPU（默认 15fps，每帧检测约 8~10ms；24fps 更高、更顺）；
  关闭「显示摄像头预览」能省一点内存带宽；不用时直接关掉开关（同时释放摄像头，省电也保护隐私）；
- 全屏游戏 / 直播时如果在意性能，可以把桌宠隐藏（右键菜单）或把帧率调到 15；
- **Debug 版（bin\Debug）明显更慢**（软件渲染约慢 2.5~3 倍，FPS / 渲染耗时数字会难看很多）；
  日常使用、长期挂桌宠请用**发布版**（`publish.ps1` 产物，dist\YuLiangToolkit\），帧率和 CPU 占用才是真实水平；
- 性能看预览左下角的统计：**FPS / 网格数 / 三角形数 / 耗时**（Core Update 是模型变形，
  Render 是软件光栅化，和窗口像素数成正比）。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| **摄像头预览颜色不对（偏绿 / 偏紫 / 偏色）** | 旧版本在某些摄像头的 Bgra8 Straight 帧上会二次转换导致错色，**更新到最新版本**即可；仍偏色的话：换摄像头的其他格式 / 换一个摄像头试；关掉其它占用摄像头的程序（微信 / QQ / 直播 / 浏览器会议可能用独占格式）；虚拟摄像头（DroidCam / OBS）格式兼容性差，优先用内置摄像头 |
| **动捕打不开 / 一直「正在启动」** | 检查 Windows 隐私设置「允许桌面应用访问摄像头」；关掉占用摄像头的程序后点「刷新设备」再开关一次（卡片里会显示具体错误） |
| **动捕没脸 / 角度乱跳** | 正对镜头、保持 40~80cm、补光；太暗 / 侧脸 / 戴眼镜眨眼不准时点「重新校准表情」或关掉对应驱动开关 |
| **音乐跟唱开了但一直「静音」/ 不跟唱** | ① 确认系统真的有声音（静音 / 音量极低 = 没声音）；② 播放器用**独占模式**（ASIO / WASAPI 独占）会绕过系统混音 → 换共享模式；③ 切了播放设备（拔耳机 / 蓝牙）会自动重启采集，等 1~2 秒；④ 卡片里会显示具体错误（没有播放设备 / 被占用） |
| **该跟唱却不张嘴（被判成纯音乐）** | 用「识别模式 → 强制跟唱」，或把「识别灵敏度」调大；纯音乐 / 纯器乐本来就不跟唱（设计如此） |
| **纯音乐被误判成带歌词 / 嘴乱动** | 用「强制纯音乐」，或把「识别灵敏度」调小 |
| **只有歌名 / 歌手显示「—」** | 播放器不支持 Windows SMTC，只是看不到媒体信息，不影响跟唱（可换支持 SMTC 的播放器如 Spotify / 系统播放器） |
| **音乐跟唱想给桌宠用** | 桌宠右键菜单「音乐跟唱：开 / 关」，状态与测试页共用；关掉工具页 / 隐藏桌宠会停止采集 |
| **鼠标跟随「向下看跟不到 / 幅度小」** | 调大「低头灵敏度」（向下）和「横向灵敏度」、加大「头转幅度」；还不行把「纵向偏移」往负方向调一点；调大平滑可减少抖动 |
| **鼠标跟随太灵敏 / 抖** | 降灵敏度、加大平滑；桌宠全屏跟随幅度和测试页共用同一套设置（在测试页调好再放桌宠） |
| **手动调好的脸/舌头过一会自己变回去** | 有系统在每帧接管这些参数：关掉「摄像头动捕」「眼睛跟随」「自动眨眼」、停掉动作、清除表情，再调就会保留 |
| **模型加载失败 / 找不到模型** | 看日志区 / 卡片里的错误原因；自定义模型路径失效时点「用内置模型」；moc3 版本过新会报「复活失败」 |
| **桌宠有白边 / 黑底** | 更新到最新版本；显卡驱动 / 远程桌面下透明合成偶尔异常，可调低渲染倍率或换主题；用发布版（Debug 版更慢） |
| **卡顿 / FPS 低** | 用发布版；降帧率到 15、渲染倍率到 0.75、纹理上限 2048；关掉摄像头预览和调试视图；桌宠宽度别太大 |
| **语音列表是空的 / 没有中文语音** | 点「重新检测」；本地语音需要 Windows 安装语音包：设置 → 时间和语言 → 语音 → 添加中文语音（在线语音不需要语音包，但要联网） |
| **说话没声音** | ① 看卡片状态 / 语音是否选了在线但断网（会自动回退本地并在状态里注明）；② 系统音量 / 应用音量被静音；③ 选中的本地语音包损坏 → 换一个语音或重新检测；点「试听」快速验证 |
| **在线语音失败 / 一直回退本地** | 需要联网且能访问微软语音服务（公司网络 / 代理可能拦截）；离线用就在语音列表手动选「本地」音色 |
| **气泡不显示** | 勾上「显示聊天气泡」；气泡只在**桌宠显示时**出现（测试页预览不显示气泡）；多屏时会被夹在桌宠所在屏幕工作区内 |
| **语速/音调调了没变化** | 在线与本地语音对 prosody 的支持略有差异（本地语音音调调整幅度较小）；改完点「试听」听一下 |
| **手势/表演不动或手动参数被覆盖** | 有演示在播时手动值会被覆盖：点「⏹ 停止所有演示」再拖；手势按钮点一下会替换当前演示 |

## 已知限制

- **不播放音乐**：本工具没有音乐播放器 / 音频库；「音乐跟唱」是**采集系统正在播放的声音**做实时分析
  （WASAPI 回环，不读麦克风），音乐要你自己用播放器放；**语音说话**会用系统音频输出播放合成语音
  （见 [💬 说话 / 轻对话](#-说话--轻对话)）；
- **音乐跟唱是启发式识别**：靠基频 / 共振峰 / 中心声道 / 音节调制等多特征判断「带歌词 / 纯音乐」，
  纯器乐、说唱、Live、人声采样等会误判 → 识别不准时用强制模式；
- **音乐跟唱默认关闭**：不申请麦克风、不录音、不存音频，只做实时特征提取；debug 自检日志会记媒体标题（注意隐私）；
- **除「在线语音」外不联网**：默认语音用微软 Edge 在线神经网络语音（需要联网，**只把要说的文字**发给微软）；
  断网会自动回退 Windows 本地 TTS；在线语音可在列表里换成「本地」彻底离线；也不支持 VTube Studio / VSeeFace /
  其它虚拟主播软件的联动（它们走自己的协议，本工具是独立实现的）；
- **语音说话的限制**：一次最多 500 字（超出截断）；在线合成失败自动回退本地并提示原因；本地语音声音偏机械；
  轻对话是**离线关键词匹配**（不是 AI 大模型），未知输入随机软妹回复；气泡只在桌宠显示时出现（测试页预览没有气泡）；
- **鼠标互动只在桌宠窗口生效**：测试页预览不响应摸头 / 捏脸（预览是调试用）；进入「鼠标穿透」模式后
  也点不到桌宠（用 Ctrl+Alt+L 恢复）；互动反应是启发式小动画（不是精确骨骼 IK），不同模型部件名不同时
  热区可能退化（换模型后按实际效果为准）；
- **一次一个模型**：一个桌宠窗口、一个模型；不支持同时挂多个模型；
- **只支持 moc3**：Cubism 2 的 `model.json` 模型不支持；
- **单个网格最多 16 个蒙版**（Cubism Core 的限制，内置模型最多用到 16 个）；
- **模型里嵌入的动作音频（`Sound` 字段）会被忽略**（没有音频引擎）；
- **模型自带的 HitAreas（摸头 / 点击命中区）不参与交互**：测试页单击模型只是查命中的网格信息，
  桌宠双击是「随机表情 / 动作」彩蛋，不会触发模型里定义的点击动作；
- **动捕只做头部 + 眨眼 + 张嘴的启发式**：没有精确眼球追踪（眼球方向由头方向近似）、
  没有身体关键点 / 手势 / 表情分类；侧脸、遮挡、光线差时不准，属于系统自带人脸检测的固有限制；
- **动捕需要摄像头和 Windows 权限**：被别的程序占用、隐私设置拒绝、设备被禁用时会打不开（卡片里会显示原因）；
- **动捕不录像、不存图、不联网**：画面只在内存里做检测；预览只在测试页窗口里显示，
  桌宠开动捕时不显示预览；关掉开关 / 切走页面 / 隐藏桌宠会释放摄像头；
- **动捕不是 VTube Studio 协议**：用的是 Windows 自带 MediaCapture / FaceAnalysis，不能和 VTS / VSeeFace 互通；
- **身体晃动是测试功能**：只做正弦（及多频叠加）模式，不是动作捕捉；晃动参数会实时写模型参数，
  与待机 / 物理叠加时观感由物理链决定；
- **表情是「单激活 + 过渡」语义**：同一时间只有一个表情生效，切换时交叉淡入淡出、旧表情参数淡回默认
  （Cubism 官方 `ExpressionMotionManager` 的语义，不是多表情叠加）；
- 软件渲染在**超小窗口 / 远程桌面**里可能有一点点锯齿（可以调高渲染倍率缓解）；
- 桌宠位置是屏幕坐标：**换分辨率 / 多显示器变化后可能被夹回主屏可显示区域**；
- 模型文件缺失 / 损坏时工具页会显示错误原因而不是崩溃，重新选对模型文件夹即可。
