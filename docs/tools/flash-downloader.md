# ⚡ Flash 下载器

> 把 4399 / 7k7k / 17yy / ArmorGames / Kongregate 上的小游戏下载到本地，**离线也能玩**。
> 两条路：Flash 独立播放器，或者内置的本地网页服务器。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **下载**：粘游戏页网址（如 `https://www.4399.com/flash/6853.htm`、`https://armorgames.com/play/14775`、
  `https://www.kongregate.com/games/Ninjakiwi/bloons-super-monkey`）→ 点「下载」或「下载并游玩」。
  单个 swf 存成 `游戏名_a6853.swf`；网页游戏（h5 / Unity）存成 `游戏名_a12346h/` 文件夹。
- **找游戏**：列表上方有**搜索框**（按名字 / 站点后缀 / `4399`、`网页` 这类词搜，空格分隔多个关键词需同时命中，
  `Ctrl+F` 聚焦、`Esc` 清空）和**排序**（按上次游玩 / 名字 / 大小 / 站点，可切正序逆序；
  默认「按上次游玩」——刚玩过的排最上面）。
- **游玩**：
  - swf → 用 `FlashPlayer.exe`（Ruffle 的 `ruffle.exe` 也行）直接打开；工具会自己找到它并拷进
    `Data\flash-downloader\tools\`；
  - 网页游戏 → 启动内置本地 HTML 服务器，用浏览器打开播放页（有背景、重玩 / 放大 / 缩小 / 全屏、四套配色）。
    **玩网页游戏时别关掉本工具**，否则 `http://localhost:1055/` 就断了。
- **多文件游戏**（只下主 swf 玩不了的那种）：
  1. 选中游戏 → 「**装入文件夹**」（把散放的 swf 收进 `游戏名_?123s/`，并写好 `SWFNetPath.ini`）；
  2. 「**关联文件下载器**」里一行一个相对路径（如 `assets/level1.swf`）→ 「批量下载」；
  3. 更省事的办法：点「**自动下载所需文件**」，然后在游戏里点「重玩」/ 刷新网页 ——
     游戏向本地服务器要文件，服务器发现本地没有就**先去网上下下来再答复**，缺什么补什么。
- **实在打不开本地 swf** 时可以「**改为 htm 打开**」：文件夹改名成 `h`、换成网页加载页 + 本地服务器打开
  （要浏览器支持 Flash，只是断网也能玩而已）。
- **自由下载工具**：给网址 + 上一级网址（防盗链用的 Referer）+ 文件名，直接存进游戏目录 ——
  不属于这几个站、或者自动解析不到的地址可以用它。
- **4399 h5 游戏的广告**：下载时会把页面里的官方 h5api 换成内置替代脚本（广告变 0 秒）；
  需要登录 / 联机排行的大游戏本地玩不了，这是设计如此。

## 支持哪些站

| 站点 | 后缀字母 | 备注 |
| --- | --- | --- |
| 4399 | `a` | 支持 h5 / Unity 网页游戏 |
| 7k7k | `b` | 有的 `gamePath` 只是外壳，要配合「装入文件夹 + 关联文件下载器」 |
| 17yy | `c` | |
| ArmorGames | `d` | swf 地址是**从页面里读出来的**（两种连字符写法都有）；没有 swf 的 HTML5 游戏自动改成整页下载 |
| Kongregate | `e` | 要跳三跳才见得到 swf；它自己的 API 库会被排掉。⚠ 编号**反推不出**游戏页（地址是「作者 / 游戏名」） |
| 其它 | `z` | 域名认不出来时按页面内容猜 |

## 设置项

| 设置 | 存哪 | 说明 |
| --- | --- | --- |
| 游戏目录 | `Config\flash-downloader\config.json` | **可以在界面上改成任意位置**，默认 `Data\flash-downloader\games\` |
| 并发数、超时、本地服务器端口、播放器路径、上次输入 | 同上 | 改一下自动保存 |

## 数据与配置

```
Data\flash-downloader\
├─ games\                     ← 下载下来的游戏（可在界面上改）
│  ├─ 怎么放游戏.txt           ← 首次运行放一份命名规则说明，可删
│  ├─ 囧星人大冒险_a6853.swf   ← 散放的单个 swf
│  └─ 欢乐厨房_a12346h\        ← 网页游戏（多文件）
│     ├─ 欢乐厨房_a12346.htm
│     ├─ SWFNetPath.ini       ← 网络路径 + 宽高（批量下载 / 自动下载都靠它）
│     └─ assets\…
└─ tools\                     ← 播放页与替代 API（首次运行从程序里释放，可自己改）
   ├─ frame.htm  FlashPage.htm  FlashPlayer.exe
   └─ tool\substiH5WanApi.js
```

> `SWFNetPath.ini` 是纯文本，人也能改：第 1 行网络路径，第 2 行必须是 `swf` / `htm` / `unknown`，
> 后面几行是宽高与（可选）新页面地址。**删了它游戏还能玩，但批量下载 / 自动下载就失效了。**

## 注意

- Flash 早就停止维护了，本工具走的是「下载游戏本体 + 本地播放器 / 本地服务器」的路子。
  遇到“安全沙箱错误”时，需要在 Flash 播放器里把自己的游戏文件夹加进「受信任位置」。
- `FlashPlayer.exe` 是 11 MB 的第三方二进制，**不在版本库里**；用「指定…」选一次就会记住并拷进 `tools\`。
- Kongregate 的游戏名后缀 `e编号` 反推不回游戏页，所以「装入文件夹」时 `SWFNetPath.ini`
  里的网络路径会留空，需要时手工填一次。
