# 📽️ PPT 阅读器

> 不装 Office / WPS 也能看 `.pptx` / `.pptm` / `.ppsx`：**文字、图片（含裁剪）、表格（含合并单元格）、
> 常见自选图形、组合、背景与主题色**按幻灯片原样还原；支持 **缩略图导航、翻页、25% ~ 400% 缩放 / 适应窗口、
> 演讲者备注、Ctrl+F 查找、复制本页文字、F5 全屏放映、最近打开、拖入文件与阅读位置记忆**，
> 还能在「⚙ 设置」里登记 **文件关联**（双击演示文稿直接用本工具打开）。
> 解析与绘制全部用 .NET 自带的 `System.IO.Compression` + `System.Xml.Linq` + WPF 矢量绘制，
> **不引第三方 PPT 库**；**只读浏览，绝不会改动原文件**。

## 能做什么

- **打开 `.pptx` / `.pptm` / `.ppsx`**：工具条「📽️ 打开演示文稿…」或 `Ctrl+O`，文件对话框默认过滤这三种格式；
  也可以把文件**直接拖到页面里**（只接受这三种扩展名）。打开后工具条显示演示文稿标题与完整路径，
  状态栏显示文件名、大小、幻灯片张数与当前页。
- **双击打开（文件关联）**：工具条「⚙ 设置」→ 勾选「双击 .pptx / .pptm / .ppsx 用本工具打开」，
  就会把三种后缀登记到 Windows「打开方式」（`HKCU`，不需要管理员），双击演示文稿 / 右键「打开方式」
  可以直接进本工具；旁边的按钮可以打开 Windows「默认应用」设置做最后一步确认。
  右键「打开方式」里的 3 个「凉雨工具集」入口（按文件类型自动分流到 PPT 阅读器）在
  **主页设置 → 打开方式关联** 里开关，和本开关互不影响（详见 [打开方式文档](open-with.md)）。
- **还原幻灯片内容**：
  - **文字**：段落对齐、大纲级别、项目符号 / 自动编号、左缩进、行距、段前段后距；
    run（文字片段）的粗体 / 斜体 / 下划线 / 删除线 / 字号 / 字体 / 颜色（含主题色 `schemeClr`）/ 上标 / 下标 / 超链接。
  - **主题与版式继承**：读 `ppt/theme/themeN.xml` 的颜色方案与字体方案；slide → slideLayout → slideMaster
    的占位符位置、字号与背景都会继承 —— 所以「标题 / 正文」不会因为幻灯片上没写坐标而挤到左上角。
  - **图片**：从包里取出图片字节显示，`srcRect` 裁剪比例与替代文字（Alt）都保留；
    超过 WPF 能解码范围的图片显示占位框，不影响整页。
  - **表格**：按 `a:tblGrid` 还原列宽、行高，`gridSpan` / `rowSpan` 合并单元格、单元格填充色与文字。
  - **自选图形 / 连接线**：矩形、圆角矩形、椭圆、三角、菱形、箭头、直线等常用几何；其余按矩形近似。
  - **组合**：`p:grpSp` 的子形状按组合的平移 / 缩放换算成幻灯片坐标后绘制；组合旋转整体处理。
  - **背景**：纯色、双色渐变、图片背景。
  - **不支持的内容**（图表 / SmartArt / 动画 / 切换 / 音视频 / 嵌入对象）：画浅灰虚线占位框并标注类型，
    保证「打不开的东西也看得见位置」，不会整页空白或崩掉。
- **缩略图导航**：左侧缩略图栏按演示顺序列出每一页（有标题显示「1. 标题」，没标题显示「第 1 页」），
  当前页高亮；点缩略图直接跳转。缩略图栏可以收起（会记住）。
- **翻页**：工具条上一页 / 下一页按钮，`←` / `→`、`PageUp` / `PageDown`、`Home` / `End`（首 / 末页）；
  状态栏页码显示 `x / N`（状态消息里写「第 x 页 / 共 N 页」）。
- **缩放 25% ~ 400%**：默认「适应窗口」（按窗口大小铺满一页）；关掉适应窗口后可用工具条 `− [100%] +`
  或 `Ctrl + 滚轮`；`Ctrl+0` 恢复 100%（并自动关掉适应窗口）。缩放百分比超出范围会自动夹回。
- **备注栏**：工具条「备注」开关右侧备注栏：有备注的页显示演讲者备注纯文本，
  没有备注的页在栏内提示「这一页没有备注」（栏保持打开）。备注栏默认收起。
- **Ctrl+F 查找**：在**所有幻灯片的正文 + 备注**里找（默认不区分大小写，可在配置里改）；
  结果列表显示「第几页 / 正文或备注 / 上下文片段」，点一条跳到对应页；
  `回车` 下一个、`Shift+回车` 上一个、`Esc` 清空。
- **📋 复制本页文字**：把当前页的**可见文字**（标题 + 正文 + 表格单元格，按阅读顺序换行）复制到剪贴板；
  不含备注（备注另存于 `Notes`，需要请到备注栏看）；成功提示「已复制本页文字（N 字）」，
  剪贴板被别的程序占用时只写状态栏，不弹窗。
- **🕘 最近打开**：工具条下拉列出最近打开过的演示文稿（新的在上、同一路径只留一条），点一条重新打开；
  文件已不存在的标灰，点了只给提示、不会报错；旁边「清空」只删记录、**不删本地文件**；
  上限可以在配置里调（0 ~ 100，0 = 不记录）。
- **💾 阅读位置记忆**：每份演示文稿记住上次看到第几页（最多 200 份，超出按保存时间淘汰最老的）；
  重新打开、或者切走工具页再回来，会回到上次那一页。关掉只是不再记录，**已有记录不会清**。
- **F5 全屏放映**：按 `F5` 进入全屏放映（没有工具条、没有缩略图），`←` / `→` / `PageUp` / `PageDown` / 空格翻页，
  `Home` / `End` 首末页，`Esc` 退出。配置里默认**跳过隐藏幻灯片**（和 PowerPoint 一致），
  关掉后隐藏页也照常播放。放映只读，不改文件。
- **开发 / 截图调试**：设置环境变量 `YLT_PPT_OPEN=<pptx 路径>` 后启动程序，打开本工具会自动加载该演示文稿
  （**只用于调试，不写进配置**，也不记最近列表）。
- **只读**：没有编辑 / 保存 / 覆盖原文件的入口；唯一会写盘的是工具自己的
  `Config\ppt-viewer\config.json`（以及全程序共用的 `Config\layout.json` 布局记忆）。
  主动勾选「文件关联」时会写当前用户注册表（见下面「文件关联」一节），但不会改动演示文稿本身。

## 支持格式与已知限制

**支持**：`.pptx`（PowerPoint 2007+ 默认格式）、`.pptm`（带宏的格式，宏不会执行，只显示内容）、
`.ppsx`（PowerPoint 放映格式，按普通演示文稿打开）。

**不支持 / 会简化**（都是只读浏览，不影响原文件）：

- **旧版 `.ppt`（PowerPoint 97-2003 二进制格式）不支持**，会提示「用 PowerPoint 另存为 .pptx 再打开」；
  同理 `.potx` 模板 / `.odp` 等其它办公格式也不支持。
- **图表（chart）、SmartArt、艺术字、公式、3D、动画、切换效果、音视频、嵌入的 OLE 对象只显示占位框**：
  看得见位置和类型名，但看不到内部内容；**不播放动画与切换**，也不播放音视频。
- **渐变只取首尾两个色标**（双色）；三色及以上、图案填充、纹理填充会简化成近似的纯色 / 双色。
- **主题字体缺失时回退到微软雅黑**；本机没装的字体会被替换，字号 / 行距与 PowerPoint 可能有细微差异。
- **复杂文字排版会简化**：文本框自动缩小 / 自动调整、竖排文字、多栏、艺术字效果、字符间距微调
  等与 PowerPoint 有差异；这是只读还原，不追求像素级一致。
- **旋转 / 翻转按记录的角度绘制**；阴影、发光、柔化边缘、3D 旋转等效果不还原。
- **表格只做阅读展示**：不能在表格里选中 / 编辑；复杂的单元格边框样式按统一细线近似。
- **备注只显示文字**：备注里的图片、表格、格式会简化或跳过。
- **图片只支持 WPF 能解码的位图**（png / jpeg / gif / bmp / tiff 等）；EMF / WMF 等矢量图显示占位提示；
  外链图片（没有嵌进 pptx 的）不联网取图。
- **隐藏幻灯片**在浏览时照常显示（缩略图 / 状态栏标注），**放映时默认跳过**（配置 `skipHiddenInShow` 可关）。
- **文件关联只是登记「打开方式」**：Windows 10/11 的最终默认程序由「默认应用」的 UserChoice 决定，
  程序不能硬改；勾选后双击没进本工具时，点设置浮层里的按钮去「默认应用」选一次即可。
- **只读**：没有编辑 / 保存 / 覆盖原文件的入口；打开、翻页、缩放、查找、复制都不会修改、移动或删除被浏览的文件。

## 区块布局（可拖拽）

页面分三块：**顶部工具条 → 主区域 → 底部状态栏**。主区域从左到右是 **缩略图栏 | 幻灯片 | 备注栏**，
两处边界各有一条独立的**竖向分隔条**（鼠标移上去变 ↔、亮起蓝线），按住左右拖即可调相邻两块的宽度，
松手自动记住；**双击**某条缝只恢复这一处默认宽度。关掉缩略图栏时左侧分隔条和缩略图栏一起收起；
关掉备注栏时右侧分隔条和备注栏一起收起；备注栏开着时翻到没有备注的页，栏内显示「这一页没有备注」、栏保持打开。

拖过的宽度记在 `Config\layout.json`（不是本工具的配置里，键名形如
`ppt-viewer.缩略图栏与幻灯片` / `ppt-viewer.幻灯片与备注栏`），全部恢复默认在
**主页设置 →「界面布局 → 恢复默认布局」**。约定见 [docs/dev/layout.md](../dev/layout.md)。

> 幻灯片是**矢量绘制**的：同一份绘制结果既当主视图按缩放放大，也当左侧缩略图缩到很小，
> 任意缩放下都清楚；适应窗口时按窗口大小等比缩放并留边。

## 怎么用

1. 在主页找到「**PPT 阅读器**」卡片（分类「文档」，也可以直接搜「PPT」/「pptx」/「演示」）打开。
2. 点工具条「**📽️ 打开演示文稿…**」（`Ctrl+O`），或者把 `.pptx` / `.pptm` / `.ppsx` 拖进页面。
3. 用左侧**缩略图**跳页，或用 `←` / `→` / `PageUp` / `PageDown` / `Home` / `End` 翻页。
4. 想看清细节：`Ctrl+滚轮` 或工具条 `−` / `+` 缩放（25% ~ 400%），点「适应窗口」回到铺满窗口；
   `Ctrl+0` 恢复 100%。
5. 想找字：按 `Ctrl+F` 输入内容，命中列表点一条跳到对应页；`回车` / `Shift+回车` 切换命中，`Esc` 清空。
6. 想看演讲者备注：点工具条「备注」打开右侧备注栏（默认收起）。
7. 需要本页文字：点「📋 复制本页文字」，粘到记事本 / 聊天窗口即可（只复制可见文字，不含备注）。
8. 想全屏演示：按 `F5` 进入全屏放映，`←` / `→` / 空格翻页，`Esc` 退出；
   隐藏幻灯片默认跳过（配置 `skipHiddenInShow` 可关）。
9. 下次接着看：直接关掉工具再打开同一份演示文稿，会自动回到上次那一页
   （可用配置里的 `rememberReadingPosition` 关掉）。
10. 想让双击演示文稿直接进本工具：工具条「**⚙ 设置**」勾选「双击 .pptx / .pptm / .ppsx 用本工具打开」
    （见上面「文件关联」一节）；右键「打开方式」的三个入口在 主页设置 → 打开方式关联 里开关。
11. 想编辑幻灯片？本工具**只读**，请用 PowerPoint / WPS 编辑原文件后重新打开。

## 设置项（`Config\ppt-viewer\config.json`）

改一下自动保存，**没有保存按钮**（配置文件由程序的配置存储统一维护）：

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `fitToWindow` | `true` | 是否「适应窗口」：开 = 按窗口大小铺满一页（默认）；关 = 用 `zoomPercent` |
| `zoomPercent` | `100` | 缩放百分比；超出 25 ~ 400 会被自动夹回（手改坏配置也不会缩放异常） |
| `showThumbnails` | `true` | 左侧缩略图栏是否显示 |
| `showNotes` | `false` | 右侧备注栏是否显示（默认收起，有备注时用户自己打开） |
| `skipHiddenInShow` | `true` | 放映时是否跳过隐藏幻灯片（默认跳过，和 PowerPoint 一致） |
| `rememberReadingPosition` | `true` | 是否记住每份演示文稿看到第几页；关掉后不再写新记录（**已有记录保留**） |
| `searchMatchCase` | `false` | 查找是否区分大小写（默认不区分） |
| `readingPositions` | `{}` | 每份演示文稿上次看到第几页：key 是规范化后的小写完整路径，value 含 `slideIndex`、`savedAtUtc`；最多 200 份，程序自动维护 |
| `recentLimit` | `50` | 最近打开最多记多少条（0 ~ 100；**0 = 不记录并清空列表**） |
| `recentEntries` | `[]` | 最近打开记录（路径 + 最后打开时间，新的在前；程序自动维护，一般不用手改） |
| `lastFolder` | `""` | 上次选文件所在文件夹，只作为打开对话框的起始目录，不会自动打开文件 |

缩略图栏 / 备注栏的**拖动宽度**不在这里，统一记在 `Config\layout.json` 的 `ppt-viewer.*` 键里。

## 文件关联（双击 .pptx 打开）

工具条「**⚙ 设置**」浮层里有一个「**双击 .pptx / .pptm / .ppsx 用本工具打开**」复选框：

- **勾选**：在 `HKCU\Software\Classes\YuLiangToolkit.PptViewer` 登记一个 ProgId，并把三种后缀写进
  `OpenWithProgids`（`Software\Classes\.pptx\OpenWithProgids` 与
  `Explorer\FileExts\.pptx\OpenWithProgids`），「打开方式」列表里就能选到「PPT 阅读器」，双击直接进本工具。
- **取消勾选**：只删本工具写的东西，并把登记前记下的原默认程序还原回去（不碰别的程序的 ProgId）。
- **只写当前用户（HKCU）**，不需要管理员；Windows 10/11 的**最终默认程序由「默认应用」里的 UserChoice 决定**，
  程序不能硬改——勾选后如果双击还是别的程序，点浮层里的「打开 Windows「默认应用」设置」选一次即可。
- 它和 **主页设置 → 打开方式关联** 是两套东西：主页那个是全局 3 个入口（按文件类型 / 文本 / 压缩包），
  其自动分流表已经包含 `.pptx` → PPT 阅读器；关闭全局开关时会顺手清掉本工具写进「打开方式」的引用，
  但**不删 ProgId、不改双击默认程序**。
- 文件关联**不在 `Config\ppt-viewer\config.json` 里**，是系统注册表状态；工具页重新打开时会重新读取，
  外部改过注册表也能反映出来（打开设置浮层时刷新）。

## 数据位置

- 配置：`Config\ppt-viewer\config.json`（首次打开工具时自动生成）。
- 布局：`Config\layout.json`（和其它工具页共用，主页设置里可以一键恢复默认）。
- **本工具不需要 `Data\ppt-viewer\`**：不拷贝、不缓存被浏览的演示文稿，也不生成临时文件
  （解析完就释放压缩包；缩略图与幻灯片都在内存里按需渲染）。
- **文件关联**：登记在 `HKCU\Software\Classes\YuLiangToolkit.PptViewer` 与三种后缀的 `OpenWithProgids`
  （**系统注册表，不在 `Config` / `Data` 里**；取消勾选会还原登记前的默认程序）。
- **主页「清理缓存」**里本工具提供两项：**最近打开记录**、**阅读位置记录**
  （只清这些使用痕迹，不动缩放 / 缩略图 / 放映等设置）。
- 程序数据都放在 exe 旁边；仓库根的同名目录只有说明，**不要**把演示文稿放进仓库目录。

## 实现说明

- **不引第三方库**：pptx 就是一个 ZIP 包 + 一堆 XML。ZIP 部件、关系（幻灯片 / 版式 / 主题 / 图片 / 备注）、
  安全读 XML、单位换算（EMU → WPF DIP，`9525 EMU = 1 DIP`）由 Core 的 `OoxmlPackage` 统一提供；
  PPT 自己的语义在 `Parsing/PptDocumentParser.cs` 里手写（幻灯片顺序、主题、版式 / 母版继承、形状、文字、备注）。
- **解析产出纯数据模型**（`Parsing/PptModel.cs`：`PptPresentation` / `PptSlide` / `PptShape` 层次 /
  `PptTextBody` / `PptTextRun` / `PptFill` / `PptTheme` …），不含 WPF 控件与图片句柄，
  所以可以在后台线程跑；解析结束即释放压缩包，只把文字与图片字节拷出来。
- **版式继承在解析阶段算完**：slide → layout → master 的占位符位置、字号、背景、主题色都解析成最终值，
  渲染器只按模型画、不再查主题 —— 自检因此可以只断言解析结果。
- **渲染在 UI 线程**：`Rendering/PptSlideRenderer.cs` 把一页画成 WPF `DrawingGroup`（已 `Freeze`，可跨线程复用）；
  同一份绘制结果既能当主视图（按缩放放大），也能当缩略图（缩到很小），矢量在任意缩放下都清楚。
- **查找是纯逻辑**：`Parsing/PptTextSearch.cs` 在每页的 `PlainText`（标题 + 正文 + 表格）与 `Notes` 里找子串，
  命中带来源（正文 / 备注）与上下文片段；大小写开关与空白查询规则都在这里，自检直接断言。
- **线程**：打开文件走 `Task.Run` 后台解析，界面状态通过基类的 `Ui(...)` / `UiAsync(...)` 切回 UI 线程；
  错误（坏文件 / 不存在的文件 / `.ppt`）显示在页面错误区，不弹 MessageBox。
- **安全**：禁 DTD / 外部实体（防 XXE）、单部件 128 MB / 整包 512 MB 上限（防压缩炸弹）；
  单个坏形状 / 缺部件降级跳过，不会因为一处损坏拒绝整份文件。
- **文件关联**：`PptFileAssociation.cs` 照 PDF / 图片阅读器的做法实现（ProgId + OpenWithProgids +
  Applications 的 `SupportedTypes`），只写 HKCU；在「⚙ 设置」浮层里勾选即可。
- 自检覆盖（`ppt-viewer` 分组，共 81 项）：工具元数据、16:9 尺寸换算与 `sldIdLst` 顺序、版式占位符继承、
  文字 run 格式 / 主题色 / 项目符号与级别、图片字节与裁剪、表格合并与填充、组合坐标与形状树计数、
  备注与 `PlainText`、查找（正文 / 备注 / 大小写 / 片段 / 统计文案）、缩放夹取与配置默认值、最近打开、
  阅读位置（保存 / 去重 / 上限淘汰 / 清空）、坏文件中文异常与坏形状降级、渲染器冻结与尺寸，
  以及文件关联的 ProgId / 后缀表 / 后缀判断 / 命令行拼装 / 状态说明（只读，不写注册表）。
