# 🃏 斗地主

> 经典斗地主：叫地主（1 / 2 / 3 分）、出牌、炸弹翻倍。
> 三种发牌模式：**经典** / **双副牌（炸弹多）** / **底牌明牌**。
> 局域网 3 人联机，房主可设**换人方式**，多出来的人排队上场。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> 在主页的 **🎲 棋牌** 类别里点进 斗地主（面包屑：`🏠 主页 › 🎲 棋牌 › 🃏 斗地主`）。
> 左侧「牌桌」与右侧「房间 / 设置」可左右拖；牌桌内部「三家信息 / 桌面 / 我的手牌」可上下拖。
> 拖完自动记住，双击某条缝只恢复这一处，全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **完整经典规则**：叫地主、三带一 / 三带二、顺子、连对、飞机（带单 / 带对）、四带二、
  炸弹、王炸；炸弹 / 王炸每出现一次，本局倍数翻一倍。
- **三种发牌模式**（右侧「发牌模式」下拉）：
  | 模式 | 牌 | 说明 |
  | --- | --- | --- |
  | 经典 | 1 副 54 张 | 三人各 17 张 + 3 张暗底牌 |
  | 双副牌（炸弹多） | 2 副 108 张 | 三人各 36 张，**4 个王（2 个王炸）、每种点数 8 张 → 炸弹明显更多** |
  | 底牌明牌 | 1 副 54 张 | 经典发牌，但 3 张底牌一开始就摊开，抢地主更刺激 |
- **联机 3 人 + 排队**：房间最多 16 人，其中 3 个席位在场打牌，其余人排队等下一局。
- **房主可设换人方式**（右侧「换人方式」）：
  1. **手动安排**：一局结束后房主自己指定谁上；
  2. **输的人下场，换排队中的下一位**；
  3. **全场换人**：不论输赢，场上的人全下场，换排队中的人上场。
  补位方式还分为「轮流上场（没上过场的优先）」与「随机上场」。

## 电脑对手（四档智慧程度）

右侧「电脑对手」卡片：单机时勾上就让电脑接管另外两家（你一个人也能打）。

| 难度 | 说明 |
| --- | --- |
| **入门** | 经常放过、偶尔乱压牌，适合练手 |
| **普通** | 会按牌型挑代价最小的一手，正常水平（默认） |
| **困难** | 会算残局、不乱拆炸弹 |
| **大师** | 叫分更准、残局算得清，比较难赢 |

- 叫地主：按手牌强度（王 / 2 / 炸弹）决定叫几分，不会瞎叫。
- 出牌：不压时先出小牌、留大牌；要压时挑最省的（不拆炸弹）。
- 只剩一手能出完时，会直接出完。

## 怎么玩

1. 点「开始一局」发牌（联机时由房主点，客户端自动同步）。
2. 叫地主：轮到的人点「不叫 / 叫 1 分 / 叫 2 分 / 叫 3 分」；叫 3 分直接定地主，
   三家都不叫则重新发牌。
3. 出牌：**点手牌选中 / 取消**（选中的牌会高亮），选好点「出牌」；
   不想压点「不要」；不确定能出什么点「提示」（列出所有能压过的牌型）。
4. 谁先出完手牌，谁那一方赢；地主赢则两个农民各输，农民赢则地主输，倍数按叫分 × 炸弹数。
5. 一局结束后按房主设的换人方式自动换人，并继续下一局。

## 联机怎么开

1. 房主填玩家名、端口留 `0`（自动挑），点「开房间」；把「复制」出来的地址发给朋友。
2. 朋友把地址粘到「加入房间」的输入框里点加入。
3. 人满 3 个自动坐满三个席位，第 4 个人开始就是**排队**状态，等换人时上场。
4. 对局中有人掉线：本局按「掉线方判负」处理，其余人继续。

## 设置项

存 `Config\doudizhu\config.json`（改一下自动保存）：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 发牌模式 | 经典 | 经典 / 双副牌（炸弹多）/ 底牌明牌 |
| 玩家名 | 空 | 联机时对方看到的名字；留空用系统用户名 |
| 开房端口 | 0 | 0 = 自动挑 |
| 上次加入的地址 | 空 | 「加入房间」输入框会带出来 |
| 换人方式 | 手动安排 | 手动 / 输的下场 / 全场换人 |
| 补位方式 | 轮流上场 | 轮流 / 随机 |

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 牌出不去 | 先看「选牌提示」：牌型不合法 / 压不过桌面都会写明原因 |
| 一直轮不到我出牌 | 上方「N 号位」那行会标「▶ 轮到」，看当前是谁的回合 |
| 我发不出牌但轮到我 | 只在**在场 3 个席位**上的人能出牌；排队中只能看 |
| 联机看不到别人的牌 | 正常：快照按座位分发，你只看得到自己的手牌 |
| 想换发牌模式 | 右侧「发牌模式」，联机时只有房主能改，下一局生效 |

## 自检

`board-new-games` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/BoardGamesNewGameChecks.cs`）覆盖斗地主部分：
牌堆构成（单副 54 / 双副 108、双副同名牌靠副数区分）、12 种牌型的识别与边界
（顺子不含 2 与王、最少 5 张、连对 ≥ 3 对、5 张同点非法）、比大小（同型同长比点数、
必须更大、炸弹压非炸弹、王炸最大）、提示只给能压过的牌、三种模式的发牌张数与不重不漏、
叫分必须更高 / 叫 3 分定地主、出牌与过牌、两家过牌清桌、结算倍数与得分、按座位生成的快照互不相同。
**纯逻辑，不建窗口、不联网。**
