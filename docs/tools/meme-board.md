# 😆 表情包收藏夹

> 工具 Id：`meme-board` ｜ 自检组：`meme-board` ｜ 配置：`Config\meme-board\config.json` ｜ 收藏图片：`Data\meme-board\images\`

> 把常用的表情包图片收进一个网格；**单击一张**就把图片复制到剪贴板，自动检测并置顶 QQ 窗口、
> 校验目标会话、聚焦聊天输入框、Ctrl+V 粘贴；设置里可以开 / 关自动发送（随机延迟）、
> 切换「仅复制到剪贴板」（防风控）、选择目标 QQ 会话。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**：左边「我的收藏」网格与右边「设置」之间可左右拖，拖完自动记住；
> 双击这条缝只恢复这一处，全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **收藏图片**：三种收进来的方式——「导入图片…」一次多选 / 直接把图片**拖进页面** / 复制一张图后点
  「从剪贴板添加」。图片都会**复制**进 `Data\meme-board\images\`，所以原图删了、挪了都不影响收藏。
  支持 `png` / `jpg` / `jpeg` / `gif` / `bmp`（大小写不敏感），其它格式会被跳过。
- **网格浏览 + 搜索**：缩略图按窗口宽度自动换行，文件名最多显示两行（完整路径看悬停提示），顶部有
  「共 N 张图片 · 占用空间」统计；搜索框按**文件名**过滤。
- **单击一张 = 复制并粘贴到 QQ**（默认）：复制到剪贴板 → 检测 QQ 窗口 → 选中目标会话 → 置顶并聚焦 QQ →
  校验当前会话 → 聚焦聊天输入框 → Ctrl+V 粘贴。每一步都写进「运行日志」，卡在哪一看就知道。
- **自动发送（可关）**：粘贴确认后随机等一小会儿（默认 0.5~1.5 秒，可调）再自动发送；发送前会**再确认
  前台仍是同一个 QQ 窗口**，中途切走了就不发。关闭后只把图片粘贴进输入框，由你自己按回车。
- **仅复制到剪贴板（防风控）模式**：点击只把图片放进剪贴板，**完全不碰 QQ**，适合怕自动操作太频繁、
  或想自己挑会话粘贴的场景。也可以右键单张图临时用「仅复制这张」或「粘贴到 QQ」。
- **目标 QQ 窗口检测**：下拉框列出当前检测到的 QQ 聊天窗口（读得到会话名的才算），如「测试群 · QQ 主窗口」
  「测试群 · QQ 窗口」；「刷新检测」重新枚举。选中的**会话名**会保存进配置，之后按会话名精确匹配。
- **粘贴前校验目标会话**（默认开）：粘贴前再读一次 QQ 当前会话，和保存的目标名不一致就中止，
  图片留在剪贴板供你手动粘贴——宁可提示「找不到 / 不一致」，也不把表情包误发到别的群。
- **右键菜单**：仅复制这张 / 粘贴到 QQ / 打开所在位置 / 从收藏删除（会真正删除数据文件，删前有确认）。
- **运行日志**：右侧卡片里实时显示检测窗口、命中目标、校验结果、粘贴 / 发送结果，便于排查；
  底部还有「清空日志」「打开数据文件夹」。

## 怎么用

1. **先把 QQ 目标群准备好**：登录 QQ（QQNT / TIM），在 QQ 里打开「测试群」——
   把 QQ 主窗口切到该群，或者双击群名打开**独立聊天窗口**，两种都能被识别。
   工具只负责「检测 / 校验 / 选择」会话，**不会自动帮你切换 QQ 会话**。
2. **选目标**：打开工具页 → 右侧「目标 QQ 窗口」点「刷新检测」→ 在下拉框里选「测试群」。
   状态行会显示「目标会话「测试群」已检测到」或「当前未检测到」；换群 / 重开 QQ 后点一次「刷新检测」即可。
3. **收图**：点「导入图片…」多选，或把图片拖进页面，或复制一张图后点「从剪贴板添加」。
   首次打开时页面中间会提示从哪里开始。
4. **单击收藏图片**（是单击，不是双击）：图片会被复制到剪贴板，然后按设置自动粘贴到 QQ。
   动作执行期间按钮会禁用；**1 秒内重复点击会被忽略**，防止焦点切走后连点误发。
5. **看自动发送**：默认开启。粘贴确认后随机等 0.5~1.5 秒再发送（优先点 QQ 的发送按钮，失败就聚焦输入框
   按回车），发送后确认输入框清空；等待期间**别切走**，否则发送前发现前台不是 QQ 会取消。
   想只粘贴不发送，把「粘贴后自动发送」的勾去掉。
6. **只复制不粘贴**：设置里选「仅复制到剪贴板（防风控）」，之后单击就只复制；或者对某一张右键
   「仅复制这张」临时走仅复制、右键「粘贴到 QQ」临时走完整流程（不受当前模式影响）。
7. **管理收藏**：搜索框过滤文件名；「刷新」重新扫描数据文件夹；选中一张后「删除选中」或右键
   「从收藏删除」（真删文件，不可撤销）；右键「打开所在位置」在资源管理器中定位原图。

> 粘贴到 QQ 的完整流程（日志里也是这几个阶段）：复制到剪贴板 → 检测 QQ 窗口 → 按会话名解析目标窗口
> →（最小化会先还原）置顶聚焦 QQ →「粘贴前校验」开时校验当前会话 → 聚焦聊天输入框 → Ctrl+V →
> 确认图片进了输入框（最多等 2.5 秒）→ 自动发送开时随机等待并再确认前台 → 发送 → 确认输入框清空
> （最多等 3 秒）。任何一步不满足都会**中止并告诉你原因**，图片始终留在剪贴板，可手动 Ctrl+V。

## 设置项

设置区在工具页右侧，改一下就自动存进 `Config\meme-board\config.json`，没有保存按钮。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 点击图片后 | 复制并粘贴到 QQ | 单选；另一项是「仅复制到剪贴板（防风控）」，只复制、完全不碰 QQ |
| 粘贴后自动发送（模拟回车） | 开 | 粘贴确认后自动发送；关掉则只粘贴进输入框。发送前会再确认前台仍是同一个 QQ 窗口 |
| 最短等待 / 最长等待 | 0.5 秒 / 1.5 秒 | 自动发送前随机等待的下限 / 上限；滑块范围 0.2~5 秒（内部允许 0.2~10 秒，超范围自动夹取，上下限填反会自动交换）。只在开启自动发送时生效 |
| 目标 QQ 窗口 | （空） | 下拉框只列出**读得到会话名**的 QQ 聊天窗口；「刷新检测」重新枚举。选中后把会话名保存进配置，之后按会话名精确匹配 |
| 粘贴前校验目标会话 | 开 | 粘贴前读一次 QQ 当前会话，和目标不一致就中止（图片留在剪贴板）。强烈建议保持开启 |

## 数据放在哪

- 配置：`Config\meme-board\config.json`（相对 **exe 所在目录**）——动作模式、目标会话名、自动发送开关、
  等待上下限（毫秒）、是否校验目标会话。
- 收藏图片：`Data\meme-board\images\`——导入 / 拖入 / 剪贴板添加都会把图片复制一份进来；
  同名文件自动改名 `名字 (1).png`，所以重复导入同一张会出现多份独立副本。**删了这个目录 = 收藏全丢。**
- 区块布局：跟其它工具页一样存在 `Config\layout.json`（键名前缀 `meme-board.`，目前只有一条
  `meme-board.收藏与设置`：收藏网格与设置卡片的左右分隔条）。
- 本工具**不写 `Cache\`**，「主页设置 → 清理缓存」不会动它。
- 「主页设置 → 重建配置」只把 `Config\meme-board` 恢复默认（目标会话、模式、延迟等回到默认值），
  **`Data\meme-board\images\` 里的收藏图片不动**。

## 常见问题

| 现象 | 原因 / 怎么改 |
| --- | --- |
| 支持 QQNT 吗？独立聊天窗口能用吗？ | 支持。顶层窗口按进程 `QQ` / `TIM` / `QQEX` 和窗口类 `Chrome_WidgetWin_1`（老版为 `TXGuiFoundation`）识别，主窗口与独立聊天窗口都算；会话名从窗口界面的 UIA 元素读取，**读不到会话名的窗口不会出现在下拉框**。QQ 大版本更新把界面元素改名时，检测 / 粘贴可能失效，需要等工具适配。 |
| 下拉框是空的 / 找不到目标群 | 多半是 QQ 没登录、没打开任何聊天窗口，或当前窗口读不到会话名。先登录 QQ、把目标群切到前台（或开独立聊天窗口），再点「刷新检测」。 |
| 窗口最小化还能粘贴吗？ | 能：粘贴前会先把 QQ 窗口还原再置顶聚焦。但如果检测时窗口还是最小化、界面没渲染，会话名可能读不出来——先还原窗口再点「刷新检测」。 |
| 提示「无法把 QQ 窗口切到前台」/ 前台焦点被抢 | Windows 的前台锁：别的程序（游戏、全屏应用、管理员权限窗口）占着前台时，系统会拒绝切窗口。工具会再重试一次并轮询约 1.5 秒，仍失败时图片仍在剪贴板，手动粘贴即可。关掉独占全屏、让两边权限一致一般能解决。 |
| 自动发送没生效 / 没发出去 | ① 先确认「粘贴后自动发送」是勾上的；② 随机等待期间切走了前台 → 发送前发现前台不是 QQ，会取消发送（图片仍留在输入框）；③ QQ 发送按钮 / 回车都失效时会提示手动发送。 |
| 自动发送延迟能调吗？ | 能：右侧「最短等待 / 最长等待」滑块（0.2~5 秒，内部允许 0.2~10 秒），上限小于下限会自动交换；只在开启自动发送时生效。 |
| GIF 发出去只有第一帧 | Windows 剪贴板只保存**静态位图**，本工具把图片放进剪贴板时也只能放第一帧（GIF 文件本身仍完整收藏在数据目录）。想发动图请在 QQ 里用「发送文件 / 从相册选」。 |
| 提示粘贴失败 / 快捷键没反应 | 部分安全软件会拦截模拟键盘（`SendInput`）。把本程序加入安全软件白名单；或用「仅复制到剪贴板」后自己按 Ctrl+V。 |
| 提示「当前会话是 X，与目标 Y 不一致」 | 开着「粘贴前校验目标会话」，而 QQ 当前会话不是目标。切回目标会话再点一次；临时关掉校验能绕过（不建议）。 |
| 单击图片没反应 | 1 秒内重复点击会被忽略（防连点误发）；另外确认图片文件还在（被删掉会在下次「刷新」后从列表消失）。 |
| 导入时有些文件被跳过 | 只支持 `png` / `jpg` / `jpeg` / `gif` / `bmp`；拖入的文件夹、`webp`、`txt` 等都会被忽略，状态栏会说明跳过了几个。 |
| 收藏里出现重复图片 | 导入时同名文件自动改名 `名字 (1).png`，重复导入同一张会出现多份独立副本；删其中一份不影响另一份。 |
| 删除能撤销吗？ | 不能。「从收藏删除」会把 `Data\meme-board\images\` 里的文件真正删掉（删前有确认框）。 |
| 搜索搜不到 | 搜索只按**文件名**过滤；换个关键字或清空搜索框恢复全部。 |
| 粘贴时会不会误发到别的群？ | 默认有双重保险：目标按**会话名精确匹配**（`测试群` 不会匹配 `测试群2` / `测试`，首尾空白与 emoji / 标点装饰会被忽略），粘贴前还会再校验一次当前会话；任一不符就中止，图片留在剪贴板。 |

## 自检

`meme-board` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/MemeBoardChecks.cs`，**49 条断言**）：工具元数据、
动作模式解析（`paste` / `clipboard`、未知值安全回退「仅复制」）、会话名归一与精确匹配
（空白 / emoji 装饰 / 大小写 / 前后缀不误匹配）、目标窗口解析（空目标不猜、多窗口非最小化优先、
按句柄取定、找不到返回空）、自动发送延迟夹取与随机取值范围、图片扩展名判定、剪贴板导入文件名、
配置默认值与 JSON 往返（走 `YLT_HOME` 临时数据根，不写仓库 Data/Config）。
全部是纯逻辑，**不碰 QQ / 剪贴板 / Win32 / 桌面**；真实置顶聚焦、粘贴、自动发送、仅复制模式由界面人工冒烟。
