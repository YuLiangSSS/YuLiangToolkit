# 🖱️ 右键菜单管理

> 把 Windows 资源管理器右键菜单里的项目列成一张表：不想要的一键**隐藏**、随时恢复；
> 残留的清不掉就**删除**（删前自动备份成 `.reg`）；缺的可以自己**添加「用 XX 打开」**。
> 隐藏只写**当前用户（HKCU）**的覆盖项；删除 HKLM 电脑级项会弹一次 UAC；添加只写 HKCU。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**（v0.42.0 起每个区块之间都能拖）：左边「右键菜单条目」列表和右边「详情 / 操作」之间可左右拖；
> 主区域和底部日志之间可上下拖，拖完自动记住；双击某条缝只恢复这一处，
> 全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- 扫描这些位置（顺序就是「位置」下拉框里的顺序）：**所有文件**、**所有文件系统对象**、**文件夹**、
  **文件夹空白处**、**驱动器**、**文件夹（Folder）**、**桌面背景**。
- 每一行列出一个菜单项：名称 + 类型（**菜单命令** / **扩展模块** / **自定义菜单**）+ 位置 + 状态
  （显示中 / 已隐藏 / 本工具隐藏 / 其他程序隐藏），行尾小按钮直接「隐藏 / 恢复显示」。
- 搜索框按名称、注册表路径、命令 / DLL 路径、类型、状态筛；还能只挑某个位置、某种类型，或者「只看已隐藏」。
- 详情卡里能看到注册表位置、命令 / DLL 路径、状态与来源说明；「隐藏 / 恢复显示」大按钮，注册表路径可以一键复制。
- **删除残留菜单**：某些软件卸载后菜单项还赖在右键里，可以直接**删掉它的注册表键**；
  删之前自动把键备份成 `.reg` 放到 `Data\context-menu-manager\backups\`，双击备份文件即可还原。
  HKCU 的项直接删；HKLM 电脑级的项会弹一次 **UAC** 提权删除。系统关键项（「打开」/「新建」）不给删。
- **添加「用 XX 打开」**：给指定后缀（例如 `.psd`、`.ai`）和 / 或**文件夹**、**文件夹空白处**、**所有文件**
  添加一条自己程序的右键菜单；只写 HKCU、不需要管理员权限，改菜单 = 先删再加。
- **「恢复全部（仅本工具隐藏的）」**：只清本工具写的隐藏标记，别的软件隐藏的东西一根手指都不碰。
- **「重启资源管理器」**：隐藏 / 删除 / 添加后菜单没变化时点一下（会关掉已经打开的文件夹窗口，
  任务栏闪一下后自动回来）。

## 怎么用

1. 打开工具，自动扫描一遍 —— 列表里就是这些位置现在能找到的全部菜单项。
2. 找某一项：搜索框敲关键词（例如「百度网盘」「WinRAR」「Git」），或者用「位置」「类型」下拉框缩小范围。
3. 选中一行 → 右边详情确认是要隐藏的那个 → 点「隐藏」；也可以直接点行尾的小按钮。
4. 正常情况立刻生效（或下一次右键时）；确认没问题就继续处理下一项。
5. 想改回来：同一行点「恢复显示」；之前隐藏了不少就用「恢复全部（仅本工具隐藏的）」一次清掉。
6. 隐藏 / 删除 / 添加完发现右键菜单没变化 → 点「重启资源管理器」（或注销 / 重启电脑）。

### 删除残留菜单

1. 选中要清理的菜单项（详情卡里会显示它实际占用的注册表键，可能 HKCU 和 HKLM 各有一份）。
2. 点「删除」→ 确认框里写明**删除不可撤回**（但会先备份）。
3. 工具先把要删的键用 `reg.exe export` 备份到 `Data\context-menu-manager\backups\`
   （文件名带时间戳和 HKCU / HKLM 前缀），再逐个删键。
4. HKCU 的键直接删掉；HKLM 的键没有权限，会**弹一次 UAC**，允许后由一个临时脚本批量删掉
   （只删这次选中的 HKLM 键）；取消 UAC 就什么都不删，工具会提示「需要管理员权限」。
5. 删完顺手清理变空的父键（例如 `SystemFileAssociations\.test\shell`），不留空壳。
6. **想反悔**：打开 `Data\context-menu-manager\backups\`，双击对应的 `.reg` 文件即可把键导回去。
7. **系统关键项不可删**：主操作 `open`（打开）和整个「新建」子菜单的扩展会被标成不可删除并说明原因。

### 添加「用 XX 打开」

1. 点「添加打开菜单」，填写表单：
   - **菜单名称**：右键里显示的文字（留空会按程序名自动填「用 XX 打开」）；
   - **程序**：选择要用来打开文件 / 文件夹的 `.exe`（必须是存在的完整路径）；
   - **文件后缀**：例如 `psd, ai`（逗号 / 分号 / 空格都行，点可省略，自动补点、转小写、去重）；
   - **作用范围**：可多选「**文件夹**」「**文件夹空白处**」「**所有文件**」，
     与上面的后缀至少填 / 勾一项。
2. 点确定 → 只往 **HKCU** 写这些键，不需要管理员权限：
   - 每个后缀：`HKCU\Software\Classes\SystemFileAssociations\<.后缀>\shell\<动词键>`，
     只影响这个后缀，**不改文件关联本身**；
   - 勾了文件夹：`HKCU\Software\Classes\Directory\shell\<动词键>`；
   - 勾了文件夹空白处：`HKCU\Software\Classes\Directory\Background\shell\<动词键>`；
   - 勾了所有文件：`HKCU\Software\Classes\*\shell\<动词键>`。
   - 动词键统一是 `YuLiangToolkit.Open.xxxxxxxx`（前缀 + 8 位随机串），列表里因此能认出「自定义菜单」。
3. 命令行：普通目标用 `"程序" "%1"`；**文件夹空白处**用 `"%V"`（右键处那个文件夹的路径）。
   图标直接取程序自己的：`"程序",0`。
4. **改已有的自定义菜单 = 先删再加**（菜单名称 / 程序 / 后缀不能就地编辑）：在列表里选中自定义菜单，
   先「删除」，再按新内容添加一次。删除同样会先备份。
5. 限制：一次最多添加 **12 个后缀**；只对**当前用户**生效（换用户 / 换机器要重新加）；
   后缀里只能写后缀本身，带路径 / 空格 / 特殊符号会被拦下并提示。

## 原理与安全（这一段重要）

**普通菜单命令**（「上传到百度网盘」「用 XXX 打开」这类）：
往 `HKCU\Software\Classes\<菜单所在的类>\shell\<动词名>` 写一个 `ProgrammaticAccessOnly` 值，数据是本工具的标记。
这是「程序还能调用、但资源管理器菜单里不显示」的公开开关；HKCU 的覆盖只对当前用户生效，
HKLM 里原始菜单键的**一个字节都不改**。

**COM 外壳扩展**（很多第三方右键菜单是这种）：往
`HKCU\Software\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked` 的黑名单里写一条，值名 = CLSID。
这是 Windows 自己的「阻止列表」，被列进去的扩展不再加载到资源管理器右键菜单。

- 隐藏只写 HKCU（当前用户），**不写 HKLM、不删任何原键、不需要管理员权限**；
- 本工具写的值数据统一带 `YuLiangToolkit.ContextMenuManager` 标记 ——「恢复全部」只清带标记的项，
  别的软件写的隐藏设置不会被误删；
- 恢复单项时如果那个 HKCU 键因此变空，会把空键一起删掉，不留空壳；
- **系统关键项不给隐藏 / 删除**：整个「新建」子菜单的 CLSID（`{D969A300-E7FF-11d0-A93B-00A0C90F2719}`）和主操作
  `open`（打开）不在可操作范围，免得把「打开」干掉、让用户以为文件坏了；
- 电脑级（HKLM）已经被其他程序 / 组策略隐藏的项只读展示，状态写「其他程序隐藏」，按钮不可点 ——
  本工具不改电脑级隐藏设置。

**删除（这个是真的删注册表键，看仔细）**：

- 只删选中条目**实际存在的那些键**（HKCU / HKLM 分别判断，`IContextMenuRegistry.TryDeleteKey` 报权限不足时记下来）；
- 删前一定先备份：`reg.exe export "<键>" "<备份 .reg>"`，备份放在 `Data\context-menu-manager\backups\`；
  备份失败 / 没删成功的键都不会被当成「已删除」；
- HKCU 的键通常不需要管理员权限；HKLM 的键会弹 **UAC**，由一个临时 `.cmd` 用
  `reg.exe delete "<HKLM 键>" /f` 逐个删（只包含这次选中的键，脚本里对键路径做引号 / 换行校验）；
- 删除后会清理本工具删出来的空父键（比如只剩空 `shell` 的 `SystemFileAssociations\.ext`）；
- **删除不可撤回**：除了那份 `.reg` 备份没有别的后悔药；备份目录默认不自动清理，需要时自己删。

**添加「用 XX 打开」**：

- 只写 **HKCU**，不动 HKLM、不动文件关联（`SystemFileAssociations` 是「给某后缀的右键加一条」，
  不是把后缀的默认打开方式改掉）；
- 动词键全部带 `YuLiangToolkit.Open.` 前缀，列表里显示成「自定义菜单」，删起来就是按这些键整组删；
- 表单先做纯逻辑校验（名称 / 程序是否存在 / 后缀格式 / 至少一个作用范围），校验不过一个键都不写；
  写键过程中出错会尽量把刚写的键回滚掉。

## Win11 的「显示更多选项」

Win11 把传统右键菜单收进了「**显示更多选项**」（Shift+F10，或者右键后点最后一项）。
本工具管的就是这里面那套传统菜单：隐藏 / 恢复 / 删除 / 添加在 Win10 和 Win11 上作用的都是这套菜单。

Win11 自带的新层菜单（以及 UWP / 打包应用注册的菜单项）**不在扫描范围** ——
它们不在这些传统注册表位置，由系统 / 应用自己管，本工具不去碰。

## 生效时机

- 大多数情况**立即生效**，或者下一次右键时生效；
- 个别菜单项是资源管理器启动时加载的 COM 扩展：隐藏 / 删除后要「重启资源管理器」才消失；
- 添加的自定义菜单通常下一次右键就出现，没出现也点「重启资源管理器」；
- 「重启资源管理器」会**关掉所有已打开的文件夹窗口**（有没保存的东西先处理好），任务栏闪一下后自动恢复。

## 限制

- 只扫描上面列的那几个传统位置；UWP 包 / Win11 新菜单项不在范围；
- 隐藏不写 HKLM 电脑级位置：对「所有用户都装了」的菜单项也只是在当前用户层面隐藏（HKCU 覆盖）；
- **删除不可撤回**，只有 `Data\context-menu-manager\backups\` 里的 `.reg` 备份能还原；
- 删除 HKLM 项需要管理员权限（会弹 UAC），取消就删除失败、一个键都不会删；
- 「新建」子菜单与「打开」被刻意保护，不能隐藏、也不能删除；
- 添加的菜单只属于**当前用户**，一次最多 12 个后缀；自定义菜单不能直接改名 / 改程序，要先删再加；
- 有些软件的菜单项是它主程序运行时才动态加上的（不常驻注册表），扫描时可能看不到，或者删了它又加回来；
- 添加时如果程序路径后来被移走 / 改名，菜单还在但点了会打不开，删掉重加即可。

## 设置项与数据

| 位置 | 内容 |
| --- | --- |
| `Config\context-menu-manager\config.json` | 「位置」「类型」两个下拉筛选与「只看已隐藏」开关；改完自动保存，下次打开还是上次那套（搜索框只存在本次运行内存里） |
| `Data\context-menu-manager\backups\` | **删除前的 `.reg` 备份**（`reg.exe export` 导出，文件名带时间 + HKCU / HKLM + 键路径）。双击即可还原；本工具不自动清理，留着自己管 |
| 注册表 | **隐藏**标记写在 `HKCU\Software\Classes\...` 与 `HKCU\Software\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked`，都带 Marker，可用「恢复全部」清干净；**删除**会真的删掉选中条目的 HKCU / HKLM 菜单键（删前已备份）；**添加**只写 `HKCU\Software\Classes\` 下的 `SystemFileAssociations\.后缀\shell\`、`Directory\shell\`、`Directory\Background\shell\`、`*\shell\`，动词键带 `YuLiangToolkit.Open.` 前缀 |

## 排查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 隐藏后右键菜单没变化 | 资源管理器缓存了菜单，或这项是启动时加载的 COM 扩展 | 点「重启资源管理器」；还不行就注销 / 重启电脑 |
| 下次打开工具，这项状态又变成「显示中」 | 那个软件启动时重写了注册表（或又装回来了） | 先关掉该软件自己的「右键菜单集成」选项，再隐藏一次 |
| 状态显示「其他程序隐藏」 | HKCU / HKLM 里已有别的软件写的隐藏值 | 想恢复就点「恢复显示」（会删掉 HKCU 那条值）；HKLM 电脑级的恢复按钮是灰的 |
| 列表里找不到某个菜单项 | 它在 Win11 新菜单 / UWP 包注册，或只在程序运行时动态添加 | 本工具不覆盖这些位置，去那个软件自己的设置里关 |
| 点「删除」后弹 UAC，允许了还是没删掉 | 那个键被系统 / 别的程序保护，或用户取消了授权 | 看日志里的「权限不足」提示；HKCU 的项不需要 UAC，HKLM 的项要允许管理员权限 |
| 删错了 / 删完想恢复 | 删除不可撤回 | 到 `Data\context-menu-manager\backups\` 找那个带时间戳的 `.reg`，双击导入后重启资源管理器 |
| 添加的自定义菜单没出现 | 资源管理器缓存 | 点「重启资源管理器」；确认勾选的作用范围（后缀 / 文件夹 / 空白处 / 所有文件）包含当前右键的位置 |
| 添加时提示「后缀不合法」 | 后缀里带了路径 / 空格 / 特殊符号 | 只写后缀本身（例如 `psd` 或 `.psd`），多个用逗号 / 分号 / 空格隔开 |

## 相关代码

- 项目：`src/YuLiangToolkit.Tools.ContextMenu/`
  - `ContextMenuContracts.cs` —— 契约、扫描位置、Marker、关键项与 CLSID 规范化、自定义菜单纯规则（纯逻辑）
  - `ContextMenuService.cs` —— 枚举 / 隐藏 / 恢复 / 恢复全部 / 删除 / 添加自定义菜单（只依赖注册表接口，便于自检替换）
  - `ContextMenuDeletion.cs` —— 删除前 `.reg` 备份 + HKLM 提权删除（临时 `.cmd` + `reg.exe delete`）
  - `ContextMenuAddResult.cs` —— 添加自定义菜单的结果
  - `RegistryContextMenuStore.cs` —— 真实注册表读写（Microsoft.Win32.Registry）
  - `ViewModels/`、`Views/` —— 列表 / 详情 / 日志界面
- 自检：`tests/YuLiangToolkit.FrameworkSelfCheck/ContextMenuChecks.cs`（内存假注册表断言，**绝不写真实注册表**）
