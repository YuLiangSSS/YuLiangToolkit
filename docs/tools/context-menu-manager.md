# 🖱️ 右键菜单管理

> 把 Windows 资源管理器右键菜单里的项目列成一张表，不想要的一键隐藏、随时恢复。
> 只写**当前用户（HKCU）**注册表里的覆盖项：不删原菜单、不改电脑级（HKLM）设置、**不需要管理员权限**。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**（v0.42.0 起每个区块之间都能拖）：左边「右键菜单条目」列表和右边「详情 / 操作」之间可左右拖；
> 主区域和底部日志之间可上下拖，拖完自动记住；双击某条缝只恢复这一处，
> 全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- 扫描这些位置（顺序就是「位置」下拉框里的顺序）：**所有文件**、**所有文件系统对象**、**文件夹**、
  **文件夹空白处**、**驱动器**、**文件夹（Folder）**、**桌面背景**。
- 每一行列出一个菜单项：名称 + 类型（**菜单命令** / **扩展模块**）+ 位置 + 状态
  （显示中 / 已隐藏 / 本工具隐藏 / 其他程序隐藏），行尾小按钮直接「隐藏 / 恢复显示」。
- 搜索框按名称、注册表路径、命令 / DLL 路径、类型、状态筛；还能只挑某个位置、某种类型，或者「只看已隐藏」。
- 详情卡里能看到注册表位置、命令 / DLL 路径、状态与来源说明；「隐藏 / 恢复显示」大按钮，注册表路径可以一键复制。
- **「恢复全部（仅本工具隐藏的）」**：只清本工具写的隐藏标记，别的软件隐藏的东西一根手指都不碰。
- **「重启资源管理器」**：隐藏后菜单没变化时点一下（会关掉已经打开的文件夹窗口，任务栏闪一下后自动回来）。

## 怎么用

1. 打开工具，自动扫描一遍 —— 列表里就是这些位置现在能找到的全部菜单项。
2. 找某一项：搜索框敲关键词（例如「百度网盘」「WinRAR」「Git」），或者用「位置」「类型」下拉框缩小范围。
3. 选中一行 → 右边详情确认是要隐藏的那个 → 点「隐藏」；也可以直接点行尾的小按钮。
4. 正常情况立刻生效（或下一次右键时）；确认没问题就继续处理下一项。
5. 想改回来：同一行点「恢复显示」；之前隐藏了不少就用「恢复全部（仅本工具隐藏的）」一次清掉。
6. 隐藏完发现右键菜单没变化 → 点「重启资源管理器」（或注销 / 重启电脑）。

## 原理与安全（这一段重要）

**普通菜单命令**（「上传到百度网盘」「用 XXX 打开」这类）：
往 `HKCU\Software\Classes\<菜单所在的类>\shell\<动词名>` 写一个 `ProgrammaticAccessOnly` 值，数据是本工具的标记。
这是「程序还能调用、但资源管理器菜单里不显示」的公开开关；HKCU 的覆盖只对当前用户生效，
HKLM 里原始菜单键的**一个字节都不改**。

**COM 外壳扩展**（很多第三方右键菜单是这种）：往
`HKCU\Software\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked` 的黑名单里写一条，值名 = CLSID。
这是 Windows 自己的「阻止列表」，被列进去的扩展不再加载到资源管理器右键菜单。

- 只写 HKCU（当前用户），**不写 HKLM、不删任何原键、不需要管理员权限**；
- 本工具写的值数据统一带 `YuLiangToolkit.ContextMenuManager` 标记 ——「恢复全部」只清带标记的项，
  别的软件写的隐藏设置不会被误删；
- 恢复单项时如果那个 HKCU 键因此变空，会把空键一起删掉，不留空壳；
- **系统关键项不给隐藏**：整个「新建」子菜单的 CLSID（`{D969A300-E7FF-11d0-A93B-00A0C90F2719}`）和主操作
  `open`（打开）不在可操作范围，免得把「打开」干掉、让用户以为文件坏了；
- 电脑级（HKLM）已经被其他程序 / 组策略隐藏的项只读展示，状态写「其他程序隐藏」，按钮不可点 ——
  本工具不改电脑级设置。

## Win11 的「显示更多选项」

Win11 把传统右键菜单收进了「**显示更多选项**」（Shift+F10，或者右键后点最后一项）。
本工具管的就是这里面那套传统菜单：隐藏 / 恢复在 Win10 和 Win11 上作用的都是这套菜单。

Win11 自带的新层菜单（以及 UWP / 打包应用注册的菜单项）**不在扫描范围** ——
它们不在这些传统注册表位置，由系统 / 应用自己管，本工具不去碰。

## 生效时机

- 大多数情况**立即生效**，或者下一次右键时生效；
- 个别菜单项是资源管理器启动时加载的 COM 扩展：隐藏后要「重启资源管理器」才消失；
- 「重启资源管理器」会**关掉所有已打开的文件夹窗口**（有没保存的东西先处理好），任务栏闪一下后自动恢复。

## 限制

- 只扫描上面列的那几个传统位置；UWP 包 / Win11 新菜单项不在范围；
- 需要管理员权限才能写的位置（HKLM 电脑级）本工具不会去写，因此对「所有用户都装了」的菜单项
  也只是在当前用户层面隐藏（HKCU 覆盖）；
- 有些软件的菜单项是它主程序运行时才动态加上的（不常驻注册表），扫描时可能看不到，或者隐藏后它又加回来；
- 「新建」子菜单与「打开」被刻意保护，不能隐藏。

## 设置项与数据

| 位置 | 内容 |
| --- | --- |
| `Config\context-menu-manager\config.json` | 「位置」「类型」两个下拉筛选与「只看已隐藏」开关；改完自动保存，下次打开还是上次那套（搜索框只存在本次运行内存里） |
| `Data\context-menu-manager\` | 没用到（本工具不落业务数据） |
| 注册表 | 隐藏标记写在 `HKCU\Software\Classes\...` 与 `HKCU\Software\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked`，都带 Marker，可用「恢复全部」清干净 |

## 排查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 隐藏后右键菜单没变化 | 资源管理器缓存了菜单，或这项是启动时加载的 COM 扩展 | 点「重启资源管理器」；还不行就注销 / 重启电脑 |
| 下次打开工具，这项状态又变成「显示中」 | 那个软件启动时重写了注册表（或又装回来了） | 先关掉该软件自己的「右键菜单集成」选项，再隐藏一次 |
| 状态显示「其他程序隐藏」 | HKCU / HKLM 里已有别的软件写的隐藏值 | 想恢复就点「恢复显示」（会删掉 HKCU 那条值）；HKLM 电脑级的恢复按钮是灰的 |
| 列表里找不到某个菜单项 | 它在 Win11 新菜单 / UWP 包注册，或只在程序运行时动态添加 | 本工具不覆盖这些位置，去那个软件自己的设置里关 |
