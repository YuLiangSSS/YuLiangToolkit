# ⏳ 倒计时

> 设个时长、按开始就倒数；到点弹通知并响铃。四个操作都能设全局快捷键。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md) ｜ [快捷键与通知](../dev/shortcuts.md)

## 能做什么

- **任意时长**：输入框支持四种写法
  - `90` —— 纯数字 = 秒
  - `5:30` —— 分:秒
  - `1:02:03` —— 时:分:秒
  - `1h30m` / `90s` / `5m` —— 带单位（也认 `1时30分`）
- **快捷预设**：默认 1 分钟 / 5 分钟 / 10 分钟 / 30 分钟，点一下就填进时长框。
- **四个动作**：开始 / 继续、暂停、重置、**+1 分钟**（临时延时不用重设）。
- **进度环**：环随剩余时间收缩，一眼看出还剩多少（可关掉只留数字）。
- **到点**：弹通知 + 响铃（可静音、可自选 `.wav`）。

## 全局快捷键

| 动作 | 默认 | 说明 |
| --- | --- | --- |
| 开始 / 继续 | `Ctrl+Alt+D` | 在浏览器、游戏、编辑器前面都能按，**按一下立刻开始倒计时** |
| 暂停 | 未设置 | 点框自己录一个 |
| 重置 | 未设置 | |
| +1 分钟 | 未设置 | |

- 每条都能单独禁用；整个工具也能一键关。
- 也可以在「主页设置 → 快捷键」统一改（两处共用同一份配置）。

## 通知

- **到点一定会弹**（不管程序在不在前台、你在不在这个页面）—— 这是倒计时的意义所在。
- **快捷键操作**（开始 / 暂停 / 重置 / 加时）只在**没在看这个页面**时弹，避免重复打扰。
- 通知设置是这个工具自己的一份：通道（应用内 / Windows）、四个角、停留时长。

## 数据放在哪

- 配置：`Config\countdown\config.json`（上次的时长、快捷键、声音、通知偏好）
- **不保留「还剩多少」**：关掉程序再打开就是停着的状态。倒计时不该跨进程续跑（电脑关了一晚上，醒来还剩 3 分钟没有意义）。

## 注意事项

- 计时用的是单调时钟（不受系统时间被改影响）。
- 不做「多个并行倒计时」：要同时盯几件事请用「闹钟」，或者开多个程序实例。
