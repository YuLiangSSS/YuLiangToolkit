# 🎧 osu! 下图器

> 把 osu! 的谱面集（beatmap）搜出来、批量下成 `.osz`。
> **搜索走 osu! 官方 API，下载走第三方镜像。**（从早先那个独立小程序 `MapDownloader` 改写过来，用法基本没变。）
>

## 能做什么

- **搜索**：关键词（标题 / 艺术家 / 作者）、模式（osu! / Taiko / Catch / Mania）、状态（Ranked / Loved / …）、
  排序（相关性 / 标题 / 艺术家 / 难度 / Ranked 时间 / 评分 / 游玩次数 / 收藏数）、是否带 NSFW。
  - **日期范围与 Key 数（mania 的键数）是本地筛选**：接口不支持这两项，所以是拉回来之后再筛的
    （界面上也写明了，免得以为搜不到）；
  - 「**加载更多**」按游标取下一页；「**获取全部**」沿着游标一直取到底（再点一次 = 停止，几千条也能拉）。
- **下载**：结果表里勾上要的那些行（或「全选」），然后四个按钮里挑一个 ——
  「选中 / 全部」×「无视频 / 含视频」。含视频的包大得多，自己权衡。
- 文件存成 `{谱面集Id} {标题}.osz`；**已经在的直接跳过**；**中途取消 / 断线不会留下半个坏文件**
  （先下 `.part` 再改名）。

## 怎么用

1. **先配凭据**：去 osu! 官网的 [OAuth 应用页面](https://osu.ppy.sh/home/account/edit#oauth) 注册一个应用
   （Client Credentials 授权），把 **Client ID** 与 **Client Secret** 填进「① API 凭据」→ 点「获取 Token」。
   换到的 Token 存在配置里（约 24 小时有效），下次打开会自动续；勾着「打开工具时自动换 Token」就不用管它。
2. 填搜索条件 → 「搜索」。想多要点就「加载更多」或「获取全部」。
3. 勾要下的行（或全选）→ 点对应按钮。下载进度、失败原因、跳过数量都会实时报。
4. **导进游戏**：把 `.osz` 双击（或拖进 osu! 窗口）就会自动导入，之后可以删掉原文件省地方。

## 设置项

| 设置 | 存哪 | 说明 |
| --- | --- | --- |
| Client ID / Client Secret / Access Token 与到期时间 | `Config\map-downloader\config.json` | Client ID 按文本存（粘贴带空格也能用） |
| 打开工具时自动换 Token | 同上 | 默认开 |
| 搜索条件（关键词 / 模式 / 状态 / 排序 / NSFW / 日期 / Key 数） | 同上 | 下次打开还是上次那套 |
| 下载目录与并发数 | 同上 | 默认 `Data\map-downloader\downloads\`，**可以换成任意目录** |

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\map-downloader\config.json` | 凭据 + 搜索条件 + 下载目录与并发 |
| `Data\map-downloader\downloads\*.osz` | 下回来的谱面包（可在界面上改目录） |

## 注意

- ⚠️ **Client Secret 与 Token 是明文存在配置文件里的**（和原版一样，只适合本机自用）。
  那个文件在 `Config\` 下、已被 `.gitignore` 忽略 —— **别把它拷给别人**。
- 下载依赖第三方镜像（`dl.sayobot.cn`），镜像抽风时只能等或换个时间；
  镜像地址写死在代码里，`OszDownloader.MirrorBase` 可以改（自检就是指向本地假镜像）。
- 谱面集被作者下架 / 删除时，镜像会 404，这时只能放弃。
- 已导入过的 `.osz` 删掉无妨，**重新下要再花一次流量**。
