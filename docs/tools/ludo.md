# ✈️ 飞行棋

> 红黄蓝绿四色、**谁进来谁点颜色坐下**（也能退出让位）；房主可自由开关规则，
> 包括「掷 5 也能起飞」的后门规则、踩子踢回家、**经过中央飞行线踢子**、临近终点必须掷到刚好点数。支持局域网联机。

## 座位：自己选颜色

- 右侧「座位」里点 **红位 / 黄位 / 蓝位 / 绿位** 就坐下；**点自己已经占的位子就是退出**，位置空出来给别人。
- 想换颜色？直接点另一个空位，会自动从原来的颜色挪过去。
- 别人已经占的位子点了会提示「已经有人了」。
- **两个颜色以上有人就能开局**（最多四个）。

## 规则（房主可改）

| 规则 | 默认 | 说明 |
| --- | --- | --- |
| 掷 6 才能起飞 | 开 | 关掉后掷 1 或 6 都能起飞 |
| **额外规则：掷 5 也能起飞** | 关 | 你要求的「后门起飞」 |
| 掷 6 可以再掷一次 | 开 | |
| **临近终点必须掷到刚好点数** | 开 | 掷多了**往回走**（不会停在终点） |
| **踩到别人棋子，让对方回家** | 开 | 落到对方棋子的格子上，对方回大本营 |
| **经过中间横向飞行线，也能把线上棋子打回家** | 开 | 中央那几格黄色飞行线，走过时线上有对方棋子就打回家 |

## 怎么玩

1. 点颜色坐下（两个颜色以上），房主点「开新局」。
2. 轮到你时点「掷骰子」，再点棋盘上**金色描边**的棋子走棋（或点「自动走一步」让程序帮你挑：优先能踢人的）。
3. 踩到别人棋子 → 对方直接回大本营；走过中央飞行线 → 线上的对方棋子也回家。
4. 四个棋子全部到终点就完成；只剩一个颜色没完成时对局结束。

## 电脑玩家（四档难度）

单机玩时可以把任意颜色设为电脑：「电脑玩家」卡片里点 红 / 黄 / 蓝 / 绿 即可切换。

| 难度 | 策略 |
| --- | --- |
| **入门** | 随机挑一枚能走的（会浪费踢人 / 进终点的机会） |
| **普通** | 踢人 &gt; 进终点 &gt; 起飞 &gt; 走得远 |
| **困难** | 再加「别送子」：走到别人一个骰子范围内要扣分 |
| **大师** | 全局评估：已完成数、剩余棋子总进度、被反杀风险 |

电脑会自动「掷骰 → 选子走」，走完自动轮到下一位。

## 联机

1. 房主填玩家名点「开房间（当房主）」，把地址发给朋友。
2. 朋友粘地址点「加入房间」。
3. **每个人自己点颜色坐下**，房主点「开新局」。
4. 房主权威：房主跑规则、广播座位与棋子位置，客户端只上报「我要掷骰 / 我要走这枚」。

## 设置项

存 `Config\ludo\config.json`：玩家名、上次加入地址、开房端口、六个规则开关。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 点了颜色没反应 | 那个颜色已经有人了（会提示名字） |
| 掷了骰子但棋子不能点 | 只有**你自己的、且能走的**棋子会亮金边 |
| 掷 5 起不了飞 | 「掷 5 也能起飞」没开（房主在规则里勾上） |
| 快到终点却往回退了 | 正常：「必须掷到刚好点数」开着，掷多了会退 |
| 别人的棋子突然回家了 | 你踩到了他，或你走过飞行线时他在线上 |

## 自检

`ludo` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/LudoChecks.cs`）：15×15 棋盘 / 52 格外圈不重复 /
四色起点等距 / 回家通道 6 格 / 飞行线位置、开局校验、起飞规则（6 点 / 后门 5 点 / 关掉必须 6）、
**精确到终点（掷多了往回退）**、踩子踢回家、**经过飞行线踢子**、掷 6 再掷、已完成颜色跳过回合、胜负判定。
**纯逻辑，不建窗口、不联网。**
