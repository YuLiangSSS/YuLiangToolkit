# 🐍 贪吃蛇

> 两种对战玩法：**共享果**（分区域抢同一颗果）与**大混战**（多蛇多果、蛇命、出生点爆炸）。
> 可调棋盘、果子上限、命数、限时、边缘规则、**按住加速**；**九档 AI**（参考「九条蛇」算法）；局域网联机。

## 两种玩法

### ① 共享果（分区域抢果）

- 把棋盘横向切成 **N 个区域**（房主设区域数，= 几条蛇），每条蛇只在自己的区域里活动。
- 场上**始终只有 1 颗果子**，并且**在所有区域里的相对位置相同**。
- 谁先吃到，谁**得分 +1、蛇身 +1 格**，然后果子立刻在所有区域一起换位置。
- 比的是**综合评分**（见下），不是单纯比谁活到最后。

### ② 大混战（多蛇多果）

- 一整张大棋盘，多条蛇（房主设人数上限）在**随机且互不重复**的出生点出生，蛇与蛇之间尽量隔开。
- 场上可以同时有**多颗果子**（房主设上限），吃掉一颗立即补一颗。
- 每条蛇有**多条命**（房主设），死了会重生（见「重生」）。
- 房主可以开**出生点 3×3 爆炸**：出生点周围一圈变成危险区，防止有人蹲点堵出生。

## 评分（谁赢）

按需求指定的权重综合评分，**吃果数量权重最重**：

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| 吃果数量 | **60%** | 吃得越多分越高 |
| 存活时间 | 20% | 活着走了多少步 |
| 连吃速度（combo） | 20% | 连续吃果的最长纪录 |

三项分别按「全场最高值」归一化后加权，所以 **吃果多的人一定占优**。

## 边缘规则（房主可选）

| 规则 | 效果 |
| --- | --- |
| **撞墙即死**（默认） | 撞到棋盘边缘立刻死 |
| **停住不动** | 撞到边缘时停住，不死也不前进 |
| **穿墙** | 从另一边出来（额外送的经典玩法） |

## 重生

- 死亡后进入**重生倒计时**（不是立刻复活），复活后**保留原蛇身长度**（房主可关）。
- 复活后有一小段**虚化保护**（半透明、能穿过别的蛇、不会受伤）。
- 死亡位置会留一条**半透明残影**（80% 透明）。

## 加速

- 房主可以在开局前选择**是否开启加速**。
- 开启后按住 **Shift** 即加速（倍率可调，默认 2×）。

## 操作

| 按键 | 作用 |
| --- | --- |
| ← → ↑ ↓ / WASD | 转向（不能 180° 掉头） |
| 按住 **Shift** | 加速（开启时） |
| 空格 | 开始 / 重开 |

## 电脑对手（九档 AI）

参考 [moe-new/snake-ai](https://github.com/moe-new/snake-ai) 的「九条蛇」，**AI 等级 1~9 直接对应九种算法**，
等级越高越聪明。每条算法都做了一处**对战适配**（原版是单人吃满棋盘，对战里要考虑别的蛇）：

| 等级 | 算法 | 怎么走 | 对战适配 |
| --- | --- | --- | --- |
| 1 | 莽夫 | 只认最短路 | 别的蛇挡路也照冲（最蠢，会送） |
| 2 | 谨慎 | 吃前先试回尾巴才吃 | 把别的蛇当障碍绕开 |
| 3 | 循规蹈矩 | 沿绕遍全盘的环线 | 环线被占就换方向 |
| 4 | 抄近路 | 沿环线，能跳就跳 | 跳之前看别的蛇会不会撞 |
| 5 | 单行道 | 每格只开两个出口 | 抢占窄道，逼别人进不来 |
| 6 | 步步为营 | 吃前先画好退路 | 退路要算别的蛇的走位 |
| 7 | 动态回路 | 换环线接口让食物更近 | 优先往有果子的方向换 |
| 8 | 可达保护 | 吃前多查会不会被隔开 | 还要看会不会被别的蛇封死 |
| 9 | 加权 Cell | 2×2 连树 + 最短路 | 树里也躲着别的蛇（最聪明） |

房主可以设 **AI 数量**与 **AI 等级**；单人玩就是「你 + N 个电脑」。

## 联机（局域网 TCP）

1. 房主填玩家名、端口留 `0`，点「开房间（当房主）」，把地址发给朋友。
2. 朋友粘地址点「加入房间」。
3. 房主调好设置后点「开始游戏」——**房主权威**：房主跑引擎、广播每帧状态，客户端只上报方向。
4. 设置（棋盘 / 果子 / 命数 / 限时 / 边缘 / 加速 / AI）都由房主统一广播。

## 设置项

存 `Config\snake\config.json`：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 玩法 | 大混战 | 共享果 / 大混战 |
| 棋盘宽 × 高 | 40 × 30 | 两轴可单独设 |
| 人数上限 | 4 | 2~8 |
| 命数 | 3 | 1~10 |
| 果子上限 | 5 | 共享果恒为 1 |
| 共享果区域数 | 2 | 2~6 |
| 限时 | 120 秒 | 0 = 不限 |
| 倒计时 | 3 秒 | 开局前的准备时间 |
| 爬行速度 | 8 格/秒 | 2~24 |
| 边缘规则 | 撞墙即死 | 死 / 停 / 穿墙 |
| 开启加速 | 是 | 按住 Shift |
| 加速倍率 | 2.0 | 1.2~4 |
| 重生保留长度 | 是 | |
| 出生点 3×3 爆炸 | 是 | 防堵点 |
| 共享果断 combo | 是 | 没吃到就断连 |
| AI 数量 / 等级 | 1 / 3 | 等级 1~9 |

## 自检

`snake` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/SnakeChecks.cs`）：设置夹取、蛇身 / 方向 / 克隆、
吃果增长、三种边缘规则、撞自己 / 撞别人 / 头对头、重生倒计时与虚化保护、共享果刷新、
大混战多果与出生点不重复、评分权重（60/20/20）、九档 AI 都能给出合法方向且高等级活得更久。
**纯逻辑，不建窗口、不联网。**
