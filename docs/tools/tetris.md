# 🧱 俄罗斯方块

> 经典 10×20 俄罗斯方块：**7-bag** 出块、**SRS 旋转 + 墙踢**、**幽灵方块**落点预览、
> **暂存（Hold）**、**接下来 3 块**预览；消行得分升级、等级越高落得越快，最高分自动记住。
> 还能**局域网 1 对 1 联机**：垃圾行互攻 / 各自计分两种模式。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> 在主页的 **🎮 游戏** 类别里点进 俄罗斯方块（面包屑：`🏠 主页 › 🎮 游戏 › 🧱 俄罗斯方块`）。
> 界面左上「棋盘」与右侧「本局 / 联机房间 / 设置」可左右拖；右列里每一块之间都能上下拖。
> 拖完自动记住，双击某条缝只恢复这一处，全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **标准现代俄罗斯方块规则**，不是简化版：
  - 7 种方块（I / J / L / O / S / T / Z），**7-bag 随机**：每一轮把 7 种洗一遍依次给出，
    所以不会连着出同一块，也不会久等不来某一块；
  - **SRS 旋转 + 墙踢**：贴墙、贴地时旋转会自动挪一格（I 的踢墙表与其它方块不同，按标准做）；
  - **软降 / 硬降**：软降一格 +1 分，硬降按落下的格子数加分并立刻锁定；
  - **幽灵方块**：实时显示当前方块落到最底的位置（可关）；
  - **暂存（Hold）**：把当前方块存起来换出下一块；一个方块落地前只能换一次；
  - **接下来 3 块**预览。
- **计分与升级**：消 1 / 2 / 3 / 4 行分别得 100 / 300 / 500 / 800 分 × 当前等级；
  每消 10 行升 1 级，等级越高下落越快（800ms 起，每级快 12%，最快 60ms）；等级封顶 20。
- **自动记住最高分**：游戏结束时刷新纪录会标「新纪录」。
- **一屏看全**：页面不进滚动条，棋盘按窗口高度自适应（窗口拉大棋盘跟着变大）。
- **切走就暂停**：切到别的工具页 / 切走程序窗口都会自动暂停（后者可在设置里关），
  切回来点「继续」接着玩 —— 不会出现「换首歌回来已经堆满」。

## 怎么玩

1. 打开工具页，棋盘上是「准备好了吗」遮罩，按 **任意方向键** 或点「开始游戏」开局。
2. 想先看规则：点页面底部 **「？ 游玩说明」** 按钮（或按 `F1`）会弹出**游玩说明窗口** ——
   每个键干什么、计分怎么算、联机怎么开房间、几条实战小技巧都在里面。**打开说明时游戏会自动暂停**，
   关掉窗口后点「继续」接着玩。
3. 键盘操作（页面上任何位置都生效）：

   | 按键 | 作用 |
   | --- | --- |
   | `←` / `→` | 左右移动 |
   | `↓` | 软降一格（按住会连续下） |
   | `↑` 或 `X` | 顺时针旋转 |
   | `Z` | 逆时针旋转 |
   | `空格` | 硬降（直接落到底并锁定） |
   | `C` | 暂存 / 换出（一手只能换一次） |
   | `Esc` 或 `P` | 暂停 / 继续 |
   | `R` | 重新开始 |
   | `Enter` | 开始 / 继续 |
   | `F1` | 打开 / 关掉游玩说明 |

4. 不想用键盘也行：页面底部有一排按钮（← → ↓ 软降 ↻ 顺时针 ↺ 逆时针 硬降 暂存 ？ 游玩说明）。
5. 方块堆到顶部、下一块出不来时游戏结束，点「重新开始」或按 `R` 再来一局。

## 联机对战（局域网 1 对 1）

页面顶部有三个单选项：**单人** / **联机 · 垃圾行互攻** / **联机 · 各自计分**。
选任意一个联机模式，右侧就会出现「联机房间（1 对 1）」卡片。

| 模式 | 规则 | 怎么算赢 |
| --- | --- | --- |
| ⚔ **垃圾行互攻** | 双方各一块棋盘；自己一次消 **2 / 3 / 4** 行，分别给对手底部塞 **1 / 2 / 4** 行垃圾行（消 1 行不送）。垃圾行每行留一个缺口，插进来的行会把你的方块往上顶 | 谁先被顶死谁输 |
| 🏁 **各自计分** | 双方各一块棋盘、互不干扰；两边用**同一个随机种子**，出块序列完全一样，比的是操作 | 谁先顶死谁输；双方都顶死时比分数，同分算平局 |

**开一局**

1. 两个人各开本工具，顶部都选**同一个联机模式**（模式以房主为准，对不上时房主会提示）。
2. **房主**：填玩家名（留空 = 系统用户名）→ 端口留 `0`（自动挑空闲端口）→ 点「开房间（等好友连进来）」。
3. 房主开好后，卡片上会出现 **「把地址复制发给好友」**：点「复制」把像 `192.168.1.5:5310` 这样的地址发过去
   （同一条局域网直接用内网地址；跨网可以配合内网穿透工具给的域名:端口）。
4. **好友**：把地址粘进「加入房间」输入框 → 点「加入房间」。
5. 人一连进来，房主这边就自动开好一局并开始下落；客户端画面由房主的权威结果驱动，
   右侧「对手」区显示对方分数 / 行数 / 等级与**棋盘缩略图**（互攻模式还显示对方即将被塞多少行垃圾）。

**要点**

- 只有**房主能「重新开始」**（要两个人同时开局），客户端那颗按钮是灰的。
- 对局中有人离开 / 掉线，本局直接结束并在状态栏说明原因；房主可以等对方重新加入再来一局。
- 房间最多 **2 人**（1 对 1），第 3 个连接会被拒绝。
- 没有聊天，只有系统提示（谁加入了、谁走了、结果如何）。
- 联机时**单人最高分不参与统计**（那是单人玩法的纪录）。

> **游玩说明窗口**里写的是同一套内容（分成「移动与旋转 / 快速落底 / 暂存与预览 / 暂停重开与开始 /
> 鼠标也能玩」五块，另有计分表与 5 条小技巧），但更细 —— 比如为什么会有墙踢、C 换出来的是第几块、
> 消 4 行为什么最划算。文案在 `TetrisHelpContent`（纯数据），自检会核对「页面上能用的每个键都写进说明了」。

## 设置项

改一下就自动存进 `Config\tetris\config.json`，没有保存按钮。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 显示幽灵方块 | 开 | 关掉后不画落点预览（想加难度时关） |
| 显示网格线 | 开 | 关掉后棋盘只剩底板与方块 |
| 显示接下来 3 块 | 开 | 关掉后右侧「接下来」整块隐藏 |
| 切走窗口时自动暂停 | 开 | 关掉后切走程序窗口也继续下落（不建议） |
| 起始等级 | 1 | 1 ~ 20；下一局开始时直接用这个等级（等级仍会按消行往上走） |
| 玩家名 | 空 | 联机时对方看到的名字；留空用系统用户名 |
| 上次加入的地址 | 空 | 「加入房间」的输入框会带出来，不用每次重填 |
| 开房端口 | 0 | 0 = 让系统自动挑空闲端口 |
| 上次联机模式 | 垃圾行互攻 | 下次打开自动回到上次选的那个联机模式 |

> 最高分也存在同一个配置文件里（`highScore`）；棋盘局面**不落盘** —— 关掉就开新局。
> 联机相关配置（玩家名 / 地址 / 端口 / 模式）也都存在这里。

## 文件放在哪

- 配置：`Config\tetris\config.json`（相对 **exe 所在目录**）：最高分、起始等级与上面几个显示开关。
- 数据：本工具不写 `Data\`、不写 `Cache\`。
- 区块大小：和别的工具页一样存在 `Config\layout.json`（键名前缀 `tetris.`）。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 按方向键没反应 | 键盘焦点不在工具页上（比如刚点过侧边栏）：点一下棋盘区域再按；或者直接用底部按钮 |
| 切回来发现游戏暂停了 | 故意的：切走工具页 / 切走窗口都会自动暂停，「切走窗口时自动暂停」可以在设置里关 |
| 最高分没更新 | 只有**超过**历史最高分才会刷新，并且是在游戏结束时写；中途退出不算 |
| 起始等级调了没感觉 | 起始等级只在**下一局**生效（`R` 或「重新开始」之后） |
| 转过不去的方块 | 规则如此：5 个踢墙位置都撞墙时旋转不成立，方块保持原样（不会硬塞） |
| 想看方块的落点 | 打开「显示幽灵方块」，半透明的就是落点位置 |
| 好友连不上房间 | 先确认两边在**同一个局域网**、地址端口没抄错；Windows 防火墙第一次会弹「是否允许」，要选允许。跨网需要用内网穿透工具，把域名:端口发给对方 |
| 加入房间报「房间已满」 | 1 对 1：房间最多 2 人（房主 + 1 个好友），第 3 个连不进来 |
| 联机时「重新开始」是灰的 | 只有房主能重开（要两个人同时开局）；客户端等房主重开即可 |
| 对方走了，本局直接结束 | 正常：对局中有人离开 / 掉线就结束本局，房主等对方重新加入可以再来一局 |

## 自检

`tetris` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/TetrisChecks.cs`）：123 条断言 ——
工具与「🎮 游戏」类别注册（含目录树归位 / 根层不再平铺）、7 种方块 × 4 朝向的形状合法性
（4 个不重复格子、都在包围盒内、O 不变形、转一圈回原样）、SRS 墙踢（表长、首项原地、
顺时针 / 逆时针互为相反、贴右墙转横成功、1 格深井转不过去）、碰撞与边界（左右墙 / 穿底 /
出场时 Y < 0 合法 / 占地重叠）、7-bag（前 7 块各一次、逐轮集齐、预览与出场一致）、
移动 / 软降 / 硬降（贴墙不可移、软降 +1、到底软降失败、硬降按格加分并落盘）、
消行与计分升级（1 行 100、4 行 800、3 级时 ×3、每 10 行升 1 级、起始等级夹取）、
暂存（首次 / 一手一次 / 互换 / 顶死后禁用）、幽灵落点与顶死判负、**游玩说明内容**
（6 个分区齐全、页面能用的每个键都写进说明、C 的一手一次与互换语义、墙踢与自动暂停都提到、
计分数字与引擎实算一致、联机小节写了开房 / 加入 / 两种模式 / 离开）、
**联机规则**（垃圾行换算 1→0 / 2→1 / 3→2 / 4→4、插到底部且每行留缺口、自己消行那手不吃垃圾、
送给对手的计数与取走、快照还原与 JSON 往返、同种子出块序列一致 / 不同种子不一致、
胜负判定含双死比分数与平局、协议 magic / 版本 / 人数上限 / 动作白名单 / 模式字符串 / 状态往返 / 坏包返回 null）、
**真回环联机**（本机开房 → 客户端连上 → 房主收到加入与动作 → 状态广播到达 → 第 3 人被拒），
配置默认值与夹取。
**不创建窗口、不渲染、不碰真实 Data/Config；联机那段只绑 127.0.0.1，不联外网。**
