# 🎖️ 军棋（陆战棋）

> 司令 → 工兵全套棋子 + 地雷 / 炸弹 / 军旗；**暗棋自动裁判**、铁路走子、**工兵拐弯**、行营安全、大本营不能再动。
> 支持**二人军棋**与**四国军棋**；局域网联机，房主可设换人方式，多出来的人排队上场。

## 能做什么

- **二人军棋（陆战棋）**：12 × 5 棋盘，双方各 6 列；每方 25 枚棋子。
- **四国军棋**：13 × 13 十字棋盘，4 人两队（对家同盟：红↔绿、蓝↔黄），
  每方 6×6 = 36 格里 5 个行营 + 2 个大本营，固定 25 个摆棋点放 25 枚棋子；
  **同盟之间不能互吃**，先夺对方**两面军旗**的一队获胜（或对方两人都没子可走）。
  行棋顺序：红 → 绿 → 蓝 → 黄。
- **暗棋自动裁判**：对方的棋子看不到等级，碰子由程序按规则自动判；
  被吃掉的棋子会向双方揭示（之后同一个棋位上的等级不再保密）。
- **完整行棋规则**：
  - 公路：上下左右一格；
  - **铁路**：沿直线可走任意格（中间不能有子）；
  - **工兵**：能在整张铁路网上**拐弯**，并能**排地雷**；
  - **行营**：进去的棋子不能被吃；**大本营**：进去的棋子不能再动。
- **联机**：房间最多 16 人，2 个（二人军棋）/ 4 个（四国军棋）席位在场，其余排队。

## 规则速查

| 棋子 | 说明 |
| --- | --- |
| 司令 / 军长 / 师长 / 旅长 / 团长 / 营长 / 连长 / 排长 / 工兵 | 号数**大吃小**；**同级同归于尽** |
| 炸弹 | 碰任何棋子（含司令、地雷、军旗）都同归于尽 |
| 地雷 | 不能移动；**只有工兵能排掉**，其它棋子碰雷同归于尽 |
| 军旗 | 不能移动；被任何棋子碰到即**夺旗获胜** |

- **胜负**：夺旗；或对方没有能动的棋子（子被吃光 / 只剩地雷与军旗）；或对方认输。
- 标准配置（每方）：司令 1、军长 1、师长 2、旅长 2、团长 2、营长 2、连长 3、排长 3、
  工兵 3、地雷 3、炸弹 2、军旗 1，共 **25 枚**。

## 电脑对手（四档智慧程度）

右侧「电脑对手」卡片：勾上就让电脑接管另一边。

| 难度 | 说明 |
| --- | --- |
| **入门** | 只防明显失误，会犯傻（随机挑次优解），适合练手 |
| **普通** | 会防守也会进攻，正常水平（默认） |
| **困难** | 会算几步连招，认真对待 |
| **大师** | 深度搜索 / 最强评估，比较难赢 |

- 二人军棋：你执红先手，电脑执蓝后手。
- 四国军棋：你执红，另外三家（含同盟绿方）由电脑接管。
- 电脑也**受暗棋限制**：它看不到你的暗棋，和真人玩的感觉一致。

## 怎么玩

1. 点「自动布阵」（或自己手动摆）——双方都布好阵后点「开始对局」，红方先走。
2. 点自己的棋子选中（会高亮所有可走位置），再点高亮位置走子。
3. 碰子自动裁判，结果会写在上方状态栏；走错了就重来（点「重开」重新布阵）。
4. 「认输」结束本局。

## 联机怎么开

1. 房主填玩家名、端口留 `0`，点「开房间」，把地址复制给朋友。
2. 朋友粘地址点「加入房间」。二人军棋 2 席、四国军棋 4 席，多出来的人**排队**等换人。
3. 房主可在「换人方式」里设：**手动安排** / **输的人下场换下一位** / **全场换人（不论输赢）**。
4. 暗棋保护：快照**按座位分发**，客户端只看得到自己的棋子与已被吃掉的明棋，看不到对手暗棋。

## 设置项

存 `Config\junqi\config.json`：玩法（二人 / 四国）、玩家名、开房端口、上次加入的地址、换人方式、补位方式。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 点棋子没反应 | 只能是**自己的**棋子；别人的棋子（暗棋）点不动 |
| 想走的地方不高亮 | 那一步不合法：铁路中间有子 / 行营里有人 / 大本营里的子不能再动 |
| 军旗怎么不能动 | 规则如此：军旗与地雷都不能移动 |
| 看不到对手是什么子 | 暗棋玩法：碰子才知道；被吃掉的子会显示出来 |
| 布阵太慢 | 点「自动布阵」随机摆好，再点「开始对局」 |

## 自检

`board-new-games` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/BoardGamesNewGameChecks.cs`）覆盖军棋部分：
25 枚标准配置与棋力顺序、棋盘布局（每方 25 个摆棋点 / 10 行营 / 4 大本营 / 铁路干线）、
裁判（大吃小 / 同级同归于尽 / 炸弹 / 工兵排雷 / 其它碰雷 / 夺旗）、
走法（公路一格、行营不能被吃、空行营可进、大本营不能动）、布阵校验（满 25 枚、
军旗 1 面、不能摆到对方一侧、不能重复布阵）、胜负（认输 / 无子可走 / 夺旗）、
暗棋过滤（自己全可见、对手全部隐藏且看不到等级）。**纯逻辑，不建窗口、不联网。**

另外 `board-new-games` 还覆盖**多席位换人规则**（`BoardMultiSeatRotation`）：
手动 / 输的下场 / 全场换人三档、席位数为 3 与 4 的情况、替补不够时不乱排、
轮流上场优先没上过场的、随机上场可复现、离线的人不参与补位。
