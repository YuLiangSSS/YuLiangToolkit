# 💬 联机聊天室

> 主机开一个 TCP 端口等人连，客户端填「IP（或域名）+ 端口」就能聊 —— 局域网直连，
> 外网用**端口映射 / 内网穿透**。**不依赖任何第三方服务**，两端都是本程序。
> 房间里还能开**群语音 / 群视频通话**（最多 8 人，媒体走同一个端口）。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **主机（傻瓜模式，默认开）**：什么都不用填 —— 点「开房间」，工具自己挑监听地址与端口
  （优先**双栈 `::`**：同一个端口 IPv4 与 IPv6 都能连；端口优先沿用上次那个，被占了就让系统挑一个空闲的）。
  开完房间界面直接把**连接信息**摊出来，照着复制给对方：
  - **本机端口**（`5200` 之类）—— 内网穿透工具的「本地端口 / 内网端口」就填它；
  - **本机的 IPv4 地址**（每张网卡一条，有线 / 无线排前面并标「推荐」；虚拟网卡会注明「别的机器多半连不上」）；
  - **本机的 IPv6 地址** —— 一条都没有时直说「当前网络没有 IPv6」，不会让你以为哪里填错了；
  - **内网穿透怎么填**：把穿透工具给你的「域名:端口」原样发给对方即可。
  想自己指定监听地址 / 端口就**取消勾选「傻瓜模式」**，输入框与「全部 IPv4 / 含 IPv6 / 只本机」按钮就回来了。
- **客户端**：填主机地址与端口 → 「连接」。支持 IPv4 / IPv6（`[fe80::1]`）/ 域名，
  也可以直接带端口（`192.168.1.7:5200`，穿透工具给的常常是这种）。
- **能发什么**：文字、图片、音频、视频、任意文件。图片直接显示预览（双击打开原图），
  音频 / 视频能在界面里播；其它文件显示成卡片，有进度条与「打开文件 / 打开所在文件夹」。
- **群语音 / 群视频通话**：房间里点「🎙 语音通话」/「📹 视频通话」就能开（主机 / 客户端谁先点谁先入会），
  最多 **8 人**；每人可单独开关麦克风 / 摄像头，有画质档位与本机码率统计。详见下面的
  「[群语音 / 群视频通话](#群语音--群视频通话)」一节。
- **省流量**：图片发送前可以在本地先压缩（默认「长边超过 1920 像素才缩」），
  预览图由**两端各自本地生成** —— 不会为了预览多花流量。
- **单次流量上限**：一次连接最多能跑多少流量，可设成「收发合计 / 仅上传 / 仅下载」或不限制。
  界面上有进度条 + 已用 / 剩余 + 实时收发速度；
  - **发送前就预检**：文件比剩余额度大 → 直接不发（不会传一半被掐断）；
  - **到上限立刻停**：发消息会被拦下并提示，对方也会收到一句「本端流量到顶，暂停发送」，免得以为你掉线。
- **记录**：**每开始一次连接都会新建一个以开始时刻命名的文件夹**，完整记下这次聊了什么（见下）。

## 界面布局

- 区块之间可以**拖动调整大小**（蓝线 + ↔ / ↕）：① 主机 / 客户端、③ 底部三栏（流量 / 发送选项 / 文件传输）、④ 房间成员 / 历史记录都能左右拖；上下方向「② 聊天 / ③ 底部三栏 / ④ 成员 + 历史 / ⑤ 协议与日志」每两块之间也都能拖；
- 松手自动记住（`Config\layout.json`）；**双击**某条分隔线只恢复这一处，全部恢复默认：**主页设置 →「界面布局 → 恢复默认布局」**。
- 聊天工具条上有「**语音通话 / 视频通话**」与「**挂断**」按钮；通话中聊天区旁边会浮出**通话面板**：参与者磁贴（谁开了摄像头 / 谁静音一眼看出）、
  **麦克风 / 摄像头开关**、画质下拉，以及**实时码率 / 丢帧 / 已通话时长**；⑤ 协议与日志里能看到通话状态变化。

## 怎么用（最快的路径）

1. 主机点「开房间」→ 把界面上列出的「地址:端口」复制给对方（同一局域网用 IPv4；外网就用穿透工具的域名）。
2. 客户端填进去 → 「连接」。
3. 两边就能发文字 / 拖文件了；想设流量上限就在「流量」那一栏选个额度。
4. 想事后翻聊天：右侧「历史记录」→ 选一次会话 → 「查看」（把那次聊天读回界面）或「文件夹」。
5. 想开语音 / 视频：点工具条上的「**🎙 语音通话**」或「**📹 视频通话**」（第一次用先点通话面板右上角的「⚙ 设置」挑设备与画质）。

## 群语音 / 群视频通话

> 房间就是会议室：**主机和客户端谁先点「语音通话 / 视频通话」谁先入会**，其他人随后点自己的按钮就进来。
> 音频固定 **16 kHz 单声道 μ-law**（40 ms 一包、640 字节），视频是 **MJPEG**（逐帧 JPEG），
> 都手写编解码 —— 不用另装插件，也不会上传到任何第三方。

### 能做什么

- **群语音**：最多 **8 人**在同一个通话里（主机也算一个）；谁静音了，通话面板里一眼看得出。
- **群视频**：开摄像头的人显示画面，没开的显示头像 / 占位；**每人单独开关**麦克风与摄像头。
- **通话时聊天、发文件照常**：文字 / 文件走原来的聊天连接，媒体走另一条连接，互不占道。
- **统计**：通话面板显示实时收发码率、丢帧数、已通话时长；谁静音 / 关摄像头在磁贴上标出来。
- **主机 / 客户端都能发起**：没有「只能主机开」的限制。主机退出通话**不会解散**这次通话
  （主机继续当中转，其他人还能继续聊）；所有人都挂断后这轮通话才结束。

### 怎么用

1. 先像平常一样开房间 / 连上主机。
2. 点聊天工具条上的「**🎙 语音通话**」或「**📹 视频通话**」（进入后工具条变成「通话中 + 挂断」）。
3. 第一次用先到「通话设置」里挑 **摄像头 / 麦克风 / 扬声器** 设备与**画质档位**（也可以留在「系统默认」）。
4. 只想听不说话就**关麦克风**；不想露脸就**关摄像头** —— 对方会立刻看到状态变化（主机广播 `callState`）。

### 音量与摄像头开关

- **麦克风关** = 不采集也不发送，对方看到 `MicOn=false`（听不到你的声音）；重新打开立刻恢复。
- **摄像头关** = 采集停掉、摄像头灯灭，对方看到的是你的头像；重新打开立刻恢复。
- 开关状态由主机统一维护并广播给所有人（主机是唯一权威），所以不会出现「我这边关了、别人还看到我在说」。

### 画质档位与带宽估算

只影响视频；音频固定 16 kHz μ-law（约 128 kbps）。

| 档位 | 分辨率 / 帧率 | 每路视频约需 | 适合 |
| --- | --- | --- | --- |
| 省流量 | 240×180 / 6 帧 | 0.3~0.6 Mbps | 人多 / 流量紧张 |
| 标准（默认） | 320×240 / 10 帧 | 0.6~1.2 Mbps | 大多数情况 |
| 高清 | 480×360 / 12 帧 | 1.5~3 Mbps | 两三人、局域网 |

- 实际带宽还取决于画面复杂度（MJPEG 不做帧间压缩，画面越花越费）。
- 主机是**中转**：第 N 个人的视频要转发给其余 N−1 个人，主机上行随人数线性增长 ——
  **人多时建议主机把档位调到「省流量」**。
- **声音卡顿先降画质档位**：视频比声音吃带宽得多；再检查是不是主机上行被占满（例如同时在传大文件），
  实在不行就让一部分人关摄像头、只开语音。

### 连的是哪条连接 / 内网穿透

- 客户端点「语音通话 / 视频通话」时会**另开一条 TCP 连接**，连的是主机**同一个监听端口**（不是新端口）：
  先发 `callHello` + 在 `welcome` 里拿到的通话令牌，主机校验通过才允许传媒体。
  这条媒体连接**不会**登记成聊天成员、也不建会话文件夹，只跑音频 / 视频 / 开关控制。
- 所以内网穿透 / 端口映射**只需要映射主机那一个端口**，不用为通话再加端口，客户端也仍然不用开任何端口。
- **通话媒体流量不计入「单次文件流量上限」**：上限只统计聊天 / 文件那条连接（否则开几分钟通话就把额度烧光）。
  通话自己的收发速率在通话面板里看。

### ⚠ 没有回声消除（AEC）

**请戴耳机**。外放时对方的声音会被你的麦克风再收进去，轻则回音、重则啸叫。
没有耳机就至少把扬声器音量调小、麦克风离远一点，并提醒对方也戴耳机。

### 设备选择与配置

| 配置项 | 说明 |
| --- | --- |
| `callCameraId` / `callMicrophoneId` / `callSpeakerId` | 设备 Id（空 = 系统默认第一个）。摄像头是 WinRT Id，麦克风 / 扬声器是 WASAPI 端点 Id |
| `callQuality` | 画质档位（`Saver` / `Standard` / `High`，默认 `Standard`） |

设备 Id 是系统给的，**换了设备 / 换了 USB 口可能对不上** —— 重新在通话设置里选一次即可；
枚举不到设备时列表会给出说明，通话仍可只用语音。

## 数据与配置

```
Data\chat-room\
├─ Protocol\chat-protocol.json   ← 协议说明（首次运行从程序里释放，能用记事本看；改过就不覆盖）
└─ Sessions\                     ← 全部会话（别把别的东西丢进来，「历史记录」会当成一次聊天列出来）
   ├─ 2025.1.3-14.5.9\           ← 文件夹名 = 开始时刻：年份.月份.日期-时间.分钟.秒
   │  ├─ 怎么用这个文件夹.md      ← 一次会话里放了什么，自己看这份
   │  ├─ session.json            ← 抬头：开始/结束时间、身份、对端、消息条数、流量统计
   │  ├─ chat-log.jsonl          ← 全部消息，一行一条 JSON（文字 / 文件 / 系统提示）
   │  ├─ images\ audio\ video\ files\   ← 收到与发出的文件按大类归位（重名自动加序号，绝不覆盖）
   │  └─ …                       ← 同一秒开两次自动补 -2、-3
   └─ 2025.1.3-20.31.7\
```

| 位置 | 内容 |
| --- | --- |
| `Config\chat-room\config.json` | 昵称 / 头像 / 傻瓜模式 / 监听地址与端口 / 上次连的主机 / 流量上限与方向 / 发图压缩 / 大文件确认 / 最近会话 / **通话画质档位** / **摄像头·麦克风·扬声器设备 Id** |

- **每端都存一份**：自己发的和收到的都落在本端会话文件夹里 —— 那就是「这次聊了什么」的完整账本。
- 会话文件夹名里的月 / 日 / 时 / 分 / 秒**不补前导零**，所以按名字排序 ≠ 按时间排序；
  界面上的「历史记录」是按时间排的。
- 工具被切走或程序关闭时会自动断开，并在那次的记录里补上结束时间与统计；通话也会一起挂断。

## 协议

自研的简单 TCP 协议：`4 字节小端长度 + JSON 头 + 裸载荷`（长度只数 JSON 头自己的字节）。
包类型有 `hello` / `welcome` / `text` / `system` / `members` / `kick` / `transferStart` / `transferDone` /
`transferCancel` / `ping` / `pong` / `bye`。

群通话（v0.71.0 起）再加 5 个：

| 包类型 | 方向 | 用途 |
| --- | --- | --- |
| `callHello` | 客户端 → 主机（媒体连接） | 媒体连接握手：带 `isMedia=true` + `callToken`（welcome 里发的） |
| `welcome` | 主机 → 客户端 | 媒体连接回执 `mediaAccepted=true`（拒绝时带原因）；聊天连接的 welcome 顺带发 `callToken` |
| `callState` | 主机 → 所有人（聊天连接） | 通话名单与每人 `micOn` / `cameraOn`；主机是唯一权威 |
| `callControl` | 客户端 → 主机（媒体连接） | 上报自己的麦克风 / 摄像头开关 |
| `callAudio` / `callVideo` | 双向（媒体连接） | 裸媒体载荷：音频 16 kHz 单声道 μ-law 40 ms / 640 B；视频 MJPEG 整帧 |

- **媒体走单独一条 TCP 连接**（主机同一个端口）：文件传输会长时间占住写锁，混在一条连接上会把声音卡成 PPT。
- 媒体连接**不加入聊天成员名单**、不建会话文件夹，只跑 `callAudio` / `callVideo` / `callControl`。
- 完整说明在 `Data\chat-room\Protocol\chat-protocol.json`（首次运行释放，人能读）。

## 注意

- **这条连接没有加密**（就是普通 TCP）。传敏感东西请自己在可信网络里用，或者先套一层加密通道（VPN / 穿透工具的 TLS）。
- 文件走控制连接本身，不另开数据端口 —— 因为穿透工具通常只映射一个端口；**通话媒体连接复用同一个端口**，理由相同。
- 内网穿透只映射主机那一个端口即可，客户端不用开任何端口。
- **通话没有回声消除**：请戴耳机，否则会啸叫 / 回音（详见上一节）。
- **通话中切到别的工具页**：聊天室页面会被外壳缓存，通话**继续跑**（麦克风 / 摄像头仍在工作），
  回到本页就能继续操作；要结束请先点「挂断」，或退出程序（退出会一起挂断）。
- 通话媒体**不计入单次流量上限**；流量上限只统计聊天 / 文件连接。
- 自检 / 无设备环境：通话链路可以用假的摄像头 / 麦克风 / 扬声器完整跑通，不需要真设备。
