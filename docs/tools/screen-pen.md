# ✏️ 屏幕画笔

> Epic Pen 风格的桌面透明批注覆盖层：不截屏也能直接在屏幕上画，画完按截图快捷键就能把批注一起截进去。

## 能做什么

- **画笔 / 荧光笔**：画笔支持透明度、圆头笔迹；荧光笔用半透明宽线。
- **橡皮**：点按或拖动删除笔画。
- **形状**：直线、矩形、椭圆、箭头；矩形 / 椭圆可选填充。
- **文字**：点一下画布定位，输入文字回车确认；Esc 取消。
- **撤销 / 重做 / 清空**：工具栏和工具页都能操作。
- **白板 / 黑板**：覆盖层可切换透明 / 白板 / 黑板背景。
- **额外调色板**：默认 24 个预设色，可打开完整调色板选择任意 `#RRGGBB` / `#AARRGGBB`；“更多颜色…”会把选中的自定义色加进预设列表。
- **鼠标穿透**：关闭绘制模式后覆盖层不拦截鼠标，画笔内容仍留在屏幕上。
- **全局快捷键**：显示 / 隐藏覆盖层、切换绘制 / 鼠标穿透、清空、撤销，默认 `Ctrl+Shift+F6` / `F7` / `F8` / `F9`，可在工具页和「主页设置 → 快捷键」修改。

## 和截图工具协作

- 屏幕画笔的覆盖层始终是桌面上的透明窗口，**截图工具捕获屏幕时会包含画笔内容**。
- 打开截图选择 / 编辑覆盖层时，屏幕画笔会**自动暂停并隐藏悬浮工具栏**，避免误触，也保证截图里只有画笔内容。
- 截图关闭后，画笔覆盖层恢复原来的绘制状态。
- 屏幕画笔没有自己的托盘图标，也不使用托盘右键菜单；工具页就是设置入口。

## 建议用法

1. 打开「桌面 → 屏幕画笔」页，点「显示屏幕画笔」。
2. 选择工具 / 颜色，直接在屏幕上画。
3. 按截图快捷键 `Ctrl+Shift+F1`，截出的图会带画笔批注；截图时画笔自动暂停。
4. 画完后可在工具栏点「隐」隐藏覆盖层，或按 `Ctrl+Shift+F6`。

## 数据位置

- 配置：`Config\screen-pen\config.json`（自动保存）
- 工具页：可恢复默认调色板、调整画笔 / 荧光笔粗细和背景模式
- 覆盖层：跟随虚拟屏幕（多显示器横向拼接时也覆盖全部屏幕）
