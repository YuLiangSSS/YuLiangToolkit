# 📮 邮件推送

> 在本机写一封**带格式的邮件**（富文本编辑器 / HTML 源码、附件、抄送密送、发送前预览），
> 点「发送」交给**邮件推送 API** —— 目前接的是 [Resend](https://resend.com) 的 `POST /emails`。
> 和「邮箱代收」（IMAP 只读收信）正好互补：一个收，一个发。

## 能做什么

- **① 收发信息**：API Key（默认遮住，点 👁 看明文）、发件人显示名 + 地址、收件人 / 抄送 / 密送 / 回复地址、主题。
  收件人一行一个也行、逗号 / 分号分隔也行；**收件人 + 抄送 + 密送合计最多 50 个**。
- **② 正文**：所见即所得的富文本编辑 —— 粗体 / 斜体 / 下划线 / 删除线、字号、文字色、背景高亮、左中右对齐、
  有序 / 无序列表、缩进、超链接、插入图片、插入表格、分隔线、清除格式；也能切到 **HTML 源码**直接改。
- **③ 附件**：文件对话框选，或直接把文件**拖进列表**；显示每个文件原始大小和 **base64 之后**的大小
  （推送服务的 40 MB 上限按 base64 后的体积算）。可执行 / 脚本类文件会被提示拒收。
  把**图片拖进正文**则是行内图片（作为 `cid:` 附件随邮件一起上传）。
- **④ 预览**：用 WebView2（Chromium，脚本已关闭）渲染真实排版，发送前先看效果；没有运行时时退回纯文本。
- **⑤ 发送记录**：每次发送的时间、收件人、主题、HTTP 状态、返回的邮件 id、错误原文都在这里；
  API Key 只显示打码后的样子（`re_C…oHo6`）。
- **查询投递状态**：按上一次返回的 id 调 `GET /emails/{id}`，把 `last_event`（delivered / bounced…）翻成中文。
- 正文草稿自动保存：关掉工具 / 下次打开还是上次那份（带格式）。

## 怎么用

1. **拿一个 API Key**：到推送服务控制台（Resend → API Keys）创建一个，粘到「API Key」框里。
   **只用发信权限就够**（不要开完全访问）。
2. **验证发件域名**：Resend → Domains 里把发件地址用到的域名加进去并通过验证（DNS 记录）。
   **发件地址的域名必须已验证**，否则会返回 403；官方测试域名 `resend.dev` 只能发给账号本人的邮箱。
3. 填发件人（显示名可空，例如 `凉雨` + `test@你的域名`）、收件人、主题。
4. 写正文（富文本或 HTML 源码），需要的话加附件 / 插图片，点右上「刷新预览」看效果。
5. 点「📤 发送」。成功会在状态行显示绿色一行与邮件 id，日志里有完整摘要；失败则显示红色原因 + 服务端原文。
6. 想确认投递情况，点「查询投递状态」（或去控制台 Emails 列表看）。

## 它到底发了什么

> 排查时对照这里：工具只是按 Resend 的接口约定发一个 POST，日志里是服务端原样返回的 JSON。

- `POST https://api.resend.com/emails`，请求头：
  - `Authorization: Bearer <你的 API Key>`
  - `User-Agent: YuLiangToolkit-MailSender/1.0` —— **必须带**，Resend 会把没有 UA 的请求直接挡在门外（403 / error code 1010）
  - `Content-Type: application/json`
  - `Idempotency-Key: …`（只有填了「幂等键」才带；同一 key 重发不会重复投递，服务端保留 24 小时）
- 请求体（值都按官方字段名，下划线风格）：

  ```json
  {
    "from": "Congratulations! <test@contact.example.com>",
    "to": ["a@example.com"],
    "subject": "主题",
    "html": "<p>正文</p>",
    "text": "正文",
    "cc": ["cc@example.com"],
    "bcc": ["bcc@example.com"],
    "reply_to": ["reply@example.com"],
    "attachments": [
      { "filename": "报告.pdf", "content": "<base64>", "content_type": "application/pdf" },
      { "filename": "图.png", "content": "<base64>", "content_type": "image/png", "content_id": "inline-1@yuliang" }
    ]
  }
  ```

  - `html` / `text` 至少一个非空（`text` 是给不显示 HTML 的客户端兜底，可在界面上关掉）；
  - 附件 40 MB 上限按 **base64 之后**算（base64 会膨胀约 4/3）；
  - 行内图片用 `content_id` 上传，HTML 里写 `<img src="cid:inline-1@yuliang">`。
- 成功是 **2xx**（Resend 实际返回 `200`，不是 201），响应体 `{"id":"…"}`；
  失败体是 `{"statusCode":…,"name":"…","message":"…"}`，工具会把 `message` 原文保留在日志里。

| 界面上的选项 | 存哪 | 说明 |
| --- | --- | --- |
| API Key | `Config\mail-sender\config.json` 的 `apiKeyCipher` | **DPAPI 密文**，同一台电脑同一用户能解，换用户 / 换机器解不开 |
| 发件人 / 收件人 / 抄送 / 密送 / 回复地址 / 主题 | 同上 | 改一下就自动保存 |
| 正文草稿（HTML） | 同上 | 富文本编辑器加载时还原成可编辑内容 |
| 附件清单 | 同上 | 只存路径；文件不存在时打开工具会自动剔除 |
| 推送地址 | 同上 | 默认 `https://api.resend.com/emails`，可改成中转 / 兼容服务 |

## 常见问题

| 状态 / 日志文案 | 原因 | 怎么办 |
| --- | --- | --- |
| `HTTP 401 · validation_error：API Key 无效…` | Key 抄错、被删、或带上了多余空格 | 回控制台重新复制一个，粘贴时别带空格 |
| `HTTP 403 …发件域名还没验证` | `from` 用的域名没在推送服务里验证通过 | 到 Domains 里完成验证；验证要 5 分钟~几小时（DNS 生效） |
| `HTTP 403 …测试域名只能发给账号本人` | 用了 `resend.dev` 这类测试发件地址发给别人 | 换成已验证域名的发件地址 |
| `HTTP 422 …字段校验失败` | 发件人 / 收件人 / 主题 / 正文有空值或格式不对 | 看日志里的服务端原文，逐项核对 |
| `HTTP 422 …附件格式不被接受` | 附件没有内容（文件读不到） | 重新添加附件 |
| `HTTP 429 …发送太频繁` | 服务端限流（约 10 次/秒） | 等一两秒再发 |
| `HTTP 429 …今天的免费额度用完了` | 免费版每天 100 封（UTC 0 点重置，多个收件人分别计数） | 等第二天，或升级套餐 |
| `网络请求失败 / 请求超时` | 网络不通、代理问题、附件太大传得慢 | 检查网络；超时是 60 秒，大附件建议压小 |
| `发送时出现异常：…` | 工具内部出错（会同时把异常类型与堆栈写进日志） | 把日志里那一行发给开发者；状态行不会再停在「正在发送…」 |
| `附件太大：…超过上限 40 MB` | 附件 base64 后超过上限 | 删掉大附件，或改用网盘链接写在正文里 |
| `附件类型被推送服务拒收` | `.exe` / `.bat` / `.ps1` 这类可执行、脚本文件 | 打包成 zip 再发（zip 不在拒收清单里） |

## 安全提示

- **API Key 就是发信凭证**：泄露了别人就能用你的域名发信、消耗你的额度。不要截图、不要发到群里、
  不要写进代码仓库。本工具把它用 Windows DPAPI 加密后保存，日志里只显示打码值。
- **建议只给「发送」权限**：控制台创建 Key 时选最小权限；需要查投递状态时，那个查询接口也要有读权限。
- 收件人地址、主题、正文都会原样发给推送服务（这是发邮件的前提）；不填 Key 时**完全不联网**。
- 发件域名请配好 SPF / DKIM（推送服务的验证流程会给出记录），否则容易进垃圾箱。

## 注意

- 工具要能访问 `api.resend.com`；公司网络 / 代理环境发不出去时先看日志里的网络错误。
- 预览依赖 **WebView2 运行时**（Win10 2004+ 一般随 Edge 自带）；缺失时预览退回纯文本，**不影响发送**。
- 富文本只覆盖邮件常用格式（见 `Views/RichTextHtml.cs` 顶部注释）；粘贴进来的复杂 HTML
  （带 CSS 类、脚本、表单）会被简化成文字 + 基本格式，这是刻意的（邮件客户端本来也不支持那些）。
- 发送记录只在界面日志里，关掉工具就没了；要留档请到推送服务的控制台看（Resend 保留 30 天）。
