# 📘 Word 阅读器

> 不装 Office 也能看 `.docx` / `.docm`：**段落样式、标题大纲、表格（含合并单元格）、图片、超链接**都能显示，
> 还能看 **页眉 / 页脚、脚注 / 尾注、文档属性（作者 / 修改时间）**；支持 **50% ~ 300% 缩放**、**大纲跳转**、
> **正文 + 表格查找**、**复制全文**、**阅读位置记忆**、**最近打开**和**拖入文件**。
> 解析与排版全部用 .NET 自带的 `System.IO.Compression` + `System.Xml.Linq` + WPF `FlowDocument`，
> **不引第三方 Word 库**；**只读浏览，绝不会改动原文件**。

## 能做什么

- **打开 `.docx` / `.docm`**：工具条「📘 打开 Word 文档…」或 `Ctrl+O`，文件对话框默认过滤这两种格式；
  也可以把文件**直接拖到页面里**（只接受 `.docx` / `.docm`）。打开后工具条显示文档标题与完整路径，
  状态栏显示文件名、大小、段落数 / 表格数 / 图片数。
- **还原基本排版**：段落对齐（左 / 中 / 右 / 两端）、左缩进、标题 1 ~ 6 级（字号递减 + 加粗 + 段前段后距）、
  粗体 / 斜体 / 下划线 / 删除线、文字颜色、字号、字体、上标 / 下标、高亮底色、制表符与软换行。
- **页眉 / 页脚**：解析 `w:sectPr` 的 `w:headerReference` / `w:footerReference`（`default` / `first` / `even`），
  通过 `word/_rels/document.xml.rels` 找到 `word/headerN.xml` / `word/footerN.xml`。
  **连续浏览的简化**：只在**文档顶部显示首个节的页眉、文档底部显示最后一个节的页脚各一次**，
  不会每页重复（单节文档两处就是同一个 `sectPr`）。用 9 磅浅灰小字 + 细分隔线与正文区分；
  工具条「页眉页脚」可以一键收起 / 展开（会记住），切换时从已解析内容**重新排版**、不重新读文件。
- **脚注 / 尾注**：解析 `word/footnotes.xml` / `word/endnotes.xml`（过滤 `w:id` 为 -1 / 0 的分隔符），
  正文里的引用显示成**蓝色上标 `[n]`**（悬停提示是脚注还是尾注）；文档末尾按顺序列出「脚注」「尾注」小节，
  多条内容按段落排。编号按**正文引用出现的先后**分配，和 Word 里看到的顺序一致。
- **文档属性**：读 `docProps/core.xml` 的作者（`dc:creator`）、最后修改者（`cp:lastModifiedBy`）、
  创建 / 修改时间，鼠标悬停在工具条标题上就能看到；文件里没写这些信息时显示文件大小与完整路径。
- **📑 大纲侧栏**：按标题级别缩进列出全部标题，点一条就滚到正文对应位置；工具条「显示大纲」可以整块收起
  （会记住），收起后阅读区自动变宽。侧栏宽度可以拖。
- **表格**：按 `w:tblGrid` 还原列宽（合并单元格用 WPF 表格的跨列 / 跨行），1 像素浅灰网格线，
  表头行加粗 + 浅灰底，单元格底纹色也保留。**表格里的文字也能被查找**。
- **图片**：从 docx 包里取出图片字节显示，按文档里写的尺寸（EMU 换算成像素）排版，
  最大缩到 **760 × 1000**；鼠标悬停显示替代文字（`descr`）。图片关系缺失或格式不支持时显示占位提示，不影响阅读。
- **超链接**：正文里的链接显示成蓝色下划线，点击用系统默认浏览器打开（只跳转，不会改文件）。
- **缩放 50% ~ 300%**：工具条「− [100%] +」、`Ctrl + 滚轮`、`Ctrl + 加号 / 减号`；`Ctrl+0` 或「100%」按钮恢复。
- **Ctrl+F 查找**：输入即搜，状态栏显示「找到 N 处 / 第 x / N 处」，命中段落**临时黄底高亮并滚到可见位置**；
  「区分大小写」复选框随时切换（改开关时已有查询会立即重算）；**表格单元格里的文字也会命中**，
  命中表格时滚到整张表格并把光标位置说明在状态栏里（格内高亮暂不支持）。
  `回车` = 下一个、`Shift+回车` = 上一个、`Esc` = 清空。
- **📋 复制全文**：工具条一键把**正文纯文本**复制到剪贴板 —— 段落之间换行、表格按「单元格 + 制表符」，
  页眉页脚 / 脚注尾注**不包含**（它们不是正文）；成功会提示「已复制全文（N 字）」，
  剪贴板被别的程序占用时会在状态栏提示重试，不会弹窗。
- **💾 阅读位置记忆**：每份文档记住上次读到的滚动比例（最多 200 份，超出按时间淘汰最老的）。
  重新打开、或者切走工具页再回来，会回到上次的位置；工具条没有开关，想关掉就改配置
  `rememberReadingPosition: false`（关掉只是不再记录，**已有记录不会清**）。
- **🕘 最近打开**：工具条下拉列出最近打开过的文档（新的在上、同一路径只留一条），点一条重新打开；
  文件已不存在的会标成灰色，点了只给提示、不会报错；旁边「清空」只删记录、**不删本地文件**。
  上限可以在配置里调（0 ~ 100，0 = 不记录）。
- **打开新文件会清掉旧文档与查找状态**；关闭工具时释放排版对象，长时间使用不会一直占着内存。
- **开发 / 截图调试**：设置环境变量 `YLT_WORD_OPEN=<docx 路径>` 后启动程序，打开本工具会自动加载该文档
  （**只用于调试，不写进配置**，也不记最近列表）。

## 区块布局（可拖拽）

页面分三块：**顶部工具条 → 主区域（左侧大纲栏 + 右侧阅读区）→ 底部状态栏**。
大纲栏和阅读区之间有一条**竖向分隔条**（鼠标移上去变 ↔、亮起蓝线），按住左右拖即可调大纲栏宽度，
松手自动记住；**双击**这条缝恢复默认宽度；关掉「显示大纲」时分隔条和大纲栏一起收起，不留空白。

拖过的宽度记在 `Config\layout.json`（不是本工具的配置里），
全部恢复默认在 **主页设置 →「界面布局 → 恢复默认布局」**。约定见 [docs/dev/layout.md](../dev/layout.md)。

> 阅读区是**满屏 Grid 里的白色纸面**，没有整页滚动条 —— 只有正文在纸面里滚，工具条和状态栏始终可见。
> 页眉只在纸面顶部出现一次、页脚只在底部出现一次，这是「连续浏览」对分页文档的简化。

## 怎么用

1. 在主页找到「**Word 阅读器**」卡片（分类「文档」，也可以直接搜「Word」或「docx」）打开。
2. 点「**📘 打开 Word 文档…**」（`Ctrl+O`），或者把 `.docx` / `.docm` 拖进页面。
3. 看长文档：用左侧**大纲**点标题跳转；用 `Ctrl+F` 查找正文 / 表格；用工具条或 `Ctrl+滚轮` 调整缩放；
   需要文字时点「📋 复制全文」。
4. 不想看页眉页脚：取消勾选工具条「页眉页脚」；想找回上次读到的位置：直接关掉工具再打开同一份文档即可。
5. 想收藏 / 编辑文档？本工具**只读**，请用 Word 或其它编辑器修改原文件后重新打开。

## 支持格式与已知限制

**支持**：`.docx`（Word 2007+ 默认格式）、`.docm`（带宏的格式，宏不会执行，只显示内容）。

**不支持 / 会简化**（都是只读浏览，不影响原文件）：

- **旧版 `.doc`（Word 97-2003 二进制格式）不支持**，会提示「请用 Word 另存为 .docx 再打开」。
  同理 `.rtf` / `.odt` / `.pdf` 也不支持。
- **页眉 / 页脚是连续浏览的简化**：只取**首个节的页眉**和**最后一个节的页脚**各显示一次，
  不区分首页 / 偶数页（解析时按 `default` → `first` → `even` 的优先级只取一个），也不会每页重复；
  多节文档里中间节的页眉页脚看不到。
- **脚注 / 尾注只做阅读展示**：正文引用显示上标 `[n]`、末尾集中列出内容；
  **脚注里的图片会跳过**（只保留文字 / 段落 / 简单表格），也不支持点击引用跳回。
  找不到引用对应内容时只显示 `[n]` 标记，不会崩。
- **页眉页脚 / 脚注尾注不参与查找、不参与大纲**（它们不是正文，跳转语义不一样）。
- **批注 / 修订痕迹不显示**（修订里「插入」的文字会保留，「删除」的文字不显示）。
- **复杂排版会简化**：多栏、文本框、艺术字、SmartArt、公式（OMML）、域代码、目录域、嵌入的 OLE 对象
  （例如内嵌的 Excel 表）都不渲染或只显示占位；嵌套表格会跳过（只保留外层表格）。
- **列表编号是简化实现**：项目符号显示为「• 」，数字 / 字母 / 罗马 / 中文数字列表按「同一列表同一级递增」还原，
  Word 里那种跨列表重启、起始值覆盖等复杂规则可能和 Word 里看到的数字不完全一致。
- **查找覆盖正文段落 + 表格单元格**，页眉页脚 / 脚注不参与；表格命中只能滚到整张表格，**不能高亮单个格子**。
- **图片只支持浏览器 / WPF 能解码的位图**（png / jpeg / gif / bmp / tiff），EMF / WMF 等矢量图显示占位提示；
  外链图片（没有嵌进 docx 的）不联网取图。
- **大文档安全上限**：内容块超过 **8000 个**、表格单元格超过 **20000 个**、图片超过 **200 张**或图片总体积超过
  **48 MB**、脚注 / 尾注超过 **300 条**时，后面的内容会省略，状态栏提示「已简化 N 处」，具体说明写在日志里。
- **复制全文只复制正文**：不含页眉页脚 / 脚注尾注，也不含图片（图片没有文字）。
- **阅读位置记的是「滚动比例」**：窗口宽度 / 缩放变化会让同一比例对应到稍微不同的位置；
  文件被改短时比例仍然合法（只是停在新文档末尾附近），不会报错。
- **只读**：没有编辑 / 保存 / 另存为 / 导出任何入口，也不会修改、移动或删除被浏览的文件。
- 纸面固定白底深字（像一张纸），**不跟随程序的深色主题**；工具条 / 大纲栏 / 状态栏跟随主题。

## 设置项（`Config\word-viewer\config.json`）

改一下自动保存，**没有保存按钮**（配置文件由程序的配置存储统一维护）：

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `zoomPercent` | `100` | 上次的缩放百分比；超出 50 ~ 300 会被自动夹回（手改坏配置也不会缩放异常） |
| `showOutline` | `true` | 大纲侧栏是否显示 |
| `showHeaderFooter` | `true` | 是否显示页眉 / 页脚（工具条「页眉页脚」复选框改它） |
| `rememberReadingPosition` | `true` | 是否记住每份文档的阅读位置；关掉后不再写新记录（**已有记录保留**） |
| `searchMatchCase` | `false` | 查找是否区分大小写（工具条「区分大小写」复选框改它） |
| `readingPositions` | `{}` | 每份文档的上次阅读位置：key 是规范化后的小写完整路径，value 含 `scrollRatio`（0 ~ 1）、`savedAtUtc`；最多 200 份，程序自动维护 |
| `recentLimit` | `50` | 最近打开最多记多少条（0 ~ 100；**0 = 不记录并清空列表**） |
| `recentEntries` | `[]` | 最近打开记录（路径 + 最后打开时间，新的在前；程序自动维护，一般不用手改） |
| `lastFolder` | `""` | 上次选文件所在文件夹，只作为打开对话框的起始目录，不会自动打开文件 |

大纲栏的**拖动宽度**不在这里，统一记在 `Config\layout.json` 的 `word-viewer.大纲与阅读区` 键里。

## 数据位置

- 配置：`Config\word-viewer\config.json`（首次打开工具时自动生成）。
- 布局：`Config\layout.json`（和其它工具页共用，主页设置里可以一键恢复默认）。
- **本工具不需要 `Data\word-viewer\`**：不拷贝、不缓存被浏览的文件，也不生成临时文件（解析完就释放压缩包）。
- **主页「清理缓存」**里本工具提供两项：**最近打开记录**、**阅读位置记录**（只清这些使用痕迹，
  不动缩放 / 页眉页脚 / 查找大小写等设置）。
- 程序数据都放在 exe 旁边；仓库根的同名目录只有说明，**不要**把文档放进仓库目录。

## 实现说明

- **不引第三方库**：docx 就是一个 ZIP 包 + 一堆 XML。ZIP 部件、关系（图片 / 超链接 / 页眉页脚）、安全读 XML、
  单位换算（EMU / twip / 磅 → WPF DIP）由 Core 的 `OoxmlPackage` 统一提供；Word 自己的语义在
  `Parsing/WordDocumentParser.cs` 里手写（段落、样式、编号、表格合并、图片、超链接、大纲、页眉页脚、脚注尾注）。
- **页眉页脚 / 脚注按「部件级关系」解析**：`word/headerN.xml` / `word/footnotes.xml` 里的图片 / 超链接
  要用**该部件自己的** `.rels`；解析上下文会临时切换关系表（图片缓存也按「部件 + 关系 Id」区分，
  避免不同部件的 `rId` 撞车）。部件缺失 / 坏 XML 时静默跳过并把说明记进日志，正文照常显示。
- **脚注编号在解析末尾统一分配**：先扫正文里 `<w:footnoteReference>` / `<w:endnoteReference>` 的出现顺序，
  再给脚注列表排序；引用没有文字也保留一个 run（渲染器据此补 `[n]` 上标）。
- **解析产出纯数据模型**（`Parsing/WordDocument.cs`，不依赖 WPF），所以可以在后台线程跑，
  自检也能在控制台里直接断言；解析结束即释放压缩包，只把文字和图片字节拷出来。
- **排版在 UI 线程**：`Rendering/WordFlowRenderer.cs` 把模型变成 WPF `FlowDocument`（白色纸面、单栏、
  默认微软雅黑 11 磅），页眉 / 页脚用 9 磅浅灰 + 细分隔线，脚注 / 尾注小节在页脚之前；
  同时给出「块下标 → 段落」与「块下标 → 渲染块（段落 / 表格 / 图片）」两张映射表 ——
  大纲跳转、查找高亮和「命中表格时滚到表格」都靠它们。`FlowDocumentScrollViewer` 负责滚动与缩放。
- **阅读位置**：`FlowDocumentScrollViewer` 自己不暴露滚动偏移，渲染器外面由视图从模板里找 `ScrollViewer`
  拿 `VerticalOffset / ScrollableHeight`，把比例交给 ViewModel；切走（`Unloaded`）、换文件前、`OnClosed`
  时落盘；打开文档后等布局完成再按比例 `ScrollToVerticalOffset`（滚动范围没量出来会重试几次）。
  页眉页脚开关只重新排版（`WordFlowRenderer.Build` 的 `WordRenderOptions`），不重新解析文件。
- **线程**：打开文件走 `Task.Run` 后台解析，界面状态通过基类的 `Ui(...)` / `UiAsync(...)` 切回 UI 线程，
  解析大文档时界面不卡；错误（例如坏文件、`.doc`）显示在页面错误区，不弹 MessageBox。
- **剪贴板**：`Clipboard.SetText` 可能因为剪贴板被别的程序占用抛 `COMException`，这里已经 try/catch 并给状态提示。
- **安全**：禁 DTD / 外部实体（防 XXE）、单部件 / 整包体积上限（防压缩炸弹）、块 / 图片 / 单元格 / 脚注数量上限（防畸形文件）。
- 自检覆盖：工具元数据、扩展名识别、段落 / 字符格式、标题 → 大纲、表格合并与列宽、图片尺寸与字节、`.doc` 拒绝、
  坏文件异常、查找（中文 / 大小写 / 预览）、配置默认值与最近列表、渲染映射；**新增**页眉页脚解析与 type 优先级、
  缺部件容错、页眉页脚 / 脚注渲染与位置顺序、脚注尾注过滤与按引用顺序编号、run 上的引用信息、复制全文纯文本、
  表格内查找、区分大小写、阅读位置保存 / 查询 / 上限淘汰 / 非法比例夹取 / 路径大小写去重、新开关默认值与
  `[JsonIgnore]` 序列化行为、文档属性（作者 / 修改时间），共 **68 项**（`word-viewer` 分组）。
