# 📊 Excel 阅读器

> 不装 Excel / WPS 也能**只读浏览 .xlsx / .xlsm 工作簿**：多工作表切换、按 Excel 列宽显示、
> 合并单元格、数字 / 日期格式、粗体斜体填充色、**冻结窗格还原、自动行高、查找单元格、右键复制、阅读位置记忆、显示公式、超链接单元格、行列标题高亮**，
> 选中任意单元格就能在底部看到**地址 / 显示值 / 原始值 / 公式 / 链接**。
> **只读**，不提供任何编辑 / 保存入口，永远不会改动原文件；解析是手写的（`System.IO.Compression` + `System.Xml.Linq`
> + Core 的 `OoxmlPackage`），**不引第三方 Excel 库、不需要装 Office**。

## 能做什么

- **打开工作簿**：工具条「📂 打开…」或 `Ctrl+O`，文件对话框默认过滤 `.xlsx` / `.xlsm`；
  也可以把文件**直接拖进窗口**（只接受 `.xlsx` / `.xlsm`）。打开后标题处显示文件名与完整路径。
- **多工作表切换**：工具条「工作表」下拉列出全部工作表（隐藏工作表名字后面带「（隐藏）」，也能切过去看）；
  切换时按该表的列宽 / 行号重建视图，状态栏同步更新「使用范围」。
- **按 Excel 的样子显示**：
  - 列标题是 **A..Z / AA..**，列宽按 Excel 的字符宽近似换算（`width × 7 + 5` 像素，夹在 24 ~ 600 之间）；
  - 行号显示 **Excel 原始行号**（隐藏行会被跳过，所以行号可能跳号 —— 这是故意的，跳号说明原表有隐藏行）；
  - 单元格的**粗体 / 斜体 / 下划线 / 字号 / 字体色 / 填充色 / 水平对齐 / 自动换行 / 缩进**都尽量还原；
  - **深色主题可读**：没有显式颜色的格子用主题前景色；有填充色时，文字颜色按「亮底深字 / 暗底浅字」自动选，
    不会出现「白底白字」或「深底深字」。
- **数字格式**：常规、`0` / `0.00`、`#,##0` / `#,##0.00`、百分比、科学计数、会计格式、日期时间、
  文本 `@`，以及**自定义格式**（`0` `#` `?` `.` `,` `%` `E+` `yyyy yy m mm d dd h hh s ss AM/PM` `[h]` 引号字面量 分号分段）。
  日期序列号会按 **1900 / 1904 日期系统**换算（含 1900 的「假闰日」），不会整体偏一天。
- **单元格类型**：共享字符串（含富文本 run，会跳过日文注音 `rPh`）、内联字符串、数字、布尔（`TRUE` / `FALSE`）、
  错误值（`#DIV/0!` 等原样显示）、ISO 日期。
- **公式只显示缓存值**：文件里存着 Excel 上次计算的结果，本工具直接显示它，并把**公式原文**放在状态栏；
  **不做公式计算**（所以用别的程序改过、还没重新计算的文件，可能显示旧值或空值，见「注意与限制」）。
- **显示公式模式**（查看公式原文，不计算）：
  - 工具条右侧「**显示公式**」勾选框，或按 ``Ctrl+` ``（反引号 / 波浪号键）切换；
  - 开启后：**有公式的格子显示 `=公式原文`**，没有公式的格子仍显示正常值；关闭后恢复显示值；
  - 过长公式会像普通文本一样**截断显示**，把鼠标停在格子上可在 ToolTip 里看到**完整公式**；
  - 开关状态会**自动保存**（`showFormulas`）；主表和冻结行表**同时生效**，切换时不重建表格，
    列宽 / 选中 / 冻结窗格 / 行高都不会被重置；状态栏会显示「显示公式」提示。
- **超链接单元格**：
  - 工作簿里的超链接会解析出来：**外部链接**（`http` / `https` / `mailto`）和**内部链接**（跳本工作簿的工作表 + 单元格，
    支持 `A1`、`Sheet2!A1`、`'我的 表'!B2` 以及带前导 `#` 的写法）；
  - 带链接的格子显示为**主题强调色 + 下划线**（深色主题可读），鼠标悬停显示**链接地址**；选中时状态栏也会显示「链接：…」/「内部链接：…」；
  - **双击**带外部链接的格子 → 用系统默认浏览器 / 邮件程序打开；
  - **双击**带内部链接的格子 → 切到目标工作表，并滚动、选中目标单元格；
  - 出于安全考虑，**外部链接只允许 `http` / `https` / `mailto`**：`file` / `javascript` / `data` 等协议
    不会打开，只在状态栏提示「只允许 http / https / mailto」；
  - 内部链接指向的工作表 / 单元格不存在（或目标在隐藏行 / 隐藏列 / 截断范围）时，只在状态栏用中文说明，不会崩。
- **行列标题高亮**：
  - 选中任意单元格时，**该行的行号头**和**该列的列字母头**会用主题强调色高亮（半透明底 + 主题色前景），
    一眼看清当前选中在哪一行 / 哪一列；
  - 切换选中会取消上一处高亮；**滚动 / 行容器复用后不残留**，新生成的选中行也会自动补上高亮；
  - 冻结行表如果正显示选中的那一行，它的行号头也会同步高亮；颜色全部取自主题 token，六套主题 / 深浅色自动适配。
- **合并单元格**：按 Excel 的语义显示 —— 左上角「锚点格」显示内容，被覆盖的格子显示为空，
  状态栏会说明当前格是「合并单元格锚点」还是「被合并单元格覆盖」。
- **隐藏行列**：隐藏行不显示、跳过后在状态栏提示数量；隐藏列不建界面列，状态栏提示「N 个隐藏列不显示」。
- **冻结窗格还原**（文件里如果是 Excel 的「冻结」）：
  - **冻结列**：主表左侧冻结，横向滚动时这些列不动（用 DataGrid 自带的 `FrozenColumnCount`）；
  - **冻结行**：主表上方多一张**只读的冻结行表**，只显示冻结的那几行；它的列宽、行号、行高和主表一致，
    横向滚动跟主表同步，不显示列标题（列标题只在主表上出现），也不会抢走鼠标点击；
  - 冻结行太高时最多占数据区 **40%**，不会把主表挤得没法看；
  - 工具条「**冻结窗格**」勾选框控制（默认开）：关掉就完全不冻结行列；状态栏显示「冻结：首行 / 前 2 列」这类提示。
- **自动行高 + 自动换行不裁**：
  - 文件里写了行高（`ht`）的行按文件的行高显示（磅换算成像素，夹在 **18 ~ 180 像素**）；
  - 没写行高的行**按内容自动撑高**，自动换行的长文本不会再被固定 24 像素的旧行高裁掉；
  - 工具条「**自动行高**」勾选框控制（默认开）：关掉后退回统一 24 像素的旧版行为；
  - 行是虚拟化复用的，滚动时会按当前行重新设置高度，不会出现「这一行还是上一行的身高」。
- **查找单元格**：
  - 工具栏第二行是查找区：输入框 + 「区分大小写」+「上一个 / 下一个」+ 命中计数；
  - `Ctrl+F` 直接聚焦查找框；**输入停顿约 300 毫秒自动查找**，按回车立即查找并跳到第一处（`Shift+回车` 跳最后一处）；
  - 搜索范围是**当前工作表**的全部已解析单元格：显示值 / 原始值 / 公式**任一命中**都算；
  - 命中后会自动滚到那一格、选中它，状态栏显示地址 / 值；计数显示「第 3 / 12 处」「没有找到」；
  - 命中太多时最多保留前 **2000** 处，计数后面会提示「只显示前 2000 处，请把关键字写得更具体」；
  - 搜索在后台线程跑、支持取消：改关键字 / 切表 / 打开新文件会立刻作废旧结果，5000 × 200 的大表也不会卡界面。
- **单元格右键复制**（只读辅助，不修改任何东西）：
  - 右键单元格 → 菜单里可以**复制显示值 / 复制原始值 / 复制公式 / 复制地址（A1）**；
  - 「复制公式」复制出来带等号（例如 `=SUM(A1:A2)`），没有公式时该项是灰的；
  - 复制成功 / 剪贴板被别的程序占用，都会在状态栏提示（不弹窗、不崩）。
- **阅读位置记忆**：按工作簿记住「上次看的是哪张工作表 + 滚到了大概哪个位置」；
  重新打开同一本（或切走工具页再切回来）会回到上次的位置。记录的工作表被删掉 / 改名时回退到第一个可见表，不报错。
- **选中即看值**：单击任意单元格，底部状态栏显示 `地址 · 值 · 原始值 · 公式 · 格式（数字格式 / 粗体 / 字号 / 对齐…）`；
  公式会注明「只显示缓存值，不计算」。
- **最近打开**：工具条「最近」下拉列出最近打开过的工作簿（新的在前、同一路径只留一条）；
  点一条直接重新打开；记录里的文件已经被移走 / 删除时，会在下拉里显示「（文件已不存在）」，
  点它只会从最近列表移除并在错误区提示，不会崩。最近列表**只删记录，不删本地文件**。
- **网格线开关**：工具条右侧「网格线」勾选框，关掉后不画单元格线（深色主题下更干净）；改一下自动保存。
- **空状态 / 错误区**：没打开文件时有引导提示；打不开 / 不支持的文件在**页面错误区**显示中文原因（不弹窗）。
- **只读不改原文件**：没有编辑、没有保存，也不会往工作簿里写任何东西。

## 怎么用

1. 在主页找到「**Excel 阅读器**」卡片（分类「文档」，也可以直接搜「Excel」或「表格」）打开。
2. 点工具条「**📂 打开…**」（或按 `Ctrl+O`），选一个 `.xlsx` / `.xlsm` 文件；
   也可以直接把文件**拖进窗口**。
3. 在「**工作表**」下拉里切换工作表；隐藏工作表的名字后面带「（隐藏）」。
4. **单击任意单元格**看底部状态栏：地址（如 `B12`）、显示值、原始值、公式、链接、格式说明；
   同时该行的**行号头**和该列的**列字母头**会高亮，方便定位。
5. **冻结窗格**：文件里有冻结时默认自动还原；不想冻结就取消勾选工具条右侧「**冻结窗格**」。
   状态栏会显示当前冻结了几行 / 几列。
6. **行高**：默认按文件行高 / 内容自动；想回到统一行高就取消勾选「**自动行高**」。
7. **查找**：按 `Ctrl+F`（或直接点查找框）输入内容；停顿一下自动查，按回车跳到第一处，
   再用「上一个 / 下一个」或 `Shift+回车` 在命中之间循环。
8. **复制**：右键单元格 → 选「复制显示值 / 原始值 / 公式 / 地址」。
9. **看公式**：勾选工具条右侧「**显示公式**」或按 ``Ctrl+` ``，有公式的格子会显示 `=公式原文`；
   再按一次（或取消勾选）恢复显示值。开关会自动记住。
10. **打开链接**：带链接的格子是主题色 + 下划线，**双击**它即可——
    外部链接用默认浏览器 / 邮件程序打开（只支持 `http` / `https` / `mailto`），内部链接跳到目标工作表并定位；
    鼠标停在格子上可以看到链接地址。
11. 想快速回到以前看过的文件：工具条「**最近**」下拉里点一条即可；
    文件不在了会显示「（文件已不存在）」，点一下会把它从最近列表移除。
12. 深色主题下觉得格子线太密：取消勾选工具条右侧的「**网格线**」。
13. 换一本：再点「打开…」选下一个文件即可（会先把当前这本的阅读位置记下来）。

> 界面是**满屏布局**（工具条 / 数据区 / 状态栏），数据区随窗口缩放；
> 超大表只解析前 5000 行 × 200 列（见「注意与限制」），状态栏会明确提示截断。

## 支持格式与已知限制

- **支持**：`.xlsx`（Office Open XML 工作簿）、`.xlsm`（带宏的工作簿，**只读、不执行宏**）。
- **不支持**：`.xls`（Excel 97-2003 旧版二进制格式）、`.xlsb`、`.xlt`。
  打开旧格式会提示「不支持旧版 .xls 文件，请用 Excel 打开后『另存为』.xlsx（或 .xlsm）再打开」。
- **不做公式计算**：只显示文件里保存的**缓存值**；公式原文照抄在状态栏。
  如果文件是别的程序生成的、还没计算过（缓存值缺失），单元格会显示为空 —— 用 Excel 打开保存一次即可。
- **显示公式只是「换显示文本」**：开了之后有公式的格显示 `=公式原文`，**不计算、不改变列宽**，
  也不会把公式写回文件；公式太长时和其它长文本一样被截断，完整内容看 ToolTip。公式单元格本来没有缓存值的话，
  开 / 关显示公式都只是空值和公式原文之间的切换。
- **超链接只解析、不编辑**：双击只做「打开 / 跳转」，没有任何写链接的能力。
  - **外部链接协议白名单**：只允许 `http` / `https` / `mailto`；`file` / `javascript` / `data` / `ftp` 等协议
    只会在状态栏提示「不打开」，**不会**交给系统默认程序（安全考虑）；
  - **内部链接只支持本工作簿**：`A1` / `Sheet2!A1` / `'我的 表'!B2`（可带前导 `#`）都支持；
    写成 `[别的书.xlsx]Sheet1!A1` 的**跨工作簿链接不支持**，状态栏会说明；
  - 目标在**隐藏行 / 隐藏列 / 截断范围**外时无法定位，状态栏提示原因；
  - 隐藏列 / 缺 rels / 坏 rels XML 不会让解析崩掉：坏链接按「没有链接」跳过。
- **行列标题高亮**：高亮颜色取自主题强调色（`AccentBrush`），六套主题 / 深浅色自动适配；
  只对**当前生成的表头容器**上色，列虚拟化时横向滚动会重新找一次，行容器复用（Recycling）时也会重设，
  所以滚动后不会残留到别的行列上。
- **不显示**：图表、图片、形状、批注、数据透视表、条件格式的视觉效果、数据验证下拉、迷你图。
  这些内容不参与单元格数据的显示（但不会影响其它格子的解析）。
- **合并单元格不是真合并**：DataGrid 里仍是一格一格显示，只是锚点格有内容、其余格为空；
  状态栏会标明当前格属于合并区域。
- **超大表会截断**：默认最多解析 **5000 行 × 200 列**（解析上限可调，但硬上限 20000 行 / 1000 列）。
  被截断时状态栏显示「工作表共 N 行，只显示前 5000 行」这类中文说明。截断只影响**显示**，不改文件。
- **隐藏行 / 隐藏列不显示**：隐藏行直接跳过（行号会跳号），隐藏列不建界面列；数量在状态栏提示。
- **列宽是近似值**：Excel 的列宽单位是「字符数」，这里按 `width × 7 + 5` 换算成像素并夹在 24 ~ 600；
  不同 Excel 版本 / 字体下可能有几像素差异。
- **冻结窗格只还原「冻结」**：
  - 只认 OOXML 的 `state="frozen"` / `state="frozenSplit"`；Excel 的「**拆分**窗格」（`state="split"`）不还原（它不是冻结）；
  - 冻结几行 / 几列按**界面可见行列**算（隐藏列 / 隐藏行不占位置）；文件里没写 `topLeftCell` 时用
    `xSplit` / `ySplit` 兜底；边界不会超过实际解析到的行列数；
  - 冻结行是**第二张只读表**叠在主表上方，所以：它没有自己的滚动条、不能在里面选中单元格，
    横向滚动跟随主表；冻结行总高度超过数据区 40% 时会被截断（属于有意限制，避免主表只剩一条缝）；
  - 冻结列用 DataGrid 的 `FrozenColumnCount`，列标题仍然只在主表顶部显示。
- **自动行高有上限**：按文件行高 / 内容撑高，但单个行最高 **180 像素**、最低 18 像素 ——
  超长文本（或莫名其妙写了很大行高的文件）不会把一行拉满整屏；完整内容仍可看状态栏 / 复制。
- **查找只查当前工作表**：不会跨工作表搜；只搜**已解析**的单元格（被截断的行 / 列不参与）；
  命中上限 2000 处；命中在**隐藏列**里时无法滚动定位，状态栏会给出说明。
- **阅读位置是「大致位置」**：记录的是纵向滚动比例（0 ~ 1），窗口大小 / 列宽变化后可能有一两行的偏差；
  只对**同一本工作簿**有效；记录的工作表不存在时回退到第一个可见工作表。
- **主题色解析是「尽量」**：优先用 `styles.xml` 里的 rgb；只有 theme 索引时读 `xl/theme/theme1.xml` 的主题色板并套 tint；
  实在解析不出来就用主题默认前景色（深色主题下仍然可读）。
- **只读不写**：不修改原工作簿，也不会在文件旁边生成任何临时文件。

## 设置项

| 设置 | 存哪 | 说明 |
| --- | --- | --- |
| 显示网格线 `showGridLines` | `Config\excel-viewer\config.json` | 默认**开**；工具条「网格线」勾选框控制，改一下自动保存 |
| 还原冻结窗格 `restoreFreezePanes` | 同上 | 默认**开**；工具条「冻结窗格」勾选框控制；关掉只是不冻结，不改原文件 |
| 自动行高 `autoRowHeight` | 同上 | 默认**开**；工具条「自动行高」勾选框控制；关掉 = 统一 24 像素 |
| 显示公式 `showFormulas` | 同上 | 默认**关**；工具条「显示公式」勾选框 / ``Ctrl+` `` 切换；开 = 有公式的格显示 `=公式原文` |
| 记住阅读位置 `rememberReadingPositions` | 同上 | 默认**开**；关掉后不再写入 / 恢复阅读位置（已有记录不删） |
| 阅读位置记录 `readingPositions` | 同上 | 字典：key = 完整路径小写，value = `sheetName` / `scrollRatio`（0~1）/ `savedAtUtc`；最多 **200** 本，超出淘汰最老的；程序自动维护 |
| 最近打开上限 `recentLimit` | 同上 | 默认 **50**，范围 **0 ~ 100**（超出会被夹住）；**0 = 不记录并清空已有列表**；调小会立刻裁掉多余的老记录 |
| 最近打开记录 `recentEntries` | 同上 | 路径 + 最近打开时间；新的在前、按完整路径去重（大小写不敏感）；程序自动维护 |
| 上次打开的文件夹 `lastFolder` | 同上 | 「打开…」对话框的起始目录，**不会自动打开**文件 |
| 恢复默认设置（按钮，当前只在代码 / 自检里用） | 改上面的显示设置 | 网格线 / 冻结还原 / 自动行高 / 显示公式 / 记住阅读位置回**默认**（前四项开、显示公式关）、最近上限回 **50**；**不清空**最近记录和阅读位置（只按 50 裁剪最近记录），也不动 `lastFolder` |

> 改一下自动保存，**没有「保存」按钮**（所有工具的统一约定）。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\excel-viewer\config.json` | 上面全部设置：网格线 / 冻结窗格 / 自动行高 / 显示公式 / 阅读位置开关与记录、最近上限与最近打开记录、上次打开的文件夹 |
| `Data\excel-viewer\` | 正常使用**不写东西**（本工具不产生缓存文件） |
| 「主页设置 → 清理缓存」 | 本工具会列出「最近打开记录」「阅读位置记录」两项（有记录时才出现）；勾选清理只清对应记录，不动显示设置，也不删工作簿 |

> `Data` / `Config` 就在 **exe 旁边**（`bin\Debug\net9.0-windows10.0.19041.0\` 或发布出来的目录），
> 整个程序目录拷走就能迁移数据。目录约定见 [shell.md](../shell.md#数据与配置都在-exe-旁边)。

## 实现说明

- **手写 xlsx 解析**：xlsx 本质是「ZIP + XML」。ZIP 部件 / 关系解析 / 安全读 XML（禁 DTD 防 XXE）/
  体积上限由 Core 的 `OoxmlPackage` 统一负责（Word 阅读器共用同一份），
  `Parsing/` 里只写「工作簿语义」：
  - `XlsxParser`：`xl/workbook.xml`（工作表清单 / 隐藏状态 / 1904 日期系统）、`xl/_rels/workbook.xml.rels`、
    `xl/sharedStrings.xml`（富文本）、`xl/styles.xml`（numFmts / fonts / fills / cellXfs）、
    `xl/worksheets/sheetN.xml`（行 / 格 / 列宽 / 合并 / 行高 / 冻结窗格 / 超链接）、
    `xl/worksheets/_rels/sheetN.xml.rels`（超链接 URL）、`xl/theme/theme1.xml`（主题色板）；
  - `ExcelNumberFormat`：内置格式 id 表 + 自定义格式的显示换算（**只做显示，不做计算**）；
  - `ExcelAddresses`：列字母 ↔ 序号、A1 引用换算；
  - `ExcelSearch`：查找纯逻辑（显示值 / 原始值 / 公式、大小写、上限、取消），在 `Task.Run` 里跑；
  - `ExcelClipboardText`：右键复制要放进剪贴板的文字（显示值 / 原始值 / 带等号的公式 / A1 地址）；
  - `ExcelCellText`：显示公式模式的纯文本逻辑（有公式 = `=公式原文`，没有公式 = 显示值；ToolTip 规则）；
  - `ExcelHyperlinks`：超链接纯逻辑（外部 URL / 内部 location 解析成模型、`http/https/mailto` 协议白名单、
    `Sheet!A1` / 引号表名的 location 解析），打开链接前的安全判断都走它。
- **冻结窗格**：解析器把 `pane` 的 `topLeftCell`（优先）或 `xSplit` / `ySplit`（兜底）换算成
  「界面可见的冻结行数 / 列数」，并夹在实际行列数内。视图层：冻结列 → 主表 `FrozenColumnCount`；
  冻结行 → 主表上方第二个只读 `DataGrid`（`ItemsSource` 取当前表前 N 行），
  两套列定义 / 列宽保持同步（拖动主表列宽后同步过去），主表 `ScrollChanged` 时把横向偏移同步给冻结表；
  冻结表不能命中鼠标，由外层 `Border` 把滚轮转给主表。切换工作表 / 重建列时都会重新应用，
  不会残留上一张表的冻结行。
- **行高**：`sheetData/row/@ht` 的单位是**磅**，解析时按 `ht × 96 / 72` 换成 DIP；
  视图在 `LoadingRow` 里按「有 ht 用 ht（夹 18 ~ 180）、否则 NaN（按内容自动）」设置行高。
  `Recycling` 模式下同一行容器会复用，所以**每次 LoadingRow 都重设**，不让上一行的高度残留；
  关掉「自动行高」时改由 `DataGrid.RowHeight = 24` 统一控制。
- **查找**：纯逻辑在 `ExcelSearch`，ViewModel 用 300ms `DispatcherTimer` 防抖 + `CancellationTokenSource`
  取消旧搜索；结果回 UI 线程应用，跳转通过事件让 View 做 `ScrollIntoView` + 选中单元格，
  状态栏的地址 / 值仍走统一的 `SelectCell`。
- **阅读位置**：ViewModel 缓存界面报告的滚动比例，只在**切工作表 / 打开另一个文件 / 切走工具页 / 关闭工具**时
  写进配置（`Config\excel-viewer\config.json` 的 `readingPositions`），避免滚动时每帧写盘；
  View 在 `Unloaded` 时把「当前表 + 比例」交给 ViewModel，`Loaded` / 列重建完成后按比例恢复。
  视图被外壳缓存后切回来仍是同一个 View，不会重置到顶部。
- **显示公式**：不在开关时克隆 / 重建任何模型 —— 单元格模板里用
  `MultiBinding(ExcelCell, 页面级 ShowFormulas)` 交给 `ExcelCellTextConverter` 计算显示文本
  （纯逻辑在 `ExcelCellText`），所以切换只发一次属性通知，列宽 / 选中 / 冻结 / 行高全部保持；
  主表与冻结行表共用同一份模板，两处同时生效。
- **超链接**：解析 `hyperlinks/hyperlink` 的 `ref`（支持区域）/ `r:id` / `location` / `display`，
  `r:id` 按**该工作表自己的 rels** 解析（不是 workbook 的 rels）；`TargetMode="External"` → URL，
  `location` → 内部链接。结果同时挂在 `ExcelCell.Hyperlink` 与 `ExcelSheet.Hyperlinks`（地址 → 链接映射）上；
  缺 rels / 坏 rels XML / 坏 ref 都按「没有链接」跳过。双击由 View 找到命中格交给 ViewModel：
  外部链接先过 `ExcelHyperlinks.TryCreateLaunchUri` 白名单再 `Process.Start(UseShellExecute=true)`；
  内部链接切工作表后通过 `CellNavigateRequested` 事件让 View `ScrollIntoView` + 选中。
- **行列标题高亮**：代码后置在 `SelectedCellsChanged` 里记录当前行 / 列，对**已生成的**
  `DataGridRowHeader` / `DataGridColumnHeader` 设置主题 `AccentBrush` 的半透明背景 + 主题色前景，
  旧容器用 `ClearValue` 恢复表头样式（不重建表、不写死颜色）；`LoadingRow` / 行容器 `Loaded` 会按当前选中重设，
  所以滚动、Recycling 复用后不残留；列虚拟化横向滚动时重新查找列标题容器。
- **WPF DataGrid 只读视图**：`IsReadOnly=True`、单元格选择、行/列虚拟化（`VirtualizationMode=Recycling`）；
  列由代码后置按当前工作表生成（每列一个 `DataGridTemplateColumn`，内容绑定该行 `Cells[列号-1]`），
  隐藏列不建；样式（表头 / 行 / 单元格 / 网格线颜色 / 右键菜单）全部走 `{DynamicResource}` 主题 token，六套主题 / 深浅色自动适配。
- **解析在后台线程**：`Task.Run` 里解析，界面状态统一走基类的 `Ui(...)`，打开大表时界面不卡。
- **内存友好**：同一样式的格子共享一个 `ExcelCellStyle` 实例；列 / 行按需虚拟化渲染，
  不会一次性给整张表生成 UIElement；冻结行表只装前 N 行。
- **调试开关（开发 / 截图用，都不写配置）**：
  - `YLT_EXCEL_OPEN=<xlsx 路径>`：启动后自动打开该工作簿；
  - `YLT_EXCEL_SELECT=<A1 地址>`（也接受 `Sheet!A1`）：打开后自动选中并滚动到该格（只读操作、不写配置），
    地址非法 / 超出范围只写日志，用来截图「行列标题高亮」这类效果。
- **只读保证**：解析器只用 `FileAccess.Read` 打开文件，全部代码里没有任何写入工作簿的路径。
- **自检**：`excel-viewer` 组共 **76** 项（原 58 项 + 超链接 / 显示公式 / 截图选择地址 / 配置新增 18 项），
  在 `tests/YuLiangToolkit.FrameworkSelfCheck/ExcelViewerChecks.cs` 里手写最小 xlsx / 超链接 xlsx 覆盖解析与纯逻辑；
  界面（高亮、双击）由截图冒烟验收。
