# 📦 压缩包工具

> 拖入即用：**解压** RAR（RAR4 / RAR5）、ZIP、7Z、TAR、TAR.GZ、TAR.BZ2、TAR.XZ、TAR.ZST、GZ、BZ2、XZ、ZST
> 等常见压缩包（支持密码、旧版 GBK 文件名、批量、进度、取消）；
> **压缩**能把文件 / 文件夹打成 **ZIP 或 7Z**。**RAR 因版权原因只能解、不能压**。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**（每个区块之间都能拖）：左边「解压」列表和右边「压缩」列表之间可左右拖；
> 上半与底部日志之间可上下拖，拖完自动记住；双击某条缝只恢复这一处，
> 全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **解压**：把压缩包拖进左栏（或点「添加压缩包…」），自动识别格式并列出「内容」（文件数 / 大小 / 是否加密）；
  选好解压位置后点「开始解压」，支持**批量**、**进度条**、**取消**、日志。
- **压缩**：把文件 / 文件夹拖进右栏（或点「添加文件… / 添加文件夹…」），选格式（**ZIP / 7Z**）和压缩级别
  （仅存储 / 最快 / 标准 / 极限），点「开始压缩」。文件夹会**递归**打包，并保留「源文件夹名」这一层。
- **密码解压**：加密 zip / 7z / rar 填上密码即可；预填了密码时能解就解，密码错会提示而不是崩掉。
- **旧版 GBK 文件名**：老压缩包里的中文名乱码时，「旧版文件名编码」选 **GBK** 就能正确还原。
- **不覆盖用户数据**：解压遇到同名文件默认**自动改名**（`a.txt` → `a (1).txt`），也可以选覆盖 / 跳过。
- **路径穿越防护**：压缩包里带 `../`、`..\` 或绝对路径的「越界条目」一律跳过并写日志，
  **绝不会**把文件写到目标目录外面（防 zip-slip）。
- 解压 / 压缩完成可以在日志里看结果，勾了「完成后打开输出位置」会直接打开资源管理器定位。

## 支持格式

| 格式 | 解压 | 创建 | 密码 | 说明 |
| --- | :---: | :---: | :---: | --- |
| **ZIP**（.zip） | ✅ | ✅ | ✅ | 最常用；支持 ZIP64、UTF-8 文件名、传统加密 / AES 解压 |
| **7Z**（.7z） | ✅ | ✅ | ✅ | 压缩率高；创建用 LZMA2 |
| **RAR**（.rar） | ✅ | ❌ | ✅ | RAR4 / RAR5 都能解；**受版权限制不能创建**（见下文） |
| **TAR**（.tar） | ✅ | ❌ | — | 仅归档、不压缩；GNU / PAX 等常见写法都能读 |
| **TAR.GZ**（.tar.gz / .tgz） | ✅ | ❌ | — | 压缩版 TAR，解压时会先解开 GZ 再解开 TAR |
| **TAR.BZ2**（.tar.bz2 / .tbz2） | ✅ | ❌ | — | 同上，BZip2 压缩 |
| **TAR.XZ**（.tar.xz / .txz） | ✅ | ❌ | — | 同上，XZ 压缩 |
| **TAR.ZST**（.tar.zst） | ✅ | ❌ | — | 同上，Zstandard 压缩 |
| **GZ**（.gz） | ✅ | ❌ | — | **单文件压缩**：解出来就是一个文件，没有目录结构 |
| **BZ2**（.bz2） | ✅ | ❌ | — | 单文件压缩 |
| **XZ**（.xz） | ✅ | ❌ | — | 单文件压缩 |
| **ZST**（.zst） | ✅ | ❌ | — | 单文件压缩 |
| ACE / ARC / ARJ / LZW | ✅ | ❌ | — | 顺带支持的老格式，**只解不压** |

> 单文件压缩（.gz / .bz2 / .xz / .zst）解压后的文件名优先用压缩包里的原始文件名；
> 拿不到时用压缩包自己的主名（`single.txt.gz` → `single.txt`），**不会**再多套一层同名目录。

## 怎么用

### 解压

1. 把压缩包（可以一次多个）拖到左上「解压」列表，或点「添加压缩包…」选择文件。
   拖进来后会**自动读一遍清单**，显示格式、文件数 / 大小、是否加密。
2. 选解压位置：
   - **压缩包旁边**（默认）：解到压缩包所在目录；
   - **指定目录**：自己选一个固定目录（会记住）。
3. 勾不勾「每个包单独子文件夹」（默认**勾上**）：勾上时每个包解到「压缩包主名」目录里，
   避免一次解一堆文件糊在原目录。
4. 同名文件处理（默认「自动改名」）、密码、旧版文件名编码按需设置。
5. 点「开始解压」；过程中可以点「取消」，已解出来的文件会保留。
6. 完成后看底部日志和状态；勾了「完成后打开输出位置」会自动打开解压目录。

### 压缩

1. 把文件 / 文件夹拖到右上「压缩」列表，或点「添加文件… / 添加文件夹…」。
   文件夹会递归统计文件数和总大小（拖入时就能看到「共 N 个文件 · X MB」）。
2. 选格式（**ZIP / 7Z**）和压缩级别（仅存储 / 最快 / 标准 / 极限）。
   默认文件名按「单个源的主名」或「压缩包-年月日-时分秒」自动生成，可自己改。
3. 选输出位置（默认第一个源旁边；也可以指定固定目录并记住）。
4. 点「开始压缩」；已完成 / 取消都会清理半成品文件。
5. 完成后同样可以「打开输出位置」。

## 覆盖策略（同名文件怎么办）

| 策略 | 行为 | 适用场景 |
| --- | --- | --- |
| **自动改名**（默认，最安全） | 目标已有同名文件时，新的解成 `名字 (1).扩展名`、`名字 (2).扩展名`… **原文件不动** | 绝大多数情况；不丢数据 |
| **覆盖** | 直接覆盖目标位置已有的同名文件 | 明确知道要更新文件时 |
| **跳过** | 目标已有同名文件就不解这个条目（计入「跳过」数） | 增量解压 / 只补缺的文件 |

> 默认是「自动改名」，因为覆盖会**永久丢掉原文件**、而且没有撤销；确认要覆盖时再手动切换。

## 密码与旧版 GBK 文件名

- **密码**只用于解压，**不会写进配置文件**（只存在本次运行的内存里），避免明文落盘；
  关闭工具再打开需要重新输入。
- 加密 zip / 7z / rar：填对密码就能解；密码错或不填会返回中文失败提示（例如「密码错误或压缩包损坏」），
  不会弹出一串英文异常。
- **旧版文件名编码**：Windows 上的老压缩包常用 GBK（代码页 936）保存中文名，直接按 UTF-8 解会乱码。
  遇到乱码时把「旧版文件名编码」从「自动」切到 **GBK** 再解一次即可；
  新压缩包（ZIP 的 UTF-8 标记 / 7Z / RAR5）一般「自动」就够。
- 压缩（创建）**暂不支持加密**：本工具只做普通 ZIP / 7Z。

## 为什么 RAR 只能解不能压（版权说明）

- RAR 的**压缩算法是专有的**，只有 RARLAB（WinRAR 官方）拥有压缩器版权；
  第三方软件要实现「**创建** RAR」需要另外取得授权。
- 本工具用的是纯托管开源库 **SharpCompress**（MIT）：它能**读** RAR（RAR4 / RAR5），
  但**不提供 RAR 写入器**——所以本工具**只解不压**，这是刻意遵守许可的选择，不是功能缺失。
- 需要「生成 RAR」时请用官方 WinRAR 或 rar.exe；本工具仍然可以正常**解压**它们做出来的 RAR。
- 本工具也**不调用**系统的 `rar.exe` / `7z.exe`：不依赖用户机器上装没装压缩软件，开箱即用。

## 限制

- **RAR 不能创建**（版权原因，见上）；创建只支持 **ZIP / 7Z**，TAR 系列目前也不做创建。
- **7Z 的「仅存储」**不是真 Store：7Z 写入器只支持 LZMA / LZMA2，选「仅存储」会自动降级成 **LZMA2 最低压缩级别**，
  日志里会写一条提示；ZIP 的「仅存储」是真不压缩。
- **创建加密压缩包不支持**（解压支持密码；创建只做普通包）。
- **分卷 / 多卷压缩包**（`.part1.rar`、`.z01` 这类）暂不支持；请先用官方工具合并或完整解压。
- 带**符号链接（软链接 / junction）**的条目会跳过并写日志，避免写到目标目录外；
  创建时源里的链接目录 / 链接文件也会跳过，防止死循环。
- 解压只做「文件还原」，不保留 NTFS 权限 / 属主等元数据；文件修改时间默认保留。
- 被占用 / 无权限的文件会跳过并写日志，整批不会因此中断；错误细节看底部日志。
- 遇到损坏的压缩包会给出中文错误提示；能解多少解多少（部分损坏的包可能只能解出前半部分）。

## 常见问题

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 解出来的中文文件名是乱码 | 老压缩包用 GBK 保存文件名 | 「旧版文件名编码」切成 **GBK** 再解 |
| 提示「密码错误或压缩包损坏」 | 密码错 / 没填密码 / 包真的坏了 | 确认密码；重新下载压缩包再试 |
| 解压出来文件名变成 `a (1).txt` | 目标目录已有同名文件，默认「自动改名」 | 正常现象；想覆盖就把同名处理改成「覆盖」 |
| 某些条目没解出来，日志说「跳过」 | 路径越界（`../`、绝对路径）、符号链接、无权限 | 多为安全防护；确认压缩包来源是否可信 |
| 想压成 RAR | RAR 压缩算法专有 | 本工具不支持创建 RAR；用官方 WinRAR，或改压 7Z / ZIP |
| 加密包能不能压出来 | 创建加密暂不支持 | 先用压缩软件加密，再交给本工具解压 |
| 大压缩包解压没反应 / 时间很久 | 正在解压（进度条可能是不确定进度） | 看日志与进度；可随时「取消」，已解文件保留 |
| 压缩包里明明有文件，列表却是空的 | 包损坏 / 格式不是表格里那些 | 看列表状态与日志里的中文失败原因 |

## 设置项与数据

| 位置 | 内容 |
| --- | --- |
| `Config\archive\config.json` | 解压目标方式与目录、是否每个包单独子文件夹、同名文件策略、是否保留时间戳、上次使用的目录、创建格式 / 压缩级别 / 输出目录、完成后是否打开输出位置。改完**自动保存**，没有「保存」按钮 |
| 密码 | **不落盘**：只存在本次运行的内存里，关闭工具即清空 |
| 输出文件 | 解压 / 压缩产物都写在用户选择的目录（默认压缩包旁 / 源旁）；本工具不往 `Data` 里塞东西 |
