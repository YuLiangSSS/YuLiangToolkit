# 📄 PDF 阅读器

> 看 PDF 不用再装别的阅读器：**纵向 上 → 下 / 横向 左 → 右连续滚动**，或者像翻书一样**双页并排、一次翻两页**；
> 还支持 **25% ~ 800% 缩放**、**Ctrl+F 全文搜索**、**📑 书签目录**，以及**双击 .pdf 直接进本工具**。
> PDF 用 Windows 自带的 `Windows.Data.Pdf` 渲染，**不引第三方 PDF 库、不用另装组件**。

## 能做什么

- **三种阅读方式**：**纵向 上 → 下**（默认，连续滚动）、**横向 左 → 右**（连续滚动）、**双页 翻页**（左右两页并排，一次翻两页）。
  切换在工具条的「阅读方式」下拉里，选中立刻生效。
- **连续滚动**：所有页按顺序排成一条长带，滚轮沿阅读方向滚 —— 一格默认 **120** 像素，可以在配置里改成 **20 ~ 600**。
- **左键拖动 + 惯性**：两种连续滚动模式下按住左键都能拖；松手后按甩动速度**继续滑一段**，
  连续甩会越甩越快（有上限：**6 像素 / 毫秒**）；拖动只沿阅读轴（纵向上下、横向左右）。
  取消工具条上的「惯性」勾选框就是松手即停。
- **双页翻页**：左右两页并排，**一次翻两页**（`[1,2] → [3,4] → …`），相邻两屏**不重叠**；
  总页数是奇数时最后一屏只有左页。滚轮向下 = 下一页、向上 = 上一页，也可以用方向键 / `PageUp` `PageDown` /
  空格 / 屏幕上的上一屏、下一屏按钮翻；翻页带约 **0.2 秒**的滑动动画，底部显示「第 x–y 页 / 共 n 页」。
  两页之间的间距还能在「⚙ 设置」里调（0 ~ 64 像素，默认 **2**）。
- **连续模式导航**：`Home` / `End` 直接跳到开头 / 结尾；`↑` `↓` `←` `→` 或 `PageUp` `PageDown` 也能滚；
  底部有一条细进度条和「第 x / n 页」，随时知道看到哪了。
- **记住每本 PDF 上次读到哪**：打开同一本 PDF（按**文件完整路径**区分）会自动回到上次读到的地方 ——
  连续滚动模式按**整体阅读比例**恢复到几乎一模一样的位置，双页翻页模式回到上次那一屏；
  如果换了阅读方式再打开，会退回到「**上次那一页**」。位置在**滚动停止约 1.2 秒**、关工具 / 关闭程序时自动保存，
  **没有保存按钮**；最多记 **200 本**（超出按最后阅读时间淘汰最老的）；不是「只记最后一本」，是每本各记各的。
- **🕘 最近浏览（上限可调）**：工具条「🕘 最近」打开右上角的最近浏览浮层，列出最近打开过的 **PDF 文件**
  （新的在上，同一路径只留一条）；点一条直接重新打开，并**自动回到上次阅读位置**；列表顶部「**清空**」只删记录、
  **不会删本地文件**；按 `Esc` 或 ✕ 关闭，打开成功后浮层也会自动收起。面板右下角提示上限在哪调；
  设置面板「最近浏览」里能把上限调到 **0 ~ 100**（默认 **50**；**0 = 不记录并清空列表**），改一下自动保存；
  工具里打开 / 双击关联 / 从最近点开都会记一条。
- **页码跳转**：工具条第二行右侧有「**跳页** [页码输入框] →」—— 输入页码（**1 起、只能 1 ~ 总页数**）后
  按**回车**或点箭头，直接跳到该页；非法页码会弹提示并把输入框内容**全选**，方便重填。
  全屏沉浸模式里鼠标移到顶部浮出的工具条也有同一个跳页框；输入框悬停提示会显示**总页数 / 当前页**，底部页码条显示当前页。
- **缩放 25% ~ 800%**：工具条第二行是「**缩放** `−` [百分比输入框] `+`」，默认 **100%**，一步 10%。
  **100% = 铺满基准**（纵向连续按窗口宽、横向连续按窗口高、双页按一屏两页铺满），**不是 PDF 原始点数 1:1**。
  `Ctrl+滚轮` 以画面中心缩放；连续模式放大后可以滚另一个轴（`Shift+滚轮`）；
  **双页模式放大后按住左键可以拖动平移**（带惯性），上一屏 / 下一屏按钮照常可用。
  放大后的页是位图重新渲染的（不是矢量），超过渲染上限会**略糊**。
- **Ctrl+F 文字搜索**：工具条搜索框**输入即搜**（带防抖），旁边显示「第 x / y 处」（当前命中页看底部页码条）；
  `回车` = 下一个命中、`Shift+回车` = 上一个、`Esc` = 清除；点搜索框右侧的 ◀ / ▶ / ✕ 也能上一个 / 下一个 / 清除。
  切换命中会跳到那一页（连续模式滚到该页开头，双页模式翻到该页所在的两页）。
  搜索基于 PDF **自带的文字层**：扫描版 / 没有 ToUnicode 字体的 PDF 搜不到文字（搜索栏会提示「无可搜索文字」）；
  **不是高亮框，是跳页 + 计数**。
- **📑 书签目录**：工具条「📑 目录」打开左侧目录面板，按 PDF 大纲层级缩进列出；点条目跳到对应页。
  PDF 没有大纲时面板里显示「这个 PDF 没有书签目录」。目录和搜索共用同一套后台文字层提取。
- **全屏沉浸阅读（F11）**：工具条第一行最右边的「全屏」按钮或 `F11` 进入全屏，`Esc` 退出。全屏会藏掉
  标题栏 / 侧边栏 / 面包屑 / 状态栏，把窗口铺满整块屏幕（**任务栏也临时藏起来**），退出后原样还原；
  **当前阅读方式不变**，只是阅读区变大，切进 / 切出全屏会尽量保持阅读位置
  （连续滚动保持画面中心、双页翻页保持当前屏）。全屏时两行工具条变成浮在阅读区顶部的**半透明圆角卡片**：
  鼠标一动就出现，停 **2.5 秒**自动缩回、鼠标指针也一起隐藏；鼠标移到顶部（或任意移动）让工具条出现后，
  缩放 / 搜索 / 目录 / 设置 / 翻页照常可用（搜索框聚焦、目录 / 设置面板打开时工具条不会自动收）。
  底部页码与进度条保留、底部操作提示收起；切走工具会自动退出全屏。
- **双击 .pdf 打开（文件关联）**：在「⚙ 设置」里勾选「**双击 .pdf 文件用本工具打开**」即登记到当前用户注册表
  （不需要管理员）；取消勾选会撤销登记并把原来的默认程序还原。Windows 10 / 11 的系统默认程序（`UserChoice`）
  受保护，如果双击还是别的阅读器，点设置面板里的「**打开 Windows「默认应用」设置**」把 `.pdf` 关联选成
  「PDF 阅读器」一次即可。程序已经开着时双击 PDF 会**复用同一个窗口**（程序级单实例，默认开）；
  也支持把 PDF 路径当命令行参数：`YuLiangTookit.exe "D:\文档\xxx.pdf"`。
- **只渲染看得见的那几页**：大 PDF 不用一次性把全本解码进内存，翻着看更省内存
  （快速甩动时页可能短暂空白一下再补上，见「注意与限制」）。
- **打开方便**：工具条「📄 打开 PDF…」或 `Ctrl+O`，文件对话框默认过滤 `.pdf`；
  打开后工具条显示**文件名 · 共 N 页**和完整路径。
- **只读不改原文件**：只是看，不会改动 PDF。

## 三种阅读方式

| 阅读方式 | 类型 | 适合 | 说明 |
| --- | --- | --- | --- |
| 纵向 上 → 下（默认） | 连续滚动 | 文档 / 长帖 / 论文 | 页从上往下排成一条长带；滚轮往下滚 = 往后看 |
| 横向 左 → 右 | 连续滚动 | 横版文档 / 演示稿 | 页从左往右排成一条长带；滚轮往下滚 = 往右看 |
| 双页 翻页 | 翻页 | 页漫 / 杂志 / 双页排版 | 左右两页并排，一次翻两页：`[1,2] → [3,4] → …`；奇数页最后一屏只有左页 |

> 换方式：工具条上的「阅读方式」下拉里选一个，选中后立刻按新方式重建视图，并**尽量停在当前页**。
> 长文档用连续滚动更顺；页漫 / 杂志 / 双页排版的文档用双页翻页更像翻书。

**双页翻页补充：**

- **一次翻两页、相邻两屏不重叠**（和图片连续阅读器的「一次翻一张」不同，看 PDF 时整屏翻过去更符合翻书直觉）。
- 总页数为奇数时，最后一屏**只有左页**，右边留空。
- 左右两页的间距可以在「⚙ 设置 → 双页页面间距」里调：**0 ~ 64 像素**，默认 **2 像素**（贴近，像翻书）；0 = 两页贴在一起。
- 翻页动画约 0.2 秒；底部显示「第 x–y 页 / 共 n 页」。
- **放大后**可以按住左键拖动平移（带惯性），也可以用 `Shift+滚轮` 上下平移。

## 怎么用

1. 在主页找到「**PDF 阅读器**」卡片（标签「媒体」，也可以直接搜「PDF」）打开。
2. 点工具条的「**📄 打开 PDF…**」（或按 `Ctrl+O`），在对话框里选一个 `.pdf` 文件 —— 对话框默认过滤 `.pdf`。
3. 打开过的 PDF 会自动回到**上次读到的地方**：连续滚动按整体比例恢复、双页翻页回到上次那一屏；
   换了阅读方式再打开则退回「上次那一页」（自动保存，没有保存按钮）。
4. 想**回到以前看过的 PDF**：点工具条「**🕘 最近**」打开最近浏览，点一条直接重新打开（并自动回到上次阅读位置）；
   列表顶部「**清空**」只删记录、**不会删本地文件**。
5. 默认是**纵向 上 → 下**连续滚动：滚轮往下看；嫌慢就按住左键往上拖，甩一下松手会继续滑。
6. 想**左右滚**：工具条的「阅读方式」下拉切成「横向 左 → 右」，滚轮往下滚 = 往右看。
7. 想**一屏两页地翻**：切成「双页 翻页」，然后用滚轮、`←` `→`、`PageUp` `PageDown`、空格或屏幕上的翻页按钮翻。
8. 想**直接跳到某一页**：在工具条第二行右侧的「**跳页**」框里填页码（1 ~ 总页数），按回车或点右边的箭头；
   填错会弹提示并全选输入框，重新填即可。全屏时鼠标移到顶部，浮出的工具条里也有这个框。
9. 想**放大看细节**：`Ctrl+滚轮`，或在工具条第二行点 `−` / `+`、直接在百分比输入框里填数字（25 ~ 800，回车或失焦生效）。
   放大后：连续模式用 `Shift+滚轮` 滚另一个轴；双页模式按住左键拖动平移。
10. 想**在 PDF 里找字**：`Ctrl+F` 聚焦搜索框，输入就搜；`回车` 下一个、`Shift+回车` 上一个、`Esc` 清除。
11. 想**按书签跳**：点工具条「📑 目录」打开左侧面板，点条目直接跳到对应页。
12. 不想要拖动惯性：取消工具条上的「**惯性**」勾选框（改一下自动保存）。
13. 连续模式下想快速到开头 / 结尾：按 `Home` / `End`。
14. 双页模式下觉得两页隔得太开 / 太近：点「**⚙ 设置**」，拖「双页页面间距」滑块（0 ~ 64 px，默认 2 px）。
15. 想让它少记 / 不记最近浏览：设置面板「**最近浏览**」拖滑块（**0 ~ 100**，默认 **50**；**0 = 不记录并清空**；调小会立刻裁掉多余的老记录）。
16. 想让**双击 .pdf 直接进本工具**：在「⚙ 设置」里勾选「双击 .pdf 文件用本工具打开」；
    如果双击还是别的阅读器，点「打开 Windows「默认应用」设置」把 `.pdf` 选成「PDF 阅读器」一次
    （Windows 的默认程序受系统保护，需要你手动确认一次；详见「注意与限制」）。
17. 调乱了想全部回默认：设置面板最下面的「**恢复默认设置**」（阅读方式回纵向、缩放 100%、双页间距 2 px、惯性开、滚轮 120）。
18. 换一本：再点「打开 PDF…」选下一个文件即可（每本的位置各记各的）。
19. 想沉浸着看：按 `F11`（或点工具条第一行最右边的**全屏**按钮）进入全屏，`Esc` 退出；全屏时鼠标一动工具条才浮出来，停 2.5 秒自动缩回。

## 操作与快捷键

| 操作 | 作用 |
| --- | --- |
| 滚轮（纵向 / 横向连续滚动） | 沿阅读方向滚一格（默认 **120px**，可在配置里改） |
| 滚轮（双页翻页） | 向下 = 下一页，向上 = 上一页 |
| `Ctrl+滚轮` | 以**画面中心**为基准缩放（25% ~ 800%，三种阅读方式都生效） |
| `Shift+滚轮`（连续滚动） | 缩放后滚**另一个轴**（纵向模式左右、横向模式上下） |
| `Shift+滚轮`（双页放大后） | 上下平移画面 |
| 左键按住拖动（连续滚动） | 拖着画面沿阅读轴走；松手后按惯性继续滑一段 |
| 左键按住拖动（双页放大后） | 拖动平移画面（带惯性）；没放大时拖不动 |
| `↑` / `↓` / `←` / `→`（连续滚动） | 连续滚动（方向随当前阅读方式） |
| `PageUp` / `PageDown`（连续滚动） | 向前 / 向后滚一段 |
| `Home` / `End`（连续滚动） | 跳到第一页开头 / 最后一页末尾 |
| `←` / `PageUp`、屏幕左按钮（双页翻页） | 上一屏（一次翻两页） |
| `→` / `PageDown` / `空格`、屏幕右按钮 / 工具条按钮（双页翻页） | 下一屏（一次翻两页） |
| `Ctrl+O` | 打开 PDF（文件对话框默认过滤 `.pdf`） |
| 工具条「🕘 最近」按钮 | 打开 / 收起右上角「最近浏览」浮层（点一条重新打开并回到上次阅读位置；`Esc` 或 ✕ 关闭） |
| `F11` | 进入 / 退出全屏沉浸阅读（全屏时工具条自动隐藏） |
| 工具条第一行最右边的「全屏」按钮 | 进入 / 退出全屏（全屏时鼠标移到顶部才看得到工具条） |
| `Ctrl+F` | 聚焦搜索框（再按一次全选） |
| 搜索框输入 | 输入即搜（防抖）；旁边显示「第 x / y 处」（当前命中页看底部页码条） |
| `回车` / `Shift+回车`（搜索框内） | 下一个命中 / 上一个命中 |
| `Esc` | 搜索框里：清除搜索 → 关掉最近浏览面板 → 关掉目录 / 设置面板 → 退出全屏（按这个优先顺序） |
| 搜索框右侧 ◀ / ▶ / ✕ | 上一个命中 / 下一个命中 / 清除搜索 |
| 工具条第二行右侧「跳页」输入框 + `回车` / 箭头按钮 | 跳到填写的页码（1 ~ 总页数；填错会弹提示并全选输入框，`Esc` 清空输入框） |
| 工具条「−」/「+」/ 百分比输入框 | 缩小 / 放大 10% / 直接填缩放比例（25% ~ 800% 生效） |
| 工具条「📑 目录」 | 打开 / 收起左侧书签目录面板 |
| 目录面板里的条目 | 跳到该条目对应的页 |
| 工具条「⚙ 设置」 | 打开 / 收起右侧设置面板（双页间距 / 文件关联 / 恢复默认） |
| 工具条「阅读方式」下拉 | 切换：纵向 上 → 下 / 横向 左 → 右 / 双页 翻页 |
| 工具条「惯性」勾选框 | 开 / 关拖动惯性（默认**开**，改一下自动保存） |
| `YuLiangTookit.exe "<PDF 路径>"` | 直接用本工具打开这个 PDF（勾选文件关联后双击 `.pdf` 等同此操作） |

## 设置项

| 设置 | 存哪 | 说明 |
| --- | --- | --- |
| 阅读方式 `ReadMode` | `Config\pdf-reader\config.json` | 共 3 种：`Vertical`（纵向 上 → 下，默认）/ `Horizontal`（横向 左 → 右）/ `Spread`（双页 翻页）。枚举按 C# 原名存字符串 |
| 拖动惯性 `InertiaEnabled` | 同上 | 默认**开**；关掉 = 松手即停。工具条上的「惯性」勾选框直接对应这一项（连续滚动拖动与双页放大后平移都受它影响） |
| 滚轮一格像素 `WheelStepPixels` | 同上 | 默认 **120**；范围 **20 ~ 600**（超出会被夹住）；连续滚动模式下滚一格走多少像素 |
| 缩放比例 `ZoomPercent` | 同上 | 默认 **100**；范围 **25 ~ 800**（超出会被夹住）。工具条百分比输入框 / `−` `+` / `Ctrl+滚轮` 都改它 |
| 双页页面间距 `SpreadGapPixels` | 同上 | 默认 **2** 像素（贴近，像翻书）；范围 **0 ~ 64**（0 = 左右两页贴在一起）。设置面板的滑块改一下立刻重排并自动保存 |
| 文件关联 | **系统注册表**（`HKCU\Software\Classes\YuLiangToolkit.PdfReader` 与 `.pdf` 的 `OpenWithProgids`），不在 `config.json` | 勾选 = 把 `.pdf` 登记到本工具（双击 / 打开方式进本工具）；取消 = 撤销登记并还原原来的默认程序。Windows 的最终默认程序由「默认应用」决定，程序不能硬改 |
| 上次打开的文件夹 `LastFolder` | `Config\pdf-reader\config.json` | 记录上次打开 PDF 所在文件夹（下次「打开 PDF」对话框从这里开始，**不会自动打开**） |
| 最近浏览上限 `RecentLimit` | 同上 | 默认 **50**；范围 **0 ~ 100**（超出会被夹住）。**0 = 不记录并清空已有列表**；调小会立刻按新上限裁掉多余的老记录；改一下自动保存 |
| 每本 PDF 的阅读位置 `readingPositions` | `Config\pdf-reader\config.json` | 字典：key = PDF 的**完整路径**（小写），value = 上次**页号**（0 起）/ **整体阅读比例**（0 ~ 1）/ **保存时的阅读方式** / **保存时间**。打开同一本时自动恢复；最多 **200 本**（超出按保存时间淘汰最老的）；程序自动维护，通常不用手改 |
| 恢复默认设置（按钮，非配置项） | 改上面除文件关联外的显示设置 | 阅读方式回**纵向 上 → 下**、缩放 **100%**、双页间距 **2 像素**、惯性**开**、滚轮 **120**；**不动文件关联**，也**不清「上次打开的文件夹」和每本 PDF 的阅读位置**；最近浏览上限回 **50**，但**不清空**已有最近浏览记录（只按 50 裁剪） |

> 改一下自动保存，**没有「保存」按钮**（所有工具的统一约定）。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\pdf-reader\config.json` | 上面全部设置 + 每本 PDF 的阅读位置 `readingPositions`（最多 200 本，自动维护）+ 最近浏览上限 `recentLimit` 与记录列表 `recentEntries`（路径 + 最近打开时间；新的在前、按路径去重） |
| `Data\pdf-reader\` | 正常使用**不写东西**；只有开发演示模式（`YLT_PDF_DEMO=1`）会生成 `demo.pdf` 并打开 |
| 系统注册表 | 文件关联登记在 `HKCU\Software\Classes\YuLiangToolkit.PdfReader`（以及 `.pdf` 的 `OpenWithProgids`），**不在 `Config` / `Data` 里**；取消勾选会撤销并还原原来的默认程序 |

> `Data` / `Config` 就在 **exe 旁边**（`bin\Debug\net9.0-windows10.0.19041.0\` 或发布出来的目录），
> 整个程序目录拷走就能迁移数据。目录约定见 [shell.md](../shell.md#数据与配置都在-exe-旁边)。

## 注意与限制

- **不支持**：**文字选择 / 复制**、**页面旋转**；**加密 PDF** 打不开（会提示「本工具暂不支持加密 PDF」）。
- **搜索依赖 PDF 自带的文字层**：扫描版 / 没有 ToUnicode 字体的 PDF 搜不到文字（搜索栏会提示「无可搜索文字」）；
  搜索结果是**跳页 + 计数**，**不是高亮框**（本工具不标注命中位置）。
- **目录依赖 PDF 大纲**：PDF 没有内置书签 / 大纲时，目录面板显示「这个 PDF 没有书签目录」，只能靠页码和搜索。
- **文字层在打开 PDF 后后台提取**：大文件要等一会儿（工具条右侧显示「正在提取文字与目录…」），提取完成前搜索和目录不可用；
  目录与搜索共用这一套提取结果。
- **缩放是位图重渲染，不是矢量**：PDF 页由系统渲染成位图，放大超过渲染上限会**略糊**（看到的是放大的像素）；
  缩放范围 **25% ~ 800%**；全屏只是阅读区变大，**不会让位图更清晰**。
- **100% 是铺满基准，不是原始点数 1:1**：纵向连续按**窗口宽度**、横向连续按**窗口高度**、双页按**一屏两页铺满**；
  百分比是相对这个基准算的。
- **文件关联需要系统确认一次**：只写当前用户（`HKCU`），不需要管理员；Windows 10 / 11 的默认程序（`UserChoice`）
  受系统保护，双击还是别的阅读器时要自己去「默认应用」确认（设置面板里会显示「已登记」还是「还需要去默认应用确认」）；
  移动 / 重装程序后如果双击失效，重新勾选一次即可（命令里的 exe 路径会更新）。
- **单实例 / 多开**：程序级单实例默认**开**（双击 PDF 复用同一个窗口，可把最小化 / 托盘中的窗口叫回前台）；
  开关在 [图片连续阅读器](picture-viewer.md) 设置面板的「**窗口 / 多开**」里，关掉后每次双击都新开一个窗口。
  这是启动级设置，**改完下次启动生效**。
- **PDF 引擎用系统自带的**：由 Windows 自带的 `Windows.Data.Pdf` 渲染，需要 **Windows 10 2004（build 19041）及以上**；
  系统缺这个组件时 PDF 打不开。
- **只渲染可见页**：大文件省内存，但**快速甩动时页面可能短暂空白**，停下来会补齐。
- **双页是一次翻两页、不重叠**：和图片连续阅读器「一次翻一张、相邻屏重叠一张」的手感不同；
  总页数为奇数时最后一屏只有左页；两页间距可调（默认 2 像素）。
- **连续模式拖动只沿阅读轴**：纵向模式上下拖、横向模式左右拖；缩放后用 `Shift+滚轮` 滚另一个轴。
  **双页模式**需要先放大才拖得动（放大后按住左键可拖动平移，带惯性）；上一屏 / 下一屏按钮始终可用。
- **惯性越甩越快有上限**：连续甩会加速，但封顶在 **6 像素 / 毫秒**（约 360 像素 / 帧），不会一下滑穿整本 PDF；
  惯性参数和 [图片连续阅读器](picture-viewer.md) 一致。不想要惯性就把工具条上的「惯性」取消勾选（松手即停）。
- **只读不写**：不修改你的 PDF 原文件。
- **阅读位置按完整路径记**：同一本 PDF 的路径变了（**改名 / 移动**）就会被当成新文件，位置重新记（从第一页开始）；
  最多记 **200 本**（超出按最后阅读时间淘汰最老的），不是只记最后一本。
- **阅读位置自动保存**：滚动停止约 **1.2 秒**、关工具 / 关闭程序时写进 `Config\pdf-reader\config.json`，**没有保存按钮**；
  连续滚动按整体比例恢复、双页翻到上次那一屏；**换过阅读方式**再打开会退回「上次那一页」。
- **最近浏览按完整路径去重**：同一个 PDF 只留一条（路径大小写不敏感）；文件**改名 / 移动**后算新记录；
  点已经不存在的记录会**自动移除**并在状态栏提示「最近打开过的 PDF 已经不在了」。「清空」只删记录，**不会删本地文件**。
- **0 = 不记录并清空**：最近浏览上限调到 0 会清空已有列表、之后不再记录；
  **「恢复默认设置」只把上限改回 50，不清空已有记录**（只按 50 裁剪）。
- **换方式会重建视图**：切换阅读方式 / 改变窗口大小时会尽量停在当前页，但排版位置会有细微变化。
- **全屏只改窗口 / 工具条显隐**：进出全屏不改变阅读方式、缩放、搜索和设置，只是阅读区变大；
  切进 / 切出会尽量保持当前位置（连续滚动保持画面中心、双页翻页保持当前屏），退出后窗口大小 / 位置原样还原。
- **全屏时工具条会自动隐藏**：鼠标一动出现，停 **2.5 秒**缩回、鼠标指针一起隐藏；鼠标移到窗口顶部（或任意移动）就能再叫出来；
  搜索框聚焦、目录面板 / 设置面板打开时工具条不会自动收。底部页码和进度条保留，底部操作提示收起。
- **切走工具自动退出全屏**：全屏状态不会带到别的工具 / 页面，外壳的标题栏 / 侧边栏等会自动还原。
