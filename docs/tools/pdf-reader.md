# 📄 PDF 阅读器

> 看 PDF 不用再装别的阅读器：**纵向 上 → 下 / 横向 左 → 右连续滚动**，或者像翻书一样**双页并排、一次翻两页**；
> 连续滚动模式下左键按住能拖着看，松手还会顺着甩动惯性继续滑一段。PDF 用 Windows 自带的
> `Windows.Data.Pdf` 渲染，**不引第三方 PDF 库、不用另装组件**。

## 能做什么

- **三种阅读方式**：**纵向 上 → 下**（默认，连续滚动）、**横向 左 → 右**（连续滚动）、**双页 翻页**（左右两页并排，一次翻两页）。
  切换在工具条的「阅读方式」下拉里，选中立刻生效。
- **连续滚动**：所有页按顺序排成一条长带，滚轮沿阅读方向滚 —— 一格默认 **120** 像素，可以在配置里改成 **20 ~ 600**。
- **左键拖动 + 惯性**：两种连续滚动模式下按住左键都能拖；松手后按甩动速度**继续滑一段**，
  连续甩会越甩越快（有上限：**6 像素 / 毫秒**）；拖动只沿阅读轴（纵向上下、横向左右）。
  取消工具条上的「惯性」勾选框就是松手即停。
- **双页翻页**：左右两页并排，**一次翻两页**（`[1,2] → [3,4] → …`），相邻两屏**不重叠**；
  总页数是奇数时最后一屏只有左页。滚轮向下 = 下一页、向上 = 上一页，也可以用方向键 / `PageUp` `PageDown` /
  空格 / 屏幕上的左右按钮翻；翻页带约 **0.2 秒**的滑动动画，底部显示「第 x–y 页 / 共 n 页」。
- **连续模式导航**：`Home` / `End` 直接跳到开头 / 结尾；`↑` `↓` `←` `→` 或 `PageUp` `PageDown` 也能滚；
  底部有一条细进度条和「第 x / n 页」，随时知道看到哪了。
- **只渲染看得见的那几页**：大 PDF 不用一次性把全本解码进内存，翻着看更省内存
  （快速甩动时页可能短暂空白一下再补上，见「注意与限制」）。
- **打开方便**：工具条「📄 打开 PDF…」或 `Ctrl+O`，文件对话框只过滤 `.pdf`；
  打开后工具条显示**文件名 · 共 N 页**和完整路径。
- **只读不改原文件**：只是看，不会改动 PDF。

## 三种阅读方式

| 阅读方式 | 类型 | 适合 | 说明 |
| --- | --- | --- | --- |
| 纵向 上 → 下（默认） | 连续滚动 | 文档 / 长帖 / 论文 | 页从上往下排成一条长带；滚轮往下滚 = 往后看 |
| 横向 左 → 右 | 连续滚动 | 横版文档 / 演示稿 | 页从左往右排成一条长带；滚轮往下滚 = 往右看 |
| 双页 翻页 | 翻页 | 页漫 / 杂志 / 双页排版 | 左右两页并排，一次翻两页：`[1,2] → [3,4] → …`；奇数页最后一屏只有左页 |

> 换方式：工具条上的「阅读方式」下拉里选一个，选中后立刻按新方式重建视图，并**尽量停在当前页**。
> 长文档用连续滚动更顺；页漫 / 杂志 / 双页排版的文档用双页翻页更像翻书。

**双页翻页补充：**

- **一次翻两页、相邻两屏不重叠**（和图片连续阅读器的「一次翻一张」不同，看 PDF 时整屏翻过去更符合翻书直觉）。
- 总页数为奇数时，最后一屏**只有左页**，右边留空。
- 翻页动画约 0.2 秒；底部显示「第 x–y 页 / 共 n 页」。

## 怎么用

1. 在主页找到「**PDF 阅读器**」卡片（标签「媒体」，也可以直接搜「PDF」）打开。
2. 点工具条的「**📄 打开 PDF…**」（或按 `Ctrl+O`），在对话框里选一个 `.pdf` 文件 —— 对话框只过滤 `.pdf`。
3. 默认是**纵向 上 → 下**连续滚动：滚轮往下看；嫌慢就按住左键往上拖，甩一下松手会继续滑。
4. 想**左右滚**：工具条的「阅读方式」下拉切成「横向 左 → 右」，滚轮往下滚 = 往右看。
5. 想**一屏两页地翻**：切成「双页 翻页」，然后用滚轮、`←` `→`、`PageUp` `PageDown`、空格或屏幕左右按钮翻。
6. 不想要拖动惯性：取消工具条上的「**惯性**」勾选框（改一下自动保存）。
7. 连续模式下想快速到开头 / 结尾：按 `Home` / `End`。
8. 换一本：再点「打开 PDF…」选下一个文件即可。

## 操作与快捷键

| 操作 | 作用 |
| --- | --- |
| 滚轮（纵向 / 横向连续滚动） | 沿阅读方向滚一格（默认 **120px**，可在配置里改） |
| 滚轮（双页翻页） | 向下 = 下一页，向上 = 上一页 |
| 左键按住拖动（连续滚动） | 拖着画面沿阅读轴走；松手后按惯性继续滑一段 |
| `↑` / `↓` / `←` / `→`（连续滚动） | 连续滚动（方向随当前阅读方式） |
| `PageUp` / `PageDown`（连续滚动） | 向前 / 向后滚一段 |
| `Home` / `End`（连续滚动） | 跳到第一页开头 / 最后一页末尾 |
| `←` / `→`、`PageUp` / `PageDown`、空格、屏幕左右按钮（双页翻页） | 翻上一屏 / 下一屏（一次翻两页） |
| `Ctrl+O` | 打开 PDF（文件对话框只过滤 `.pdf`） |
| 工具条「阅读方式」下拉 | 切换：纵向 上 → 下 / 横向 左 → 右 / 双页 翻页 |
| 工具条「惯性」勾选框 | 开 / 关拖动惯性（默认**开**，改一下自动保存） |

## 设置项

| 设置 | 存哪 | 说明 |
| --- | --- | --- |
| 阅读方式 `ReadMode` | `Config\pdf-reader\config.json` | 共 3 种：`Vertical`（纵向 上 → 下，默认）/ `Horizontal`（横向 左 → 右）/ `Spread`（双页 翻页）。枚举按 C# 原名存字符串 |
| 拖动惯性 `InertiaEnabled` | 同上 | 默认**开**；关掉 = 松手即停。工具条上的「惯性」勾选框直接对应这一项 |
| 滚轮一格像素 `WheelStepPixels` | 同上 | 默认 **120**；范围 **20 ~ 600**（超出会被夹住）；连续滚动模式下滚一格走多少像素 |
| 上次打开的文件夹 `LastFolder` | 同上 | 记录上次打开 PDF 所在文件夹（下次「打开 PDF」对话框从这里开始，**不会自动打开**） |

> 改一下自动保存，**没有「保存」按钮**（所有工具的统一约定）。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\pdf-reader\config.json` | 上面全部设置（阅读方式 / 惯性 / 滚轮步长 / 上次打开的文件夹） |
| `Data\pdf-reader\` | 正常使用**不写东西**；只有开发演示模式（`YLT_PDF_DEMO=1`）会生成 `demo.pdf` 并打开 |

> `Data` / `Config` 就在 **exe 旁边**（`bin\Debug\net9.0-windows10.0.19041.0\` 或发布出来的目录），
> 整个程序目录拷走就能迁移数据。目录约定见 [shell.md](../shell.md#数据与配置都在-exe-旁边)。

## 注意与限制

- **功能有意做得很简单**：不支持**缩放**、**搜索**、**文字选择**、**书签 / 目录**、**页面旋转**。
- **不支持加密 PDF**：有密码保护的 PDF 打不开，会提示「本工具暂不支持加密 PDF」。
- **不支持双击 `.pdf` 文件关联**：不能双击 PDF 直接进本工具，只能用工具里的「打开 PDF…」打开。
- **PDF 引擎用系统自带的**：由 Windows 自带的 `Windows.Data.Pdf` 渲染，需要 **Windows 10 2004（build 19041）及以上**；
  系统缺这个组件时 PDF 打不开。
- **只渲染可见页**：大文件省内存，但**快速甩动时页面可能短暂空白**，停下来会补齐。
- **双页是一次翻两页、不重叠**：和图片连续阅读器「一次翻一张、相邻屏重叠一张」的手感不同；
  总页数为奇数时最后一屏只有左页。
- **拖动只沿阅读轴**：纵向模式上下拖、横向模式左右拖，不能横向 / 纵向自由拖（本工具没有自由平移）。
- **惯性越甩越快有上限**：连续甩会加速，但封顶在 **6 像素 / 毫秒**（约 360 像素 / 帧），不会一下滑穿整本 PDF；
  惯性参数和 [图片连续阅读器](picture-viewer.md) 一致。不想要惯性就把工具条上的「惯性」取消勾选（松手即停）。
- **只读不写**：不修改你的 PDF 原文件。
- **换方式会重建视图**：切换阅读方式 / 改变窗口大小时会尽量停在当前页，但排版位置会有细微变化。
