# 📅 日历

> 月视图日历：上/下月、回今天、点选某天，键盘也能翻。窗口右上角也能显示日期时间。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **月视图**：固定 6 行 × 7 列（42 格），月份长短不会让界面跳动。
- **导航**：`‹` / `›` 换月、「今天」回到当月并选中今天。
- **选中某天**：点一下即可，底部显示完整日期（`2026年11月13日 周五`）。
- **键盘**：`←` `→` 挪一天、`↑` `↓` 挪一周、`PgUp` / `PgDn` 换月、`Home` 回今天。
- **周末高亮**（可关）、**每周从周一开始**（可关 = 从周日开始）、**显示/不显示上、下月的日期**。

## 窗口右上角的日期时间

这块由**外壳**提供（不用打开本工具）：

- 显示：`2026年11月13日 周五  14:05:09`，点一下弹出一个小日历（和 Windows 任务栏右下角那个一样：换月、回今天、点选某天，点外面或按 Esc 关闭）。
- **显示哪个时区**：跟随「全球时钟」工具里选定的那只钟 —— 在时钟页右键某只钟 →「让标题栏显示这一只」。
  没有城市时用本机时区。
- **显示日期 / 时间**两个开关在「主页设置 → 日期时间显示」里，默认都开；两个都关就整块隐藏。

## 数据放在哪

- 配置：`Config\calendar\config.json`（每周第一天 / 周末高亮 / 显示上下的日期）
- 不产生 `Data\` / `Cache\` 文件。

## 注意事项

- **不做农历 / 节假日 / 日程提醒 / 与系统日历同步**：前两个要么引第三方库、要么手写万年历表，
  超出本工具范围；后两个是另一个量级的功能。需要请另外提。
