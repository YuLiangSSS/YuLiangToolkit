# 🚀 软件启动器

> 把常用的 `.exe` 程序和 `.lnk` 快捷方式收进一个图标墙（像资源管理器的小图标视图那样铺开），
> 双击图标就能启动；右边一栏显示软件全名 / 目标路径 / 版本 / 大小等详细信息，
> 还能重命名、换图标、删除，以及**一键清空无效项**（快捷方式失效、软件已卸载 / 删除）。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**：左边「图标墙」与右边「详细信息」之间可左右拖，拖完自动记住；
> 双击这条缝只恢复这一处，全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **导入程序 / 快捷方式**：点「导入」可以一次多选 `.exe` / `.lnk`；也可以直接把文件（或桌面上的快捷方式）
  **拖进工具页**。重复导入同一个路径时不会多出一条，而是直接选中列表里已有的那条。
- **资源管理器式图标墙**：每格一个图标、图标下面显示名字（名字太长会自动截断，完整名字看右侧详情），
  按窗口宽度自动换行；悬停 / 选中都有高亮，选中项右边显示详细信息。
- **双击启动**：双击图标（或选中后按 Enter / 点右侧「启动」）就像在桌面双击一样启动它。
  `.lnk` 会按快捷方式里保存的参数 / 起始位置启动，行为与资源管理器一致。
- **右侧详细信息**（名字太长、文件名看不出是什么软件时看这里）：
  - 显示名、导入的原文件（exe / lnk）完整路径；
  - 快捷方式解析出的**目标程序路径**、启动参数、起始位置；
  - 软件全名（版本信息里的「文件说明」/「产品名」）、公司名、文件版本 / 产品版本；
  - 文件大小、修改时间、导入时间、文件类型（是否快捷方式）。
- **启动 / 重命名 / 更改图标 / 打开所在位置 / 删除**：所有操作都在右侧按钮和图标右键菜单里
  （「删除」在界面上的按钮叫「从启动器移除」，右键菜单同样）。
- **更改图标**：可以选 `.ico`、`.exe`、`.dll`（取里面的图标）或 `.png` / `.jpg` / `.bmp` 图片；
  选中的图标会统一转成 PNG 复制进数据文件夹，所以**原图标文件被删 / 移动也不影响**。
  「恢复默认图标」就回到程序或快捷方式自带的图标。
- **清空无效项**：一键扫出并删除
  - 导入的 exe / lnk 文件本身被删除 / 移动的；
  - `.lnk` 已损坏、读不出目标的；
  - 快捷方式指向的程序已被**卸载 / 删除**的（这是「已删除的软件」最常见的残留）；
  - 手改配置塞进来的不支持类型。
  清空前会弹出确认框告诉你一共几项、分别叫什么；**只删除启动器里的记录和自定义图标，
  绝不删除硬盘上的程序或快捷方式本身**。

## 怎么用

1. 打开工具页 → 点右上「导入 exe / 快捷方式…」（可按住 Ctrl / Shift 多选），或直接把 `.exe` / `.lnk` 拖进页面。
2. 图标出现在左边的图标墙里；单击选中，右边会显示这个软件的完整信息。
3. 想启动时：**双击图标**，或选中后点右侧「启动」（Enter 也行）。
4. 想改名字：点「重命名」，在右侧输入框里改完按 Enter 或点「确定」；
   这只改启动器里显示的名字，**不会去改磁盘上的文件名**。点「取消」或按 Esc 放弃。
5. 想换图标：点「更改图标…」选一个图标 / 程序 / 图片文件；点「恢复默认图标」回到程序自带图标。
6. 想移除：点「从启动器移除」确认即可（只从启动器里移除，磁盘上的程序不动）。
7. 有软件卸载了 / 快捷方式失效了：点右上「清空无效项 (N)」，确认后一次性清掉；N 就是当前扫到的条数。
   平时打开页面会自动检查一次状态（可在配置里关掉自动检查，只用「刷新状态」手点）。

## 设置项

改一下就自动存进 `Config\launcher\config.json`，没有保存按钮。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 打开页面时自动检查失效项 | 开 | 每次打开工具页扫一遍状态，把失效项标红；关掉后只能点「刷新状态」 |
| 上次选中的启动项 | （自动） | 切走再回来 / 重开程序时恢复选中项 |

## 数据放在哪

- 配置：`Config\launcher\config.json`（启动项列表、显示名、导入路径、自定义图标相对路径、设置项）。
- 数据：`Data\launcher\icons\`（自定义图标，统一存成 PNG）。
- 区块布局：跟其它工具页一样存在 `Config\layout.json`（键名前缀 `launcher.`）。
- 「主页设置 → 重建配置」会把上面这些恢复到默认（启动项列表清空）；「清理缓存」不会动它（本工具不写缓存）。

> 注意：启动器**不复制、不移动、不修改**被导入的程序，只记住路径并读取图标 / 版本信息。
> 所以导入后如果把程序挪了位置，会显示「文件不存在」，需要重新导入新的位置。

## 常见问题

| 现象 | 原因 / 怎么改 |
| --- | --- |
| 某个启动项变暗、显示「文件不存在」 | 导入的 exe / lnk 被删除或移动了。重新导入新位置，或用「清空无效项」清掉。 |
| 快捷方式显示「目标程序已卸载 / 删除」 | `.lnk` 本身还在，但它指向的程序没了（软件卸载后的残留）。「清空无效项」会清掉这类。 |
| 显示「快捷方式已损坏」 | `.lnk` 读不出目标（文件损坏 / 权限不足 / 指向已不存在的网络位置）。 |
| 双击没反应 / 提示找不到程序 | 检查右侧「目标路径」是否还在；被 Windows 拦截的程序（如需要管理员权限的）会由系统弹 UAC。 |
| 图标有点模糊 | 部分老程序只带 16 / 32 像素小图标，放大显示就会糊；点「更改图标」换一张大图即可。 |
| 我点「从启动器移除」会不会把软件卸载？ | 不会。移除只从启动器列表移除记录和自定义图标，磁盘上的程序 / 快捷方式原样保留。 |
| 重命名会不会改程序文件名？ | 不会。只改启动器里显示的名字。 |

## 自检

`launcher` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/LauncherChecks.cs`，53 条断言）：
导入扩展名校验、路径规范化与导入去重、默认显示名（lnk 用快捷方式名 / exe 优先文件说明）、
名字清洗（控制字符 / 超长截断 / 空白兜底）、自定义图标缓存路径与安全判断、
失效判定（文件丢失 / 快捷方式损坏 / 目标已卸载，用假 probe 注入）、清空无效项的挑选项与顺序、
配置默认值与 JSON 往返。全部是纯逻辑，**不启动 Shell、不启动任何程序**；
真实启动、图标提取、拖入文件由界面人工冒烟。
