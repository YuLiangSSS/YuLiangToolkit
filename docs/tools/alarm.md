# ⏰ 闹钟

> 多个闹钟、按星期重复、贪睡；到点弹通知并响铃。关掉页面也照样会响。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md) ｜ [快捷键与通知](../dev/shortcuts.md)

## 能做什么

- **多个闹钟**：每个有独立的时间、备注、重复星期、开关。
- **重复**：勾选星期几（一~日），都不勾 = **只响一次**（响过自动关掉）。
  - 常用：工作日（一二三四五）/ 每天（全勾）/ 某一天。
- **备注**：写「起床」「开会」，列表里显示成标题。
- **下次响铃**：列表里每条都显示「明天 07:00 · 还有 8 小时 23 分」。
- **编辑**：点闹钟的时间 → 展开编辑区，改时间 / 备注 / 重复 / 是否可贪睡。

## 响铃

- 到点会：**弹通知 + 响铃**。
- 响铃时页面上方出现横幅：可以「停止」或「**贪睡**」（推迟 N 分钟再响，N 可设 1~60）。
- 可选「反复播放，直到我停止或贪睡」——默认只响一声。
- 响铃音可自选系统音或 `.wav`；也可一键静音（只弹通知不出声）。

## 几点设计说明

- **到点检测靠「到了设定时刻且今天还没响过」**，不靠「提前排好一个精确定时器」。
  好处是电脑睡眠 / 休眠醒来之后照样会响（醒来那一刻直接补齐），不会因为错过的定时器而永久不响。
  代价：如果休眠跨过了某个闹钟的整点，醒来会立刻响一次（这通常正是你要的）。
- **关掉页面也照样会响**：闹钟的计时器挂在工具上，不依赖页面是否打开。
- 关掉程序**不会**响：本工具不是系统服务，程序没开就没有闹钟。

## 数据放在哪

- 配置：`Config\alarm\config.json`（全部闹钟 + 响铃音 + 贪睡时长 + 通知偏好）
- 首次运行会放一个「工作日 07:00 起床」的闹钟（可以直接删）。

## 注意事项

- 不做「按农历 / 每周某天以外的周期」（例如「每月 1 号」）——需要请另外提。
- 不做系统级闹钟（不写 Windows 任务计划）：程序没运行就不会响。
