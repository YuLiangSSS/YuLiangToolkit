# 🔔 通知管理

> 所有工具发过的通知都记在这里，可筛选、可逐条删除、可一键清空。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md) ｜ [通知体系](../dev/shortcuts.md)

## 能做什么

- **自动记录**：任何工具发出的通知（快捷键操作秒表、以后的闹钟 / 提醒…）都会自动记一条，**不需要那个工具做任何额外的事**。
- **列表**：最新在前，每条显示时间、来源（工具名）、类型色条、标题、正文摘要、实际送达的通道。
- **筛选**：按来源（下拉框里的选项是从历史里自动归纳的）、按类型（信息 / 成功 / 警告 / 错误）、搜关键词（标题 / 正文 / 来源）。
- **删除**：每行右侧 `✕` 删单条；右上「清空全部」一键清空（会再确认一次，不能撤销）。
- **时间显示**：今天只写 `14:05`，昨天写 `昨天 14:05`，更早写 `11月5日 14:05`，跨年带年份。

## 设置

- **记住历史**（默认开）：写盘，重启后还在。关掉时会**删除已有历史文件**，只在本次运行期间记录。
- **最多保留多少条**（默认 500，可调 100~5000）：超出丢最旧的。
- **通知**：本工具自己的一份（用于「清空完成」这类提示），通道与角落独立于别的工具。

## 数据放在哪

- 配置：`Config\notification-history\config.json`
- 历史：`Config\notification-history\history.json`（关掉「记住历史」时会被删掉）

## 扩展性（给以后的工具）

新工具想让自己发的通知进历史，**什么都不用做** —— 只要照常：

```csharp
NotificationCenter.Show(settings, new NotificationRequest("标题", "正文", NotificationKind.Info, "你的工具Id"));
```

来源会显示成那个工具的 `ITool.Name`（外壳启动时自动登记）。如果想让来源名更好看，也可以自己调
`NotificationCenter.RegisterSource("id", "显示名")`。

想加新的通知通道（手机推送 / 邮件…），实现 `INotificationSink` 并注入 `NotificationCenter.SetSinks` 即可，
本工具与所有调用方都不用改。
