# 🧩 应用管理器

> 仿 Windows「设置 → 应用 → 安装的应用」：看本机装了哪些桌面应用（名称 / 发布者 / 版本 / 占用大小 /
> 安装日期 / 装在哪个盘），按**驱动器**筛选、按**名称 · 安装日期 · 占用大小 · 发布者**排序并切换**正序 / 逆序**，
> 每个应用右侧直接**卸载**、**修改**。
>
> 数据与「设置 → 应用」同源：读的是注册表里的卸载项（ARP），**只读**，不写注册表、不删文件。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**：左边「应用列表」和右边「详情」之间可左右拖；「主区域 / 运行日志」之间可上下拖，拖完自动记住；
> 双击某条缝只恢复这一处，全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **列出已安装应用**：页头显示「已找到 N 个应用」，每条给出名称、发布者 · 版本、占用大小、安装日期、装在哪个盘，
  左侧 32px 图标取自程序自己的 exe（和资源管理器里看到的一致）。
- **按驱动器筛选**：下拉框里是「所有驱动器」+ 应用实际落在的每个盘（显示卷标，例如 `Acer (C:)`、`数据 (D:)`），
  外加「未记录位置」兜住没写安装目录的老软件。盘符按「安装目录 → 图标路径 → 卸载命令」的顺序推断。
- **排序**：名称 / 安装日期 / 占用大小 / 发布者，右边一个按钮在**正序 ↑ / 逆序 ↓** 之间切换。
  **没记安装日期 / 占用大小的应用，不论正序逆序都排在最后**（不会因为逆序就跑到最上面）。
  排序值相同时按名称兜底，顺序稳定、不会每次刷新都乱跳。
- **搜索**：按应用名 / 发布者 / 版本过滤，和驱动器筛选叠加生效。
- **卸载 / 修改**：每行右侧两个按钮（右侧详情里也有大按钮）。
  - 有 `UninstallString` 才能卸载，有 `ModifyPath` 才能修改；没有的按钮是灰的，悬停会说明原因。
  - 点之前默认弹一次确认框，列出应用名和**真正要执行的完整命令行**，确认后才启动。
  - 启动的是**应用自己登记的卸载 / 修改程序**，要不要真的卸载由它自己的界面问你 —— 本工具不做静默卸载。
  - 卸载 / 修改程序退出后自动重扫列表，卸掉的项会自己消失。

## 怎么用

1. 打开工具页，默认会自动扫描一次（可在设置里关掉）；也可以随时点右上「刷新」。
2. 用「驱动器」下拉框限定范围，「搜索」框再收窄到某个应用。
3. 「排序依据」选名称 / 安装日期 / 占用大小 / 发布者，点右边的「正序 ↑ / 逆序 ↓」换方向。
   - 想找占空间最大的：排序依据选「占用大小」→ 切「逆序」。
   - 想找最近装的：排序依据选「安装日期」→ 切「逆序」。
4. 点某一行，右侧看完整信息（含安装位置与注册表来源）。
5. 要卸载就点行右侧（或右侧详情里的）「卸载」→ 确认框核对命令行 → 确定 → 在安装程序的界面里继续；
   想修复 / 改安装选项就点「修改」。
6. 卸载程序退出后列表自动刷新；也可以在「运行日志」里核对刚才启动的命令与退出码。

> ⚠️ **本工具不替你决定卸载**：它只把 Windows 安装程序登记的入口叫起来。
> 真正删除文件的是那个安装程序，所以会出现它自己的「确定要卸载吗」界面，个别程序还会弹 UAC。

## 数据从哪来

| 项目 | 来源 |
| --- | --- |
| 有哪些应用 | `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall`、`HKLM\SOFTWARE\WOW6432Node\...\Uninstall`（32 位）、`HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall`（只给当前用户装的） |
| 名称 / 发布者 / 版本 | `DisplayName` / `Publisher` / `DisplayVersion` |
| 占用大小 | `EstimatedSize`（KB，**安装程序自己写的估算值**，不是实时统计磁盘占用） |
| 安装日期 | `InstallDate`（常见 `20260626` 写法，也认 `2026-06-26`） |
| 装在哪个盘 | 依次看 `InstallLocation` → `DisplayIcon` → `UninstallString` 里的盘符 |
| 卸载 / 修改命令 | `UninstallString`（有 `QuietUninstallString` 时优先用它）/ `ModifyPath` |
| 图标 | `DisplayIcon`，取不到就退回卸载程序、安装目录的系统图标 |

### 扫描时的过滤规则

为对齐「设置 → 应用」，下面这些**不列**：

- 没有 `DisplayName` 的空项；
- `SystemComponent = 1` 的系统组件；
- 带 `ParentKeyName` 的（属于另一个产品的子项）；
- `ReleaseType` 是 `Security Update` / `Update Rollup` / `Hotfix` / `ServicePack` 这类补丁更新；
- 没有卸载命令、名字又像 `KB5031354` 的更新残留项；
- **同名重复项**：同一个应用在 HKLM / HKCU / WOW6432Node 里各有一条时（32 / 64 位安装包最常见），
  按 `HKLM(64) → HKCU → HKLM(WOW64)` 的优先级留一条。

> **不含 Microsoft Store 应用**：`.msix` / Appx 包不在注册表卸载项里，本工具只收传统桌面程序。
> 商店应用请继续用「设置 → 应用」。

### 数据怎么清洗

注册表里的值不一定干净，扫描时会统一清理：

- 结尾的 `\0` 与首尾空白（实测 `osu!(lazer)` 这类程序的 `DisplayName` / `InstallDate` 是定长缓冲，
  值后面拖一长串 NUL，普通 `Trim()` 去不掉）；
- `DisplayIcon` 末尾的 `,0` 图标序号与多余的引号；
- 卸载命令拆成「可执行文件 + 参数」：带引号的路径、不带引号但含空格的路径（按 `.exe` 结尾切）、
  以及 `msiexec /X{GUID}` 这种没有路径的 MSI 入口都能正确拆开。

## 设置项

改一下就自动存进 `Config\app-manager\config.json`，没有保存按钮。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 搜索词 / 驱动器 / 排序依据 / 正逆序 | 空 / 所有驱动器 / 名称 / 正序 | 和列表一样会记下来，下次打开还是上次的筛选与排序 |
| 显示未记录大小的应用 | 开 | 关掉后注册表没写 `EstimatedSize` 的老软件会从列表里消失 |
| 卸载 / 修改前先确认 | 开 | 确认框里会列出应用名与真正要执行的命令行 |
| 操作结束后自动重扫 | 开 | 卸载程序退出后自动重新读列表 |
| 打开页面时自动扫描 | 开 | 截图冒烟模式（`YLT_SHOT`）下会自动跳过，不会卡在扫描上 |

## 文件放在哪

- 配置：`Config\app-manager\config.json`（相对 **exe 所在目录**，不是仓库根目录）。
- 数据 / 缓存：本工具不写 `Data\`、也不写 `Cache\`（扫描结果与图标只在内存里），
  「主页设置 → 清理缓存 / 重建配置」只会把上面这些选项恢复默认。
- 区块大小：跟其它工具页一样存在 `Config\layout.json`（键名前缀 `app-manager.`）。

## 安全与限制

- **只读注册表**：扫描全程用 `OpenSubKey(..., writable: false)`，不新建 / 不修改 / 不删除任何键。
- **卸载必须你主动点**：打开页面、刷新、筛选、排序都不会启动任何程序；点按钮还要过确认框。
- **不静默卸载**：不带 `/S`、`/quiet` 之类参数，让安装程序自己的界面问你要不要卸载。
- **不强制提权**：用 `UseShellExecute` 交给 Windows，需要管理员的卸载程序会自己弹 UAC；
  你点了「否」只会记一行日志，不会崩。
- **不经过 cmd.exe**：命令按「exe + 参数」分开传给系统，路径里的空格、`&`、`|` 不会被当成命令分隔符。
- **只列桌面应用**：商店 / MSIX 应用不在注册表卸载项里，本工具看不到它们（见上）。
- 个别卸载程序会要求先关掉软件本身，或者在卸载后提示重启；这些都在它的界面里处理。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 某个应用没出现在列表 | 它可能是商店应用（本工具不含 MSIX），或者被过滤了（系统组件 / 补丁 / 同名重复项） |
| 「大小」显示未知 | 注册表里没写 `EstimatedSize`，安装程序没提供这个值；这不影响卸载 |
| 「安装日期」显示未知 | 注册表里没写 `InstallDate`；同理不影响卸载 |
| 排序时一堆「未知」挤在最后 | 这是刻意设计：没记日期 / 大小的不分正逆序都沉底 |
| 「卸载」按钮是灰的 | 那条注册表项没有 `UninstallString`，只能到安装目录手动卸载（悬停提示会说） |
| 「修改」按钮是灰的 | 没有 `ModifyPath`（不是 MSI 安装，或者安装程序没提供修复入口） |
| 点了卸载却什么都没发生 | 看「运行日志」里的命令行与退出码；有些卸载程序被安全软件拦了，或需要先关闭软件本身 |
| 磁盘筛选里没有某个盘 | 那个盘上没有登记过安装位置的应用；「未记录位置」里可以找到不写安装目录的老软件 |

## 自检

`app-manager` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/AppManagerChecks.cs`）：

- 过滤规则（系统组件 / 子项 / 补丁 / KB 残留 / 空名）、同名去重的来源优先级；
- 安装日期解析（`8` 位、分隔符写法、越界、带 `\0` 填充）、大小与盘符 / 驱动器标签格式化；
- 卸载命令拆分（带引号 / 不带引号含空格 / `msiexec` / 写坏的引号 / 多余空格）；
- 排序（四个依据、正逆序、未知值沉底、同值稳定）、筛选（搜索 / 驱动器）；
- 行对象展示文本、工具元数据、配置默认值与 JSON 往返；
- **真实一次只读扫描**：断言不抛异常、无重名、每条都有来源、卸载命令都拆得开、名字里没有控制字符。

全部安全：**不写注册表、不删文件、绝不启动任何卸载 / 修改程序**。
