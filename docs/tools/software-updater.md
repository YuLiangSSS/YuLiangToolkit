# ⬆️ 软件升级器

> 读出电脑上装了哪些应用、哪些有新版本，勾好要升级的（**多行多选 / 全选 / 全不选 / 反选**），
> 再一键按顺序批量升级。数据全部来自系统自带的 **winget**（Windows 应用安装程序），
> 本工具**不自带更新源、不常驻后台、不自动升级**。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**：左边「应用列表」和右边「设置」之间可左右拖；「主区域 / 批量升级与进度 / 运行日志」
> 三块之间可上下拖，拖完自动记住；双击某条缝只恢复这一处，
> 全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **读已安装应用**：`winget list` 扫出本机装了什么，表格里直接给出「当前版本 / 可用版本 / 状态」，
  包 Id 放在应用名下面的灰色副标题行（它太长，独占一列会把版本列挤没），完整信息鼠标悬停可见。
  默认只显示有可用版本的应用，关掉「只看可更新」就能看到扫描到的全部应用。
- **获取可用更新**：切到「仅列出可更新」扫描范围时走 `winget upgrade`，更快，只列有新版的应用。
- **挑要升级的**：每行一个复选框；也能在列表里用 **Ctrl / Shift 多选行**，再点
  「勾选选中行 / 取消勾选选中行」批量处理；表头复选框是**三态**（全勾 / 部分 / 全不勾），
  点一下在「全选 / 全不选」之间切。旁边的「全选 / 全不选 / 反选」按钮作用于**当前筛选后可见**的行，
  被搜索 / 筛选藏起来的行保持原样，不会被偷偷改掉。
- **批量升级**：按列表顺序逐个执行 `winget upgrade --id <Id> --exact`，逐个显示进度与日志；
  单项失败或超时会记下来并继续下一个，不会一挂全挂。升级前默认弹一次确认框，列出要升级的应用。
- **随时取消**：点「取消」会结束当前 winget 进程（连子进程一起），剩下的项标记为「已跳过」。

## 怎么用

1. 打开工具页，默认会自动扫描一次（可在设置里关掉）；也可以随时点右上「刷新扫描」。
2. 列表按「只看可更新」显示有新版的应用；搜索框按应用名 / 包 Id / 来源过滤。
3. 勾要升级的应用：
   - 直接点行首复选框；
   - 或在列表里 Ctrl / Shift 多选几行 → 点「勾选选中行」；
   - 或点「全选」把当前可见且可升级的全部勾上，再用「反选」微调。
4. 点「升级选中的 N 个应用」→ 确认框里核对清单 → 确定后开始逐个升级。
5. 看进度条 / 状态栏 / 运行日志；「✓ 已升级」「✗ 失败」「已跳过」会标在每一行的状态列。
6. 全部结束后点「刷新扫描」，列表会换成 winget 报告的最新版本状态。

> ⚠️ **灰掉的行不能勾**：没有可用版本、来自注册表 / MSIX（`ARP\Machine\…`、`MSIX\…`）、
> 或包 Id 被 winget 截断（末尾 `…`）的应用，winget 没法按 Id 升级，工具直接把它们挡下。

## 数据从哪来（调用的命令）

| 动作 | 实际执行的命令 |
| --- | --- |
| 扫描范围「全部已安装应用」 | `winget list --disable-interactivity --nowarn` |
| 扫描范围「仅列出可更新」 | `winget upgrade --disable-interactivity --nowarn`（勾了「包含版本未知的包」时加 `--include-unknown`） |
| 升级一个应用 | `winget upgrade --id <Id> --exact --disable-interactivity --accept-package-agreements --accept-source-agreements`（可再加 `--silent` / `--include-unknown`） |

- 所有参数都用 `ProcessStartInfo.ArgumentList` **逐项**传入，不拼成一个字符串；传给 `--id` 的值还要过
  白名单（只允许 ASCII 字母数字与 `. _ - +`，不能以 `-` 开头），防止表格里的异常 Id 被当成另一个选项。
- 输出按 **UTF-8** 捕获，解析器自己识别中英文表头，并按「终端显示列宽」切列（中文占 2 列），
  ANSI 颜色、`\r` 进度帧、分隔线、`41 升级可用。` 这类统计行都会被过滤掉。
- **不引第三方 NuGet 包**：winget 是 Windows 10/11 上「应用安装程序」（App Installer）自带的命令行组件，
  工具只调用它，不改写它的源、不动任何注册表。扫描是只读的，**不需要管理员权限**。

## 设置项

改一下就自动存进 `Config\software-updater\config.json`，没有保存按钮。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 扫描范围 | 全部已安装应用 | 「全部」看得到所有应用；「仅列出可更新」只跑 `winget upgrade`，更快 |
| 只看可更新 | 开 | 列表只显示有可用版本的应用；关掉可看全部扫描结果 |
| 打开页面时自动扫描 | 开 | 截图冒烟模式（`YLT_SHOT`）下会自动跳过，不会在截图时卡在扫描 |
| 升级前先确认清单 | 开 | 弹确认框列出将升级的应用（最多列 12 个，其余显示数量） |
| 静默安装（`--silent`） | 关 | 不弹安装程序界面；个别安装器不支持静默参数时仍会自行弹窗 |
| 包含版本未知的包（`--include-unknown`） | 关 | 只对 `winget upgrade` 子命令生效 |
| 单个应用升级超时 | 10 分钟 | 可选 5 / 10 / 20 / 30 / 60 分钟；超时终止这一项并继续下一个（代码里夹到 1~120 分钟） |

## 文件放在哪

- 配置：`Config\software-updater\config.json`（相对 **exe 所在目录**，不是仓库根目录）。
- 数据：本工具不写 `Data\`、也不写 `Cache\`；扫描结果与日志只留在内存 / 界面里，
  所以「主页设置 → 清理缓存 / 重建配置」不会动它的数据，重建配置只会把上面这些选项恢复默认。
- 区块大小：跟其它工具页一样存在 `Config\layout.json`（键名前缀 `software-updater.`）。

## 安全与限制

- **升级必须你主动点按钮**：打开页面、刷新扫描、勾选都不会触发任何安装。
- 不带 `--all`：一次只升级一个包 Id，方便逐个看进度、失败后继续，也避免误升级没勾的东西。
- 只接受 winget 官方源能识别的 Id；ARP / MSIX 来源、被截断的 Id、含空格 / 引号 / 中文的 Id 全部拦下。
- **可能弹 UAC**：个别安装程序需要提权，或 `--silent` 不被支持时会弹出自己的界面，需要你手动确认。
  升级前建议先保存好正在编辑的内容。
- winget 没装 / 源还没就绪时只提示，不崩溃、不写任何东西；去 Microsoft Store 更新
  「应用安装程序」后点「刷新扫描」即可。
- 本工具不做版本回滚，也不卸载软件；升级结果以 winget 的退出码为准。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 列表一直空 | 没检测到 winget，或 winget 源还在初始化：等一会儿点「刷新扫描」；确认 `winget --version` 能跑 |
| 某些应用没出现在列表 | 默认「只看可更新」且扫描范围可能只列有新版的应用；关掉「只看可更新」或切「全部已安装应用」 |
| 行是灰的、勾不上 | 这台应用来自注册表 / MSIX 或 Id 被截断，winget 没有可执行的升级入口 |
| 某项显示「✗ 失败」 | 看运行日志里的 winget 退出码 / 报错；常见是安装程序要求交互、需要 UAC、或软件正在运行 |
| 升级后列表还显示旧版本 | 点「刷新扫描」重新读一次；winget 源本身也可能有缓存延迟 |

## 自检

`software-updater` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/SoftwareUpdaterChecks.cs`）：
winget 中英文表格解析（CJK 显示列宽 / ANSI 回车帧 / 分隔线与统计行）、包 Id 安全白名单、
扫描与升级命令拼装、批量勾选规则（多选 / 全选 / 全不选 / 反选 / 表头三态）、工具元数据与配置默认值。
全部是纯逻辑断言，**不启动 winget.exe、不联网**；真实扫描与升级由界面人工冒烟验收。

截图冒烟默认会跳过自动扫描（免得截图卡在扫描上）。要验收「真实表格 → 解析 → 列表」整条链路，
可以设 `YLT_SCAN_IN_SHOT=1` 强制扫一次，并用 `YLT_SHOT_DELAY_MS=15000` 把截图等待时间拉长。
