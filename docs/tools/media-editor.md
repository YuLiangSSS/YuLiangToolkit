# ✂️ 剪辑工具

> 简易视频 / GIF 剪辑：生成时间轴缩略图定位、拖播放头设起点 / 终点、把要保留的片段逐个加进列表
> （可排序拼接），最后导出 **GIF** 或 **MP4 / MKV / MOV / AVI / WebM**。
> 不做实时渲染预览，但可以一键生成低清预览片段，用系统播放器确认效果。

## 能做什么

### ① 选文件（视频 / GIF）

- 支持**视频**（MP4 / MKV / MOV / AVI / WebM / FLV / TS 等，选择框里都能选）和 **GIF**；
  选完自动用 `ffprobe` 读出**时长、分辨率、帧率、视频编码、音轨、文件大小**。
- **接着上次剪**：上次打开的文件如果还在，启动时会自动载入（连时间轴缩略图一起生成）。
- 「① 源文件」里有「打开文件」「所在文件夹」「重新读取」；换文件会清空旧片段，回到「整段一条」的状态。
- 输入 GIF 也能剪；它本身没有音轨，所以导出成视频时结果也没有声音。

### ② 时间轴缩略图

- 载入后按总时长**平均抽样**生成缩略图（默认 12 张，界面可选 4 / 8 / 12 / 16 / 20 / 24 张），横向排开；
  缩略图上的时间是近似值，只用来快速定位。改数量后点「刷新缩略图」重新生成。
- **点缩略图** = 把播放头跳到那个时间；上方**滑块**可以连续拖，右侧大图跟着显示最近一张缩略图。
- 取起点 / 终点：把播放头拖到位，点「**起点 = 播放头**」或「**终点 = 播放头**」；
  也可以在输入框里直接写 `12.5`、`00:12.500`、`1:02:03.500`。

### ③ 保留片段（裁剪 + 多段拼接）

- 每一条片段有**起点 / 终点**；「＋ 添加片段」把这一段加进列表，「更新选中」改当前这一条，
  「删除选中 / 清空 / 恢复整段」管理列表。
- **「上移 / 下移」调整顺序，导出时按列表顺序拼接**；列表显示每条的时间范围和时长，
  下方显示「保留 N 个片段 · 合计 xx:xx.xxx」。
- 片段**可以重叠**：导出时按顺序原样拼接，重叠部分会重复播放（不会自动合并 / 去重）。
- 自动校验：时间夹到 `0 ~ 总长`、起止颠倒自动交换、片段最短 **0.05 秒**；超范围 / 太短会提示。

### ④ 生成预览（低清 mp4）

- **不是实时预览**：点「生成预览（低清 10 秒）」会按当前片段列表另存一个低清 MP4
  （480 宽、H.264 CRF 28 / `veryfast`、**看拼接结果的开头最多 10 秒**；源有音轨就带 AAC 128k，
  带 `+faststart`），生成后**自动用系统默认播放器打开**。
- 文件在 `Cache\media-editor\preview-*.mp4`，每次生成一个带时间戳的新文件；
  「打开预览」可以再打开最近一次生成的预览。

### ⑤ 导出（视频 / GIF）

- **视频**：MP4 / MKV / MOV / AVI / WebM。编码器与录屏工具共用同一套目录：
  H.264（`libx264` / NVENC / AMF / QSV）、H.265（`libx265` / 硬件版）、AV1（`libsvtav1` / 硬件版）、
  VP9（`libvpx-vp9`）、MPEG-4 Part 2（`mpeg4`）、Motion JPEG（`mjpeg`）；界面按**本机 FFmpeg + 当前容器**过滤。
- **画质 / 码率二选一**：画质优先 CRF / CQ 0~51，或码率优先 1~100 Mbps。
- **输出帧率**：保持源（默认）/ 15 / 24 / 30 / 60；**输出宽度**：原始（默认）/ 1920 / 1280 / 960 / 800 / 640 / 480
  （**只缩小，不放大**）。
- **保留原音轨**（默认开）：按容器编码 —— MP4 / MKV / MOV 用 AAC、AVI 用 MP3、WebM 用 Opus；
  音频码率 128 / 192 / 256 kbps。源文件没有音轨时自动按无声导出。
- **GIF**：两遍调色板（`palettegen` + `paletteuse`）；颜色数 256 / 128 / 64，
  抖动 Floyd–Steinberg / 有序 / 无，可无限循环。**GIF 没有音轨**，帧率取「输出帧率」（保持源 = 15 FPS）。
- **导出会重新编码**（不是流复制），按片段列表裁剪 / 拼接 / 缩放 / 改帧率；
  文件名 `前缀-日期-时间.扩展名`（默认前缀「剪辑」，如 `剪辑-20260102-030405.mp4`），重名自动加 ` (2)`。
- 导出成功后可**自动打开输出文件夹**；也能用「**打开上次导出**」再打开成品。
- 载入、生成缩略图、生成预览、导出**运行中都能点「取消」**。

## 怎么用

1. 先确认 FFmpeg：工具会自动从「配置里的路径 → `PATH` → 常见安装位置」找 `ffmpeg.exe`；
   找不到就点「选择 FFmpeg…」手动指定，或点「下载 FFmpeg」去 gyan.dev 的下载页。
   探测媒体信息还需要**同目录的 `ffprobe.exe`**（找不到会提示重新选 FFmpeg 目录里的 `ffmpeg.exe`）。
   FFmpeg 是全局设置，和音频工具 / 录屏共用。
2. 点「选择视频 / GIF…」选文件 → 自动读取信息并生成时间轴缩略图（第一次会等几秒）。
   上次的文件还在的话，打开工具就会自动载入。
3. 定位：拖播放头滑块或点缩略图；用「起点 = 播放头」「终点 = 播放头」取时间，也可以直接输入。
4. 点「＋ 添加片段」把这段加进保留列表；要保留多段就重复第 3、4 步，用「上移 / 下移」排顺序，
   下方会显示合计时长。
5. 选导出格式与参数：视频选编码器 / 速率控制 / 画质或码率 / 帧率 / 宽度 / 是否保留音轨；
   GIF 选颜色数 / 抖动 / 是否循环。
6. 建议先点「生成预览（低清 10 秒）」用系统播放器确认裁剪点和片段顺序
   （预览最长 10 秒，只用于看效果）。
7. 满意后点「开始导出」；运行中可点「取消」；完成后默认自动打开输出文件夹。
8. 之后想再打开成品 / 预览，用右侧的「打开上次导出」「打开预览」「输出文件夹」。

## 界面布局

- 三个可拖区块：
  - 左「**设置**」：① 源文件 ② 时间轴（缩略图 / 播放头 / 起止点）③ 保留片段
    ④ 导出设置 + 输出位置，最下面是 FFmpeg 状态（这一栏内部还能单独滚动；鼠标停在
    片段列表 / 缩略图条上滚滚轮，内层滚到头后会接着滚这一栏，不会卡住）；
  - 右「**预览 / 导出**」：当前缩略图大图、生成预览 / 打开预览 / 输出文件夹、开始导出 + 进度 + 取消、
    状态、最近导出路径、打开上次导出；
  - 底部「**运行日志**」。
- 分隔条：`media-editor.设置与预览`（左右）、`media-editor.主区域与日志`（上下）。
  松手自动记住（`Config\layout.json`），**双击**某条只恢复这一处；
  全部恢复默认：**主页设置 →「界面布局 → 恢复默认布局」**。

## 设置项

### 导出与编码

| 界面上的选项 | 可选值 | 默认 |
| --- | --- | --- |
| 格式 | 动图 GIF / MP4 / MKV / MOV / AVI / WebM | MP4 |
| 编码器 | 按当前容器 + 本机 FFmpeg 过滤（H.264 / H.265 / AV1 / VP9 / MPEG-4 / MJPEG，含硬件项） | `libx264`（切到 WebM 会换成 VP9） |
| 速率控制 | 画质优先（CRF / CQ）/ 码率优先（Mbps） | 画质优先 |
| 画质（CRF / CQ） | 0~51（滑块，越小越清晰） | 23 |
| 目标码率 | 1~100 Mbps（滑块） | 8 Mbps |
| 输出帧率 | 保持源帧率 / 15 / 24 / 30 / 60 FPS | 保持源（0） |
| 输出宽度 | 原始分辨率 / 1920 / 1280 / 960 / 800 / 640 / 480 px（**只缩小，不放大**） | 原始（0） |
| 保留原音轨 | 开 / 关（仅视频格式） | 开 |
| 音频码率 | 128 / 192 / 256 kbps | 192 kbps |
| GIF 颜色数 | 256 / 128 / 64 色 | 256 色 |
| GIF 抖动 | Floyd–Steinberg / 有序（`bayer`）/ 无 | Floyd–Steinberg |
| GIF 无限循环 | 开 / 关（关 = 只播一遍） | 开 |

### 输出与时间轴

| 界面上的选项 | 可选值 | 默认 |
| --- | --- | --- |
| 输出文件夹 | 任意目录 | `视频\YuLiangToolkit 剪辑` |
| 文件名前缀 | 任意文字（非法字符自动替换，最长 40 字符） | `剪辑` |
| 导出后自动打开输出文件夹 | 开 / 关 | 开 |
| 时间轴缩略图数量 | 4 / 8 / 12 / 16 / 20 / 24 张（改后点「刷新缩略图」） | 12 张 |

> 上面所有选项都存 `Config\media-editor\config.json`，**改一下就自动保存，没有「保存」按钮**；
> 缩略图数量改完点时间轴旁的「刷新缩略图」即可生效。FFmpeg 路径存在 `%AppData%\YuLiangToolkit\settings.json`，
> 是**全局设置**（和音频工具 / 录屏共用）。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\media-editor\config.json` | 导出格式 / 编码器 / 画质码率 / 帧率 / 宽度 / GIF / 音轨 / 输出目录 / 前缀 / 上次打开的文件 / 缩略图数量（**片段列表不保存**） |
| `Cache\media-editor\thumbs-*\thumb-*.jpg` | 时间轴缩略图（160 px 宽的 JPG）；每次载入生成一个新目录，旧的可清理 |
| `Cache\media-editor\preview-*.mp4` | 生成的预览片段；每次一个带时间戳的文件，可清理 |
| `Cache\media-editor\palette-*.png` | GIF 导出时的调色板临时文件；导出结束自动删除，失败 / 取消也尽量清理 |
| `%AppData%\YuLiangToolkit\settings.json` | 全局 FFmpeg 路径，和音频工具 / 录屏共用 |
| `Data\media-editor\` | 不使用（成品写到你选的输出文件夹） |

> 片段列表只是这一次编辑的临时状态，不写进配置：**重新打开文件会回到整段**。
> 缓存都在 `Cache` 下，可以在「主页设置 → 清理缓存」一键清掉。

## 注意 / 限制

- **不是实时预览**：没有播放器、不能边拖边看；「生成预览」是另存一个低清 MP4（最长 10 秒）用系统播放器打开，
  只适合快速确认裁剪点和拼接顺序。
- **导出会重新编码**：多片段 / 长视频会比较慢；GIF 要跑两遍（调色板 + 合成），更慢。运行中可以点「取消」。
- **片段按列表顺序拼接**：可以重叠，但不会自动合并 / 去重，重叠部分会重复播放。
- 片段最短 **0.05 秒**；超出 `0 ~ 总长` 会自动夹取，起止颠倒会自动交换；太短 / 无效会提示。
- **缩略图时间是近似值**（按总时长平均抽样），不保证逐帧精确；要精确请直接输入时间。
- **输出宽度只缩小不放大**；帧率选「保持源」时沿用源视频帧率。
- **「保留原音轨」只对视频格式有效**：GIF 没有音轨；源文件本身没有音轨时会自动按无声导出。
- **输入文件被移动 / 删除**后会失败并提示，重新选文件即可。
- 需要 `ffmpeg.exe`，探测信息还需要同目录的 `ffprobe.exe`；缺 ffprobe 时会提示重新选择 FFmpeg。
- **不支持**：实时逐帧预览、多轨、特效、变速、字幕、转场；片段列表 / 编辑状态也不保存。
- **导出 / 预览失败或取消不会留下半成品**：会删掉刚写的文件，原因只写到状态栏和运行日志里。
- 缓存（缩略图 / 预览）都可以清理：`Cache\media-editor\` 下的东西删了最多重新生成，不影响已导出的成品。
- GIF 文件大小由「宽度 × 帧率 × 颜色数 × 时长」共同决定；GIF 帧率取「输出帧率」（保持源 = 15 FPS）。
