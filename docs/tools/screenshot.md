# 📷 截图工具

Snipaste 风格的截图工作流：先冻结整个桌面，再框选、编辑、复制 / 保存 / 贴图。截图页本身就是完整的操作台和设置页，不创建托盘图标，也不提供托盘右键菜单。

## 截图流程

1. 在工具页点「开始截图」，或按全局快捷键（默认 `Ctrl+Shift+F1`）。
2. 主窗口暂时隐藏，桌面冻结成一张覆盖全屏的截图。
3. 拖动鼠标框选区域；框选后可拖动选区、拉八个控制点调整大小。
4. 在选区上方工具栏选择标注工具并绘制；右上角显示选区物理像素尺寸，鼠标附近有放大镜和像素颜色。
5. 点「复制」/「保存」/「贴图」，或按 `Enter` / `Ctrl+C` / `Ctrl+S` / `P`。
6. `Esc` / 右键取消；有选区时双击选区可直接复制。

## 标注工具

- 矩形、椭圆（可填充半透明色）
- 箭头、直线
- 画笔、荧光笔
- 文字（就地输入，`Enter` 确认、`Esc` 取消）
- 序号（自动递增）
- 马赛克、模糊（拖动框住要处理的区域）
- 取色（点击复制颜色值）
- 橡皮擦（点击删除标注）
- 撤销 / 重做（`Ctrl+Z` / `Ctrl+Y`）
- OCR 文字识别（识别选区文字并复制）
- 调色板：工具栏「调色板」打开额外 24 色 + 自定义十六进制颜色输入

## 输出与历史

- 「复制」写入剪贴板；「保存」弹出保存对话框；「贴图」把成品放到桌面。
- 可设置截图后自动复制、自动保存、保存后打开文件夹。
- 输出格式支持 PNG / JPG；文件名前缀、输出文件夹可改。
- **压缩程度**：不压缩（原图）/ 轻度（JPG 92）/ 标准（JPG 82）/ 高压缩（JPG 70）。开启压缩后，保存、复制、历史、贴图都会使用所选 JPG 档位；不压缩保持原图。
- 截图历史默认保存在 `Cache\screenshot\history\`，页面可查看缩略图、复制、贴图、打开、定位、删除或清空；清空历史不影响已保存到输出文件夹的原图和桌面贴图。

## 全局快捷键

| 默认快捷键 | 动作 |
| --- | --- |
| `Ctrl+Shift+F1` | 打开截图框选 / 编辑覆盖层 |
| `Ctrl+Shift+F2` | 截屏并复制 |
| `Ctrl+Shift+F3` | 重复上一次的框选区域 |
| `Ctrl+Shift+F4` | 把剪贴板图片贴到桌面 |

四条都可在本页右侧修改，也会出现在「主页设置 → 快捷键」汇总里；工具页提供总开关、单条启用和清空。

## 贴图组

- 从剪贴板贴图、截图后贴图、历史记录贴图都会归到当前贴图组。
- 工具页「切换到下一贴图组」循环切换默认 / 参考图 / 对照图三组。
- 「隐藏 / 显示所有贴图」会隐藏全部贴图，再次点击显示当前组。
- 贴图本身复用「屏幕贴纸」的窗口：拖动、滚轮缩放、四边四角拉伸、单独置顶都保留。
- 在贴图上点右键 →「编辑图片…（画笔 / 高亮 / 橡皮）」，可以做轻量批注并保存为新贴图；不会覆盖原图。

## 托盘菜单迁移

原 Snipaste 托盘右键里的动作都放在本页：

- 截屏、截屏并复制、自定义截屏（目标 + 延迟）、重复上次区域
- 贴图、隐藏 / 显示所有贴图、切换贴图组
- 清空截屏历史
- 全局快捷键总开关与各条启用 / 清空
- 设置本身就在右侧栏

没有「重新启动 / 退出」这两个应用级动作；它们由 YuLiangToolkit 主窗口负责。

## 配置位置

- 配置：`Config\screenshot\config.json`
- 贴图源文件：`Data\screenshot\pins\`
- 历史截图：`Cache\screenshot\history\`

相关自检组：`screenshot`（选区换算 / 输出文件名 / 标注命中 / 渲染器 / 快捷键与配置）。

和「屏幕画笔」协作：屏幕画笔是桌面透明覆盖层，截图时它的画笔内容会被一起捕获；打开截图选择层时屏幕画笔自动暂停，避免误操作。
