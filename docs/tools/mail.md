# 📬 邮箱代收

> 用 IMAP 把 **Gmail / QQ / 163 / 126 / Outlook / 企业邮箱** 等多个邮箱的**收件箱 / 已发送 / 垃圾箱**收到同一个页面里看：
> 只读拉取最近邮件、按邮件夹合并成一个列表、关键词搜索、查看正文与附件。
> **不会删除、移动，也不会把邮件标记成已读**——服务器上的状态保持原样；授权码 / 应用专用密码用
> Windows DPAPI 加密后存在本机配置里。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**（v0.42.0 起每个区块之间都能拖）：悬停缝隙亮起蓝线 + ↔ / ↕ 光标；
> 左侧「账号 + 收件箱 / 已发送 / 垃圾箱」导航 / 中间收件列表 / **右侧整块阅读区**三栏可左右拖；
> 账号编辑、网络代理、日志都是**弹窗**，不再占用主界面（双击左侧账号即可编辑；工具条有「网络代理」「日志」）；
> 松手自动记住；双击某条缝只恢复这一处；全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **多账号 + 三文件夹**：左侧每个账号下平铺 **收件箱 / 已发送 / 垃圾箱**（再加一个「全部邮件」汇总）；
  每个文件夹只拉最近 N 封（默认 30，可改 5~200），点哪个文件夹就只看哪个，账号行看全部；
  点账号行看「全部邮件」，双击账号名编辑配置。
- **排序 / 搜索**：可按 **日期 / 发件人 / 收件人 / 主题 / 账号 / 附件 / 优先级 / 是否未读 / 大小** 排序（升序 / 降序）；
  搜索框同时匹配主题、发件人、收件人、账号名；「只看未读」快速过滤。
- **只读、不改状态**：收件箱 / 已发送 / 垃圾箱都按 `ReadOnly` 打开，拉正文用 `BODY.PEEK` 语义，**不会产生已读回执 / 不会标已读**；
  工具里也没有删除 / 移动命令。
- **正文与附件**：选中一封才连回该账号拉完整内容（列表只取摘要，省流量）；**HTML 邮件用 WebView2（Chromium）
  渲染成 Foxmail 那种富文本**——图片、表格、边框、颜色、内嵌 `cid:` 图片都能看；**Ctrl+滚轮缩放**；
  不想看排版可以勾「纯文本」。附件可以「打开」（临时目录 + 默认程序）、「保存」（另存为）或「全部保存」（选文件夹）；
  **附件行按住直接拖到桌面 / 资源管理器**即可复制文件；附件只在内存里解码，不会自动写进 Data 目录。
- **授权码加密保存**：QQ 的「授权码」、Gmail 的「应用专用密码」用 Windows DPAPI（当前用户）加密后
  写进配置；配置文件里没有明文，**换 Windows 用户 / 换电脑后解不开**，需要重新填一次。
- **自动跟随 Windows 系统代理**：Gmail 等境外邮箱经常「浏览器能打开、IMAP 直连却超时」——默认读取
  Windows 系统代理（和 Chrome 用同一个），并遵守系统代理的**例外列表**（例如 `*.qq.com` 会自动直连）；
  也可以在工具条「网络代理」弹窗里改成直连或手动填代理。
- **可选打开时自动刷新**：勾选后每次打开工具页自动收一次；也可以随时点「刷新全部」。
  一个账号失败只影响它自己的状态，其它账号照常收。

## 怎么用

### 1. 准备授权码 / 应用专用密码（不同邮箱不一样）

| 邮箱 | 要填什么 | 怎么弄 |
| --- | --- | --- |
| **Gmail** | **应用专用密码**（16 位，**不是** Gmail 登录密码） | Google 账号 → 安全 → 开启**两步验证** → 「应用专用密码」→ 新建一个（名字随便）→ 复制 16 位密码。工具表单里有「打开 Gmail 应用专用密码页」按钮。 |
| **QQ 邮箱** | **授权码**（16 位左右，**不是** QQ 密码） | QQ 邮箱网页 → 设置 → 账号 → 开启「IMAP/SMTP 服务」→ 按提示生成「授权码」。 |
| **163 / 126** | **授权码**（不是登录密码） | 网易邮箱网页 → 设置 → POP3/SMTP/IMAP → 开启 IMAP 服务 → 生成授权码。 |
| **Outlook / Microsoft 365** | 授权码 / 应用密码 | 微软现在基本强制 OAuth2，基础认证可能被服务器拒绝；**本版没有实现 OAuth2**，个人账号可先试应用密码，企业账号通常不行。 |
| **企业邮箱 / 自建** | 授权码或应用密码 | 看管理员是否允许 IMAP 和第三方客户端；选「自定义」填服务器 / 端口。 |

> ⚠ **浏览器里已经登录 Gmail ≠ 工具能直接复用**：IMAP 登录需要单独的「应用专用密码」。
> 工具不会读取你浏览器里的 Cookie / 登录态，也不会代你登录网页。

### 2. 新增 / 编辑账号（弹窗）

1. 点工具条「新增账号」打开**账号设置弹窗**（不再占用右栏）。
2. 选 **服务商预设**（Gmail / QQ 邮箱 / 网易 163 / 126 / Outlook / 自定义），
   服务器、端口、SSL 会自动填好（一般不用手改）；旁边有「打开帮助页」。
3. 填**显示名称**（可选）、**邮箱地址**和**授权码 / 应用专用密码**
   （Gmail 的 16 位密码如果复制出来带空格，去掉空格再填）。
4. 点弹窗里的「测试连接」：成功会显示 `✅ 连接成功：INBOX 共 N 封（只读）`；
   失败会显示中文原因（认证失败 / SSL / 网络 / 服务器拒绝）。
5. 点「保存」关闭弹窗；再点工具条「刷新全部」，左侧会出现每个账号的收件箱 / 已发送 / 垃圾箱。

> **编辑账号**：双击左侧账号（或选中后点「编辑选中」）打开同一个弹窗。
> 弹窗里的修改点「保存」才生效，点「取消」不会动原配置。
> 账号前面的勾选框是「参与代收」：临时不想收某个账号时取消勾选即可，配置不会丢。

### 3. 看邮件 / 文件夹 / 附件

- 左侧点 **收件箱 / 已发送 / 垃圾箱**，中间列表只显示该文件夹；点账号行看这个账号的「全部邮件」。
  列表第二行会标出「账号 + 邮件夹」，已发送里的联系人显示为「收件人」，收件箱显示「发件人」。
- 单击列表里的一封 → 右侧**整块阅读区**显示发件人 / 收件人 / 时间 / 正文 / 附件。
- HTML 邮件默认富文本，`Ctrl + 滚轮`缩放；不想看排版时勾「纯文本」。
- 「复制正文」把当前正文（纯文本版本）复制到剪贴板；它左边的「**⛶ 全屏浏览**」把正文铺满整屏阅读
  （见下面「全屏浏览」）。
- **附件**：每行有「打开」（存到临时目录后用系统默认程序打开）和「保存」（另存为）；
  右上「全部保存」可以选一个文件夹一次性存下当前邮件的所有附件（重名自动加序号）；
  **按住附件行直接拖到桌面 / 资源管理器**也会复制一份。
  附件只在内存里解码，**不会自动写进 Data 目录**；拖拽用的临时文件在 `Cache\mail-collector\drag`，一天后自动清理。
- 打开工具时列表是空的：本工具**不缓存邮件内容**，每次打开都按当前文件夹重新拉取（只拉摘要，很快）。

### 4. HTML 富文本 / 纯文本

- HTML 邮件默认用 **WebView2（和 Edge / 网页浏览器同一个 Chromium 内核）**渲染：图片、表格、边框、背景色、
  内嵌 `cid:` 图片都会正常显示；远程图片也会加载（可能需要你的系统代理）。
- **缩放**：在正文区域按 `Ctrl + 滚轮` 放大 / 缩小（Ctrl + `+` / `-`、Ctrl + `0` 也可以）；只影响显示。
- 不想看排版 / 觉得可疑时，勾选正文上方的「**纯文本**」即可切回纯文本；HTML 邮件没有纯文本部分时，
  工具会先转成可读的纯文本，保证永远有内容能看。
- 安全：预览里 **JavaScript 一律关闭**，开发工具 / 宿主对象 / 弹窗也都关掉；邮件里的链接点了用默认浏览器打开，
  不会在邮件里导航。注意：远程图片本身可以带追踪像素，介意的话把发件人加入黑名单或切纯文本看。
- 需要机器上有 **WebView2 运行时**（Win10 2004+ 一般随 Edge 自带）；缺失时工具自动退回纯文本，不影响收信。
- 预览缓存放在 `Cache\mail-collector\WebView2\`，随时可被「主页设置 → 清理缓存」清掉。

### 5. 全屏浏览

正文上方「⛶ 全屏浏览」（在「复制正文」左边）把当前邮件铺满整屏阅读，外壳的标题栏 / 侧边栏 / 状态栏一起让位。

- **退出**：按 `Esc`，或点右上角悬浮工具栏最右边的 **✕**，或再点一次「全屏浏览」。
- **悬浮工具栏**：鼠标移到屏幕顶部就从上边滑下来，离开后约 1 秒自动收起（不会挡住正文）。
  左边 `＋ 放大`、中间百分比输入框（默认 `100`，可输入 `25 ~ 400` 后回车）、`－ 缩小`，右边 `✕` 关闭。
- **缩放**：`Ctrl + 滚轮`等同于点放大 / 缩小，每档 10%；纯文本改字号，HTML 走 WebView2 的缩放比例，两者都从 100% 起算。
- 全屏里的「复制正文」「纯文本」和主界面是同一套命令 / 开关，改哪边都一样。
- 正文是 HTML 时，全屏会另外建一份 WebView2（同一个缓存目录、同样的安全设置：脚本关闭、链接用默认浏览器打开）；
  没有 WebView2 运行时则退回纯文本，不影响使用。

### 6. 排序

列表上方的排序条（在搜索框下面）：

- 排序键：**日期 / 发件人 / 收件人 / 主题 / 账号 / 附件 / 优先级 / 是否未读 / 大小**；
- 「附件」把带附件的排在前面；「优先级」按邮件头里的高 / 普通 / 低优先级排；
- 右边按钮切换 **降序（↓）/ 升序（↑）**；默认日期降序（最新邮件在最上面）；
- 排序只影响显示顺序，不改服务器上的任何东西；选择会记进配置，下次打开还是这套。

### 7. 拉取数量 / 自动刷新

- 工具条「每个账号取最近 [30] 封」：**每个系统文件夹**（收件箱 / 已发送 / 垃圾箱）各取最近 N 封，
  改成 5~200 之间的数字，越界会自动夹取。默认 30；Gmail 的收件箱很大时可以用 30~50，太多会慢。
- 「打开工具时自动刷新」默认勾选；不过一次会连三个文件夹，第一次打开可能需要十几秒；不想每次打开都联网就取消勾选，需要时手动点「刷新全部」。

### 8. 网络代理（Gmail 连接超时看这里）

国内网络下 **Gmail 的 IMAP 常常直连不通**，表现是「Chrome 能打开 Gmail，工具却提示连接超时」。
本工具默认 **自动跟随 Windows 系统代理**（也就是 Chrome / 系统正在用的那个代理）：

1. 点工具条「网络代理」打开**代理设置弹窗**；
2. 默认是「自动（跟随 Windows 系统代理）」——工具会读取 Windows 的代理设置，
   并遵守系统代理的**例外列表**（例如 `*.qq.com` 会直连，Gmail 走代理）；
3. 状态行会显示当前实际使用的代理，例如 `当前：系统代理 127.0.0.1:7897（HTTP）`；
4. 如果自动模式还是连不上：
   - 代理软件可能只支持 SOCKS5：选「自定义代理」，填服务器 / 端口，类型选「SOCKS5」；
   - 或者先选「直连（不使用代理）」排除代理本身的问题；
5. 点弹窗「保存」后立即生效；再点「刷新全部」重试。

> 同一份代理设置对**所有账号**生效，但每个域名会分别判断是否在例外列表里：
> 所以 QQ 可以直连、Gmail 走代理，互不影响。
>
> 注意：HTML 预览里的远程图片是 **WebView2 自己走系统代理**，和这里的 IMAP 代理设置是两套。

### 9. 日志（弹窗）

- 工具条「日志」打开运行日志弹窗：账号连接 / 拉取结果、错误原因都在里面；
- 窗口开着时新日志实时出现；可以清空日志、打开配置 / 数据文件夹；
- 日志不打印授权码；不再占用主界面空间。

## 只读保证

- 收件箱 / 已发送 / 垃圾箱都按 `FolderAccess.ReadOnly` 打开；
- 拉取单封正文走 `GetMessage`（只读模式下服务器不会标记已读）；
- 代码里**没有** `Delete` / `Move` / `Store`（标记已读 / 未读）等写命令；
- 代收结果只存在内存里，切走 / 关闭工具就清空（配置里只保存账号信息）。

## 设置项

| 界面上的选项 | 存哪 | 说明 |
| --- | --- | --- |
| 账号列表：显示名称 / 邮箱 / 服务器 / 端口 / SSL / 是否启用 | `Config\mail-collector\config.json` | 弹窗里点「保存」写入；自动落盘 |
| 授权码 / 应用专用密码 | 同上（`passwordCipher` 字段） | DPAPI 密文，不是明文 |
| 每个账号取最近多少封 | 同上（`fetchCount`） | 5 ~ 200（**每个文件夹**各取这么多） |
| 打开工具时自动刷新 | 同上（`refreshOnOpen`） | 默认开 |
| 上次选中的账号 / 邮件夹 | 同上（`lastSelectedAccountId` / `lastSelectedFolder`） | 重新打开工具时恢复选中（收件箱 / 已发送 / 垃圾箱 / 全部邮件） |
| 网络代理模式 / 服务器 / 端口 / 类型 | 同上（`proxy` 对象） | 默认 `auto`（跟随 Windows 系统代理）；可选 `direct` / `custom` |
| 收件列表排序键 / 升降序 | 同上（`sortBy` / `sortDescending`） | 默认 `date` + 降序 |

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\mail-collector\config.json` | 账号信息、DPAPI 加密后的授权码、拉取设置、排序、网络代理设置 |
| `Data\mail-collector\` | 暂时没用到（邮件不落盘；附件由「另存为」决定去哪里） |
| `Cache\mail-collector\WebView2\` | HTML 预览的浏览器缓存（Cookie / 临时文件），**随时可删** |
| `Cache\mail-collector\drag\` | 拖拽附件时临时落盘的文件（一天后自动清理，随时可删） |

> 配置文件可以放心打开看：**看不到授权码明文**。但密文和你的 Windows 账户绑定，
> 把配置拷到别的电脑 / 别的 Windows 用户下会解不开（界面显示空，重新填一次即可）。

## 安全提示

- 授权码 / 应用专用密码等价于对应邮箱的登录凭证（但比主密码权限小、可单独吊销）：
  **不要**把 `Config\mail-collector\config.json` 发给别人。界面上授权码框已改为密码框（只显示圆点），
  截图不会直接露出明文；但明文在内存里，公共电脑上仍建议用完清理配置并吊销。
- 建议给每个邮箱单独生成一个应用专用密码，只在信任的电脑上使用；不用了随时去邮箱后台
  「吊销 / 删除」该密码，不影响主账号登录。
- 本工具**只连你填的 IMAP 服务器**，不会把邮件内容 / 账号信息上传到任何第三方服务器；
  没有统计、没有遥测。
- 如果你在公共电脑上用，用完请到「主页设置 → 重建配置」或直接删除
  `Config\mail-collector\config.json`，并去邮箱后台吊销该应用密码。

## 常见问题

| 现象 / 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| `认证失败：邮箱地址或授权码 / 应用专用密码不对` | 填了登录密码而不是授权码 / 应用专用密码；或邮箱地址写错；Gmail 没开两步验证导致不能生成应用密码 | 按上面「准备授权码」重做；QQ 用授权码，Gmail 用 16 位应用专用密码 |
| `SSL 握手失败` | 端口和 SSL 不匹配（常见是 993 选了「不使用 SSL」，或 143 选了 SSL） | 预设会自动填对；自建服务器按管理员给的值改 |
| `网络连接失败` / `连接超时` | 网络不通、代理 / 防火墙拦截、服务器域名写错；**Gmail 在国内常见直连超时** | 点工具条「网络代理」看状态行是不是 `系统代理 127.0.0.1:...`；没有就开代理或选自定义 SOCKS5；QQ 直连正常但 Gmail 超时基本就是这个问题 |
| Gmail 一直认证失败，但应用密码是对的 | Google 账号 / 组织策略关闭了「应用专用密码」，或没开两步验证 | 打开两步验证后重新生成；组织账号需要管理员允许 |
| Gmail 应用专用密码页面显示 `The setting you are looking for is not available for your account` | 账号开启了两步验证，但应用密码入口被高级保护 / 组织策略 / 账号类型隐藏 | 先确认两步验证已开；如果仍不可用，本版没有 OAuth2，只能换账号或用支持应用密码的账号 |
| QQ 认证失败 | QQ 邮箱没开启 IMAP/SMTP 服务，或授权码复制错 | 网页版 QQ 邮箱 → 设置 → 账号 → 开启 IMAP/SMTP 并重新生成授权码 |
| Outlook 认证失败 | 微软已停用基础认证，需要 OAuth2 | 本版暂不支持 OAuth2；换用支持应用密码的个人账号，或等后续版本 |
| 换了电脑 / 重装系统后密码框是空的 | DPAPI 密文和 Windows 用户绑定 | 在账号弹窗里重新填一次授权码即可 |
| HTML 邮件显示成纯文本 / 没有样式 | 机器没有 WebView2 运行时，或预览启动失败（详情状态会写原因） | 装 Microsoft Edge WebView2 Runtime 后切走再切回工具；临时看纯文本不影响收信 |
| HTML 邮件里的远程图片不显示 | 网络 / 系统代理没连上图片服务器（邮件渲染用的是系统代理，不是工具里的 IMAP 代理设置） | 确认系统代理正常；或先看纯文本 |
| Ctrl+滚轮不能缩放 | 鼠标不在正文区，或当前是纯文本邮件 | 先在右侧正文里点一下再 Ctrl+滚轮；纯文本走系统字体，不需要缩放 |
| 看不到附件 / 没有「打开 / 保存」 | 这封邮件本身没有附件，或服务器摘要没给 MIME 结构 | 换一封带附件的邮件；附件标记来自摘要，点开正文后以附件列表为准 |
| 点「打开」附件没反应 | 系统没有关联该文件类型的默认程序 | 改用「保存」到本地后手动打开 |
| 附件拖到桌面没反应 | 拖拽时需要先按住附件行再移动，且要等文件从服务器解码完 | 按住附件行拖到桌面 / 文件夹；大附件多等半秒 |
| 某个账号的「已发送 / 垃圾箱」是空的或显示「服务器未提供」 | 服务商没有启用该文件夹，或文件夹名不在常见中英文候选里 | 先在网页版确认文件夹有邮件；本工具会优先用 IMAP SPECIAL-USE，再按常见名称兜底 |
| 列表顺序不对 | 排序条选的是别的排序键 / 方向 | 检查列表上方的排序下拉框和 ↓ / ↑ 按钮 |
| 列表是空的 / 只有几封 | 只拉当前账号三个系统文件夹最近 N 封，不拉「所有邮件 / 自定义文件夹」 | 加大「每个账号取最近 N 封」；确认邮件在收件箱 / 已发送 / 垃圾箱 |
| 附件大小显示「—」 | 服务器没给出可用的编码流长度 | 不影响保存，直接点「保存」即可 |
| 打开工具时没有自动刷新 | 没勾「打开工具时自动刷新」，或没有启用的账号 | 勾上开关 / 点「刷新全部」 |
