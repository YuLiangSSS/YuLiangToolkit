# 📬 邮箱代收

> 用 IMAP 把 **Gmail / QQ / 163 / 126 / Outlook / 企业邮箱** 等多个邮箱的**收件箱**收到同一个页面里看：
> 只读拉取最近邮件、合并成一个列表、按账号筛选 / 关键词搜索、查看正文与附件。
> **不会删除、移动，也不会把邮件标记成已读**——服务器上的状态保持原样；授权码 / 应用专用密码用
> Windows DPAPI 加密后存在本机配置里。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**（v0.42.0 起每个区块之间都能拖）：悬停缝隙亮起蓝线 + ↔ / ↕ 光标；
> 左侧账号栏 / 中间收件列表 / 右侧「详情 · 账号设置」三栏可左右拖，主区域与日志可上下拖；
> 右栏的「邮件详情 / 账号设置」是互斥页签（同一块地方切换，不需要分隔条）；
> 松手自动记住；双击某条缝只恢复这一处；全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **多账号合并收件**：每个账号只拉「收件箱最近 N 封」（默认 30，可改 5~200），全部合并成一张列表，
  按时间倒序排列；每行显示未读点、主题、发件人、账号标签、时间。
- **只读、不改状态**：收件箱按 `ReadOnly` 打开，拉正文用 `BODY.PEEK` 语义，**不会产生已读回执 / 不会标已读**；
  工具里也没有删除 / 移动命令。
- **账号筛选 / 搜索 / 只看未读**：右侧下拉框按账号筛选；搜索框同时匹配主题、发件人、账号名；
  「只看未读」快速过滤。
- **正文与附件**：选中一封才连回该账号拉完整内容（列表只取摘要，省流量）；纯文本优先，
  只有 HTML 的邮件会转成纯文本显示（本工具**不加载网页内核**，避免为了看邮件再开一个浏览器引擎）；
  附件可以「保存」到你自己选的位置，保存路径由「另存为」对话框确认。
- **授权码加密保存**：QQ 的「授权码」、Gmail 的「应用专用密码」用 Windows DPAPI（当前用户）加密后
  写进配置；配置文件里没有明文，**换 Windows 用户 / 换电脑后解不开**，需要重新填一次。
- **可选打开时自动刷新**：勾选后每次打开工具页自动收一次；也可以随时点「刷新全部」。
  一个账号失败只影响它自己的状态，其它账号照常收。

## 怎么用

### 1. 准备授权码 / 应用专用密码（不同邮箱不一样）

| 邮箱 | 要填什么 | 怎么弄 |
| --- | --- | --- |
| **Gmail** | **应用专用密码**（16 位，**不是** Gmail 登录密码） | Google 账号 → 安全 → 开启**两步验证** → 「应用专用密码」→ 新建一个（名字随便）→ 复制 16 位密码。工具表单里有「打开 Gmail 应用专用密码页」按钮。 |
| **QQ 邮箱** | **授权码**（16 位左右，**不是** QQ 密码） | QQ 邮箱网页 → 设置 → 账号 → 开启「IMAP/SMTP 服务」→ 按提示生成「授权码」。 |
| **163 / 126** | **授权码**（不是登录密码） | 网易邮箱网页 → 设置 → POP3/SMTP/IMAP → 开启 IMAP 服务 → 生成授权码。 |
| **Outlook / Microsoft 365** | 授权码 / 应用密码 | 微软现在基本强制 OAuth2，基础认证可能被服务器拒绝；**本版没有实现 OAuth2**，个人账号可先试应用密码，企业账号通常不行。 |
| **企业邮箱 / 自建** | 授权码或应用密码 | 看管理员是否允许 IMAP 和第三方客户端；选「自定义」填服务器 / 端口。 |

> ⚠ **浏览器里已经登录 Gmail ≠ 工具能直接复用**：IMAP 登录需要单独的「应用专用密码」。
> 工具不会读取你浏览器里的 Cookie / 登录态，也不会代你登录网页。

### 2. 新增账号

1. 点工具条「新增账号」（或账号卡片右上角「＋」），右栏会自动切到「账号设置」页签。
2. 选 **服务商预设**（Gmail / QQ 邮箱 / 网易 163 / 126 / Outlook / 自定义），
   服务器、端口、SSL 会自动填好（一般不用手改）。
3. 填**邮箱地址**和**授权码 / 应用专用密码**（Gmail 的 16 位密码如果复制出来带空格，去掉空格再填）。
4. 点「测试选中账号」：成功会显示 `✅ 连接成功：INBOX 共 N 封（只读）`；
   失败会显示中文原因（认证失败 / SSL / 网络 / 服务器拒绝）。
5. 再点工具条「刷新全部」，列表里就会出现各账号最近 N 封邮件。

> 每改一个字段都会自动保存，**没有「保存」按钮**。账号前面的勾选框是「参与代收」：
> 临时不想收某个账号时取消勾选即可，配置不会丢。
> 左栏选中账号后点「编辑账号」也可以随时切回右栏「账号设置」。

### 3. 看邮件

- 单击列表里的一封 → 右侧显示发件人 / 收件人 / 时间 / 正文 / 附件。
- 「复制正文」把当前正文复制到剪贴板。
- 附件区域每行有「保存」按钮，选择保存位置即可；附件只在内存里解码，**不会自动写进 Data 目录**。
- 打开工具时列表是空的：本工具**不缓存邮件内容**，每次打开都按当前收件箱重新拉取（只拉摘要，很快）。

### 4. 拉取数量 / 自动刷新

- 工具条「每个账号取最近 [30] 封」：改成 5~200 之间的数字，越界会自动夹取。
  Gmail 的收件箱很大时建议 30~50 封，太多会慢。
- 「打开工具时自动刷新」默认勾选；不想每次打开都联网就取消勾选，需要时手动点「刷新全部」。

## 只读保证

- 收件箱按 `FolderAccess.ReadOnly` 打开；
- 拉取单封正文走 `GetMessage`（只读模式下服务器不会标记已读）；
- 代码里**没有** `Delete` / `Move` / `Store`（标记已读 / 未读）等写命令；
- 代收结果只存在内存里，切走 / 关闭工具就清空（配置里只保存账号信息）。

## 设置项

| 界面上的选项 | 存哪 | 说明 |
| --- | --- | --- |
| 账号列表：显示名称 / 邮箱 / 服务器 / 端口 / SSL / 是否启用 | `Config\mail-collector\config.json` | 改一下自动保存 |
| 授权码 / 应用专用密码 | 同上（`passwordCipher` 字段） | DPAPI 密文，不是明文 |
| 每个账号取最近多少封 | 同上（`fetchCount`） | 5 ~ 200 |
| 打开工具时自动刷新 | 同上（`refreshOnOpen`） | 默认开 |
| 上次选中的账号 | 同上（`lastSelectedAccountId`） | 重新打开工具时恢复选中 |

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\mail-collector\config.json` | 账号信息、DPAPI 加密后的授权码、拉取设置 |
| `Data\mail-collector\` | 暂时没用到（邮件不落盘；附件由「另存为」决定去哪里） |

> 配置文件可以放心打开看：**看不到授权码明文**。但密文和你的 Windows 账户绑定，
> 把配置拷到别的电脑 / 别的 Windows 用户下会解不开（界面显示空，重新填一次即可）。

## 安全提示

- 授权码 / 应用专用密码等价于对应邮箱的登录凭证（但比主密码权限小、可单独吊销）：
  **不要**把 `Config\mail-collector\config.json` 发给别人，截图时也留意别把工具页的密码框拍进去。
- 建议给每个邮箱单独生成一个应用专用密码，只在信任的电脑上使用；不用了随时去邮箱后台
  「吊销 / 删除」该密码，不影响主账号登录。
- 本工具**只连你填的 IMAP 服务器**，不会把邮件内容 / 账号信息上传到任何第三方服务器；
  没有统计、没有遥测。
- 如果你在公共电脑上用，用完请到「主页设置 → 重建配置」或直接删除
  `Config\mail-collector\config.json`，并去邮箱后台吊销该应用密码。

## 常见问题

| 现象 / 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| `认证失败：邮箱地址或授权码 / 应用专用密码不对` | 填了登录密码而不是授权码 / 应用专用密码；或邮箱地址写错；Gmail 没开两步验证导致不能生成应用密码 | 按上面「准备授权码」重做；QQ 用授权码，Gmail 用 16 位应用专用密码 |
| `SSL 握手失败` | 端口和 SSL 不匹配（常见是 993 选了「不使用 SSL」，或 143 选了 SSL） | 预设会自动填对；自建服务器按管理员给的值改 |
| `网络连接失败` / `连接超时` | 网络不通、代理 / 防火墙拦截、服务器域名写错 | 先 `Test-NetConnection imap.gmail.com -Port 993` 能通再试；公司网络可能需要代理 |
| Gmail 一直认证失败，但应用密码是对的 | Google 账号 / 组织策略关闭了「应用专用密码」，或没开两步验证 | 打开两步验证后重新生成；组织账号需要管理员允许 |
| QQ 认证失败 | QQ 邮箱没开启 IMAP/SMTP 服务，或授权码复制错 | 网页版 QQ 邮箱 → 设置 → 账号 → 开启 IMAP/SMTP 并重新生成授权码 |
| Outlook 认证失败 | 微软已停用基础认证，需要 OAuth2 | 本版暂不支持 OAuth2；换用支持应用密码的个人账号，或等后续版本 |
| 换了电脑 / 重装系统后密码框是空的 | DPAPI 密文和 Windows 用户绑定 | 重新填一次授权码即可 |
| 列表是空的 / 只有几封 | 只拉「收件箱」最近 N 封，不会拉「所有邮件 / 垃圾箱 / 自定义文件夹」 | 加大「每个账号取最近 N 封」；确认邮件在收件箱 |
| 附件大小显示「—」 | 服务器没给出可用的编码流长度 | 不影响保存，直接点「保存」即可 |
| 打开工具时没有自动刷新 | 没勾「打开工具时自动刷新」，或没有启用的账号 | 勾上开关 / 点「刷新全部」 |
