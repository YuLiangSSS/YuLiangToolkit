# 🔤 文本转换器

> 把文字转成各种样子；还能自己绑快捷键，选中任何程序里的文字按一下就**就地转换**。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md) ｜ [快捷键与通知](../dev/shortcuts.md)

## 页面用法

1. 在左边输入或粘贴文本 → 右边选一种转换 → 点「转换 ↓」。
2. 结果可以「复制」，也可以「拿回去再转」（连续转多次，比如先转火星文再转 Emoji）。

## 支持的转换

| 分组 | 转换 |
| --- | --- |
| **大小写** | 全大写 / 全小写 / 词首大写 / 句首大写 / 反转大小写 |
| **风格** | 转繁体（可再点一次转回）/ 火星文（可逆）/ 圈字 ①②③ / 全角 / 小号大写字母 / 花体字母 / 倒置文字（可逆） |
| **Emoji** | 转 Emoji（多字词优先，`牛马 → 🐮🐴`、`开心 → 😄`）/ 逐字 Emoji（每个能对上的字都换） |
| **形近字** | 同音字（`牛 → 妞`） |
| **编码** | Base64 编码 / 解码、URL 编码 / 解码、摩斯电码 |
| **清理** | 去首尾空格 / 去掉所有空格 / 合并成一行 / 去掉空行 / 反转文字 / 字符去重 |

- 圈字、全角、倒置、转繁体、火星文都是**可逆**的：再点一次就转回来。
- 对不上的字符原样保留（不会把整句话变成看不懂的符号）。
- 解码类（Base64 / URL）遇到非法输入会给中文提示，不会抛异常。

## 自定义快捷键（重点）

在页面下方「自定义快捷键」里：

1. 点「+ 添加快捷键」；
2. 点左边的框，按下组合键（例如 `Ctrl+Shift+T`）；
3. 在右边的下拉里选要做哪种转换。

**用法**：在任何程序（QQ、微信、浏览器、编辑器）里**先选中文字**，再按你设的快捷键，选中的内容会**就地变成转换后的样子**。

### 它是怎么做到的

1. 记下你剪贴板里原来的文字；
2. 给前台程序发 `Ctrl+C`，把你选中的内容复制下来；
3. 转换；
4. 把结果放进剪贴板，发 `Ctrl+V` 替换掉选区；
5. **把剪贴板还原成你原来的内容**（不弄丢你复制的东西）。

### 需要知道的三点

- **必须先选中文字**。没选中会弹一条通知「没有选中文本：请先选中要转换的文字再按快捷键」。
  识别方式：`Ctrl+C` 之后剪贴板内容没变 → 判定为没选中。
- **目标程序要支持 `Ctrl+C` / `Ctrl+V`**。绝大多数输入框都支持；个别程序（某些游戏内聊天、管理员权限窗口）可能不行。
- 操作完剪贴板会「闪一下」（复制 → 粘贴 → 还原），但最终**还是你原来的内容**。不想还原可以在页面上关掉「转换后还原剪贴板」。

## 数据放在哪

- 配置：`Config\text-converter\config.json`（输入框内容、上次选的转换、全部自定义快捷键、还原开关、通知偏好）

## 注意事项

- 转换是纯文本处理，**不联网**、不调用任何第三方接口。
- Emoji 词表只收常见词（动物 / 情绪 / 天气 / 食物等），刻意没做太激进——否则正常的话会变成一堆图标。
- 火星文 / 繁简用的是内置的常用字对照表（几百字），不做全字符集转换。
