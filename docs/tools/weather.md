# ⛅ 天气预报

> 查收藏城市的实时天气与未来预报：当前温度 / 体感 / 湿度 / 风向风力 / 气压 / 云量，未来 7 天与逐小时趋势；多城市一键切换，断网自动显示上次缓存。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **当前天气卡片**：大字温度、天气现象（emoji 按昼夜自动换：夜里 ☀️ 换 🌙）、体感温度，
  下面一排小格：湿度 / 风 / 风向（八方位中文）/ 海平面气压 / 云量 / 当前降水 / 日出 / 日落。
- **未来逐小时**：从「现在」起的 12 / 24 / 48 小时（右侧可调），每小时显示时间、天气 emoji、温度与降水概率，横向滚动。
- **未来 7 天**：每天一行：今天 / 明天 / 周几、日期、天气、最低 ~ 最高温、降水概率（没有概率就显示降水量）。
- **城市收藏与切换**：右侧搜索框输入城市名（**中文 / 拼音 / 英文名都可以**，如「北京」「New York」），
  点一条结果加入收藏并自动刷新；收藏列表点一下就切换；行尾 ✕ 移除。
  首次运行自带北京 / 上海 / 广州 / 成都。
- **单位与选项**：温度单位（摄氏 / 华氏）、风速单位（km/h / m/s）、逐小时条数（12 / 24 / 48）——
  改动**本地重新渲染，不重新联网**；自动刷新（关 / 每 30 分钟 / 每 1 小时 / 每 3 小时）。
- **断网兜底**：每次拉取成功都会把响应快照写进 `Cache\weather\`；联网失败时自动显示上次的快照，
  状态栏注明「缓存数据 · 时间」，不会白屏。

## 数据从哪来

- 数据来自 [Open-Meteo](https://open-meteo.com/)（`api.open-meteo.com/v1/forecast` + `geocoding-api.open-meteo.com/v1/search`）：
  **完全免费、不需要 API Key、不限商用**，城市搜索支持中文（返回中文地名）。
- 拉取的是公制原始数据（摄氏 / km/h），界面单位换算在本地做，所以切单位不消耗请求。
- 天气现象是 WMO 天气代码表（0 晴 / 3 阴 / 61 雨 / 71 雪 / 95 雷阵雨…），本工具收录全部实际会出现的代码；
  未知代码回退显示「未知 🌍」，不会开天窗。
- 请求带 `User-Agent: YuLiangToolkit-Weather/1.0`；接口报错（HTTP 200 但 `error=true`）会翻译成一条可读的异常，
  状态栏只显示原因摘要，完整信息在日志里。

## 界面

- 左列三块：当前天气（大温度 + 详情格）/ 未来逐小时（横向滚动）/ 未来 7 天，每两块之间都有分隔条可以上下拖；
- 右侧设置卡片（添加城市 / 收藏城市 / 显示选项 / 数据说明 / 运行日志），与左列之间也有分隔条左右拖；
- 所有分隔条松手自动记住、双击恢复默认，全部恢复在「主页设置 → 界面布局 → 恢复默认布局」。

## 数据放在哪

- 配置：`Config\weather\config.json` —— 收藏城市列表、当前城市、单位、自动刷新间隔都在这里，改动自动落盘。
- 缓存：`Cache\weather\last-{城市Id}.json` —— 每座城市一份拉取快照（断网兜底用），
  随时可以删，删了只是丢了兜底数据；「主页设置 → 清理缓存」会清理这里。

## 注意事项

- 需要**联网**才能拉新数据；断网 / 接口故障时靠缓存兜底，首次使用（还没有任何快照）时会提示失败。
- Open-Meteo 的逐小时预报最多 48 小时，7 天是最多可拉的天数里本工具选的默认档；
  再往后的日子（10 / 16 天）不在本工具范围内。
- 时区由接口按坐标自动解析（`timezone=auto`），「现在」以接口返回的当地时间对齐，
  逐小时第一格就是当前整点，不怕城市跨时区。
- 自检（`weather` 组）覆盖：WMO 代码表 / 风向方位 / 单位换算 / URL 组装 / 假 handler 请求层 /
  切片与文案 / 展示模型 / 缓存与配置往返；**不出网**，真实拉取请人工冒烟。
