# ⏱️ 秒表

> 开始 / 暂停 / 停止 / 计次，三条快捷键在任何程序前面都能按，后台按了会在屏幕角落弹通知。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md) ｜ [快捷键体系与通知](../dev/shortcuts.md)

## 能做什么

- **大号数字**：`mm:ss.cc`（超过一小时自动变 `h:mm:ss.cc`），百分秒可以在设置里关掉。
- **四个动作**：开始 / 继续、暂停、停止并归零、计次。
  - 开始：停着就从 0 开始；暂停中接着走；**已经在走时再按不会重置**（不会一不小心把计时清零）。
  - 暂停：时间保留，点开始接着走。
  - 停止：归零，**同时清空计次**（和实体秒表的「复位」一样）。
  - 计次：记一段；列表里显示第几次、总时长、与上一次的间隔。暂停时也能计次。
- **计时不受页面影响**：切到别的工具、把窗口最小化，计时照常走（切回来还是那个数）。
- **关掉程序不会假装还在计时**：秒表状态不落盘，重开就是 00:00.00。

## 快捷键

三条，默认：

| 动作 | 默认 | 说明 |
| --- | --- | --- |
| 开始 / 继续 | `Ctrl+Alt+F9` | 已经在走时按它不会重置 |
| 暂停 | `F10` | 停着时按它会提示「还没开始计时」 |
| 停止并归零 | `F11` | 同时清空计次 |

- **全局生效**：在浏览器、游戏、编辑器前面都能按（程序不用在前台）。
- **改键**：秒表页右侧设置卡片里直接点框改；也可以在「主页设置 → 快捷键」统一改（两处共用同一份配置）。
- **禁用**：每一条都能单独关（秒表页的「启用」勾选框，或汇总页右侧的「禁用」）；整工具也能一键关（「启用这个工具的快捷键」）。
- **分步快捷键**：想把「`Ctrl+K` 然后 `Ctrl+C`」这种两步设成开始，去汇总页点「拆分」，再录第二步。
  两步之间等多久是**全程序统一设置**（主页设置 → 快捷键，默认 5 秒，也可以设成不限时）。

## 提示音

开始 / 暂停 / 停止**各一份**，可分别设成：

- 不播放
- 系统音（默认通知 / 提示 / 提醒 / 错误 / 疑问）
- 自定义 `.wav` 文件（点「…」选；**只支持 wav**，这是系统播放接口的限制）

每题都能「试听」；顶部还有「静音」总开关（保留选择，只是不播）。

## 通知

只在**按快捷键**时弹，而且**只在没在看秒表页**的时候弹（正在看页面的话界面本身就在变，再弹一次是打扰）。

通知设置是**这个工具自己的一份**（不集中到主页设置里，这样不同工具可以各自弹在不同角落）：

- 通道：应用内小窗 / Windows 通知（托盘气泡）
- 位置：左上 / 右上 / 左下 / **右下（默认）**
- 停留时长：1 ~ 15 秒
- 底部有个「发一条测试通知」，改完立刻能看到效果

## 数据放在哪

- 配置：`Config\stopwatch\config.json`（快捷键、声音、显示开关、通知偏好都在这，改一下自动保存）
- 本工具不产生 `Data\` / `Cache\` 文件。

## 注意事项

- 多主键组合（例如合并出来的 `Ctrl+U+K`）走键盘钩子识别，**前台是管理员权限的窗口时收不到**（Windows 限制，任何非驱动级钩子都一样）。
- 不做跨进程计时恢复，也不保存历史计次。
