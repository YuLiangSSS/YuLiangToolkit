# 🎥 视频转音频

> 把视频里的音轨抽出来：**有损 MP3**、**无损 FLAC**，或者**原样拷贝音轨**（不重新编码，最快）。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **三种模式**（后端都是 FFmpeg）：
  - **有损 MP3**：`libmp3lame`，码率 128 / 192 / 256 / 320 kbps；
  - **无损 FLAC**：`-c:a flac`（compression_level 8）；
  - **无损提取原始音轨**：`-c:a copy` 不重新编码 —— 先用 `ffprobe` 探出音轨是什么编码，
    再自动挑容器（m4a / opus / ogg / flac / wav …）。因为不转码，**速度只取决于读盘**。
- **批量**：一次处理一整个文件夹，带进度条、逐文件状态、实时日志，随时可以取消
  （取消会把 ffmpeg 的进程树一起杀掉）。
- **重名不会覆盖**：输出文件重名自动加 ` (1)`、` (2)`。
- 源文件夹可以**递归**；扩展名过滤可改（默认只扫 `.mp4`，可以写成 `mp4;mov;mkv` 这种）。

## 界面布局

- 「源文件与输出 | 转换设置」可以**左右拖动**，「文件列表 / 进度与日志」可以**上下拖动**（蓝线 + ↔ / ↕）；
- 松手自动记住（`Config\layout.json`）；**双击**某条分隔线只恢复这一处，全部恢复默认：**主页设置 →「界面布局 → 恢复默认布局」**。

## 怎么用

1. 第一次用先确认 FFmpeg：工具会自动从「配置里的路径 → `PATH` → 常见安装位置」找 `ffmpeg.exe`；
   找不到就点「选择 FFmpeg」手动指定，或者点「下载 FFmpeg」去官方下载页。
2. 选**源文件夹**（可选要不要递归），选**输出文件夹**（不选就放在源文件旁边）。
3. 选模式与参数（MP3 码率 / FLAC 压缩级别 / 并行数）。
4. 点开始，进度条与日志会实时更新；中途想停就点取消。

## 设置项

| 界面上的选项 | 存哪 | 说明 |
| --- | --- | --- |
| 转换模式、码率、FLAC 压缩级别、并行数 | `Config\video-to-audio\config.json` | 改一下就自动保存 |
| 源文件夹、是否递归、输出文件夹、扩展名过滤 | 同上 | 下次打开还是上次那套 |
| FFmpeg 路径 | `%AppData%\YuLiangToolkit\settings.json` | **全局设置**，几个功能共用 |

> 从老版本升级时，会把旧配置（`%AppData%\YuLiangToolkit\settings.json` 里那套）
> **一次性迁移**到这个功能的配置里，跑过一次就不再迁移。

## 注意

- **「原样提取」得到的是原始编码**：源视频是 AAC 就得到 m4a，是 Opus 就得到 opus —— 这是特性，不是 bug；
  想要统一格式就用 MP3 / FLAC 模式。
- 转换过程中别去动源文件；产物是直接写在目标路径上的。
- 大量文件时并行数别开太高，机械硬盘与 CPU 都要喘气。
