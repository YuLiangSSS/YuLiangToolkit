# 🍜 osu! LN 转换器

> 把 osu!mania 谱面里的**普通音符批量变成长条（LN / 面条）**：按密度档位、概率、时值分母、
> 转换轨道和间隔随机生成 LN 长度，也可以反过来把 LN 压成普通键（Level -3 / 反相 Level 10）。

> 主页上归在「**音游工具**」类别里：点类别卡片进类别页，顶部面包屑（`主页 › 音游工具 › osu! LN 转换器`）
> 可以点回上一级。同一个类别下还有 osu! 下图器 / Key 转换器 / 等级计算器。

## 能做什么

- **14 档 Level**：从「把所有 LN 压成普通键」到「满 LN / 反相」都有，见下面的档位表。
- 可调「转多少」（LN%）、「LN 多长」（Divide）、「只转哪几条轨道」（Column）、
  「每隔多少行重抽一次轨道」（Gap）、随机种子。
- 高级选项：**保留原 LN**（已经有的长条不动）、**修复尾判误差**（把尾巴吸附到节拍网格）、
  **忽略已转换的谱面**（避免重复转）、**修改 OD**（默认保留原谱 OD）。
- 批量：拖 `.osu` 文件或文件夹（递归），列表显示键数 / 状态；进度 / 日志 / 取消；
  单个文件失败不中断整批。

## 怎么用

1. 把 `.osu` 文件或文件夹拖进页面（或点「选择文件…」）；文件夹递归查找、重复文件自动去重。
2. 在「② 转换参数」调参数 —— **改一下自动保存**；「参数说明 ▾」里有每一档 Level 的完整解释。
3. 点「**开始转换**」；进度 / 统计 / 日志实时刷新，可「取消」（当前文件处理完就停）。
4. 看统计「共 N 个：成功 x · 跳过 y · 失败 z」；日志里逐个文件写输出路径或跳过原因。
   点「打开输出文件夹」跳到输出目录。
5. **新文件在哪**：写在**原谱面所在目录**，文件名按元数据拼成
   `{艺术家} - {标题} ({谱师}) [{难度名}].osu`；难度名前会加 `[LN-Lv3-C10]` 这样的前缀，
   谱师追加 ` & LNTransformer`（或替换），因此正常不会覆盖原谱。

## Level 档位表（-3 ~ 10，共 14 档）

| Level | 名称 | 效果 |
| --- | --- | --- |
| **-3** | Hold off | 把所有 LN 压成普通键（**输出不含 LN**）；这一档下 **LN% / 转换轨道 / 间隔都不生效** |
| **-2** | 完全随机 | LN 长度在「当前音 → 下一个音」之间**完全随机**取（不吸附网格、不参与 Fix Error） |
| **-1** | 随机等分 | 把两音之间按 `1/Divide` 拍等分，随机取其中一份 |
| **0** | 常规 LN | 按 1/100 拍左右的正态分布取长度，最接近手写 LN |
| **1 ~ 7** | 从轻到密 | `mu = Level × 11`，数值越大 LN 越长、越密（3 = 轻、5 = 中、7 = 密） |
| **8 / 9** | 更密 / 最密 | 同 1~7，但分布更宽（σ 分别放宽到 0.9 / 1.0） |
| **10** | Invert（反相） | 原本没 LN 的地方补 LN；已有 LN 是否保留由「保留原 LN」决定 |

> 所有档位最终都还要过两道筛子：① `LN%` 概率（没命中就还是普通键）；
> ② 「转换轨道」随机集合（不在选中轨道上的 LN 会被压回普通键）。
> 所以最终 LN 数量一定 ≤ LN%。**固定种子 + 相同参数 = 同一张谱每次结果完全一样。**

## 参数说明

| 参数 | 范围 / 默认 | 说明 |
| --- | --- | --- |
| 转换等级 Level | −3 ~ 10，默认 **3** | 见上面的档位表；**-3 档下 LN% / 转换轨道 / 间隔不生效** |
| LN 占比 LN% | 0 ~ 100，默认 **100** | 符合条件的声音有多少概率变 LN；100 = 全部符合条件的普通键都变 |
| 等分 Divide | 1 ~ 16，默认 **4** | LN 时长按 `1/Divide` 拍计算（4 = 1/4 拍一格） |
| 转换轨道 Column | 0 ~ 10，默认 **10** | 只在其中一部分轨道上转 LN；超过谱面键数时按全部轨道算（0 = 不限制） |
| 间隔 Gap | 0 ~ 20，默认 **12** | 每隔多少行音符重抽一次转换轨道；`0` = 整张谱用同一套轨道 |
| 随机种子 | 默认 **114514** | 固定种子结果可复现；**清空**则每次随机 |
| 修改 OD | 默认**不勾** = 保留原谱 OD | 勾选后才用右边的数值覆盖谱面 OD（0~10，默认 8） |
| 忽略已转换的谱面（Ignore） | 默认**勾选** | 谱师 / 难度名带 LNTransformer 标记的谱面直接跳过，避免重复转换 |
| 修复尾判误差（Fix Error） | 默认**勾选** | 把 LN 尾巴吸附到 1/Divide 拍的整数格上，减少游戏里尾判的细小误差 |
| 保留原 LN（Original LN） | 默认**不勾** | 原谱里已有的长条原样保留，不再参与重新生成 |
| 替换谱师为 | 默认不勾 | 勾选且填了名字才替换；不勾 = 在原谱师后追加 ` & LNTransformer` |
| 源键数过滤 | 1K ~ 10K，默认全不勾 | 勾了哪些就只转哪些键数；**一个都不勾 = 全部转换** |

| 位置 | 内容 |

## 注意

- **只支持 osu!mania**：非 mania、损坏、键数不在 1~10 的谱面会**跳过**并在日志里写原因；
  源键数不在勾选的过滤范围里也会跳过。
- **可能覆盖同名文件**：输出文件名由元数据决定，目标目录里已有同名文件时**直接覆盖、无备份**
  （同一张谱重复转、或两张谱元数据完全相同的时候会发生）。重要谱面先自己留一份。
- **「忽略已转换的谱面」是靠标记判断的**：谱师里含 `LNTransformer`，或难度名里带 `[LN...]` 都算“已转换”。
  自己给别的谱面起过类似名字也可能被误跳过 —— 这时把 Ignore 取消勾选即可。
- **已修复的已知问题**：
  - **OD 不再被写成 0**：默认**保留原谱 OD**（不会把谱面 OD 写坏），
    勾了「修改 OD」才覆盖。
  - **「保留原 LN」对全部轨道生效**。
  - **支持 1K / 2K 源谱面**（列坐标用通用公式，不会越界）。
  - **谱面缺少红线 / 时间点时不再闪退**：新版把异常转成「跳过 + 原因」写在日志里。
- **Level -2（完全随机）行为最特殊**：长度不吸附节拍网格、也不参与 Fix Error，
  且对「保留原 LN」的支持有限 —— 对成品要求高时建议先用**固定种子 + 小批量**试听，
  或改用其它档位。
- **解析/写回用 OsuParsers（MIT）**：它只认识标准 `.osu` 段落，写回时**未建模的键值、注释、自定义段落会丢失**。
- 处理是**串行**的（解析库编解码内部有静态状态、非线程安全），大文件夹会慢一些；
  不要同时开两个任务处理同一批文件。转换是纯本地计算，**不联网**。
