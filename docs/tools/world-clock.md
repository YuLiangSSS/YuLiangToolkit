# 🕐 全球时钟

> 一页看多座城市的当前时间：表盘 / 列表两种视图，带日期、与本地时差、跨日角标和昼夜状态。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **两种视图，随时切**：右上角下拉框选「表盘（一面钟墙）」或「列表（一行一个城市）」。
  - 表盘：圆盘自绘（刻度 / 时分秒针），一眼看出那边是几点、是不是半夜；
  - 列表：一行一个城市，城市名 / 日期 / 时间 / 时差排成列，赶时间查准点用它。
- **每只钟都告诉你这些**：数字时间（可带秒）、日期与星期、**与本地时差**（快 8 小时 / 慢 5 小时 30 分 / 与本地相同）、
  **跨日角标**（明天 / 昨天 —— 最容易搞错的就是这个）、**昼夜状态**（🌅 清晨 / ☀️ 白天 / 🌇 傍晚 / 🌙 夜晚，夜里的卡片底色会自动压暗）、
  **夏令时**角标（伦敦 / 纽约这种一年换两次的地方）。
- **加城市**：右侧「添加城市」里搜中文名 / 英文名 / 国家名都行（`伦敦`、`London`、`英国` 都能搜到），点一下加入。
  内置约 100 座常用城市。
- **城市库里没有？手填偏移**：写 `+5:30`、`-3`、`5.5`、`UTC+8` 都行（范围 -12:00 ~ +14:00，含半小时 / 45 分钟时区）。
  这只钟固定按你写的偏移走，不受夏令时影响。
- **排序**：按住卡片上的 `≡` 拖动；右键还能「上移 / 下移 / 置顶」；
  工具栏的「按时间排」按当地时间从早到晚排、「按名称排」按城市名排（**锁定的城市位置不变**）。
- **锁定防手滑**：每只钟右上角有个锁。
  - 锁定后：`✕` 按钮**直接不显示**、`≡` 手柄也消失（不能拖动），右键「删除」点了也只会提示先解锁；
  - 解锁就是点一下那个锁，不弹框；
  - 工具栏「全部锁定 / 全部解锁」可以一次处理所有钟。
- **删错了能反悔**：删除不弹确认框，删掉后钟区下方会出现「已删除「伦敦」· 撤销」，**6 秒内**点「撤销」就按原位置放回去。
- **复制**：双击列表里的一行复制那一只的时间；右键「复制这一只的时间」；右侧「复制全部时间」把所有城市一行一个复制走。

## 界面

- 左边是钟区（表盘墙 / 列表），右边是设置卡片，中间的分隔条可以左右拖（尺寸自动记住，双击恢复默认，
  全部恢复在「主页设置 → 界面布局 → 恢复默认布局」）。
- 设置卡片里能调：表盘大小（130 ~ 320）、显示秒、24 小时制、显示日期、显示时差、夜里换暗底色、表盘刻度。

## 时间算得对不对

- 换算统一走 `TimeZoneInfo.ConvertTimeFromUtc` 那一套（`ClockMath.Resolve`），**夏令时交给 Windows 时区库**，
  不是硬编码偏移表 —— 各国夏令时规则会变，写死迟早过时。
- 表盘 / 秒针只在**这一页可见**时刷新，并且每次对齐到整一秒再刷（不空转、秒数也不跳）。
- 时区 Id 在本机查不到（手改配置写坏了）时不会崩：按 UTC 显示并标记出来，提示你改成自定义偏移。

## 数据放在哪

- 配置：`Config\world-clock\config.json` —— 城市列表（顺序、锁定、自定义偏移）与外观选项都在这里，改一下自动落盘。
- 本工具没有 `Data\` / `Cache\` 目录（不产生任何用户文件）。

## 注意事项

- 只做「看时间」：没有闹钟 / 整点报时 / 托盘常驻小钟。要做请另外提。
- 城市库里每个时区 Id 都有自检断言（`world-clock` 组会真查本机时区库），系统缺哪个会直接报出来。
