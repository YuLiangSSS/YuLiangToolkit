# 🖥️ 任务管理器

> 一个「够用的本地任务管理器」：实时看整机 **CPU / 内存 / GPU / 硬盘读写**，
> 列出每个进程的 **PID、CPU、内存、GPU、占用端口**；选中进程能看详情、**结束任务**
> （三级后备：`Process.Kill()` → `taskkill /T /F` → `wmic delete`），
> 还能查看并管理 **开机启动项**（启用 / 禁用 / 删除）。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**：左边「进程列表」与右边「详情」之间可左右拖，进程区与「开机启动」之间可上下拖，
> 拖完自动记住；双击某条缝只恢复这一处，全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

### 1. 系统监测（页面顶部概览卡）

- **CPU**：总占用百分比（取两次采样的差值，和系统「任务管理器」的口径一致）；
- **内存**：已用 / 总量 + 百分比；
- **GPU**：所有 GPU 引擎的占用合计 + 专用显存合计（显卡驱动不提供计数器时显示「不可用」，
  集显 / 虚拟机 / 老驱动可能出现这种情况，不影响其它功能）；
- **硬盘**：全盘读取 / 写入速度（`KB/s`、`MB/s`……）；
- 另外显示 CPU 型号、显卡型号、系统版本、开机时长、进程 / 线程总数，以及每个固定磁盘的已用 / 剩余容量。

### 2. 进程列表

- 每行：**进程名 / PID / CPU / 内存 / GPU / GPU 内存 / 占用端口**；
- **搜索**：进程名、PID、可执行文件路径、端口号都会被搜到；
- **排序**：CPU / 内存 / GPU / 名称 / PID / 端口数，可升序 / 降序；
  列表是**实时排序**的——每轮刷新重排也不会丢选中项、不会把滚动条弹回顶部；
- **隐藏系统进程**：系统目录里那些 / 读不到路径的进程可以先藏起来；
- **刷新间隔**：1 / 2 / 3 / 5 / 10 秒；也可以「暂停监测」再手动「刷新」一次。

### 3. 进程详情（选中某一行后）

- 进程名、PID、CPU、内存、GPU、GPU 内存；
- 可执行文件完整路径、运行用户、启动时间、优先级、主窗口标题、线程数、句柄数、虚拟内存；
- **占用的端口**：TCP / UDP、IPv4 / IPv6 全部列出（协议、本地 / 远端端点、TCP 状态）；
- 快捷操作：**结束任务**、**打开文件位置**、**复制 PID**、**复制路径**。

### 4. 结束任务（三级后备）

和系统任务管理器一样，按顺序尝试，上一级成功就停：

1. **`Process.Kill()`** —— 最直接；对以管理员权限启动的进程经常失败；
2. **`taskkill /PID {pid} /T /F`** —— `/T` 会连同子进程树一起结束；
3. **`wmic process where name='…' delete`** —— 最后的兜底（Windows 11 24H2 起部分系统已移除 wmic，
   这时会明确告诉你「此系统已移除 wmic」，而不是假装成功）。

- 每一步的**成功 / 失败和原因**都会写进日志，失败时弹窗列出三级分别试了什么；
- **系统关键进程**（`csrss.exe` / `winlogon.exe` / `lsass.exe` / `services.exe` 等）受 Windows 保护，
  点「结束任务」会**提前拦下并提示「拒绝访问」**，不会让程序崩掉；
- 结束 `explorer.exe` 这类桌面外壳进程会额外提醒（桌面 / 任务栏会短暂消失，系统通常会自动重启它）；
- 默认**结束前弹确认框**（设置里可关），避免误点。

> 普通权限运行时，管理员启动的进程可能提示「拒绝访问」。想结束它们，请**右键以管理员身份运行本程序**。

### 5. 开机启动项

扫描四类来源（只读，不改动任何东西）：

- 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（当前用户）；
- 注册表 `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`（所有用户，含 32 位分支）；
- 注册表 `RunOnce`（只运行一次）；
- 当前用户 / 公共「启动」文件夹里的快捷方式 / 程序。

每条显示：**名称、状态（已启用 / 已禁用）、来源、启动命令 / 目标程序**。可以：

- **启用 / 禁用**：写 Windows 自己的 `StartupApproved` 记录（和系统任务管理器那个开关是同一份数据，
  所以关掉之后系统任务管理器里也会显示「已禁用」，重启后真的不会自启）；
- **删除**：注册表值 / 启动文件夹里的文件（会先弹确认框）；
- **打开文件位置** / **复制命令**。

> 只删「启动记录」，**不会卸载程序本身**。HKLM / 公共启动文件夹里的项目需要管理员权限才能改，
> 普通权限下这些按钮是灰的。

## 怎么用

1. 打开工具页就开始自动监测（默认每 2 秒刷一次）。
2. 想看某个进程：在左边列表里点它 → 右边详情会自动补全（端口 / 路径 / 用户等）。
3. 想结束它：点右侧「结束任务」，确认后等结果；失败会告诉你三级各自的原因。
4. 想找占端口的进程：直接在搜索框输入端口号（例如 `8080`）。
5. 想调排序 / 刷新频率：用列表上方的下拉框和复选框，改完自动保存。
6. 想看 / 改开机启动项：拉到底部「开机启动」区块，选中一行后用右侧按钮操作。

## 设置项

改一下就自动存进 `Config\task-manager\config.json`，没有保存按钮。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 刷新间隔 | 2 秒 | 1 / 2 / 3 / 5 / 10 秒可选；监测循环按它跑 |
| 排序方式 | CPU | CPU / 内存 / GPU / 名称 / PID / 端口数 |
| 降序 | 开 | 关掉就是从小到大（按名称排序时建议关） |
| 搜索关键字 | 空 | 上次搜的内容会记住 |
| 隐藏系统进程 | 关 | 系统目录进程 / 读不到路径的进程不显示 |
| 结束任务前确认 | 开 | 默认弹确认框 |
| 采集 GPU 占用 | 开 | 显卡驱动不支持计数器时自动降级为「不可用」 |
| 采集端口占用 | 开 | 关掉后进程列表不显示端口、详情不列端口，可减少开销 |

## 数据放在哪

- 配置：`Config\task-manager\config.json`（只有上面这些设置项）。
- 本工具**不写 Data / Cache**。
- 区块布局：跟其它工具页一样存在 `Config\layout.json`（键名前缀 `task-manager.`）。

## 常见问题

| 现象 | 原因 / 怎么改 |
| --- | --- |
| GPU 一直显示「不可用」 | 显卡驱动没提供 Windows 的 GPU 性能计数器（集显 / 虚拟机 / 部分老驱动常见）。CPU、内存、硬盘、进程都不受影响。 |
| 某个进程 CPU 一直是 0.0% | CPU 占用是两次采样的平均差值：刚启动的进程、以及两次采样间完全睡眠的进程会显示 0。 |
| 端口一列是空的 / 提示读取失败 | 普通权限通常能读端口表；如果失败，右键以管理员身份运行本程序再试。 |
| 结束任务失败，提示「拒绝访问」 | 对方进程以管理员权限运行。以管理员身份重启本程序后再试；系统关键进程无论什么权限都结束不了（Windows 保护）。 |
| 提示「此系统已移除 wmic」 | Windows 11 24H2 起部分版本不再自带 wmic，前两级（Process.Kill / taskkill）仍然有效；这个提示只是说明第三级兜底不存在。 |
| 开机启动项的「启用 / 禁用 / 删除」是灰的 | 那一项在 HKLM 或公共启动文件夹，需要管理员权限；以管理员身份运行本程序后即可操作。 |
| 关掉开机启动项后，系统任务管理器里也显示已禁用？ | 正常：两边读的是同一份 `StartupApproved` 数据。想彻底删除请用「删除」。 |
| 列表刷新时选中项 / 滚动位置乱跳 | 不应该发生：进程行按 PID 原地更新、实时排序保留选中。如果遇到请记录进程名与操作步骤反馈。 |
| 监测太耗性能 | 把刷新间隔调到 5 / 10 秒，或在设置里关掉「采集 GPU / 端口」，也可以点「暂停监测」。 |

## 自检

`task-manager` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/TaskManagerChecks.cs`）覆盖：

- 数字格式化（字节 / 速度 / 百分比 / 运行时长 / 端口摘要 / TCP 状态 / 路径省略）；
- 结束任务三级方案（顺序 / taskkill 参数 / wmic 参数与进程名规范化 / 失败才继续 / 结果文案）；
- 开机启动命令解析（引号 / 无引号 / 环境变量 / rundll32）、StartupApproved 12 字节标记往返；
- 系统关键进程 / 桌面外壳名单；
- 进程行对象原地合并、搜索命中、显示文本；配置默认值与 JSON 往返；
- **只读**采样本机（自己的进程、端口表、整机内存、整机快照）——**不结束任何进程、不写注册表、
  不修改开机启动项**；真实结束任务 / 启动项启停由界面人工冒烟验收。
