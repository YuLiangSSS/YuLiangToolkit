# 🎬 视频 / 音乐播放器

> 本地播放器：中间是画面（音频时显示封面），下面是进度条与一排控制按钮，右边是播放列表。
> 支持播放列表、列表 / 单曲 / 随机、**可调步长的快进快退**、音量，还会记住上次听到哪儿。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **三种打开方式**：`📂 文件夹`（可多选）、`🎵 文件`（多选）、**把文件 / 文件夹直接拖进窗口**。
  同一个文件重复打开会自动去重。
- **读取范围可筛**：音频 + 视频 / 仅音频 / 仅视频；要不要连子文件夹一起读；再开一个文件夹是**追加**还是**覆盖**。
- **播放顺序**：列表循环 / 单曲循环 / 随机播放（随机一轮内不重复，一轮放完才重洗，不会连着放同一首）。
- **快进快退**：步长可调（0.1 ~ 60 秒，**精确到 0.1 秒**）。
  - **左键**快退 / 快进按钮 = 按步长跳；
  - **右键**快退 = 上一首，**右键**快进 = 下一首；
  - 进度条可以直接点，也可以按住拖动。
- **记住上次**：播放列表和听到的位置都存在 `Data\media-player\playlist.json`，
  下次打开自动接上（**只选中、不自动出声**）；文件被删了的条目会自动跳过。
- **全屏（沉浸式）**：点画面右下角的圆钮或按 `F11` → 画面铺满**整个屏幕**（连任务栏那块也一起盖住），
  标题栏 / 侧边栏 / 播放列表全部让出来。**鼠标往屏幕下方一动**，底部就会浮出一条控制条
  （正在放什么 + 进度条 + 全套按钮，最右边是「退出全屏」）；**2.5 秒不动鼠标**，控制条自动缩回去、
  鼠标指针也一起隐藏，屏幕上只剩画面。`Esc` 或控制条上的按钮退出全屏；切走工具时也会自动退出。
- **后台播放**（默认开）：切到别的工具 / 回主页时**声音不断**，左下角浮出一个**迷你播放条**：
  一行从右往左循环滚动的标题 + 快退 / 播放暂停 / 快进（**左键跳步长、右键上一首 / 下一首**），
  点标题直接回到播放器。切回来时列表、进度都还在（视图被保留，不是重新加载）。

## 怎么用

1. 点右边列表上方的「📂 文件夹」挑一个音乐 / 视频文件夹（可以一次选多个，也可以直接把文件夹拖进窗口）。
2. 双击列表里的某一行开始播放；想换歌就点（或双击）另一行，或者用右键快进 / 快退。
3. 想让「快进 10 秒」而不是 5 秒：点左上角齿轮 → 「播放」→ 拖「快进 / 快退步长」的滑块（或直接输入数字）。
4. 设置项都在同一个页面里，改完直接关掉面板就行 —— **没有保存按钮**，改一下就落盘。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进一个步长 |
| `Enter` | 播放列表里选中的那一行 |
| `Delete` | 从列表移除选中的那一行（不删磁盘文件） |
| `Ctrl+O` / `Ctrl+Shift+O` | 打开文件 / 打开文件夹 |
| `F11` | 全屏 / 退出全屏 |
| `Esc` | 退出全屏（全屏时）→ 关掉设置面板 |
## 设置项

| 设置 | 存哪 | 说明 |
| --- | --- | --- |
| 打开文件夹时读取哪些文件 | `Config\media-player\config.json` | 音频 + 视频 / 仅音频 / 仅视频；**手动打开与拖放也按它过滤** |
| 连子文件夹一起读取 | 同上 | 默认开；扫描在后台线程跑 |
| 再开一个文件夹 | 同上 | 只添加（追加）/ 先清空（覆盖）；「打开文件」与拖放一律追加 |
| 快进 / 快退步长 | 同上 | 0.1 ~ 60 秒，0.1 秒精度 |
| 播放顺序 | 同上 | 与播放条右边那个「循环 / 单曲 / 随机」按钮是同一个值 |
| 音量 | 同上 | 0 ~ 100 |
| 恢复上次的列表 / 位置 | 同上 | 关掉就不恢复 |
| 后台播放 | 同上 | 默认开；切走时继续出声 + 左下角出现迷你播放条。关掉 = 切走即停 |
| 上次打开的文件夹 | 同上 | 文件对话框从这里开始 |

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\media-player\config.json` | 上面所有设置 |
| `Data\media-player\playlist.json` | 播放列表快照：全部路径 + 上次那首 + 听到第几秒 |

## 注意

- **能播哪些格式取决于系统的 Media Foundation 解码器**：mp3 / wav / flac / m4a / wma / ogg 与
  mp4 / mkv / webm / avi / mov 之类一般都行；打不开时会提示一句人话，而不是静默失败。
- 列表行**不显示时长**：几百首歌逐个去探测太慢，只有当前这首打开后才在下面显示总时长。
- 切换工具 / 返回主页默认**不会停播**（后台播放开着）；想让它停就把设置里的「后台播放」关掉。
- 全屏是**整窗全屏**：任务栏也会被盖住，按 `Esc` 或点右下角那个按钮退出。
- 播放器只读文件，**不改任何标签 / 不做转码**；要转格式请用「视频转音频」。
