# 🗂️ 打开方式

> 把凉雨工具集登记进 Windows 右键 → **打开方式**：列表里会出现 **3 个入口** ——
> **按文件类型打开**（自动分流）、**以文本方式打开**、**以压缩包方式打开**。
> 任意文件右键都能选到本工具；PDF / 图片 / Word / Excel / 压缩包 / 音视频 / 文本会自动交给对应功能。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**（每个区块之间都能拖）：左边「登记到系统」和右边「按文件类型打开」之间可左右拖；
> 主区域与底部运行日志之间可上下拖，拖完自动记住；双击某条缝只恢复这一处，
> 全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

| 入口 | 效果 |
| --- | --- |
| **凉雨工具集（按文件类型打开）** | 看扩展名自动分流：PDF → PDF 阅读器、图片 → 图片连续阅读器、`.docx` → Word 阅读器、`.xlsx` → Excel 阅读器、压缩包 → 压缩包工具、音视频 → 播放器、文本 / 代码 → 文本编辑器；**认不出的扩展名用文本编辑器兜底** |
| **凉雨工具集（以文本方式打开）** | 不管什么文件都交给**文本编辑器**（适合看日志 / 配置 / 脚本、或临时看陌生文件的内容） |
| **凉雨工具集（以压缩包方式打开）** | 不管什么文件都当成压缩包交给**压缩包工具**（探测格式、密码、内容列表；不是压缩包会在列表里标「读取失败」，不会破坏文件） |

> 三个入口用同一套单实例逻辑：程序已经开着时，选「打开方式」只是把文件交给现有窗口，**不会再多开一个窗口**。

## 怎么用

1. 打开左侧「**文件**」分类 → **🗂️ 打开方式**（也可以主页搜索「打开方式」）。
2. 勾选「**在右键「打开方式」里显示凉雨工具集（3 个入口）**」。
3. 到资源管理器里右键任意文件 → **打开方式** → 选择需要的入口（首次可能等几秒才刷新列表）。
4. 想换默认程序：Windows 的「打开方式 → 始终使用此应用」仍然有效；也可以点页面上的
   「打开「默认应用」设置」在系统设置里选一次。

页面上的其它东西：

- **状态说明**：显示是否已登记、入口副本是否与当前程序版本一致；
- **修复 / 刷新**：程序更新或把文件夹挪了位置后点一下，会按当前 exe 重建入口副本和注册表命令；
- **列表里会出现的 3 个入口**：逐条说明三种模式（和上表一致）；
- **按文件类型打开（自动模式）**：右侧列出「哪个工具认领哪些扩展名」；
- **模拟**：填一个文件路径 → 显示自动模式会交给哪个工具（**只显示结果，不会真的打开文件**）。

## 数据与注册表

| 内容 | 位置 |
| --- | --- |
| 入口副本 exe | 和主程序 **同一个目录**：`<主程序名>.open-text.exe` / `<主程序名>.open-archive.exe`（只是同一个程序的两个入口名，依赖仍在主程序目录；「按文件类型」直接用主程序 exe） |
| 打开方式注册 | `HKCU\Software\Classes\Applications\<入口 exe 名>`（`FriendlyAppName` / `DefaultIcon` / `shell\open\command`） |
| 本功能状态 / 备份 | `HKCU\Software\YuLiangToolkit\OpenWith`（记录是否安装、自动入口原来的名字与命令，取消登记时还原） |
| 页面配置 | `Config\open-with\config.json`（只记「模拟」输入框上次的路径） |

> **只写当前用户（HKCU）**，不需要管理员权限；**不改任何后缀的默认程序**（`UserChoice` 由 Windows 保护，
> 也属于未公开行为，本工具不硬抢）。取消勾选会删掉 3 个 Applications 条目和 2 个入口副本，
> 自动入口按登记前的原样还原。

## 常见问题

**Q：为什么列表里出现 4 个「凉雨工具集」？**
A：如果之前单独开过 **PDF 阅读器 / 图片阅读器设置里的「文件关联」**，那两个阅读器会额外登记一个
不带后缀的「凉雨工具集」入口；如果是在旧版本 / 旧目录里登记的，它的命令可能还指向旧 exe
（在「打开方式」里和本工具的「按文件类型」看起来同名）。把对应阅读器设置里的关联关掉再打开一次即可刷成当前路径，
或直接忽略那一条（功能不冲突）。

**Q：为什么「以文本方式 / 以压缩包方式」要用入口副本，而不是一个程序写三个注册表项？**
A：Windows 的「打开方式」列表**按 exe 路径去重**：同一个 exe 即使写三条不同参数的命令，也只会显示成一条。
所以用两个同目录的入口副本（复制主程序 exe，体积和主程序相同、依赖共用）来区分路径；
点哪条入口就带 `--open-as=text` / `--open-as=archive` 启动，主程序据此选模式。

**Q：为什么以文本方式打开后，自动保存不工作了？**
A：这是**故意的保护**：文本编辑器默认 0.9 秒自动保存，而「打开方式」可能把 `.exe` / `.zip` 这类二进制
交给它；如果误触键盘就自动写回去，可能**直接写坏原文件**。所以从「打开方式」打开的标签会**暂停自动保存**
（Ctrl+S / 保存按钮仍然可用；关掉该标签重新从编辑器打开即恢复正常自动保存）。

**Q：程序更新 / 换目录了怎么办？**
A：启动时会自动按当前路径刷新一次；也可以到本页面点「**修复 / 刷新**」，或取消勾选再重新勾选。

**Q：想彻底恢复原状？**
A：取消勾选即可（只删本工具写入的东西）。如果还想清理备份信息，注册表里的
`HKCU\Software\YuLiangToolkit\OpenWith` 会随取消登记一起删除。

## 自检

`open-with` 组只测纯逻辑（三种模式 / 命令行解析 / 扩展名分流 / 注册表命令拼装 / 状态只读函数），
**绝不调用登记 / 取消登记**（避免往开发机真实注册表写东西）。真正的登记往返由用户点界面或 Lead 手动验证。
