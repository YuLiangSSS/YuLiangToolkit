# 🎼 osu!mania 谱面编辑器

> 边听音乐边摆 note：左键放普通键、按住下拖放长条（LN）、右键删除，音频与时间轴**精确同步**。
> 只做 mania（不做 hitsounds）；红线和绿线（SV）都能读能改，**绿线 SV 只做数据、不影响播放**。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **打开 / 保存 .osu**：直接改原文件（不另存新谱）。保存时**只重建 `[TimingPoints]` 与 `[HitObjects]`
  两段的正文**，其它段落、未知键、注释、`[Events]` 原样保留。
- **摆 note**：左键点一下放普通键；切到「长条」工具后按住左键往下拖就是 LN（拖太短会自动落成普通键）。
- **改 note**：拖动已有的 note 可以整体平移（换列 / 改时间），拖 LN 的**尾巴**只改结束时间。
- **删 note**：对着 note **右键**即可删除；也可以选中后按 `Delete`。
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`。**一次拖动 = 一步撤销**（不是几十步）。
- **自动保存**：无操作 N 秒后自动写盘（默认 10 秒，可在右侧面板改，范围 2~600）。
  「操作」包括摆放 / 拖动 / 删除 note、滚时间轴、缩放、点按钮、**移动鼠标**、按键 —— 全程有互动就不会被打断。
  **播放中不自动保存**（写盘可能卡一下，正听节奏时闪一下很难受），暂停后重新计空闲。
- **退出提醒**：有未保存改动时退出程序会问「保存 / 不保存 / 取消」。
  切走工具页（视图进缓存）时会先静默落盘一次，不会丢。
- **采样**：编辑器**不做 hitsounds**。新写的 note 一律用默认采样 `0:0:0:0:`（采样组 / 序号 / 音量都是 0，
  也就是「不单独指定、交给谱面默认」）；已有 note 上的采样信息原样保留、不被改写。
- **音频同步**：打开谱面时按 `AudioFilename` 自动加载同目录音频，播放头与音乐对齐；
  支持 mp3 / ogg / wav / flac / m4a / aac / wma（ogg 由 NVorbis 纯托管解码）。
- **时间点（红线 / 绿线）**：列表里能看到全部红线（BPM）和绿线（SV），可以加、删、改，
  也可以直接在画布左标尺上拖动时间点。**绿线 SV 不改播放速度**（真正的 SV 效果属于 gameplay，本工具不做）。
- **网格吸附**：按节拍细分（1 / 2 / 3 / 4 / 6 / 8 / 12 / 16）吸附到当前红线的节拍网格；
  中期变速的谱面会**分段按各自的红线**算（不会用全场第一条红线一把算）。
- **音频偏移**：界面里可调（毫秒）。每条声卡 / 耳机的缓冲延迟不同，觉得音符整体和音乐错开时用它对齐。

## 音频同步怎么做精确的（核心）

这是本工具最要紧的部分，做法和「拿 `MediaElement.Position` 直接用」完全不同：

| 层 | 做法 | 为什么 |
| --- | --- | --- |
| 时间源 | NAudio `WaveOut` 的**设备字节位置**（`waveOutGetPosition`）÷ 每秒字节数 | WPF `MediaElement.Position` 精度只有几十毫秒、刷新间隔可达 200ms，30ms 偏差就是「音符和鼓点明显错开」 |
| 平滑 | `PlaybackClock`：以单调时钟为锚点推进 + 定时用设备位置校准 | 设备位置本身有缓冲粒度噪声（±30ms），直接用会让播放头每帧乱跳 |
| 校正 | 小漂移（< 120ms）**只微调推进速率**（±1.5%），大漂移才硬对齐 | 画面绝对平滑；又不会和声音长期分离 |
| 定位 | `Stop → 源 CurrentTime = 目标 → 重建输出设备 → Play → 时钟 Start(目标)` | `WaveOut` 的 `GetPosition` 在 Stop 后归零，复用旧设备会让设备位置与源位置永久错开 |
| 延迟 | **不减**任何延迟值；用户可用「音频偏移」自己微调 | `GetPosition` 报的已经是「耳朵此刻听到的位置」（它从 Play 起就恒定落后真实时间一个缓冲深度）；再减一次会让画面比声音还早 |

**关于那 64ms**：`GetPosition` 恒定落后真实时间约 64ms（25ms × 3 缓冲），这 64ms 就是缓冲里
还没出声的部分，所以它报的位置正好是「耳朵听到的内容」。不同声卡 / 蓝牙耳机 / 系统混音器的延迟各不相同，
所以界面给了「**音频偏移**」输入框（单位 ms，正数 = 画面往后推）：觉得音符整体和音乐错开时，用它对齐。

自检里有两条配套断言：假时钟验证逻辑（暂停 / 定位 / 漂移 / 硬重同步 / 时钟倒退不回退），
**真机断言**真的开声卡播 1.2 秒，要求时钟与真实时间误差 < 150ms、偏移真的作用到时钟上。
没有可用声卡时跳过并记 PASS。

## 大量 note 怎么做到不卡（渲染）

谱面动辄几万到十几万 note，如果每个 note 一个 WPF 控件，创建慢、内存爆、布局 O(n)，
再加虚拟化也救不了（`VirtualizingStackPanel` 只能按线性顺序虚拟化，而谱面要按**时间窗口**取）。

这里的做法：

1. **零控件自绘**：整个时间轴只有一个 `ChartCanvas`（`FrameworkElement.OnRender`），
   绘制量 = 屏幕上那几百个矩形，**与谱面总大小无关**；
2. **二分取窗口**：`NoteIndex` 维护「按开始时间升序」的下标数组 + 二分；
   因为 LN 可能「头在屏外、身体还在屏内」，查询时下界按**全谱最长 LN 长度**放宽；
3. **每帧只建一次快照**：`ChartRenderState.Build` 做完裁剪 + 抽稀，绘制层只做坐标变换；
4. **极端缩放下抽稀**：一屏看整张谱面时按时间均匀抽稀到上限（12000），宁可少画也不卡 UI；
5. **画笔冻结缓存**：Brush / Pen 全部缓存并 `Freeze()`，不在 `OnRender` 里 new。

自检对这条有硬指标（12 万 note 的谱面）：单帧构建快照 < 8ms、快照只含可见 note、
极端缩小抽稀到上限内、命中测试 200 次 < 60ms、保存 / 读回各 < 2s。

## 怎么用

1. 点「打开谱面…」或把 `.osu` 拖进页面（只接受 mania 谱面）。
2. 同目录有 `AudioFilename` 指向的音频时会自动加载；没有就点「重新加载」旁的音频按钮手动选。
3. `空格` 播放 / 暂停，`Esc` 停止，`←` / `→` 微调 10ms。
4. 选「普通键」或「长条」，在轨道上点击 / 拖动摆 note；右键删；拖已有点改位置。
5. 改完不用管：**无操作 10 秒会自动保存**（右侧面板可改间隔 / 关掉）；也可以随时 `Ctrl+S` 手动保存。

### 快捷键

| 键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `Esc` | 停止（回 0） |
| `Ctrl+S` | 保存 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（`Ctrl+Shift+Z` 也是重做） |
| `Delete` | 删除选中的 note |
| `1` / `2` | 切普通键 / 长条 |
| `Q` | 开关网格吸附 |
| `←` / `→` | 播放头 −10ms / +10ms |

### 鼠标

| 操作 | 作用 |
| --- | --- |
| 左键点空白（普通键工具） | 放一个普通键 |
| 左键按住往下拖（长条工具） | 放一条 LN |
| 左键拖已有 note | 平移（可换列） |
| 左键拖 LN 尾部 | 只改结束时间 |
| **右键点 note** | **删除** |
| 点 / 拖左侧标尺 | 拖动播放头（对齐节奏用） |
| 中键拖动 / 滚轮 | 滚时间轴 / 以鼠标为中心缩放 |

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\osu-mania-editor\config.json` | 网格细分 / 吸附 / 音量 / 是否跟随播放头 / 缩放 / **音频偏移** / **自动保存开关与间隔** / 上次目录（改一下自动保存） |

> 编辑器**不复制**谱面到自己的数据目录，也不缓存音频。切走页面时音频会停。

## 注意

- **只支持 osu!mania**：其它模式的谱面会提示并拒绝打开。
- **保存会重排时间点与打击物**：按时间升序重写（osu! 本来也要求有序），
  行内的注释会随原段落保留，但两段正文里的历史缩进 / 空行会被规整。
- **不做 hitsounds 编辑**：读出来的 `hitSound` / 采样信息会原样保留回写，但界面上不提供修改；
  新写的 note 固定用默认采样 `0:0:0:0:`（音量 0 = 交给谱面默认）。
- **绿线 SV 不做实际效果**：只读写数据，播放速度不受 SV 影响（和 osu! 的 SV 语义一致 —— SV 影响的是
  音符下落速度，不影响音频）。
- **自动保存是「静默」的**：不弹窗、不打断操作，只在状态栏写一句；播放中不保存。
  关掉自动保存的话，切走页面前记得 `Ctrl+S`（切走时仍会静默落盘一次，但退出程序会提示你）。
- 音频走 NAudio（MIT）+ NAudio.Vorbis（MIT，内部 NVorbis，MIT），见
  [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md)。
