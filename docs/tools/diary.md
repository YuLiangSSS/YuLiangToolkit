# 📔 日记本

> 给自己写日记：左边是历史日记（按日期排、可搜索），右边边写边自动保存；支持富文本与普通文本两种写法。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **两种写法，随时切换**：
  - **富文本**——跟邮箱编辑器一样：加粗 / 斜体 / 下划线 / 删除线、文字颜色、标题（正文 / 大标题 / 中标题 / 小标题）、
    无序 / 有序列表、左中右对齐、插入图片、清除格式；快捷键 `Ctrl+B / I / U`。
  - **普通文本**——只写纯文字，不解析任何格式（适合随手记、代码片段、流水账）。
  - 切换写法时**文字内容会保留**（富文本降级成纯文字会去掉格式、保留文字与换行；普通文本升级成富文本会把换行转成段落）。
- **历史日记列表**：按「创建日期」倒序（可切换成最早在前），每条显示日期徽标、标题、正文摘要、心情、时间；
  顶部搜索框按**标题或正文**搜索。点哪篇就编辑哪篇。
- **自动保存**：边打字边静默落盘（约 1.5 秒），切换日记 / 关闭工具 / 按 `Ctrl+S` 也会立刻保存；不用点保存按钮也不会丢。
- **心情**：顶部一排 emoji（😀 😊 😐 😔 😡 🥳），点一下记在当天那篇上，列表里能一眼看到；`✕` 清除。
- **新建 / 删除**：右上「＋ 新建日记」（或 `Ctrl+N`）写今天的日记；编辑区右上「删除」删当前这一篇（会先确认，不能撤销）。

## 界面怎么摆

| 区域 | 内容 |
| --- | --- |
| 左栏 | 搜索框 + 历史日记列表（按日期排、带摘要与心情）；底部显示统计与状态 |
| 分隔条 | 左右两栏之间的竖条，可左右拖动调宽度，自动记住 |
| 右栏 | 标题 + 日期 + 心情 / 富文本工具条 + 保存·删除 / 正文编辑区 / 底部字数与保存状态 |

## 数据放在哪

- 每篇日记一个 JSON：`Data\diary\entries\<Id>.json`（`Id` 是「时间戳-随机串」，同时用于文件名与排序）。
- 配置：`Config\diary\config.json`（记住「最新在前」还是「最早在前」、新建日记默认用哪种写法）。
- 一篇一个文件的好处：某篇不小心写坏只丢这一篇（坏文件会被自动备份成 `*.bad-*.json`），其它篇不受影响；
  也可以直接进文件夹备份 / 拷走。

## 注意

- 全部在本机，**不联网、不上传**。
- 富文本里插入的图片记录的是图片在本机的路径；如果之后把原图移动 / 删掉，那篇里的图片会显示不出来（文字不受影响）。
  需要长期保存的配图，建议先放进一个固定文件夹再插入。
