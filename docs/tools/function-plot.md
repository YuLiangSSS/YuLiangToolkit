# 📈 函数绘图

> 同时画多条函数曲线：每条可以单独设**定义域**、颜色、显示开关；拖动平移、滚轮缩放、双击复位；
> **网格与坐标轴可以在设置里隐藏**；随时**自动求点** —— 光标停在图上读各函数的 y、输入 x 求所有函数值、
> 或按当前范围自动生成点值表。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**：左上「绘图区」与左下「求值 / 点值表」可上下拖；左列与右列（函数列表 + 设置）可左右拖；
> 右列里「函数列表」与「设置」可上下拖。拖完自动记住，双击某条缝只恢复这一处，
> 全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **同时画多个函数**：右侧列表里点「+ 添加函数」，每条都有一行编辑器；默认已经放了 `sin(x)` 和 `cos(x)`
  两条，打开就能看到效果。每条函数可以：
  - 改**表达式**（实时校验：写错只在这条上标红提示中文原因，其它曲线照常画）；
  - 选**颜色**（8 个调色板颜色，深浅主题下都看得清）；
  - 勾掉**显示**（不画但保留配置，随时勾回来）；
  - 设**定义域**（左端 / 右端，留空 = 不限制，用当前可视范围）。两端写反了会自动交换。
- **自由看图**：左键按住拖动 → 平移；滚轮 → 以光标为中心缩放；双击 → 复位到
  X ∈ [−10, 10]、Y ∈ [−6, 6]。当前范围会实时显示在工具条上。
- **坐标系可隐藏**：设置里「隐藏坐标系」关掉坐标轴与刻度、「隐藏网格」关掉网格线 ——
  只留曲线（截图 / 出图时很实用）。图例、十字准星也可以单独关。
- **自动求各种点的值**（三种方式）：
  1. **光标读数**：鼠标停在绘图区，底部「光标」区实时显示当前 x，以及**每个可见函数**在该 x 的 y；
     函数在该点无定义（或不在定义域内）就显示「无定义」。
  2. **输入 x 求值**：在「x = 」里填一个数点「求值」，下面的表列出所有函数在该点的 y，一行一个函数。
  3. **自动取点**：点「自动取点」，按当前 X 范围均匀取 10 个点，生成 x 列 + 各函数值列的点值表。
- **渐近线不画假竖线**：`tan(x)`、`1/x` 这类在极点附近会**自动断线**，不会画出一根假的竖线；
  超出当前 Y 范围的部分自动裁掉，并在边缘补交点。

## 怎么用

1. 打开工具页，默认就有 `sin(x)` 和 `cos(x)` 两条曲线。
2. 在右侧函数列表里改表达式：输入框失焦或按回车后曲线刷新；写法错误会在该行下面给出中文原因。
3. 想加曲线：点「+ 添加函数」；想删：点该行的删除按钮。每条都能单独设颜色、显示开关、定义域。
4. 拖动 / 滚轮调整视角，双击空白处复位。
5. 想知道某个点的值：把鼠标移到图上读底部读数，或在「x =」里输入数字点「求值」，
   或点「自动取点」看一张现成的表。
6. 设置区可以调角度单位、采样点数、自动 / 手动 Y 范围，以及隐藏坐标系 / 网格 / 图例 / 准星。

## 支持的表达式写法

和「计算器」共用同一个表达式引擎（`src/YuLiangToolkit.Core/Expressions/`）：

- 四则运算 `+ - * /`、乘方 `^`（右结合）、取模 `mod`、阶乘 `!`、括号、一元正负号；
- **省略乘号**：`2x`、`2(x+1)`、`(x+1)(x-1)`、`3sin(x)`；
- 变量 `x`；常量 `pi` / `π`、`e`、`tau` / `τ`；
- 函数：`sin cos tan asin acos atan atan2 sqrt cbrt abs exp ln lg log log2 log10 floor ceil round trunc sign
  sinh cosh tanh asinh acosh atanh pow mod hypot clamp min max nCr nPr rad deg`（`log(x)` 是常用对数，
  `log(底, x)` 指定底）；
- 顺手兼容 `× ÷ − ² ³`、全角括号和全角数字。

> 三角函数按设置里的**角度单位**计算：弧度制下 `sin(pi/2)=1`，角度制下 `sin(90)=1`。

## 设置项

改一下就自动存进 `Config\function-plot\config.json`，没有保存按钮。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 隐藏坐标系 | 关 | 勾上后不画坐标轴与刻度（曲线、图例照常） |
| 隐藏网格 | 关 | 勾上后只留坐标轴和曲线 |
| 角度单位 | 弧度 | 「弧度」或「角度」；只影响三角与反三角函数 |
| 采样点数 | 1200 | 200 ~ 4000；越大曲线越平滑，也越费 CPU |
| 自动 Y 范围 | 开 | 按当前可见曲线自动算 Y 上下界（会忽略极少量极端值，避免 `tan` 把 Y 撑到 1e12）；关掉后用下面的手动范围 |
| X / Y 范围 | −10~10 / −6~6 | 手动范围；写反自动交换。双击复位或点「复位」回到默认 |
| 十字准星 | 开 | 鼠标在图上时画虚线准星与坐标读数 |
| 图例 | 开 | 绘图区右上角显示「颜色 + 表达式」清单 |

## 文件放在哪

- 配置：`Config\function-plot\config.json`（相对 **exe 所在目录**），函数列表（表达式 / 颜色 / 定义域）
  和上面这些设置都存在这里；关掉再打开曲线还在。
- 数据：本工具不写 `Data\`、不写 `Cache\`，没有「重新生成」之类的缓存。
- 区块大小：和别的工具页一样存在 `Config\layout.json`（键名前缀 `function-plot.`）。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 曲线中间断开 | 正常的刻意行为：函数在该段无定义（如 `sqrt` 的负半轴）、或超出当前 Y 范围、或接近渐近线（`tan` / `1/x`）——断线比画假竖线更准确 |
| 只看到一两段、其余被裁掉 | Y 范围太小或自动 Y 范围开了；关掉自动 Y、把 Y 范围调大，或缩小查看 |
| 刚打开只有 `sin` / `cos` 两条 | 默认函数列表，可在右侧改表达式或添加新函数 |
| 函数写错后整条不见了 | 该行会标红提示中文错误；其它曲线不受影响。修正表达式后自动恢复 |
| 定义域填了却整条不显示 | 定义域和当前可视 X 范围没有交集（例如定义域 [100, 200] 而视图是 −10~10）|
| 缩放后曲线「跑出屏幕」 | 双击绘图区复位到默认范围 |
| `sin(90)` 不对 | 当前是弧度制：在设置里切「角度」，或写 `sin(pi/2)` |
