# 🔢 数字转换器

> 输入一个数字，同时得到它几乎所有常见写法：中文小写 / 大写、人民币金额大写（写支票、转账备注用）、
> 英文念法（`one thousand` 或 `a thousand`、`one hundred and twenty-three`）、序数词、罗马数字、
> 千分位、二 · 八 · 十六进制、科学计数法、逐位念号码。
> 反过来也能把「壹拾贰圆叁角肆分」读回 `12.34`。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局**：左边「要转换的数字」与「写法口味」之间可上下拖，左右「输入区 / 结果区」之间可左右拖；
> 拖完自动记住，双击某条缝只恢复这一处，全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

| 结果行 | 例子（输入 `1234.56`） | 什么时候用 |
| --- | --- | --- |
| 标准写法 | `1234.56` | 去掉千分位、多余的 0、前导 `+` |
| 中文小写 | 一千二百三十四点五六 | 写说明、念数字 |
| 中文大写 | 壹仟贰佰叁拾肆点伍陆 | 财务 / 票据里的数字大写 |
| 中文序数 | 第一千二百三十四点五六 | 排名、楼层、周年 |
| **人民币金额大写** | 壹仟贰佰叁拾肆圆伍角陆分 | **写支票 / 转款备注 / 借条** |
| 人民币金额小写 | 一千二百三十四圆五角六分 | 中文小写的金额说法 |
| 英文基数词 | a thousand two hundred and thirty-four point five six | 念数字 |
| 英文序数词 | a thousand two hundred and thirty-four point five six | 第几（整数时是 `-third` 这种） |
| 英文金额 | a thousand two hundred and thirty-four dollars and fifty-six cents | 英文票据 |
| 英文支票 | one thousand two hundred thirty-four and 56/100 dollars | 英文支票的金额栏 |
| 英文逐位读 | one two three four point five six | 念号码 / 订单号 |
| 罗马数字 | —（超过 3999） | 章节、钟表、赛事届数 |
| 千分位 | `1,234.56` | 表格 / 报表 |
| 每 4 位分组 | `1234.56` | 念银行卡号、手机号 |
| 科学计数法 | `1.23456×10³` | 科学 / 工程 |
| 二 / 八 / 十 / 十六 / 三十六进制 | 只有整数才有 | 写代码、调色、短链接 |

- **一改就重算**：输入框里敲一个字符，右边所有结果立刻刷新（纯字符串运算，没有 IO）。
- **点一行就复制**：单击某一行复制它的内容，或点「复制全部」把「标题：内容」整段拿走。
- **中文金额也能当输入**：把「壹拾贰圆叁角肆分」「一百二十三」「0x1F」粘进来，会先读回数值再转出各种写法。
- **示例按钮**：左边「试试这些」点一下直接填进输入框，省得自己敲。

## 中文金额的两条规则（重要）

财务大写有两个细节各地写法不同，这里做成开关（默认都开）：

| 开关 | 关掉 | 打开 |
| --- | --- | --- |
| 元后角为零、分有值时补「零」 | 壹仟陆佰捌拾圆伍分 | 壹仟陆佰捌拾**零**伍分 |
| 角有值、分为零时写「整」 | 壹拾贰圆叁角 | 壹拾贰圆叁角**整** |

其它固定规则：

- 金额**四舍五入到分**（`12.345` → 壹拾贰圆叁角伍分）。
- 不足一元时**不写「零圆」**：`0.5` → 伍角整、`0.05` → 伍分；`0` → 零圆整。
- 大写保留财务写法「壹拾贰圆」，小写按口语「十二圆」。
- 货币单位可切 **圆 / 元**（支票、财务多写「圆」，合同、发票也常见「元」）。

## 英文念法的三条规则

| 开关 | 关掉 | 打开 |
| --- | --- | --- |
| 英式：百位后加 `and` | one hundred twenty-three | one hundred **and** twenty-three |
| 开头的 1 念 `a` | one thousand | **a** thousand（只对带量级的档：a thousand / a million；单独的 100 仍念 one hundred） |
| 十位与个位之间加连字符 | twenty three | twenty**-**three |

- 最多到 `decillion`（10³³，36 位），再大这一行会给空白并提示。
- 小数部分逐位念（`3.14` → three point one four），序数词只把最后一个词变序。
- 还提供了**年份读法**给代码调用：`1998` → nineteen ninety-eight、`2005` → two thousand and five、
  `1905` → nineteen oh-five、`2024` → twenty twenty-four（界面暂未铺成结果行）。

## 中文数字的位数上限

按「万 / 亿」循环叠用（万 10⁴、亿 10⁸、万亿 10¹²、亿亿 10¹⁶、万亿亿 10²⁰、亿亿亿 10²⁴），
**最多 24 位整数**。再大中文没有日常单位了，这一行会给空白并提示超出范围。

> 刻意不用「兆 / 京」：大陆口语里「兆」常被当成 10⁶（兆瓦、兆像素），写在金额上会读错。

## 怎么用

1. 在「要转换的数字」里输入（阿拉伯数字或中文金额都行）。
2. 需要的话改「写法口味」（金额单位、补零 / 整、英文 and / a / 连字符）——改完立即重算。
3. 点右边任意一行复制它，或「复制全部」拿走整段。

## 设置项

改一下就自动存进 `Config\number-converter\config.json`，没有保存按钮。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 输入 | `1234.56` | 上次输入的内容，下次打开还在 |
| 金额单位 | 圆 | 圆 / 元 |
| 元后补零 | 开 | 见上面「中文金额的两条规则」 |
| 角后写整 | 开 | 同上 |
| 英式 and | 开 | 关掉是美式 |
| 开头念 a | 开 | 只影响带量级的档 |
| 连字符 | 开 | twenty-three / twenty three |
| 进制 | 16 | 输入没写 `0x` / `0b` / `0o` 前缀时按它解析 |

## 文件放在哪

- 配置：`Config\number-converter\config.json`（相对 **exe 所在目录**，不是仓库根目录）。
- 数据：本工具不写 `Data\`、不写 `Cache\`；「重建配置」会把上面这些选项恢复默认。
- 区块大小：和别的工具页一样存在 `Config\layout.json`（键名前缀 `number-converter.`）。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 「罗马数字」那行是空的 | 只有 1 ~ 3999 的整数能写罗马数字（小数、负数、0 都不行） |
| 「进制」那行是空的 | 只有非负整数能转进制 |
| 中文 / 英文那几行空着 | 位数超出范围（中文 24 位、英文 36 位），界面上会有提示 |
| 输入「一二三」结果和想的不一样 | 「一二三」会被当作中文数字读成 123；要逐位念请先填阿拉伯数字（结果里的「英文逐位读 / 中文逐位」按原样念） |
| 金额比输入多了 1 分 | 金额按财务规则四舍五入到分（`12.345` → 壹拾贰圆叁角伍分） |
| 输入 0x1F 提示看不到 | 十六进制按前缀识别，会自动换成十进制再转换其它写法 |

中文与金额文本反向解析（大小写混用、阿拉伯数字混用、1000 个随机整数正反向往返）、
英文基数词（`a thousand` / 英式 and / 连字符 / 百万级）、美式口味、负数 / 小数 / 逐位、序数词（含 `twenty-third`）、
年份读法、英文金额与支票、罗马数字双向（含非规范写法被拒）、千分位 / 4 位分组 / 科学计数法（含 e 写法）/
二·八·十六·三十六进制双向、整条转换流水线（含中文金额与 `0x1F` 当输入、超大数提示、空行过滤）、
配置默认值与夹取、配置 JSON 往返。**不创建窗口、不碰剪贴板、不写真实 Config。**
