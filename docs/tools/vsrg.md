# 🎹 VSRG

> 竖直下落式音游：把 osu!mania 谱面集的 `.osz` 拖进窗口就能导入（**只认 `Mode: 3`**），
> 自动整理成 `Mapset` 谱面集；**1K ~ 10K** 都能玩，可改键位 / 判定档 / 面条尾判宽度 / 滚动速度 / 音频偏移，
> 支持**全屏游玩**与**暂停退出**。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> 在主页的 **🎮 游戏** 类别里点进 VSRG（面包屑：`🏠 主页 › 🎮 游戏 › 🎹 VSRG`）。

## 能做什么

- **读 osu!mania 谱面**：`.osu` 里 `[General]` 的 `Mode` 必须是 `3`（不是就整张拒掉），
  键数取 `[Difficulty] CircleSize`，支持 **1K / 2K / 3K / 4K / 5K / 6K / 7K / 8K / 9K / 10K**。
- **拖 `.osz` 导入**：`.osz` 就是 zip，解出谱面 / 音频 / 背景图，跳过视频与 hitsound（省空间），
  每张 mapset 一个文件夹。
- **四个界面**：选歌 →（开始）游玩 → 结算；另有设置页。全屏、暂停、退出都在这一套里。
- **判定可以自己调**：档位数量、每档的名字 / 窗口 / 准确率权重都能改，档位顺序能排，能加自定义档；
  Standard 预设四档删不掉。面条尾判可以单独开关并给一个宽度乘数。

## 谱面放在哪（Mapset 结构）

```
<exe 所在目录>\Data\vsrg\Mapset\
  └── 艺术家 - 标题\                  ← 一张 mapset 一个文件夹（重名自动加 (2)、(3)…）
       ├── audio.ogg / song.mp3       ← 音频（谱面 [General] AudioFilename 指向的那个文件，保留原名）
       ├── bg.jpg                     ← 背景图（[Events] 里声明的；没声明就取文件夹里第一张图）
       ├── Artist - Title (4K).osu    ← 各难度谱面，一张一个文件
       ├── Artist - Title (7K).osu
       └── mapset.json                ← 程序读的索引（难度清单 / 键数 / note 数 / 导入时间）
```

- `mapset.json` 是缓存：删掉也能用（下次打开会按文件夹里的 `.osu` 现场重建，只是慢一点）。
- 想手工往 `Mapset` 里放谱面也行：文件夹里只要有能读的 mania `.osu`，打开列表就能看见。
- 配置在 `<exe 所在目录>\Config\vsrg\config.json`（改一下最多 400ms 自动落盘，没有保存按钮）。
- 区块大小按项目惯例存在 `Config\layout.json`（键名前缀 `vsrg.`）。

## 导入 .osz

1. 把 `.osz` **直接拖进窗口**（可以一次拖多个），或者点右上角**「导入 .osz」**选文件。
2. 导入时逐张判定 `.osu`：
   - `Mode` 不是 3 → 这一张跳过（会在结果里说明）；
   - 键数不在 1~10 → 这一张跳过；
   - **一张能玩的都没有 → 整包拒绝**，不会在 `Mapset` 里留下半个空文件夹。
3. 导入结果会写成一行状态：「已导入「艺术家 - 标题」：3 个难度，跳过 1 张不支持的谱面（另有 5 个文件不是谱面 / 音频 / 图片，已忽略）。」

> 压缩包里的可疑路径（`../`、绝对路径、盘符、隐藏名）**整条丢弃**，不会解到 `Mapset` 外面，也不会改个名字收进来。
> 视频（`.mp4` / `.avi` 等）和 `hitsound/` 里的采样不导入（osu! 的 .osz 里常有几十 MB 视频）。

## 选歌页

- 左栏：全部谱面集（艺术家 - 标题 / 难度数 / 键数范围）。
- 右栏：封面（谱面集背景图）+ 元数据 + 难度列表 + **「▶ 开始游玩」**。
- 左栏与右栏之间有一条**可拖的分隔条**（双击恢复默认；全部恢复默认在 **主页设置 → 界面布局**）。
- 底部按钮：**定位这首歌**（在资源管理器里选中文件夹）、**删除这首歌**（只删这一个文件夹，会二次确认）。
- 右上：**导入 .osz**、**设置**；列表上方：**刷新**、**打开文件夹**（打开 `Mapset` 根目录）。

## 游玩

- 开始游玩前若设置了**全屏**：点「开始游玩」立刻进全屏 → 进游玩界面；**打完 / 中途退出会先退出全屏再进结算**。
- 屏幕上：顶部信息栏（曲名 / 准确率 / Combo / 进度 / 暂停 / 退出），下面是自绘的轨道 + 判定线 + 下落 note。
- **暂停**：`Esc` 或 `P`（也可以点右上「暂停」）。暂停遮罩上有**继续**和**退出到选歌**。
- **退出当前歌曲**：右上「退出」或暂停遮罩里的「退出到选歌」→ 直接回选歌页（不进结算）。
- 切到别的工具页 / 切走程序窗口会自动暂停（后者可在设置里关），回来点「继续」接着玩。

### 判定线下面的按键字母

判定线下方会画当前这份谱面每条轨对应的键（例如 4K 默认是 `A S D F`），方便第一次玩时对位置。

## 设置

### 游玩

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 开始游玩时进入全屏 | 关 | 开 = 点开始立刻全屏进游玩，结束时自动退出全屏并进结算 |
| 切走窗口时自动暂停 | 开 | 关掉后切走程序窗口也继续（不建议） |
| 音频偏移 | 0 ms | −500 ~ 500。音乐听起来**偏晚**就填正数（判定时间整体往后挪） |
| 滚动速度 | ×7.0 | 1.0 ~ 20.0。note 从屏幕顶落到判定线的时间 = `900 / 速度` 毫秒（×7 → 约 129ms） |
| 音量 | 0.85 | 0 ~ 1 |

### 键位（1K ~ 10K）

- 1~10 轨**各自的按键**都能改：点一下那一轨的方框 → 按一个键 → 立刻绑定（`Esc` 取消）。
- 默认：`A S D F G H J K L ;`（第 10 轨是分号）。
- 只认**单键**：修饰键（Shift / Ctrl / Alt / Win）、`Tab`、`Esc` 不能绑（`Esc` 留给暂停与取消捕获）。
- 同一个键绑到两轨会**标红提示**（游玩时先出现的那一轨生效）。
- 「恢复默认键位」一键回到上面那套。

### 判定档

判定档是**有序列表，从严格到宽松**。按下键时，在本轨找最早一个还没判过的 note，
按顺序取**第一个**窗口够得着的档；所有窗口都够不着就是 Miss。

- **Standard 预设四档**：

  | 档位 | 窗口 | 准确率权重 |
  | --- | --- | --- |
  | Marvelous | ±22 ms | 100% |
  | Good | ±50 ms | 65% |
  | Bad | ±90 ms | 30% |
  | Miss | 兜底（超过最宽窗口 / 没按） | 0% |

- 数值都能改（名字 / 窗口 / 权重），也能用 **↑ ↓** 调顺序 —— 调完立刻生效。
- **四档预设删不掉**（删除按钮是灰的）；点「加一档」可以自己加档，自定义档能删能改。
- **Miss 永远是兜底**：它不参与「按顺序匹配」，也永远排在最后（往上挪不了）。
- 「恢复 Standard」把整套判定档恢复成上面那四档。
- 判定档配置不合法（没有 Miss 档、权重超 100 之类）时页面上会标红，**开始游玩会拦住**并跳到设置页。

### 面条（长条）尾判

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 面条尾部判定 | 开 | 关掉后面条**只判头**，尾不参与判定、也不进准确率分母 |
| 尾部宽度乘数 | 1.5 | 尾判窗口 = 该档窗口 × 这个乘数（0.1 ~ 10） |

- 开着时，一条面条算**两个判定单元**（头 + 尾），两个都进准确率分母。
- **头部没打上**：尾判一起算 Miss（没按下去谈不上保持）。
- **松手指的时刻**决定尾判：`|松开时刻 − 尾巴时刻|` ≤ 该档窗口 × 乘数 → 命中该档；
  早于「尾巴 − 最宽档窗口 × 乘数」松 → 尾判 Miss；
  一直按到「尾巴 + 最宽档窗口 × 乘数」之后 → 尾判**最严档**（和 osu! 一样「按到底算满」）。
- 例：普通 note 的 Marvelous 窗口是 22ms，乘数 1.5 → 面条尾巴的 Marvelous 窗口是 33ms；
  Good 50ms → 75ms。

## 准确率

```
准确率 = Σ(每次判定命中档的权重) / (已判定的单元数 × 最高权重) × 100%
```

- 分母用**已判定单元数**，所以中途退出也能显示一个诚实的数；还没判定任何单元时显示 100%（和 osu! 一致）。
- 例：一个 Marvelous（100）+ 一个 Good（65）→ (100 + 65) / (2 × 100) = 82.5%。

## 结算

- 显示：**准确率 / 最大 Combo / 各判定档次数** + 曲名与难度。
- 只有**真的打完整首**（全部音符判完 + 时间过完）才进结算；中途退出回选歌页、不记成绩。
- **不做评级**，也**不记录历史最佳成绩**（按需求）。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 拖 .osz 没反应 | 只认 `.osz`；拖文件时鼠标要是「复制」光标。文件夹不会被导入的，请压成 .osz 或直接放进 `Mapset` |
| 导入报「没有可以玩的 osu!mania 谱面」 | 这个包里没有 `Mode: 3` 的谱面（标准 / 接谱 / 太鼓都不收），或者键数不在 1~10 |
| 导入后某张难度没出现 | 那张 .osu 不是 mania 或者键数超范围 —— 导入结果那行会写「跳过 N 张」 |
| 列表里一首歌都没有 | 点「刷新」；或者看 `打开文件夹` 里有没有东西（`Data\vsrg\Mapset`）。手工放进去的文件夹只要有 mania .osu 也能识别 |
| 提示「这首歌缺音频文件」 | 谱面 `[General] AudioFilename` 指向的文件不在这个文件夹里（有些人会把 .osz 解压后删音频）→ 开始游玩被拦住 |
| 按了键没出判定 | ① 设置里看这一轨绑的是哪个键（判定线下方也会画）；② 键盘焦点在工具页上（点一下游玩区域） |
| 音乐和 note 对不上 | 调**音频偏移**（音乐偏晚就填正数）。这个值只影响判定时间，不会改音频本身 |
| 全屏后想退出 | `Esc` / `P` 暂停，点「退出到选歌」；打完也会自动退全屏 |
| 判定太严 / 太松 | 设置页改判定档的窗口与权重，或者调顺序（把宽松档排前面）；面条尾巴太难受就提高尾部乘数 |
| 改了判定档但这一局没变 | 正常：**一局开始时拍一份判定快照**，游玩途中改设置不影响本局，下一局生效 |
