# 🎹 KPS 按键统计（音游键 viewer）

> 实时 **KPS（每秒按键数）**、每键累计计数器、按键可视化，外加一个**透明置顶 Overlay** ——
> 打 DJMAX / osu!mania / 其它音游时把键位和 KPS 叠在游戏画面上，也可以只当本地按键统计工具。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md) ｜ [DmNote 来源](#来源与致谢)

> **界面布局**：区块之间可以拖动调整大小（缝隙亮起蓝线 + ↔ / ↕ 光标），拖完自动记住；
> 双击某条缝只恢复这一处；全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。

## 能做什么

- **KPS 统计**：当前 KPS、峰值 KPS、平均 KPS、总按键数、统计时长，以及最近 10~120 秒的 KPS 折线图。
- **键位显示**：按行排列的键位格子，按下时切换背景 / 文字颜色，可加缩放、发光、闪光效果；
  每个键可单独设置文字、宽度倍数、按下颜色、按键图片。
- **每键计数器**：每个键下方显示累计按下次数（可关）；计数可以存进配置，重启程序后继续累计。
- **预设**：内置 4K / 5K / 6K / 8K / 方向键，外加 2 套带侧键的简化版（4K+侧键 / 8K+侧键，共 7 套）；
  每套预设的布局改动分别记住；也可以把当前布局「另存为」自己的预设。
- **Overlay**：透明、无边框、始终置顶、默认点击穿透（锁定）；解锁后可以鼠标拖动、滚轮缩放，位置会自动记住。
- **音符效果**：按住键时格子里有一道音符反复滑过（速度 / 高度 / 颜色 / 透明度 / 反向可调）。
- **键音**：按键时播放声音；不选文件时用内置合成点击声，也可以选自己的 WAV。
- **全局热键**：显示 / 隐藏 Overlay、锁定 / 解锁、重置统计、暂停监听，都能绑定热键（游戏里也生效）。

## 快速上手

1. 主页 →「音游工具」类别 → 打开 **KPS 按键统计**；工具打开时会自动开始监听（状态条显示「监听中 · Raw Input」）。
2. 点右上角 **显示 / 隐藏 Overlay**（或按 `Ctrl+Shift+O`），Overlay 会出现在桌面右下角。
3. 把 Overlay 拖到游戏画面上（先按 `Ctrl+Shift+L` 解锁，拖好后再按一次锁上；锁上后鼠标点击会穿透，不挡游戏）。
4. 回到工具页，在「键位预览」里点一个键 → 「改键…」→ 按下你游戏里对应的物理键；按同样方式配好整排。
5. 打歌时看 Overlay 上的 KPS / 每键计数即可。停止使用时在工具页暂停监听，或关掉 Overlay。

> 第一次打开工具时只显示工具页，Overlay 默认关闭（和 DmNote 一致）；之后会记住上次 Overlay 是否显示。

## KPS / 统计口径

和 DmNote 的口径一致（DmNote 的 `keyStatsService`）：

| 指标 | 口径 |
| --- | --- |
| 当前 KPS | 最近 **1000ms** 内「物理按下」的次数（1 秒滑动窗口，整数） |
| 峰值 KPS | 每 **50ms** 采样一次当前 KPS，取历史最大值 |
| 平均 KPS | **只对「当前 KPS > 0」的采样点**取算术平均并四舍五入（空闲时间不会稀释平均值） |
| 总按键数 | 当前布局里所有键的累计按下次数（含存进配置的历史值） |
| 折线图 | 每 **100ms** 采一个点；纵轴自动取「历史最大值 / 峰值 / 当前值」中的最大值，不写死上限 |
| 只统计绑定的键 | 勾选后，没在布局里出现的物理键不计入 KPS / 总按键（默认关：任何键都算） |

- 长按不会重复计数：输入层只在「真正按下」时计一次，按住不放不会刷 KPS。
- 关掉页面且 Overlay 也关掉时，本次会话的按键数会并入配置里的每键计数器并清零会话统计（重新开始统计）。
- 「重置统计」会同时清零会话统计和配置里的每键累计计数器。

## 键位 / 预设

- **选键**：在「键位预览」里点一个按键，右侧「选中按键」面板显示它的信息。
- **改键**：点「改键…」后按下物理键；`Esc` 取消。改键时这次按键不会计入统计。
- **显示文字**：留空 = 自动显示键名；也可以写 `SPACE`、`A` 之类的自定义文字。
- **宽度倍数**：1~4 倍宽（空格键 / 长条键很好用）。
- **按下颜色**：留空 = 用全局按下颜色；也可以填 `#AARRGGBB` 单独指定。
- **按键图片**：支持 PNG / JPG / BMP / GIF；图片会复制到 `Data\kps\keys\` 下，原文件删了也不影响。
- **启用 / 禁用**：禁用后该键不在布局里占位，但配置保留，随时能再启用。
- **加行 / 加键 / 删键 / 删行**：「键位预览」下方的按钮；选中键后还可以左移 / 右移、上移行 / 下移行。
- **切换预设**：右上角「预设」下拉框。每套预设的布局改动会分别记住；「恢复该预设默认布局」恢复内置键位；
  「另存为预设」把当前布局存成自定义预设，自定义预设可以删除。

> 说明：DmNote 的键位是自由画布（每个键可拖到任意位置、任意大小），本工具为了贴合 YuLiangToolkit
> 的实现方式是**按行排列**的简化布局；功能上覆盖「多套键位、改键、单键样式、计数器」这些核心需求。

## 外观 / 效果 / 音符效果 / 键音

- **按键外观**：**正方形按键开关**（默认开：键宽 = 键高；关掉后可以分别调键宽 / 键高做长条键、宽键）、间距、圆角、字号、计数字号，
  空闲背景 / 按下背景 / 边框 / 文字 / 按下文字 / 计数器颜色，以及每键计数器的总开关。
- **按下效果**：按下缩放、发光、闪光、动画时长（40~300ms）。
- **音符效果**：按住键时格子里有一道音符反复滑过 —— 颜色、透明度、滑过时间（150~2000ms）、
  音符高度（占格子高度的比例）、反向（从下往上）可调。它是 DmNote「下落音符」的简化版（不画在格子外）。
- **键音**：启用后每次按下播放一次；可选内置合成点击声或自己的 **WAV** 文件（只支持 WAV：项目不引第三方音频库）。
  音量 0~100 控制内置音；自定义 WAV 的音量由系统音量决定。

## Overlay

- **显示 / 隐藏**：工具页按钮，或全局热键 `Ctrl+Shift+O`。
- **锁定（点击穿透）**：默认锁定。锁定时鼠标事件会穿透到下面的游戏窗口，Overlay 不可被点到 / 拖动。
  按 `Ctrl+Shift+L` 解锁后可以直接拖动，也可以用鼠标滚轮缩放（`0.4× ~ 3×`，按「缩放基准」固定某个角 / 中心）。
  位置与缩放会自动保存，下次打开还原。
- **显示内容**：当前 KPS、键位格子、总按键数、峰值 KPS、平均 KPS、KPS 折线图、每键计数器，逐项开关。
- **外观**：缩放、不透明度、背景色（默认全透明，可填 `#AARRGGBB` 半透明底板）、始终置顶、缩放基准点。
- **多显示器 / DPI**：位置按逻辑坐标（DIP）保存；换了显示器 / 分辨率导致位置越界时会被拉回可见区域。
- **独占全屏游戏的限制**：任何「始终置顶」窗口都盖不住独占全屏（Exclusive Fullscreen）——请把游戏改成
  **无边框窗口 / 窗口化**。这是 Windows 行为，不是本工具的 bug。
- **没有 OBS 模式**：按需求「直播插件相关」部分不做，所以没有 OBS 浏览器源 / OBS 模式。

## 全局热键

| 功能 | 默认热键 | 说明 |
| --- | --- | --- |
| 显示 / 隐藏 Overlay | `Ctrl+Shift+O` | 和 DmNote 默认一致；游戏里也生效 |
| 锁定 / 解锁 Overlay | `Ctrl+Shift+L` | 解锁后可拖动 / 滚轮缩放 |
| 重置统计 | `Ctrl+Shift+R` | 同时清零会话统计与每键累计计数 |
| 暂停 / 继续监听 | `Ctrl+Shift+P` | 暂停后所有键不计数 |

所有热键都可以在工具页「全局热键」里点「设置…」重新捕获（至少带一个 Ctrl / Alt / Shift / Win 修饰键，
`Esc` 取消），点「清除」变成不注册。注册失败（被别的软件占用等）会在状态条里写明原因。

## 数据与配置

| 内容 | 位置 |
| --- | --- |
| 配置（所有选项 + 每键累计计数器） | `Config\kps\config.json`（改一下自动保存，没有保存按钮） |
| 按键图片 | `Data\kps\keys\`（选图片时自动复制进来） |
| 按键计数器 | 存进配置；切走页面 / 关 Overlay / 退出程序时把本次会话并入配置 |

> 运行时目录在 **exe 旁边**（`bin\Debug\net9.0-windows10.0.19041.0\` 或发布目录）。整个程序目录拷走即可迁移；
> 反过来 `dotnet clean`、手删 `bin` / `dist` 会连数据一起删掉。

## 实现说明（开发者）

- 全局输入：`src/YuLiangToolkit.Tools.Kps/Services/RawInputKeyboard.cs` —— Windows **Raw Input**
  （`RIDEV_INPUTSINK`，后台也能收键；同进程不加 `RIDEV_NOLEGACY`，避免影响 WPF 文本框），
  失败时退回 `WH_KEYBOARD_LL` 低级键盘钩子；长按自动重复在按下集合里兜底去重。
- 统计引擎：`Statistics/KpsStatistics.cs`（纯逻辑、时钟可注入，自检用假时钟验证口径）。
- 后台会话：`KpsSession.cs`（输入 → 统计 → Overlay / 热键 / 键音；页面切走后 Overlay 可继续运行）。
- 界面：`Views/KpsView.xaml`（设置页）、`Views/Controls/KeyGridView.xaml`（键位网格）、
  `Views/Controls/KpsGraphView.cs`（KPS 折线图）、`Views/OverlayWindow.xaml`（透明 Overlay）。
- 自检：`tests/YuLiangToolkit.FrameworkSelfCheck/` 的 **kps** 组：
  `dotnet run --project tests\YuLiangToolkit.FrameworkSelfCheck\YuLiangToolkit.FrameworkSelfCheck.csproj -- kps`
