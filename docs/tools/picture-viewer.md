# 🖼️ 图片连续阅读器

> 普通看图器一屏一张，看条漫 / 长图 / 漫画得一张张点。这个工具把**一个文件夹里的图片按页码首尾相接拼成一条长带**
> （无缝、无间距），滚轮沿着阅读方向一路滚过去，就能连着看；也可以切成**双页 / 单页翻页**，像翻漫画书一样一页页翻。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> **界面布局可拖拽**（v0.41.0 起；v0.42.0 补全）：两个浮层区块各有**自己独立的一条缝**，宽度各记各的 ——
> 打开「⚙ 设置」时，它左边缘那条缝可以左右拖（亮起蓝线 + **↔**）：把设置面板拖窄 / 拖宽（面板浮在图片上方，不挤压阅读区）；
> 打开「🕘 最近」时，它左边也有一条同样的缝，可以单独调最近浏览面板的宽度（两个面板互斥，不会同时出现）。
> 拖完自动记住（`Config\layout.json`），**双击**某条缝只恢复这一处；全部恢复默认在 **主页设置 → 界面布局**。
> 面板关着时对应的那条缝也一起收起来（不占位置、不挡图片）。

## 能做什么

- **连续滚动：一条长带，无缝衔接**：文件夹里的图按顺序首尾相接，中间**没有间距、没有分页**，像看一张超长的图（三种连续方向共用这条带）。
- **六种阅读方式**：**连续滚动**三种方向 —— 纵向 上 → 下（默认，条漫 / 长图）、横向 左 → 右（中式漫画，第一张最左）、
  横向 右 → 左（日式漫画，第一张最右）；**翻页**三种 —— 双页 左 → 右、双页 右 → 左（日式镜像）、单页浏览（一次一张）。
  **切换统一在设置面板的「阅读方式」下拉里**（顶部工具条那个按钮只显示当前方式，点它会打开设置面板）。
- **双页翻页**：中间并排两页（右边是下一张），翻页时整页滑动、右边的图移到左边、新的从右边进来；
  **一次只翻一张**，所以相邻两屏会重叠一张，最后一屏不足两页时另一侧留空。
- **翻页动画**：默认开、约 0.2 秒的滑动动画；关掉就是直接换图（动画只在 100% 且没平移时播放，放大 / 平移时直接切换）。
- **滚轮连续浏览**：连续模式下滚一格就走一格；横向模式下滚轮直接左右滚，**不用按 Shift**。
  翻页模式下滚轮默认**翻页**，也可以在设置里改成**缩放**。
- **拖着看**：左键按住拖动画面；中键锚点可以「甩」起来，移动鼠标就快速滚动（**仅连续滚动模式**，见下面「操作与快捷键」）。
- **缩放 25% ~ 800%**：顶部工具条的百分比输入框直接改数字（默认 100%），或点放大镜 `−` / `+` 一步 10%；
  连续模式缩放作用于整条长带，翻页 / 单页模式作用于当前屏。
- **放大后自由拖拽**：放大到超出视口后，左键按住可以**上下左右随便拖**，不再只沿阅读方向。
- **拖动惯性**：默认**开**；甩一下松手画面会按甩动速度继续滑一段再慢慢停（两个轴都有），速度太慢或到边界自动停。设置里可以关掉，关掉就是松手即停。
- **滚轮惯性**：默认**开**；连续滚动模式下滚一格滚轮后，会按「滚轮步长 × 系数」再沿同一方向**继续滑一段**再减速停下 ——
  一格默认 120px 时大约再滑 **480px（约 4 格）**，滚一下就能滚很远。它和上面的**拖动惯性是两个独立设置**，可以只开一个；
  「惯性越滑越快」只影响拖动惯性。设置面板「拖动惯性」下面就是「滚轮惯性（滚一格继续滑一段）」勾选框，改一下自动保存。
- **惯性越滑越快**：默认**开**（手机漫画 App 的手感）；在画面还在滑的时候再甩一下，速度会**叠加**上去而不是清零，连续甩可以一直加速。有速度上限，不会失控。设置里可以关掉，关掉后每次松手只用这一次甩动的速度。**只影响拖动惯性**，不影响滚轮惯性。
- **省内存**：连续模式下滚出视野的图片会自动释放（默认开）；翻页 / 单页模式也只在用到时才解码，看大图集不会越看越吃内存。
- **双击图片直接打开（文件关联）**：在设置里勾选「文件关联」后，双击 `.jpg` / `.png` 等图片会直接进本工具，自动加载这张图所在的整个文件夹，并**定位到刚才双击的那一张**：连续模式滚到它的位置，翻页 / 单页模式直接翻到那一页。
- **单实例唤醒**：程序已经开着时再双击图片，不会再开第二个窗口，而是把已有窗口叫到前面、在同一个窗口里打开新图片和它所在的文件夹（最小化 / 托盘状态也能恢复）。
- **🕘 最近浏览（上限可调）**：工具条「🕘 最近」打开右上角的最近浏览浮层，列出最近打开过的**图片文件夹**
  （新的在上，同一路径只留一条）；点一条直接重新加载该文件夹；列表顶部「**清空**」只删记录、**不会删本地文件**；
  按 `Esc` 或 ✕ 关闭，打开成功后浮层也会自动收起。面板右下角提示上限在哪调；设置面板「最近浏览」里能把上限调到
  **0 ~ 100**（默认 **50**；**0 = 不记录并清空列表**），改一下自动保存；
  打开成功的文件夹（包括双击图片时所在的文件夹）会自动记一条。
- **点路径开目录**：工具条第二行显示当前文件夹路径，**点一下就在资源管理器里打开它**（悬停会变强调色、鼠标变手型），方便直接去文件夹里改文件名 / 加图。
- **全屏沉浸阅读（F11）**：工具条最右边的「全屏」按钮或 `F11` 进入全屏，`Esc` 退出。全屏会藏掉标题栏 / 侧边栏 / 面包屑 / 状态栏，
  把窗口铺满整块屏幕（**任务栏也临时藏起来**），退出后原样还原；**当前阅读方式不变**，只是阅读区变大，
  并尽量保持当前阅读位置（连续滚动保持画面中心、翻页保持当前屏）。
  全屏时工具条变成浮在阅读区顶部的**半透明圆角卡片**：鼠标一动就出现，停 **2.5 秒**自动缩回、鼠标指针也一起隐藏；
  鼠标移到顶部（或任意移动）让工具条出现后，就能调阅读方式 / 缩放 / 设置 / 退出全屏；滚轮 / 拖动 / 翻页照常可用。
  底部页码和进度条照常显示；设置面板打开时工具条不会自动收。切走工具会自动退出全屏。
- **图片边框（默认开）**：每张图外面可以套一圈「内边框 → 填充 → 外边框」三层边框，用来隔开相邻两张图。三层的粗细都能调（内 / 外 0~32、填充 0~128 像素，0 = 不画），三种颜色都按 **RGBA 0~255**（含透明度）独立调，还配了调色板；连续 / 双页 / 单页模式都生效。

## 六种阅读方式

| 阅读方式 | 分类 | 适合 | 说明 |
| --- | --- | --- | --- |
| 纵向 上 → 下（默认） | 连续滚动 | 条漫 / 长图 | 第一张在最上面；往后读 = 内容往下走 |
| 横向 左 → 右 | 连续滚动 | 中式漫画 | 第一张在最左边；往后读 = 内容往右走 |
| 横向 右 → 左 | 连续滚动 | 日式漫画 | **第一张排在最右边**；往后读 = 内容往左走 |
| 双页 左 → 右 | 翻页 | 普通页漫 | 中间**并排两页**，右边是下一张；翻页时整页往左滑，右边的图移到左边、新的从右边进来 |
| 双页 右 → 左 | 翻页 | 日式漫画 | 日式镜像：**左边是下一张**；翻页时整页往右滑 |
| 单页浏览 | 翻页 | 单张细看 / 大图 | **一次一张**，按阅读顺序前后翻 |

> 换方式：点**顶部工具条**上显示当前方式的那个按钮（例如「双页 左 → 右」）会打开设置面板，
> 在「阅读方式」下拉里选一个即可。**切换只在设置面板里做** —— 工具条只显示当前方式，
> 这样以后加更多方式也不用挤工具条。选中后立刻生效，并尽量保持阅读位置
> （连续 → 翻页按阅读比例换算页号，翻页 → 连续按页号换算比例）。

**翻页模式补充：**

- **双页一次只翻一张**：相邻两屏会**重叠一张**（「右边的图放到左边」的动效就是这么来的）；最后一屏不足两页时另一侧留空。
- 翻页 / 单页都按阅读顺序前后翻，底部显示页码，例如「第 3–4 张 / 共 20 张」。
- 翻页动画默认开（约 0.2 秒）；**只在 100% 且未平移时播放**，放大 / 平移状态翻页直接切换。

## 怎么用

1. 按 `Ctrl+O` 选一个图片文件夹。**只读这一层**，不进子文件夹。
2. 想快速回到以前看过的文件夹：点工具条「**🕘 最近**」打开最近浏览，点一条直接重新加载；
   列表顶部「**清空**」只删记录、**不会删本地文件**。
3. 图片按文件名顺序排好、首尾相接 —— 命名成 `001.jpg`、`002.jpg` 这样最省事
   （`2` 会排在 `10` 前面；纯数字文件名的图集也按数字顺序）。
4. 默认是纵向连续滚动：滚轮沿阅读方向连续往后看，**滚一下会顺着滚轮惯性再滑一段**（想一格一停就在设置里关掉「滚轮惯性」）；嫌慢就按住左键拖，或者用中键锚点甩起来。
5. **想换阅读方式**：点顶部工具条上显示当前方式的那个按钮 → 在设置面板的「阅读方式」下拉里选一个（立刻生效）。
   想一页页翻就选**双页 左 → 右** / **双页 右 → 左** / **单页浏览**，然后用左右箭头按钮、`←` / `→`、`PageUp` / `PageDown` 或**空格**翻页。
6. 图太小 / 字看不清：改**顶部工具条**的**百分比输入框**（回车或失焦生效），或点放大镜 `−` / `+`（一步 10%）。
   放大后左键可以上下左右自由拖；`Ctrl+滚轮` 以视口中心缩放，`Shift+滚轮` 往另一轴平移。
7. 看日漫发现方向反了：在设置里换成**横向 右 → 左**（连续滚动）或**双页 右 → 左**（翻页）——
   日式模式下左右翻页键 / 按钮的语义会跟着互换。
8. 设置项都在同一个面板里，**改一下就自动保存，没有「保存」按钮**；按 `Esc` 关面板。
   「拖动惯性」和「滚轮惯性」是**两个独立勾选框**，可以只开一个。
9. 想让双击图片直接进本工具：在设置面板最下面勾选「文件关联」（见下一节）。
10. 想调整图片之间的分界：设置面板「图片边框」里分别改内边框 / 填充 / 外边框的 RGBA 颜色和粗细（或点调色板）；调乱了随时点最下面的「恢复默认设置」。
11. 想让它少记 / 不记最近浏览：设置面板「**最近浏览**」拖滑块（**0 ~ 100**，默认 **50**；**0 = 不记录并清空**；调小会立刻裁掉多余的老记录）。
12. 想每次双击图片都新开一个窗口：设置面板「窗口 / 多开」里取消「单实例模式」（默认是开着的，改完下次启动生效）。
13. 想直接去图片所在文件夹改文件名 / 加图：点工具条第二行的**文件夹路径**，会在资源管理器里打开它。
14. 想沉浸着看：按 `F11`（或点工具条最右边的**全屏**按钮）进入全屏，`Esc` 退出；全屏时鼠标一动工具条才浮出来，停 2.5 秒自动缩回。

## 图片边框（默认开）

设置面板里的「图片边框」用来把相邻两张图隔开，从内到外分三层：

| 层 | 作用 | 粗细范围（像素） | 说明 |
| --- | --- | --- | --- |
| 内边框 | 紧贴图片的描边 | 0 ~ 32 | 给图加一圈轮廓，0 = 不画 |
| 填充 | 内、外边框之间的底色带 | 0 ~ 128 | 真正“隔开两张图”的那条带 |
| 外边框 | 最外层的描边 | 0 ~ 32 | 和相邻图片的填充接在一起，形成分界 |

- **颜色**：每层都能独立调 **R / G / B / A 四个通道（0~255，A = 透明度）**，填完立刻生效；
  旁边有预览色块和 12 个颜色的**调色板**（含透明色），点一下就套用。
- **默认样式**：1px 深色内边框 + 6px 灰带填充 + 1px 亮灰外边框；深色背景下能看出分界又不会抢图。
  不想要边框就把「显示图片边框」关掉。
- **布局**：100% 缩放时「图片 + 边框」刚好铺满一屏；缩放后边框不跟着放大（固定像素粗细）；
  双页模式两页会先让出边框再贴中间接缝。
- **恢复默认**：设置面板最下面有「恢复默认设置」按钮，点了会回到默认状态（阅读方式 = 纵向 上→下、缩放 100%、
  边框颜色 / 粗细 / 拖动惯性 / 滚轮惯性 / 滚轮等全部回默认）；文件关联不受影响。注意「上次打开的文件夹」也会清空。

## 双击图片打开（文件关联）

设置面板最下面有「文件关联」：

- 勾选后会把 **`.jpg` `.jpeg` `.png` `.bmp` `.gif` `.webp` `.tif` `.tiff`** 登记到本工具（只写当前用户注册表，**不需要管理员**）。
  之后双击图片、或在右键「打开方式」里选「图片连续阅读器」，就会直接打开这张图并加载它所在文件夹。
- **Windows 10 / 11 的提醒**：系统对「默认应用」有保护（`UserChoice`），程序不能硬改。如果双击后打开的还是
  照片 / WPS 之类的看图程序，点设置面板里的「**打开 Windows 默认应用设置**」按钮，把图片格式的默认程序选成
  「图片连续阅读器」一次即可（之后双击就稳定进本工具）。状态栏那一行会告诉你有几种格式还需要确认。
- 取消勾选会撤销登记，并把各后缀**原来的默认程序还原**（关联前会先备份）。
- 也可以不走关联，直接把图片路径当命令行参数：`YuLiangTookit.exe "D:\图片\003.png"`，效果相同（打开并定位）。
- 程序已经开着时，每次双击都会**复用同一个窗口**：会把已有窗口从最小化 / 托盘恢复并置前，在同一个窗口里打开新图片和它所在的文件夹（不会越开越多）。如果更喜欢每次开新窗口，可以在设置「窗口 / 多开」里关掉**单实例模式**（默认开）。这个开关是**启动级**的，改完下次启动生效；万一已有窗口卡死连不上，程序也会自动退回另开一个窗口兜底。

## 操作与快捷键

| 操作 | 作用 |
| --- | --- |
| 滚轮 | **连续模式**：沿阅读方向滚一格（横向模式下也能左右滚，**不用按 Shift**）；**滚轮惯性**开着时滚一下会继续滑一段再停（和拖动惯性是两回事）；**翻页模式**：按设置项 `PagedWheel` 决定 —— 翻页（默认）或缩放 |
| `Ctrl+滚轮` | 以**视口中心**为基准缩放（放大 / 缩小都保持在中间附近；各模式都生效） |
| `Shift+滚轮` | **连续模式**：向**垂直阅读方向的另一轴**平移（纵向模式左右、横向模式上下）；**翻页模式**：左右平移（放大后才有得移） |
| 左键按住拖动 | 拖着画面走（像用手抓着纸推）；**放大后可以上下左右自由拖**，松手还会按惯性滑一段 |
| 左右箭头按钮（翻页模式） | 上一张 / 下一张；**日式模式下语义与提示互换**（左边按钮 = 下一张） |
| `←` / `→`（翻页模式） | 上一张 / 下一张；**日式模式下互换** |
| `PageUp` / `PageDown`（翻页模式） | 上一张 / 下一张 |
| `空格`（翻页模式） | 下一张 |
| 放大镜 `−` / `+` | 缩小 / 放大一步 **10%**（顶部工具条） |
| 百分比输入框 | 直接填缩放比例（**25% ~ 800%**，回车或失焦生效；非法输入不改） |
| 中键**单点**（按下后很快松开，短于判定时长） | **仅连续滚动模式**：锚点留在原地并显示**圆形箭头指示器**；之后移动鼠标，按离锚点的距离快速滚动；再按**任意键**（左 / 中 / 右）锚点消失 |
| 中键**按住**（超过判定时长） | **仅连续滚动模式**：锚点出现，移动鼠标快速滚动；**一松手锚点立刻消失** |
| `Ctrl+O` | 打开文件夹 |
| 工具条「🕘 最近」按钮 | 打开 / 收起右上角「最近浏览」浮层（点一条重新打开；`Esc` 或 ✕ 关闭） |
| `F11` | 进入 / 退出全屏沉浸阅读（全屏时工具条自动隐藏） |
| 工具条最右边的「全屏」按钮 | 进入 / 退出全屏（全屏时鼠标移到顶部才看得到工具条） |
| `Home` / `End` | 连续模式：跳到第一张开头 / 最后一张末尾；翻页模式：跳到第一张 / 最后一张 |
| `Esc` | 退出中键锚点 → 关掉最近浏览面板 → 退出全屏 → 关掉设置面板（按这个优先顺序） |
| `YuLiangTookit.exe "<图片路径>"` | 直接进本工具、加载这张图所在文件夹并定位到它（等同于双击图片） |
| 点击工具条上的**文件夹路径** | 在资源管理器里打开当前图片所在文件夹（路径行悬停变蓝 / 鼠标手型；没有打开文件夹时不可点） |

> 「单点」和「按住」的分界就是设置里的**单点 / 按住判定**（`MiddleHoldMilliseconds`，默认 250 毫秒）。

## 设置项

| 设置 | 存哪 | 说明 |
| --- | --- | --- |
| 阅读方式 `ScrollMode` | `Config\picture-viewer\config.json` | 共 6 种：纵向 上 → 下（默认）/ 横向 左 → 右 / 横向 右 → 左 / 双页 左 → 右 / 双页 右 → 左 / 单页浏览 |
| 翻页模式滚轮 `PagedWheel` | 同上 | 默认 `TurnPage`（翻页）；改成 `Zoom` 则滚轮在翻页 / 单页模式下**缩放**。连续模式不受影响 |
| 翻页动画 `PageTurnAnimation` | 同上 | 默认**开**（约 0.2 秒滑动）；关掉 = 直接换图。只在 100% 且未平移时播放 |
| 滚轮一格像素 `WheelStepPixels` | 同上 | 默认 **120**；连续模式下滚一格走多少像素 |
| 单点 / 按住判定 `MiddleHoldMilliseconds` | 同上 | 默认 **250** 毫秒；中键按下后没超过这个时长就算「单点」 |
| 自动释放离屏图片 `AutoUnloadOffscreen` | 同上 | 默认**开**；连续模式下滚出视野的图片释放掉，省内存 |
| 缩放比例 `ZoomPercent` | 同上 | 默认 **100**；范围 **25 ~ 800**（超出会被夹住）。**100% = 铺满基准**：连续模式纵向按窗口宽度、横向按窗口高度，翻页 / 单页按视口铺满，不是图片原始像素 1:1 |
| 拖动惯性 `InertiaEnabled` | 同上 | 默认**开**；松手后画面按甩动速度继续滑一段再逐渐减速，太慢或到边界自动停；关掉 = 松手即停。和下面的滚轮惯性是**两个独立设置** |
| 滚轮惯性 `WheelInertiaEnabled` | 同上 | 默认**开**；连续滚动模式下滚一格后按「滚轮步长 × 系数」再滑一段再减速停下（一格 120px 时约再滑 **480px**）。和拖动惯性独立，可以只开一个；翻页 / 单页模式不生效 |
| 惯性越滑越快 `InertiaAccelerate` | 同上 | 默认**开**；下一次甩动把还在滑的残余速度**加上去**（连续甩 = 一直加速，有上限）；关掉 = 每次只用这一下甩动的速度 |
| 上次打开的文件夹 `LastFolder` | 同上 | 记录上一次打开的文件夹（下次「打开文件夹」对话框从这里开始，**不会自动打开**） |
| 最近浏览上限 `RecentLimit` | 同上 | 默认 **50**；范围 **0 ~ 100**（超出会被夹住）。**0 = 不记录并清空已有列表**；调小会立刻按新上限裁掉多余的老记录；改一下自动保存 |
| 文件关联 | **系统注册表**（`HKCU\Software\Classes\YuLiangToolkit.PictureViewer` 与各后缀的 `OpenWithProgids`），不在 `config.json` | 勾选 = 把 8 种图片后缀登记到本工具（双击 / 打开方式进本工具）；取消 = 撤销登记并还原原来的默认程序。Windows 的最终默认程序由「默认应用」决定，程序不能硬改 |
| 单实例模式 `SingleInstanceEnabled` | `Config\picture-viewer\config.json` | 默认**开**：双击图片复用同一个窗口；关掉 = 多实例（每次新开窗口）。**启动级设置**，改完下次启动生效；恢复默认会回到开 |
| 图片边框 `BorderEnabled` | `Config\picture-viewer\config.json` | 默认**开**；关掉 = 不画任何边框（图片完全贴在一起） |
| 边框粗细 `BorderInnerSize` / `BorderFillSize` / `BorderOuterSize` | 同上 | 默认 **1 / 6 / 1** 像素；范围分别是 **0~32 / 0~128 / 0~32**（超出夹住），0 = 不画那一层 |
| 边框颜色 `BorderInnerColor` / `BorderFillColor` / `BorderOuterColor` | 同上 | 默认 `#FF0E1014` / `#FF39414F` / `#FF5B6474`；格式 **`#AARRGGBB`**（A=透明度，每个通道 0~255） |
| 恢复默认设置（按钮，非配置项） | 改上面全部配置 | 阅读方式回**纵向 上→下**、缩放 100%、边框 / 拖动惯性 / 滚轮惯性 / 惯性越滑越快 / 滚轮 / 翻页设置全部回默认；**不动文件关联**，但会清空「上次打开的文件夹」；最近浏览上限回 **50**，但**不清空**已有最近浏览记录（只按 50 裁剪） |

## 注意与限制

- **只负责看图**：不支持旋转，也不做图片编辑。
- **「100%」是铺满基准，不是原图像素 1:1**：纵向模式按**窗口宽度**、横向模式按**窗口高度**把整条长带铺满一屏，
  百分比是相对这个基准算的；翻页 / 单页模式同样以铺满视口为基准。所以 100% 时一张很大的图其实已被缩小显示。
  百分比始终夹在 **25% ~ 800%**。
- **翻页动画有前提**：只在缩放 **100% 且未平移**时播放；放大 / 平移状态翻页直接切换，免得动画把位置带偏。
- **双页是一次翻一张，不是一次翻两页**：相邻两屏会**重叠一张**；最后一屏不足两页时另一侧留空。
  双页模式下两页在**中间接缝对齐**。
- **中键锚点在翻页模式不启用**：单页 / 双页下没有「沿阅读方向自动滚」的概念，
  中键单点 / 按住那一套只有连续滚动模式才有；翻页请用左右按钮、方向键、`PageUp` / `PageDown` 或空格。
- **放大超过原图像素不会更清晰**：图片按**原图分辨率**解码，放大只是把已有像素拉大，会变糊；
  全屏只是阅读区变大，**不会让图片更清晰**（位图不会重新渲染出更多细节）。
- **窗口大小变化时**会尽量保持**画面中心**大致不动，不会跳来跳去。
- **全屏只改窗口 / 工具条显隐**：进出全屏不改变阅读方式、缩放和设置，只是阅读区变大，
  并尽量保持阅读位置（连续滚动保持画面中心、翻页保持当前屏）；退出后窗口大小 / 位置原样还原。
- **全屏时工具条会自动隐藏**：鼠标一动出现，停 **2.5 秒**缩回、鼠标指针一起隐藏；鼠标移到窗口顶部（或任意移动）就能再叫出来；
  设置面板开着时工具条不会自动收。
- **切走工具自动退出全屏**：全屏状态不会带到别的工具 / 页面，外壳的标题栏 / 侧边栏等会自动还原。
- **惯性叠加有上限**：一直连续甩会越来越快，但封顶在 6 像素 / 毫秒（约 360 像素 / 帧），不会一下滑穿整本漫画；
  想回到“每次只用这一下的速度”，把设置里的「惯性越滑越快」关掉即可。**这只影响拖动惯性，滚轮惯性不叠加**。
- **滚轮惯性只在连续滚动生效**：双页翻页 / 单页浏览模式下滚轮仍然是一格翻一次（不会继续滑；`PagedWheel` 改成缩放时也是一格一步）；
  `Ctrl+滚轮` 缩放、`Shift+滚轮` 平移照旧。
- **想「滚一格只滚一格」**：把设置面板里的「滚轮惯性（滚一格继续滑一段）」关掉即可（默认开）；
  它和拖动惯性互相独立，可以只开其中一个。
- **只读所选文件夹的当前层**，不进子文件夹。想看子文件夹里的图，把那个文件夹直接选进来即可。
- **顺序不能手动调**：默认按文件名自然排序（`2` 在 `10` 前面；纯数字文件名的图集按数字顺序），
  **没有拖拽排序**。想让某张排前面就改文件名。
- **超大图集偏慢（连续模式）**：整条长带是一次性建好的（几千张会占内存 / 首次搭带变慢；漫画一话通常几十张，不用担心）；
  翻页 / 单页模式按需解码当前屏附近的几页，大图集反而更省。
- **支持的格式**：`.jpg` `.jpeg` `.png` `.bmp` `.gif` `.webp` `.tif` `.tiff`；其它文件直接忽略。
  `.webp` / `.tif` 能不能显示取决于系统自带的 WIC 解码器（Windows 10 之后一般都有）；解码器缺失时这些图会被静默跳过。
- 图片按 **WPF 自带的解码行为**显示，不额外做方向 / 色彩处理（带 EXIF 旋转标记的图可能按原方向显示）。
- 只读不写：**不做图片编辑**，不会改动你的图片。
- **文件关联只写当前用户**：不动 `HKEY_LOCAL_MACHINE`、也不需要管理员；移动 / 重装程序后如果双击失效，重新勾选一次即可（命令里的 exe 路径会更新）。系统默认程序（`UserChoice`）受 Windows 保护，需要你在「默认应用」里确认一次，本工具不会硬改。
- **最近浏览按完整路径去重**：同一个文件夹只留一条（路径大小写不敏感）；文件夹**改名 / 移动**后算新记录；
  点已经不存在的记录会**自动移除**并在状态栏提示「最近打开过的文件夹已经不在了」。「清空」只删记录，**不会删本地文件**。
  记录存在 `Config\picture-viewer\config.json`，也可以在「**主页设置 → 清理缓存**」里勾「最近浏览记录」一键清掉（同样只删记录、不删本地文件）。
- **0 = 不记录并清空**：最近浏览上限调到 0 会清空已有列表、之后不再记录；
  **「恢复默认设置」只把上限改回 50，不清空已有记录**（只按 50 裁剪）。
- **单实例 / 多开可切换**：设置面板「窗口 / 多开」里的「单实例模式」默认**开**（双击图片复用同一个窗口）；关掉后每次双击 / 启动都新开一个窗口（多实例）。这是启动级设置，**改完下次启动生效**。
- **图片边框会占掉一点显示区域**：边框粗细算在布局里，100% 时「图 + 边框」刚好铺满一屏；边框不随缩放变粗，放大后图会更大、边框仍是固定像素。
- **恢复默认会清空「上次打开的文件夹」**：其它设置回默认，当前已经打开的图片不受影响；文件关联是系统级开关，不会被恢复默认改掉，需要单独去勾选 / 取消。
