# 🖼️ 图片连续阅读器

> 普通看图器一屏一张，看条漫 / 长图 / 漫画得一张张点。这个工具把**一个文件夹里的图片按页码首尾相接拼成一条长带**
> （无缝、无间距），滚轮沿着阅读方向一路滚过去，就能连着看。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **一条长带，无缝衔接**：文件夹里的图按顺序首尾相接，中间**没有间距、没有分页**，像看一张超长的图。
- **三种阅读方向**（顶部工具条的「滚动方式」三个按钮随时换）：纵向从上到下（默认，条漫 / 长图）、横向从左到右（中式漫画）、
  横向从右到左（日式漫画，第一张从最右边开始）。
- **滚轮连续浏览**：滚一格就走一格；横向模式下滚轮直接左右滚，**不用按 Shift**。
- **拖着看**：左键按住拖动画面；中键锚点可以「甩」起来，移动鼠标就快速滚动（见下面「操作与快捷键」）。
- **省内存**：滚出视野的图片会自动释放（默认开），看大图集也不会越看越吃内存。

## 三种滚动方式

| 滚动方式 | 适合 | 说明 |
| --- | --- | --- |
| 纵向从上到下（默认） | 条漫 / 长图 | 第一张在最上面；往后读 = 内容往下走 |
| 横向从左到右 | 中式漫画 | 第一张在最左边；往后读 = 内容往右走 |
| 横向从右到左 | 日式漫画 | **第一张排在最右边**；往后读 = 内容往左走 |

> 换方向点**顶部工具条**「滚动方式」旁那三个按钮之一，改完立刻生效、自动保存。

## 怎么用

1. 按 `Ctrl+O` 选一个图片文件夹。**只读这一层**，不进子文件夹。
2. 图片按文件名顺序排好、首尾相接 —— 命名成 `001.jpg`、`002.jpg` 这样最省事
   （`2` 会排在 `10` 前面；纯数字文件名的图集也按数字顺序）。
3. 滚轮沿阅读方向连续往后看；嫌慢就按住左键拖，或者用中键锚点甩起来。
4. 看日漫发现方向反了：点**顶部工具条**「滚动方式」里的**横向 右 → 左**。
5. 设置项都在同一个面板里，**改一下就自动保存，没有「保存」按钮**；按 `Esc` 关面板。

## 操作与快捷键

| 操作 | 作用 |
| --- | --- |
| 滚轮 | 沿阅读方向滚一格（横向模式下也能左右滚，**不用按 Shift**） |
| 左键按住拖动 | 拖着画面走（像用手抓着纸推） |
| 中键**单点**（按下后很快松开，短于判定时长） | 锚点留在原地并显示**圆形箭头指示器**；之后移动鼠标，按离锚点的距离快速滚动；再按**任意键**（左 / 中 / 右）锚点消失 |
| 中键**按住**（超过判定时长） | 锚点出现，移动鼠标快速滚动；**一松手锚点立刻消失** |
| `Ctrl+O` | 打开文件夹 |
| `Home` / `End` | 跳到第一张开头 / 最后一张末尾 |
| `Esc` | 关掉设置面板 / 退出锚点 |

> 「单点」和「按住」的分界就是设置里的**单点 / 按住判定**（`MiddleHoldMilliseconds`，默认 250 毫秒）。

## 设置项

| 设置 | 存哪 | 说明 |
| --- | --- | --- |
| 滚动方式 `ScrollMode` | `Config\picture-viewer\config.json` | 纵向从上到下（默认）/ 横向从左到右 / 横向从右到左 |
| 滚轮一格像素 `WheelStepPixels` | 同上 | 默认 **120**；滚一格走多少像素 |
| 单点 / 按住判定 `MiddleHoldMilliseconds` | 同上 | 默认 **250** 毫秒；中键按下后没超过这个时长就算「单点」 |
| 自动释放离屏图片 `AutoUnloadOffscreen` | 同上 | 默认**开**；滚出视野的图片释放掉，省内存 |
| 上次打开的文件夹 `LastFolder` | 同上 | 记录上一次打开的文件夹（下次「打开文件夹」对话框从这里开始，**不会自动打开**） |

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\picture-viewer\config.json` | 上面全部设置（改一下自动保存） |
| `Data\picture-viewer\` | 只有**开发演示模式**（`YLT_PICTURE_DEMO=1`）才会生成演示图片；正常使用不会往这里写东西 |

> `Data` / `Config` 就在 **exe 旁边**（`bin\Debug\net9.0-windows\` 或发布出来的目录），
> 整个程序目录拷走就能迁移数据。目录约定见 [shell.md](../shell.md#数据与配置都在-exe-旁边)。

## 注意与限制

- **只负责「连续滚动着看」**：不支持缩放、不支持旋转，也不做图片编辑。
- **超大图会缩放**：纵向模式下按**窗口宽度**、横向模式下按**窗口高度**缩放到刚好铺满一屏；
  **暂不支持原图像素级 1:1 显示**（以后需要再加）。
- **只读所选文件夹的当前层**，不进子文件夹。想看子文件夹里的图，把那个文件夹直接选进来即可。
- **顺序不能手动调**：默认按文件名自然排序（`2` 在 `10` 前面；纯数字文件名的图集按数字顺序），
  **没有拖拽排序**。想让某张排前面就改文件名。
- **超大图集偏慢**：整条长带是一次性建好的（几千张会占内存 / 首次搭带变慢；漫画一话通常几十张，不用担心）。
- **支持的格式**：`.jpg` `.jpeg` `.png` `.bmp` `.gif` `.webp` `.tif` `.tiff`；其它文件直接忽略。
  `.webp` / `.tif` 能不能显示取决于系统自带的 WIC 解码器（Windows 10 之后一般都有）；解码器缺失时这些图会被静默跳过。
- 图片按 **WPF 自带的解码行为**显示，不额外做方向 / 色彩处理（带 EXIF 旋转标记的图可能按原方向显示）。
- 只读不写：**不做图片编辑**，不会改动你的图片。
