# ⚫ 联机五子棋

> 开一个 TCP 房间，和朋友联机下五子棋 —— 局域网直连，外网用**端口映射 / 内网穿透**。
> **一个房间最多 16 人**：只有坐在两个「上场位」上的两个人比赛，其余人**观战**；
> **房主安排谁上场**，也可以开**自动轮换**（输的下场 / 双方都下场）。
> 同一台电脑上也能「同机双人」轮流下。**不依赖任何第三方服务**，两端都是本程序。

## 能做什么

- **三种入口**：**同机双人**（一台电脑轮流落子）/ **开房间**（房主）/ **加入房间**（客户端）。
- **多人房间（最多 16 人）**：房主 + 最多 15 个客户端。房间里有两种角色：
  - **选手**：坐在「**先手位（黑棋）**」或「**后手位（白棋）**」上的两个人；
  - **观战者**：其余所有人（包括没坐席位的房主）。
  右侧「**房间成员**」卡列出每个人：身份（房主 / 玩家）、位置（先手位 / 后手位 / 观战）、
  **已打几局**、在线 / 离线；顶部一行显示「你现在是什么身份」。
- **观战**：观战者能看到**实时棋盘**、房间聊天、成员列表和轮次/结果，但**不能走子、不能悔棋 / 求和 / 认输、
  不能开始下一局**；观战者掉线**不会**让对局暂停。
- **房主安排上场**（「**上场安排**」卡）：房主用两个下拉框把任意成员安排到先手位 / 后手位
  （**也可以把房主自己排上去**，或者留空位）；还有「**交换座位**」「**清空座位**」。
  - **对局进行中席位锁定**，等这一局结束才能换人；
  - 房主**不坐席位也能控制房间**（安排人 / 自动轮换 / 开始下一局 / 结束本局），相当于裁判。
- **自动轮换**（每局结束后自动排好下一局上场的人，**但不会自动开始**——房主点「开始下一局」）：
  - **自动上场方式**：`手动安排`（默认，房主自己挑人）/ `输的下场`（赢家留场、输家下场换人）/
    `双方都下场`（两个人都换）；
  - **补位方式**：`轮流上场`（**没上过场的人优先**，同样场次按进房先后顺序）/
    `随机上场`（没上过场的人里随机挑，同场次的才随机）；
  - **平局**：`输的下场` 不轮换（没有输家）；`双方都下场` 照样换人；
  - **人数不够就回退**：`输的下场` 至少要有 1 个替补、`双方都下场` 至少要有 2 个替补，
    否则维持原上场（不会硬把同一个人排两次）；
  - **上场次数**：完整打完一局才 +1；作废的局、中途退出都不算 —— 补位时场次少的优先。
- **作废本局**（房主）：对局进行中想要重开，点「**结束本局（作废）**」**点两下确认**；
  作废不加分、席位不变，之后可以重新安排再开始。
- **棋盘**：默认 15×15，可以切到 19×19（开房 / 开局前设置才生效，见「注意」）。
- **禁手（可选，默认关闭）**：开启后**只对黑棋**生效 ——
  - 黑棋落在「**三三**」「**四四**」「**长连**（≥6 子）」判**禁手负**；
  - 黑棋「**正好五连**」永远算赢（**五连优先于长连**），不会把赢棋误判成禁手；
  - **白棋没有禁手**：白棋长连同样算赢；
  - 还可以单独开关「**显示禁手点**」：黑方回合时把当前的禁手点标在棋盘上。
- **胜负判定**：横 / 竖 / 斜任意方向连成五子获胜；**关闭禁手时长连（≥6 子）也算赢**；
  获胜的连子会高亮，最后一手有标记；棋盘下满判和。
- **悔棋 / 认输 / 求和 / 再来一局**：同机双人随时可悔；**联机只有场上的选手能发起**，
  请求要对方（或房主）点「同意」（会显示在房间里），同意后由主机应用并同步局面。
- **棋谱**：每步一行，例如 `1. 黑 H8`、`2. 白 I9`。
  列用 `A~O`（19 路时 `A~S`），行号**从下往上**数 `1~15`（19 路时 `1~19`）；可一键复制整份棋谱。
- **房间聊天**：所有人都能发文字（观战者也能）；系统提示（谁进来了 / 谁上场了 / 谁掉线了）会混在聊天记录里。
- **掉线不用重开**：**房主是权威**——**席上的选手**网络断了，主机**不重置棋局、不关房间**，
  显示「对局暂停 · 等席上的玩家重连回来」；掉线的人会**自动重连**（默认每 2 秒试一次、最多 60 秒），
  连上后**保留原来的席位与上场次数**，拿到当前最新局面继续下。
  只有**房主关房 / 主动离开**才不重连（会明确提示，不会无限重试）。

## 怎么联机

### 主机：开房间

1. 主页「**棋牌**」类别 → 打开「**联机五子棋**」。
2. 右栏「房间」里填：**玩家名**（别人看到的昵称）、**端口**（默认 `5310`，填 `0` 表示让系统自动挑一个空闲端口）、
   **房主执子**（决定房主默认坐先手位还是后手位）。端口被别的程序占用时会提示「开房间失败」，改成 `0` 最省事。
3. 点「**开房间**」。开好后界面会把本机的「**地址:端口**」列成若干行（IPv4 / IPv6 各一条，带「推荐」标记，
   最多显示 3 行，更多会折叠提示），每行都能单独复制，也可以点「**复制邀请**」把整段邀请文案复制走。
4. 把地址发给别人（**最多 16 人**，人满后新的连接会被提示「房间已满」）。
5. 大家在「**房间成员**」里出现后，房主在「**上场安排**」里把两个人放到先手位 / 后手位
   （可以放自己；点「交换座位」「清空座位」调整），然后点「**开始对局**」——**双方都要等主机开始后才能落子**。

### 客户端：加入房间

1. 把对方发来的地址填进「**加入地址**」。**地址里要带端口**，例如 `192.168.1.5:5310`、
   IPv6 写成 `[fe80::1]:5310`；外网就是内网穿透工具给你的 `域名:端口`。只填 IP / 域名会被提示「请填写端口」。
2. 点「**加入房间**」。加入后默认是**观战**（能看到棋盘但不能下）；等房主把你安排上场、并点开始对局后，
   你会自动执对应的一边（先手位 = 黑棋、后手位 = 白棋）。

> 一台电脑上两个人轮流下：点「**同机双人**」即可，不用开端口、也不用填地址。
> 玩完想断开：点「**离开房间**」（房主离开 = 房间关闭；其他人离开 = 自动从成员表移除、若是选手会清空他的席位）。
> 掉线会自动重连；想主动放弃重连就点「**停止重连**」。

## 自动轮换的排人规则

| 自动上场方式 | 一局结束后 | 平局时 |
| --- | --- | --- |
| 手动安排（默认） | 席位不动，等房主自己选 | 席位不动 |
| 输的下场 | 赢家留原席位，输家下场 → 替补 1 人 | 不轮换（没有输家） |
| 双方都下场 | 两个人都下场 → 替补 2 人 | 照样换人 |

- **替补从哪来**：所有**在线**、且**不在场上**的成员。
- **先补谁**：上场次数少的优先；次数一样时，`轮流上场` 按进房顺序（早进的先），
  `随机上场` 在这些同次数的人里随机挑（随机也**不会**打乱「没上过场的人优先」这条）。
- **排好之后不会自动开局**：聊天里会提示「已自动安排下一局」，房主确认后点「**开始下一局**」。
- 候补不够时**保持原上场**并提示「没有可替换的选手，维持原上场」。

> 举例：房主（黑）vs 小明（白），房主赢、模式是「输的下场 + 轮流上场」，房间还有没上过场的小刚和小美 →
> 小明下场，小刚上场（小刚进房更早）；下一局就是「房主（黑）vs 小刚（白）」。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 玩家名 | `玩家` | 别人看到的昵称；同机双人也会显示 |
| 端口 | `5310` | 主机监听端口；`0` = 让系统自动挑一个空闲端口（界面上写「0 = 自动挑」） |
| 加入地址 | （空） | 客户端上次连的地址，下次自动填好（要带端口，如 `192.168.1.5:5310`） |
| 房主执子 | 黑棋 | 决定房主**默认坐哪个席位**（先手位 = 黑棋 / 后手位 = 白棋）；开房后还可以在「上场安排」里改 |
| 自动上场方式 | 手动安排 | 手动安排 / 输的下场 / 双方都下场（房主在「上场安排」卡里改） |
| 补位方式 | 轮流上场 | 轮流上场（没上过场优先 + 进房顺序）/ 随机上场（没上过场的人里随机） |
| 启用禁手 | 关 | 开启后黑棋三三 / 四四 / 长连判负（白棋不受影响） |
| 显示禁手点 | 开 | 黑方回合时在棋盘上标出禁手点（仅开启禁手时有意义） |
| 棋盘大小 | 15 路 | 15×15 / 19×19 |
| 显示棋谱 | 开 | 是否在下方显示棋谱列表（棋谱本身照常记） |

> 所有设置都是**改一下就自动保存**，没有「保存」按钮。设置存在 `Config\gomoku\config.json`（见下）。
> 设置卡片上有一句提示：**开房前设置生效；已开局改动会在下一局生效**。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\gomoku\config.json` | 上面所有设置：玩家名 / 上次加入地址 / 端口 / 房主执子 / **自动上场方式 / 补位方式** / 禁手 / 显示禁手点 / 棋盘大小 / 显示棋谱 |

- 联机**不开新的数据端口**：所有内容都走主机那一个 TCP 端口（内网穿透只映射它即可）。
- **`Data\gomoku\` 这版没有用到**（对局不落盘，没有历史记录文件）；关掉工具或程序，这一局就结束了
  （想留棋谱请在「棋谱」卡片里点复制，自己存下来）。

## 注意

- **连接没有加密**（就是普通 TCP）。传敏感内容请只在可信网络里用，或者先套一层加密通道（VPN / 穿透工具的 TLS）。
- **一个房间最多 16 人**（房主 + 15 个客户端）：人满后新的连接会收到「房间已满」并断开，房间里原有的人不受影响。
- **只有席上的选手能走子**：观战者点棋盘不会有反应；房主会忽略非场上玩家的走子动作。
  「悔棋 / 求和 / 认输 / 再来一局」也只有席上的选手能用；房主不下场时作为裁判处理这些请求。
- **对局暂停**：对局进行中如果**席位上有人掉线 / 席位空着**，所有人棋盘只读（「对局暂停」）；
  观战者掉线**不**暂停。席上的人重连回来、或房主换人并重开后恢复。
- **掉线与重连**：掉线的人自动重连（成员保留、席位保留、上场次数保留）；重连中棋盘只读、不会重复加入；
  「离开房间」按钮在重连中会变成「**停止重连**」。**房主关房 / 主动离开不会自动重连**。
- **作废本局**要连点两次「结束本局（作废）」确认（3 秒内不点第二下自动取消）；作废**不加分**。
- **防手滑**：联机对局中「认输」点第一下会变成「再点一次确认认输」；「离开房间」第一下会变成
  「再点一次确认离开」（对局进行中还会提示「离开会中断本局」）。
- **开房前设置才生效**：禁手、棋盘大小、房主执子这类在开局时固定；对局中改了也**只对下一局生效**。
- 规则上本工具采用的是「**自由规则五子棋（无禁手）**」+ 可选「黑棋禁手」：
  禁手判定以「落下这一子之后是否形成三三 / 四四 / 长连」为准，没有实现全部连珠细节（如三三的复杂嵌套），
  够日常对弈用；双方事先约好开不开禁手即可。
