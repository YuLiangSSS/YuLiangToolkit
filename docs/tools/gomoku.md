# ⚫ 联机五子棋

> 开一个 TCP 房间，和朋友联机下五子棋 —— 局域网直连，外网用**端口映射 / 内网穿透**。
> 同一台电脑上也能「同机双人」轮流下。**不依赖任何第三方服务**，两端都是本程序。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **三种玩法**：**同机双人**（一台电脑轮流落子）/ **开房间**（主机）/ **加入房间**（客户端）。
  开房间与加入房间的步骤见下面「怎么联机」。
- **棋盘**：默认 15×15，可以切到 19×19（开房 / 开局前设置才生效，见「注意」）。
- **禁手（可选，默认关闭）**：开启后**只对黑棋**生效 ——
  - 黑棋落在「**三三**」「**四四**」「**长连**（≥6 子）」判**禁手负**；
  - 黑棋「**正好五连**」永远算赢（**五连优先于长连**），不会把赢棋误判成禁手；
  - **白棋没有禁手**：白棋长连同样算赢；
  - 还可以单独开关「**显示禁手点**」：黑方回合时把当前的禁手点标在棋盘上。
- **胜负判定**：横 / 竖 / 斜任意方向连成五子获胜；**关闭禁手时长连（≥6 子）也算赢**；开启禁手后白棋长连算赢、黑棋长连判禁手负。
  获胜的连子会高亮，最后一手有标记；棋盘下满判和。
- **悔棋 / 认输 / 求和 / 再来一局**：同机双人随时可悔；**联机时要对方点「同意」**
  （请求会显示在房间里，对方同意后由主机应用并同步局面）。
- **棋谱**：每步一行，例如 `1. 黑 H8`、`2. 白 I9`。
  列用 `A~O`（19 路时 `A~S`），行号**从下往上**数 `1~15`（19 路时 `1~19`）；可一键复制整份棋谱。
- **房间聊天**：对局中也能发文字，系统提示（谁进来了 / 谁悔棋了）会混在聊天记录里。
- **掉线不用重开**：**主机是权威**——客户端网络断了，主机**不重置棋局、不关房间**，界面显示
  「对局暂停 · 等待对方重连」；客户端会**自动重连**（默认每 2 秒试一次，最多 60 秒），
  连上后拿到**当前最新局面**继续下，聊天记录也喂回一句「已重新连接，继续对局」。
  只有**房主关房 / 主动离开**才不重连（会明确提示，不会无限重试）。

## 怎么联机

### 主机：开房间

1. 主页「**棋牌**」类别 → 打开「**联机五子棋**」。
2. 右栏「房间」里填：**玩家名**（对方看到的昵称）、**端口**（默认 `5310`，填 `0` 表示让系统自动挑一个空闲端口）、
   **房主执子**（黑先 / 白后）。端口被别的程序占用时会提示「开房间失败」，改成 `0` 最省事。
3. 点「**开房间**」。开好后界面会把本机的「**地址:端口**」列成若干行（IPv4 / IPv6 各一条，带「推荐」标记），
   每行都能单独复制，也可以点「复制邀请」把整段邀请文案复制走。
4. 把地址发给对方。对方连上后，主机点「**开始对局**」——**双方都要等主机开始后才能落子**。

### 客户端：加入房间

1. 把对方发来的地址填进「**加入地址**」。**地址里要带端口**，例如 `192.168.1.5:5310`、
   IPv6 写成 `[fe80::1]:5310`；外网就是内网穿透工具给你的 `域名:端口`。
   只填 IP / 域名会被提示「请填写端口」。
2. 点「**加入房间**」。连上后等主机开始对局，然后轮流落子。

> 一台电脑上两个人轮流下：点「**同机双人**」即可，不用开端口、也不用填地址。
> 玩完想断开：点「**离开房间**」（主机离开 = 房间关闭；客户端离开 = 回离线界面）。
> 客户端掉线会自动重连；想主动放弃重连就点「**停止重连**」。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 玩家名 | `玩家` | 联机时对方看到的昵称；同机双人也会显示 |
| 端口 | `5310` | 主机监听端口；`0` = 让系统自动挑一个空闲端口（界面上写「0 = 自动挑」） |
| 加入地址 | （空） | 客户端上次连的地址，下次自动填好（要带端口，如 `192.168.1.5:5310`） |
| 房主执子 | 黑棋 | 开房时主机执黑（先手）还是执白（后手）；「再来一局」会交换 |
| 启用禁手 | 关 | 开启后黑棋三三 / 四四 / 长连判负（白棋不受影响） |
| 显示禁手点 | 开 | 黑方回合时在棋盘上标出禁手点（仅开启禁手时有意义） |
| 棋盘大小 | 15 路 | 15×15 / 19×19 |
| 显示棋谱 | 开 | 是否在下方显示棋谱列表（棋谱本身照常记） |

> 设置卡片上有一句提示：**开房前设置生效；已开局改动会在下一局生效**。
> 所有设置都是**改一下就自动保存**，没有「保存」按钮。设置存在 `Config\gomoku\config.json`（见下）。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\gomoku\config.json` | 上面所有设置：玩家名 / 上次加入地址 / 端口 / 房主执子 / 禁手 / 显示禁手点 / 棋盘大小 / 显示棋谱 |

- 联机**不开新的数据端口**：所有内容都走主机那一个 TCP 端口（内网穿透只映射它即可）。
- **`Data\gomoku\` 这版没有用到**（对局不落盘，没有历史记录文件）；关掉工具或程序，这一局就结束了
  （想留棋谱请在「棋谱」卡片里点复制，自己存下来）。

## 注意

- **连接没有加密**（就是普通 TCP）。传敏感内容请只在可信网络里用，或者先套一层加密通道（VPN / 穿透工具的 TLS）。
- **房间最多两人**（主机 + 1 位客户端）：第三个人连进来会收到「房间已满」的提示并被断开，房间里原有的两人不受影响。
- **掉线与重连**：客户端断网 → 自动重连，主机侧「对局暂停 · 等待对方重连」、棋局原样保留，对方回来后继续；
  重连中棋盘只读、不会重复加入。「离开房间」按钮在重连中会变成「**停止重连**」。
  **房主关房 / 主动离开不会自动重连**（客户端收到明确原因后回到离线界面）。
- **暂停期间不能落子**（防止对方回来发现自己被白走一步）；重连成功会提示「已重新连接，继续对局」。
- **防手滑**：联机对局中「认输」点第一下会变成「再点一次确认认输」；「离开房间」第一下会变成
  「再点一次确认离开」（对局进行中还会提示「离开会中断本局」）。
- **开房前设置才生效**：禁手、棋盘大小、房主执子这类在开局时固定；对局中改了也**只对下一局生效**（当前这局不会重置）。
- 规则上本工具采用的是「**自由规则五子棋（无禁手）**」+ 可选「黑棋禁手」：
  禁手判定以「落下这一子之后是否形成三三 / 四四 / 长连」为准，没有实现全部连珠细节（如三三的复杂嵌套），
  够日常对弈用；双方事先约好开不开禁手即可。
