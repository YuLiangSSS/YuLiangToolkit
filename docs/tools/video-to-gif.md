# 🖼️ 视频转 GIF

> 把一个视频文件**截取一段**转成 **GIF 动图**。可以精确设起始时间 / 时长 / 帧率 / 宽度 / 颜色数 / 抖动算法，
> 用 FFmpeg 的两遍调色板编码（`palettegen` → `paletteuse`），颜色准、体积小。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **视频文件 → GIF**：选一个本地视频（mp4 / mkv / mov / webm / avi / m4v / flv / ts 等），截取一段转成 GIF。
- **精确截取**：
  - **起始时间**：秒（`83.5`）或 `mm:ss` / `hh:mm:ss`（`01:23.5`、`1:02:03`）；
  - **截取时长**：秒；`0` = 一直截到视频结尾（GIF 会非常大，不建议）。
- **画质 / 体积可控**：
  - **帧率**：10 / 12 / 15 / 20 / 24 / 30 FPS（默认 15，GIF 的常用平衡点）；
  - **宽度**：原宽 / 320 / 480 / 640 / 800 / 960 / 1280 px，高度按比例自适应；**只缩不放**，
    选比原视频还大的宽度也不会把画面拉花；
  - **颜色数**：256（最佳）/ 128 / 64 / 32，越少体积越小；
  - **抖动**：Floyd–Steinberg（最细腻）/ Bayer（有序）/ Sierra2 / Sierra2 4a（轻快）/ 不抖动；
  - **循环**：无限循环播放，或只播一次。
- **两遍调色板编码**：第一遍 `palettegen` 从截取片段里统计最优 256 色调色板，第二遍 `paletteuse`
  套用 —— 比直接把视频录成 GIF 颜色准得多（这也是「录屏 / GIF」和「剪辑工具」用的同一套办法）。
- **进度 / 取消 / 日志**：第二遍编码实时显示进度；随时可以取消（FFmpeg 进程树一起杀掉）。
- **输出不覆盖**：目标 GIF 已存在时自动加 ` (2)`、` (3)`，不会覆盖已有文件。

## 怎么用

1. 第一次用先确认 FFmpeg：工具会自动从「配置里的路径 → `PATH` → 常见安装位置」找 `ffmpeg.exe`；
   找不到就点「选择 FFmpeg…」手动指定，或点「下载 FFmpeg」去官方下载页。
2. 选**源视频**，按需改**输出目录**（不选就放在源视频旁边）。
3. 填**起始时间**和**截取时长**（秒或 `mm:ss`）。
4. 调 **GIF 参数**（帧率 / 宽度 / 颜色数 / 抖动 / 循环），右边会显示参数摘要。
5. 点「开始转换」。第一遍生成调色板，第二遍合成 GIF；完成后点「打开输出目录」。

## 界面布局

- 「源文件与输出 | GIF 参数」左右可拖；「设置行 / 进度与日志」上下可拖（`video-to-gif.设置与日志`）。
- 松手自动记住（`Config\layout.json`）；**双击**某条分隔线只恢复这一处，全部恢复默认：
  **主页设置 →「界面布局 → 恢复默认布局」**。

## 注意 / 限制

- **GIF 体积与「时长 × 帧率 × 分辨率 × 颜色数」成正比**：截短一点、降帧率、缩小宽度、减少颜色都能显著减小体积。
- **GIF 只有 256 色**，渐变色 / 照片类画面会有轻微色带；「抖动」越细（Floyd–Steinberg）越自然但体积略大。
- 起始时间用的是**关键帧快速 seek**（`-ss` 放在 `-i` 前）：起点可能不精确到毫秒，误差通常在半秒内，一般够用。
- 纯 `.m4s` 分片或特殊封装如果读不出来，先用播放器 / FFmpeg 转成普通 mp4 再转 GIF。
- 转换中别去动源文件；产物直接写在目标路径上（同名自动加序号，不覆盖）。
