# ⭐ 跳棋（六芒星）

> 六芒星 121 个点位；**2 / 3 / 4 / 6 人**（5 人没有合法排布）；
> **谁进来谁自己选角**，第一个选的人决定这一局用哪套组合；
> 经典跳棋规则（跨过相邻棋子落到它后面，可连跳），**占满对面角全部 10 个点**获胜；
> 防卡出生点、**让棋**（自己区域可删棋子降低难度）；带电脑对手。

## 棋盘

六芒星 121 格：

| 部分 | 格子数 |
| --- | --- |
| 六个角，每个角 | 10（4+3+2+1） |
| 中央六边形 | 61 |

每方 10 枚棋子摆在自己的角里，目标是**对面的那个角**（上↔下、右上↔左下、右下↔左上）。

## 人数与位置规则

| 人数 | 合法排布 |
| --- | --- |
| **2 人** | 面对面：上+下 / 左上+右下 / 左下+右上 |
| **3 人** | 上+左下+右下，或 下+左上+右上 |
| **4 人** | 两两相邻、每组间隔一个空位：左上+左下 & 右上+右下，或 下+左下 & 上+右上 等 |
| **6 人** | 六个角全占 |
| **5 人** | **不支持**（没有合法排布） |

**第一个选位置的人决定规则**：一旦第一个人选了某个角，本局就锁定到含这个角的某一套组合，
后面的人只能在这套组合里挑剩下的位置。界面会提示「这套组合剩下的位置」。

## 跳的规则

- **跳**：沿六个方向，跨过**紧邻的一枚棋子**（自己的也可以），落到它**后面的空位**；可以连续跳（能拐弯）。
- **走一格**：房主可以选是否允许走一格到相邻空位（关掉则**只能跳**）。
- **防卡出生点**：自己初始区域里**还有棋子**时，只能先动初始区域里的棋子 —— 防止有人用自己的子把对面堵死在出生点。

## 让棋

- 开局前，可以点自己区域里的棋子再点「让掉选中棋子」，把自己这边的棋子删掉几枚（**降低自己的难度**）。
- 可让的枚数由「让棋上限」控制；设为 0 即关闭。

## 电脑对手

| 难度 | 策略 |
| --- | --- |
| 入门 | 随机挑走法（会走废棋） |
| 普通 | 挑「离目标角最近」的一步 |
| 困难 | 一步前瞻（走完看对手最好的一步） |

## 怎么玩

1. 选人数 → 点右下角的「上 / 右上 / 右下 / 下 / 左下 / 左上」坐下（第一个选的人决定组合）。
2. 人齐了点「开局」。
3. 点自己的棋子（会亮**金圈**），再点落点走过去。
4. 把对面角 **10 个点全部占满**就赢。

## 设置项

存 `Config\checkers\config.json`：玩家名、人数、让棋上限、AI 难度与数量、
规则开关（允许走一格 / 必须先清初始区域）、开房端口、上次加入地址。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 点某个角提示不在组合里 | 「第一个人定规则」：只能在那一套组合里挑剩下的位置 |
| 棋子不能动 | 自己初始区域还有棋子时，只能动那里的（防卡出生点的规则） |
| 想只跳不走 | 关掉「允许走一格到相邻空位」 |
| 5 人玩不了 | 六芒星没有 5 人的合法排布，只能 2 / 3 / 4 / 6 人 |
