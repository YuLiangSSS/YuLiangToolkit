# 🚀 开机启动管理

> 管理随 Windows 启动的程序：扫描**注册表 Run / RunOnce** 与**「启动」文件夹**，
> 逐个**启用 / 禁用**（写 Windows 自己的 `StartupApproved`）、**删除**、**打开程序位置**、**复制启动命令**。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> 本工具从「任务管理器」里拆出来独立成页，任务管理器从此专注进程 / 性能监测。

## 能做什么

### 1. 启动项列表

扫描四类来源：

- 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（当前用户）；
- 注册表 `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`（所有用户，含 32 位分支）；
- 注册表 `RunOnce`（只运行一次）；
- 当前用户 / 公共「启动」文件夹里的快捷方式 / 程序。

每条显示：**名称、状态（已启用 / 已禁用）、来源、启动命令 / 目标程序**。

- **列宽可拖**：鼠标移到列头之间的竖线，光标变 ↔，拖动就能调列宽；
- **点列头排序**：直接点「名称 / 状态 / 来源」列头排序；
- **搜索**：名称 / 命令 / 来源都能搜；多个关键词用空格分隔（每个词都要命中）。

### 2. 操作

- **启用 / 禁用**：写 Windows 自己的 `StartupApproved` 记录（和系统任务管理器那个开关是同一份数据，
  所以关掉之后系统任务管理器里也会显示「已禁用」，重启后真的不会自启）；
- **删除**：注册表值 / 启动文件夹里的文件（会先弹确认框）；
- **打开文件位置** / **复制命令**。

> 只删「启动记录」，**不会卸载程序本身**。HKLM / 公共启动文件夹里的项目需要管理员权限才能改，
> 普通权限下这些操作会失败并提示；点「以管理员身份重启」提权后就能操作。

### 3. 按需管理员权限（UAC）

平时**不需要**右键「以管理员身份运行」：

- 普通权限时工具条上有「**以管理员身份重启**」按钮；
- 启用 / 禁用 / 删除系统级启动项失败时，弹窗会问「要以管理员身份重新启动本程序吗？」；
- 点「是 / 确定」→ Windows 弹 **UAC** → 授权后本程序以管理员身份重新启动，并**自动回到「开机启动管理」页面**。

为什么是「重启整个程序」而不是「只给这一次操作提权」：Windows 不支持给运行中的进程临时加管理员令牌，
要么重启进程，要么额外常驻一个管理员权限的代理进程。本工具选前者（和任务管理器、
「主页设置 → 渲染与性能 → 重启本程序」共用同一套机制），实现简单、不需要常驻高权限进程。

## 怎么用

1. 打开工具页会自动扫描一遍启动项（只读）。
2. 想看某项的完整命令 / 位置：选中那一行，底部或悬浮提示会显示完整内容。
3. 想关掉某项自启：选中 → 点「禁用」；想恢复就点「启用」。
4. 想彻底清除某项：选中 → 点「删除」（确认后删掉启动记录）。
5. 系统级项目改不动：点「以管理员身份重启」，同意 UAC 后自动回到本页。
6. 想找某一项：用搜索框按名称 / 命令 / 来源搜（空格分词）。

## 数据放在哪

- 本工具**不写 Data / Cache**，也**不建配置文件**（每次打开即实时扫描系统真实状态）。
- 修改的是**系统本身的启动项**（注册表 / 启动文件夹），不是本工具的配置文件。

## 常见问题

| 现象 | 原因 / 怎么改 |
| --- | --- |
| 「启用 / 禁用 / 删除」失败或没反应 | 那一项在 HKLM 或公共启动文件夹，需要管理员权限；点「以管理员身份重启」提权后再操作。 |
| 关掉某项后，系统任务管理器里也显示已禁用？ | 正常：两边读的是同一份 `StartupApproved` 数据。想彻底删除请用「删除」。 |
| `RunOnce` 项禁用了还是自启一次 | Windows 对 `RunOnce` 没有单独的 StartupApproved 键，「禁用」对它实际不生效（它下次开机仍执行一次再自我删除）；要阻止请直接「删除」。 |
| 列表是空的 | 系统里确实没有开机启动项，或读某些来源被权限 / 组策略挡住（只跳过该来源，不报错）。 |
| 删除后程序还在 | 「删除」只删启动记录 / 快捷方式，**不会卸载程序本身**。 |

## 自检

`startup-manager` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/StartupManagerChecks.cs`）覆盖：

- 工具元数据（Id / 名称 / 分类 / 排序 / 标签 / 描述）；
- 启动项显示文本（来源 / 状态 / 命令摘要截断）；
- **只读**扫描本机全部启动项（不写注册表、不删除任何启动项）。
