# 🎥 录屏 / GIF

> 用系统 FFmpeg 的 `gdigrab` 采集屏幕：**全屏 / 框选区域 / 指定窗口 → GIF（两遍调色板，颜色准、体积可控）
> 或 MP4（H.264）**，也能一键截 PNG；带倒计时、置顶控制条、F8 全局停止热键和最长录制时长。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

### ① 三种录制来源

- **全屏（主显示器）**：直接录主屏。多显示器想录第二块就用「区域」框选。
- **区域**：点「框选区域…」弹出铺满所有显示器的浮窗，拖出矩形，**Enter 或「✓ 使用这个区域」确认**、
  **Esc / 右键 / 「取消」放弃**；会记住上次的区域，下次打开时预填。
- **窗口**：下拉框枚举当前**可见、有标题、没最小化**的窗口，录的是点「开始录制」时
  （倒计时之前）算出来的屏幕矩形 —— 之后窗口移动 / 缩放不会跟着走。列表按标题去重，同名窗口只出现一个。

### ② 两种输出格式 + PNG 截图

- **GIF（默认）**：两遍编码 —— 第一遍 `palettegen`（`stats_mode=diff`）统计调色板，第二遍
  `paletteuse` 套用，比直接录成 GIF 颜色准得多。可调颜色数 / 抖动 / 是否无限循环。
- **MP4**：把中间素材重新编码成 H.264（`libx264`）+ `+faststart`，网页 / 手机直接能播；CRF 18 / 23 / 28 三档。
- **PNG 截图**：点「📷 截图」按当前来源截一张；区域来源如果还没框选过，会先让你框选。

### ③ 录制控制

- 采集流程：FFmpeg `gdigrab` → 中间 MKV（`libx264 ultrafast`，只当临时素材）→
  **停止时向 FFmpeg 的 stdin 写 `q`** 让它正常收尾，再转成最终文件（GIF 两遍 / MP4 一遍）。
- **倒计时** 0 / 3 / 5 / 10 秒；倒计时浮窗结束后才启动 FFmpeg，所以**倒计时不会被录进去**；
  倒计时中按 Esc / 点浮窗可取消。
- **置顶控制条**：计时 + 停止按钮，可按住拖动；区域录制时优先摆到区域外面，全屏时放屏幕右上角
  （可能会被一起录进去，见「注意 / 限制」）。
- **F8 全局停止热键**：切到别的窗口也能停；被别的软件占用时会提示，改用控制条 / 本页按钮。
- **最长录制时长**：到点由 FFmpeg 自己退出，工具监听到之后自动停止并生成文件。
- 录制中选项会禁用，避免中途改参数导致收尾对不上；采集在后台进程里跑，切走页面 / 切到别的窗口不受影响。

### ④ 文件与最近生成

- 文件名 `前缀-日期-时间.gif`（默认前缀「录屏」，例如 `录屏-20260102-030405.gif`），重名自动加 ` (2)`、` (3)`。
- 生成后默认自动打开输出文件夹。
- 「最近生成（本次运行）」最多 30 条，可打开文件 / 在文件夹中显示 / 复制最近一次路径 / 清空列表。

## 怎么用

1. 第一次用先确认 FFmpeg：工具会自动从「配置里的路径 → `PATH` → 常见安装位置」找 `ffmpeg.exe`；
   找不到就点「选择 FFmpeg…」手动指定，或点「下载 FFmpeg」去 gyan.dev 的下载页。
   **FFmpeg 是全局设置**，和音频工具共用。
2. 选来源：**全屏** / **区域**（点「框选区域…」拖框，Enter 确认）/ **窗口**（下拉选一个，点「刷新窗口」重新枚举）。
3. 选格式与参数：GIF 或 MP4、帧率、输出宽度；GIF 再选颜色数 / 抖动 / 是否循环，MP4 再选画质。
4. 设置录制行为：是否录鼠标光标、倒计时、最长录制、置顶控制条、F8 热键、生成后是否自动打开文件夹。
5. 点「● 开始录制」；设了倒计时就等它走完，然后开始采集。
6. 停止：按 **F8**，或点置顶控制条上的停止，或回到本页点「■ 停止录制」。
   停止后自动生成文件；GIF 要跑两遍，状态栏 / 运行日志会显示进度。
7. 生成完可以在「最近生成」里打开，或点「📂 输出文件夹」直接去保存位置。
   想换保存目录 / 文件名前缀，在「④ 保存位置」里改（改一下自动保存）。

## 界面布局

- 四个可拖区块：
  - 左「**录制设置**」：① 录制来源 ② 输出格式与参数 ③ 录制行为 ④ 保存位置，最下面是 FFmpeg 状态；
  - 右上「**录制控制**」：计时、开始 / 停止按钮、状态提示、最近一次输出路径、📷 截图与 📂 输出文件夹；
    生成 GIF / MP4 时会显示进度条和「取消生成」按钮（取消后中间素材留在缓存里）；
  - 右下「**最近生成（本次运行）**」；
  - 底部「**运行日志**」。
- 分隔条：`screen-recorder.设置与控制`（左右）、`screen-recorder.控制与最近生成`（上下）、
  `screen-recorder.主区域与日志`（上下）。松手自动记住（`Config\layout.json`），**双击**某条只恢复这一处；
  全部恢复默认：**主页设置 →「界面布局 → 恢复默认布局」**。

## 设置项

### 录制设置（默认值）

| 界面上的选项 | 可选值 | 默认 |
| --- | --- | --- |
| 来源 | 全屏（主显示器）/ 区域（拖框选择）/ 窗口（录这个窗口的位置） | 区域 |
| 格式 | 动图 GIF（两遍调色板）/ 视频 MP4（H.264） | GIF |
| 帧率 | 5 / 10 / 15 / 20 / 24 / 30 FPS | 15 FPS |
| 输出宽度 | 原始分辨率 / 1920 / 1280 / 960 / 800 / 640 / 480 px（**只缩小，不放大**） | 960 px |
| GIF 颜色数 | 256 / 128 / 64 色 | 256 色 |
| GIF 抖动 | Floyd–Steinberg / 有序（`bayer`）/ 无 | Floyd–Steinberg |
| GIF 无限循环 | 开 / 关（关 = 只播一遍） | 开 |
| MP4 画质 | 高画质 CRF 18 / 标准 CRF 23 / 小体积 CRF 28 | CRF 23 |
| 录制鼠标光标 | 开 / 关 | 开 |
| 开始前倒计时 | 0 / 3 / 5 / 10 秒 | 3 秒 |
| 最长录制 | 不限制 / 30 秒 / 1 分钟 / 2 分钟 / 5 分钟 | 不限制 |
| 录制中显示置顶控制条 | 开 / 关 | 开 |
| 允许按 F8 停止录制 | 开 / 关 | 开 |
| 生成后自动打开输出文件夹 | 开 / 关 | 开 |
| 输出文件夹 | 任意目录 | `视频\YuLiangToolkit 录屏` |
| 文件名前缀 | 任意文字（非法字符自动替换，最长 40 字符） | `录屏` |

> 上面所有选项都存 `Config\screen-recorder\config.json`，**改一下就自动保存，没有「保存」按钮**；
> FFmpeg 路径存在 `%AppData%\YuLiangToolkit\settings.json`，是**全局设置**（和音频工具共用）。
> 手改 config 时：帧率 / 宽度 / 颜色数 / 画质 / 倒计时 / 最长录制会**吸附到最近的界面档位**，
> 文件名前缀里的非法字符会替换成 `_`；坏值不会让录制崩掉（正数宽度 / 时长不会被吸成「原始 / 不限」）。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\screen-recorder\config.json` | 所有选项（来源 / 区域坐标 / 窗口标题 / 格式 / 帧率 / 宽度 / GIF / MP4 / 行为 / 输出文件夹 / 前缀） |
| `Cache\screen-recorder\capture-*.mkv` | 中间素材；生成成功后自动删除，**失败 / 取消 / 退出生成超时会留着**，可在「主页设置 → 清理缓存」里清掉 |
| `%AppData%\YuLiangToolkit\settings.json` | 全局 FFmpeg 路径，和音频工具共用 |
| `Data\screen-recorder\` | 不使用（结果写到你选的输出文件夹） |

## 注意 / 限制

- **不录声音**：`gdigrab` 只采画面。要录系统声音得装虚拟声卡（例如 virtual-audio-capturer），本工具不装、也不提供声音选项。
- **`gdigrab` 是 GDI 截屏**：部分**独占全屏游戏 / HDR / 受保护内容**可能录成黑屏或颜色不对；遇到就把游戏设成**窗口化 / 无边框**。
- **窗口来源不跟随移动**：矩形在点「开始录制」时就定下了（倒计时期间移动也不会重算），之后拖动 / 缩放窗口，画面不会跟着变（区域同理，区域是固定坐标）。
- **全屏 = 主显示器**：多显示器先用「区域」框选；程序是系统 DPI 感知，**多屏各自缩放不同时框选坐标会按系统缩放换算，副屏上可能明显偏移**——混合缩放的多屏建议先把显示缩放统一（或改用全屏 / 固定窗口）。
- **帧率上限 30**。GIF 文件大小由「宽度 × 帧率 × 颜色数 × 时长」共同决定，建议 GIF 用 10~15 FPS、960 px 宽以内；
  实在太大就降宽度 / 颜色数 / 帧率，或改用 MP4。
- **全屏录制时置顶控制条可能被一起录进去**（GDI 截屏没法保证排除）；想要完全干净就关掉「显示控制条」，用 F8 停止。
- 录制区域最小 16×16；如果上次框选的区域已经不在屏幕上（换分辨率 / 拔了副屏），会提示重新框选。
- 程序**退出时如果还在录**，会尽量在 20 秒内把文件生成完；失败就把中间素材留在 `Cache\screen-recorder\`，下次可以手动转或清理掉。
- GIF 是两遍编码（统计调色板 + 合成），比 MP4 慢一些；录制越久、尺寸越大，生成文件等得越久。
