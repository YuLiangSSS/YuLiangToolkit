# 🎥 录屏 / GIF

> 用系统 FFmpeg 的 `gdigrab` 采集屏幕：**全屏 / 框选区域 / 指定窗口** → **GIF**（两遍调色板）
> 或 **MP4 / MKV / MOV / AVI / WebM**（H.264 / H.265 / AV1 / VP9 / MPEG-4 / MJPEG 编码器可选）；
> 支持**麦克风 + 系统声音**、**摄像头预览与屏幕叠加**、**可自定义的全局快捷键**，也能一键截 PNG。

## 能做什么

### ① 三种录制来源

- **全屏（主显示器）**：直接录主屏。多显示器想录第二块就用「区域」框选。
- **区域**：点「框选区域…」弹出铺满所有显示器的浮窗，拖出矩形，**Enter / 「✓ 使用这个区域」确认**、
  **Esc / 右键 / 「取消」放弃**；会记住上次的区域，下次打开时预填。
- **窗口**：下拉框枚举当前**可见、有标题、没最小化**的窗口，录的是点「开始录制」时
  （倒计时之前）算出来的屏幕矩形 —— 之后窗口移动 / 缩放不会跟着走。列表按标题去重，同名窗口只出现一个。

### ② 输出：GIF 或五种视频容器

- **GIF（默认）**：两遍编码 —— 第一遍 `palettegen`（`stats_mode=diff`）统计调色板，第二遍
  `paletteuse` 套用，比直接录成 GIF 颜色准得多；可调颜色数 / 抖动 / 是否无限循环。**GIF 不含声音。**

**五种视频容器：**

| 容器 | 说明 |
| --- | --- |
| **MP4** | 最通用，网页 / 手机 / 剪辑软件都认；写 `+faststart`（边下边播） |
| **MKV** | 兼容性最好，几乎所有编码都能装；不需要 `+faststart` |
| **MOV** | 苹果 / 剪辑软件常用；写 `+faststart` |
| **AVI** | 老播放器 / 老剪辑软件；音频用 MP3 |
| **WebM** | 网页用；默认 VP9 + Opus |

**编码器可选**（界面只列出本机 FFmpeg 真的支持、且和当前容器兼容的项；检测失败时按容器兼容性兜底）：

| 编码 | 界面里的编码器 | 能装进的容器 |
| --- | --- | --- |
| H.264 | `libx264`（软件，最稳）/ `h264_nvenc` / `h264_amf` / `h264_qsv` | MP4 / MKV / MOV / AVI |
| H.265（HEVC） | `libx265`（软件，体积小）/ `hevc_nvenc` / `hevc_amf` / `hevc_qsv` | MP4 / MKV / MOV |
| AV1 | `libsvtav1`（软件，压缩率高）/ `av1_nvenc` / `av1_amf` / `av1_qsv` | MP4 / MKV / MOV / WebM |
| VP9 | `libvpx-vp9`（软件，WebM 常用） | WebM / MKV |
| MPEG-4 Part 2 | `mpeg4`（老播放器 / AVI） | AVI / MKV / MP4 / MOV |
| Motion JPEG | `mjpeg`（AVI 剪辑） | AVI / MOV / MKV |

- NVIDIA NVENC / AMD AMF / Intel QSV 属于**硬件编码**：需要显卡和驱动支持，不可用就换回软件编码。
- 默认编码器是 `libx264`；**WebM 默认 VP9**（本机没有 VP9 时用列表里第一个可用编码器）。
- **画质 / 码率二选一**：
  - **画质优先**（默认）：CRF / CQ 0~51（=0 最清晰文件最大、=51 最省空间，常用 18~28）；
  - **码率优先**：目标码率 1~100 Mbps。
- **视频只编码一次**：录制时先按选定编码器写中间 MKV，停止后只做「**封装 + 混音**」（视频流 `-c:v copy`），
  所以生成很快。H.265 进 MP4 / MOV 会自动加 `hvc1` 标记（苹果设备 / 剪辑软件兼容）。
- **输出宽度**：视频格式在采集阶段就缩放到目标宽度（只缩不放、不二次编码）；GIF 在合成时按滤镜缩放。

### ③ 声音（仅视频格式）

- **两路可分别开关、任意组合**：
  - **麦克风**：系统默认麦克风（WASAPI）；
  - **系统声音（扬声器回环）**：WASAPI loopback 直接录电脑正在播放的声音，**不需要装虚拟声卡**。
- **音量滑块 0~200%**（100% = 原始音量），**录制中拖动实时生效**，不用重新开录。
- 停止后自动混进视频：音频码率 128 / 192 / 256 kbps；容器决定编码 ——
  **MP4 / MKV / MOV 用 AAC、AVI 用 MP3、WebM 用 Opus**；两路都有就混音，只有一路就单轨。
- **音画自动对齐**：声音比画面晚启动的毫秒数会记下来，收尾时用 `adelay` 补静音，不会出现声音越录越晚。
- 某一路启动失败 / 录制中被拔设备，**只记日志、继续录画面**；完全没采到数据的音轨不会硬塞进视频。

### ④ 摄像头（预览 / 屏幕覆盖）

- **启用摄像头** → 下拉选设备（可「刷新」）→ 页面内**实时预览**，默认**左右镜像**（自拍习惯，可关）。
- **摄像头屏幕覆盖**：把摄像头画面做成一个**置顶无边框小窗**叠在屏幕上：
  - 可**拖动**移动、**滚轮缩放**（宽度 120~800 px）、**右键菜单**（左右镜像 / 重置到屏幕右下角 / 关闭摄像头覆盖）；
  - 预览时先把它拖到目标窗口的角落摆好，**开始录制后 gdigrab 会把它一起录进画面**（OBS 那种摄像头叠加效果）；
  - 不想要叠加就隐藏覆盖（或一开始就不打开），此时摄像头不录进画面；
  - 覆盖窗口**故意做成普通不透明窗口**（不是分层 / 透明穿透窗口），避免 gdigrab 的 BitBlt 抓不到或抓成黑块；
    界面里的「不透明度」是画面和黑底混合的比例，不是窗口穿透。
- 摄像头默认**关**，屏幕覆盖默认**关**，镜像默认**开**；录制中也能随时开关预览 / 覆盖，
  但画面里只会**从打开那一刻起**出现。

### ⑤ 可自定义的全局快捷键

- 两枚：**开始 / 停止录制**（默认 `F8`）、**截图**（默认未设置），可分别「设置…」。
- 点「设置…」弹出「按下新的快捷键」对话框：直接按组合键，**Enter / 保存**确认、**Esc 取消**；
  无效组合用红字说明原因。按 Esc 关掉对话框不会改掉原来的快捷键。
  - `F1`~`F24` 可以单独用；
  - 字母 / 数字 / Space（以及 Tab、方向键等）**必须带** Ctrl / Alt / Shift / Win 之一。
- 有**启用开关**；注册失败（组合被别的软件占用等）会在**录制控制卡右上角**和**运行日志**里提示，换一个组合即可。
- **开始 / 停止**热键空闲时也能直接启动录制；长按只触发一次（不会狂切）。

### ⑥ 录制控制与文件

- **倒计时** 0 / 3 / 5 / 10 秒；倒计时浮窗结束后才启动 FFmpeg，所以**倒计时不会被录进去**，
  倒计时中按 Esc / 点浮窗可取消。
- **置顶控制条**：计时 + 停止按钮，可拖动；区域录制时优先摆到区域外面，全屏时放屏幕右上角。
- **最长录制时长**：到点由 FFmpeg 自己退出，工具监听到后自动停止并生成文件。
- 录制流程：`gdigrab` → 中间 MKV → **停止时向 FFmpeg 的 stdin 写 `q`** 正常收尾 → 封装 / 混音（视频）
  或两遍调色板（GIF）；生成过程中可以点「**取消生成**」（不会留下半成品，中间素材保留在缓存）。
- 文件名 `前缀-日期-时间.扩展名`（默认前缀「录屏」，例如 `录屏-20260102-030405.mp4`），重名自动加 ` (2)`、` (3)`。
- 生成后默认自动打开输出文件夹；「最近生成（本次运行）」最多 30 条，可打开 / 在文件夹中显示 /
  复制最近一次路径 / 清空。

## 怎么用

1. 第一次用先确认 FFmpeg：工具会自动从「配置里的路径 → `PATH` → 常见安装位置」找 `ffmpeg.exe`；
   找不到就点「选择 FFmpeg…」手动指定，或点「下载 FFmpeg」去 gyan.dev 的下载页。
   **FFmpeg 是全局设置**，和音频工具共用；录屏、转 GIF、混音都靠它。
2. 选来源：**全屏** / **区域**（点「框选区域…」拖框，Enter 确认）/ **窗口**（下拉选一个，点「刷新窗口」重新枚举）。
3. 选**格式**：GIF 或 MP4 / MKV / MOV / AVI / WebM；视频再选**编码器**、**速率控制**（画质优先 / 码率优先）
   和画质 / 码率滑块。
4. （视频格式）设置**声音**：勾「录制麦克风」/「录制系统声音」，拖音量滑块，选音频码率。
   GIF 没有声音选项。
5. （可选）设置**摄像头**：勾「启用摄像头」→ 选设备 →「开启预览」看画面；
   要叠加进画面就点「显示屏幕覆盖」，把它拖到角落摆好（再点一次隐藏）。
6. （可选）设置**快捷键**：确认「启用全局录制快捷键」勾着；点「开始 / 停止」或「截图」旁的「设置…」，
   按下组合键后 Enter 保存；截图热键可以用「清除」取消。
7. 设置**录制行为与保存位置**：鼠标光标、倒计时、最长录制、置顶控制条、生成后是否自动打开文件夹、
   输出文件夹、文件名前缀。
8. 点「● 开始录制」→ 倒计时结束开始采集 → 想停时按**快捷键（默认 F8）** / 点控制条 / 回到本页点
   「■ 停止录制」→ 自动生成文件。视频格式只做封装 + 混音（很快），GIF 要跑两遍（慢一些），
   状态栏 / 运行日志会显示进度；生成中可点「取消生成」。

## 界面布局

- 四个可拖区块：
  - 左「**录制设置**」：① 录制来源 ② 输出格式与画质（GIF 专属 / 视频编码）③ 声音 ④ 摄像头
    ⑤ 全局快捷键 ⑥ 录制行为 ⑦ 保存位置，最下面是 FFmpeg 状态；
  - 右上「**录制控制**」：计时、开始 / 停止、生成进度 + 取消生成、状态、最近输出路径、
    画面 / 声音 / 摄像头摘要、📷 截图与 📂 输出文件夹；
  - 右下「**最近生成（本次运行）**」；
  - 底部「**运行日志**」。
- 分隔条：`screen-recorder.设置与控制`（左右）、`screen-recorder.控制与最近生成`（上下）、
  `screen-recorder.主区域与日志`（上下）。松手自动记住（`Config\layout.json`），**双击**某条只恢复这一处；
  全部恢复默认：**主页设置 →「界面布局 → 恢复默认布局」**。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\screen-recorder\config.json` | 所有选项（来源 / 区域 / 窗口标题 / 格式 / 编码器 / 画质码率 / 帧率 / 宽度 / GIF / 声音 / 摄像头 / 快捷键 / 行为 / 输出路径 / 前缀） |
| `Cache\screen-recorder\capture-*.mkv` | 画面中间素材；生成成功后自动删除，**失败 / 取消 / 退出生成超时会留着**（GIF 的 `*.palette.png` 调色板临时文件会自动删） |
| `Cache\screen-recorder\mic-*.wav`、`speaker-*.wav` | 录制的麦克风 / 系统声音原始音轨；混音成功自动删除，失败或取消时保留 |
| `%AppData%\YuLiangToolkit\settings.json` | 全局 FFmpeg 路径，和音频工具共用 |
| `Data\screen-recorder\` | 不使用（结果写到你选的输出文件夹） |

> 中间素材 / 音轨都在 `Cache` 里，可以在「主页设置 → 清理缓存」一键清掉。

## 注意 / 限制

- **GIF 不含声音**：声音只有视频格式（MP4 / MKV / MOV / AVI / WebM）才有；选了 GIF 时声音设置整块不显示。
- **`gdigrab` 是 GDI 截屏**：部分**独占全屏游戏 / HDR / 受保护内容**可能录成黑屏或颜色不对；遇到就把游戏设成
  **窗口化 / 无边框**。
- **摄像头覆盖只有在屏幕上看得见时才会被录进画面**：独占全屏游戏、锁屏、窗口最小化后都无效；
  它本质是一个真实屏幕窗口，所以要「先摆好位置再录」。
- **声音用系统默认设备**：麦克风用系统默认麦克风、系统声音用默认播放设备；**界面里不能挑具体音频设备**
  （想换设备先去 Windows 声音设置改默认）。录制中换了默认设备 / 拔掉设备，这一路声音会停并记日志。
- **系统声音在完全无声时可能没有音轨**：回环采不到任何数据时不会硬塞一条空音轨。
- **硬件编码器不保证可用**：NVENC / AMF / QSV 依赖显卡和驱动，FFmpeg 打不开时换回软件编码
  （H.264 最稳）；需要更小体积可以试软件 `libx265` / AV1（编码更慢）。
- **画质模式默认用 `veryfast`**（软件 H.264 / H.265）或硬件默认速度，优先保证实时采集不卡机；
  追求更小体积可以换编码器，但注意别让采集掉帧。
- **窗口来源不跟随移动**：矩形在点「开始录制」时就定下了（倒计时期间移动也不会重算），之后拖动 / 缩放窗口，
  画面不会跟着变（区域同理，区域是固定坐标）。
- **全屏 = 主显示器**：多显示器先用「区域」框选；程序是系统 DPI 感知，多屏各自缩放不同时，
  框选坐标按系统缩放换算，副屏上可能明显偏移 —— 混合缩放的多屏建议先把显示缩放统一（或改用全屏 / 固定窗口）。
- **帧率上限 30**。GIF 文件大小由「宽度 × 帧率 × 颜色数 × 时长」共同决定，建议 GIF 用 10~15 FPS、960 px 宽以内。
- **全屏录制时置顶控制条可能被一起录进去**（GDI 截屏没法保证排除）；想要完全干净就关掉「显示控制条」，
  用快捷键停止。
- 录制区域最小 16×16；如果上次框选的区域已经不在屏幕上（换分辨率 / 拔了副屏），会提示重新框选。
- **快捷键被占用时会提示**（控制卡右上角 + 日志），换一个组合即可；字母 / 数字不带修饰键不允许单独注册。
- 程序**退出时如果还在录**，会尽量在 20 秒内把文件生成完；失败就把中间素材留在 `Cache\screen-recorder\`，
  下次可以手动清理。
- GIF 是两遍编码（统计调色板 + 合成），比视频格式慢；视频格式停止后只封装 + 混音，通常很快。
