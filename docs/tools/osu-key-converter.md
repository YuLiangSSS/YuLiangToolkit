# 🎹 osu! Key 转换器

> 把**低键数**的 osu!mania 谱面「扩」成更高键数：随机挑原谱的列复制 / 插入到新列里，
> 可以留出若干空白列降低密度、按时间清子弹；新谱面按元数据自动改名、写回原谱面所在目录。

> 主页上归在「**音游工具**」类别里：点类别卡片进类别页，顶部面包屑（`主页 › 音游工具 › osu! Key 转换器`）
> 可以点回上一级。同一个类别下还有 osu! 下图器 / LN 转换器 / 等级计算器。

## 能做什么

- **低 K → 高 K**：4K→7K、7K→10K 都可以。**只支持低转高**，目标键数必须大于源谱面键数
  （源 1~9K、目标 2~10K）。
- 一次拖一整批：`.osu` 文件或文件夹（递归查找），列表里显示每个文件的键数与状态；
  带进度条、日志、取消；单个文件失败不会中断整批。
- 参数全都能调：目标键数、转换间隔 Gap、去子弹 Clean、空白列 Blank、随机种子、替换谱师，
  以及「只转哪些源键数」（1K~9K 勾选框）。
- **固定随机种子 = 结果可复现**：同一张谱、同一套参数，每次转出来完全一样（方便对比 / 回滚）。

## 区块布局（可拖拽）

v0.41.0 起，这一页的区块大小可以自己拖（**① 文件列表 / ② 转换参数 / ③ 进度与日志 三个区块的相邻边都有缝**）：

- **① 文件列表 ↔ ② 转换参数**：两者中间那条横缝能上下拖（鼠标移上去亮蓝线、光标变 **↕**），列表 / 参数卡跟着变高变矮；
- **①、② ↔ ③ 进度与日志**：左边这一列和右边的日志卡之间那条竖缝能左右拖（**↔**）—— ③ 竖跨整个主体高度，
  它和 ①、② 的边界本来就是同一条连续边，所以一条缝同时管这两段（不是漏做：再拆成两条会争同一列宽度）；
- 三个区块内容多了都各自内部滚动，拖矮不会裁内容；拖完自动记住（`Config\layout.json`），
  下次打开还是调好的样子；**双击**某条缝只恢复这一处；全部恢复默认在 **主页设置 →「界面布局 → 恢复默认布局」**。

> 平时缝隙只留一条淡淡的提示线（默认 **18%** 透明度）；鼠标移上去才亮起蓝线。提示线浓淡在
> **主页设置 →「界面布局 → 分隔条提示线（鼠标不在上面时）」** 里调（**0% = 完全看不见**、**100% = 一直显示实心蓝线**）。

（实现约定见 [docs/dev/layout.md](../dev/layout.md)。）

## 怎么用

1. 打开工具，把 `.osu` 文件或文件夹拖到页面任意位置（或点「选择文件…」）。
   文件夹会**递归**找所有 `.osu`；重复文件自动去重。列表会逐个读出键数（4K / 7K…）。
2. 在「② 转换参数」里调参数 —— **改一下自动保存**，不用点保存。
   不熟悉参数就点右上角「参数说明 ▾」展开完整解释。
3. 点右下角「**开始转换**」。进度条、统计文字、日志实时刷新；中途可以点「取消」
   （当前文件处理完就停，已处理的结果保留）。
4. 结束后看统计：「共 N 个：成功 x · 跳过 y · 失败 z」，日志里每个文件都写了
   输出路径 / 跳过原因 / 失败原因。点「打开输出文件夹」直接跳到输出目录。
5. **新文件在哪**：写在**原谱面所在目录**，文件名按谱面元数据拼成
   `{艺术家} - {标题} ({谱师}) [{难度名}].osu`（自动删掉 Windows 非法字符）。
   工具会把难度名前缀改成 `[4To7C]` / `[4To7C2B]` 这类，所以新文件名与原谱不同 —— 正常不会覆盖原谱。

## 参数说明

| 参数 | 范围 / 默认 | 说明 |
| --- | --- | --- |
| 目标键数 | 2 ~ 10，默认 **8** | 想转成几 K。必须大于源谱面键数；转出来的难度名会带 `[源K To 目标K C]` 前缀 |
| 转换间隔 Gap | 0 ~ 20，默认 **10** | 每隔多长一段重新抽一次「复制哪些列」。数字越大，每次参与复制的音符段越短、整谱换列越频繁；`0` = 整张谱一次处理完 |
| 去子弹 Clean | 0 ~ 16，默认 **4** | 清掉 `1/Clean` 拍内的二连音（`4` = 清掉 1/4 拍内重复的键）；`0` = 不去重 |
| 空白列 Blank | 0 ~ 9，默认 **0** | 随机把若干复制出来的列留空，用来降低高键数谱面的密度；实际最多到「目标键数 − 源键数」 |
| 随机种子 | 默认 **114514** | 固定种子结果可复现；**清空**则每次随机 |
| 替换谱师为 | 默认不勾 | 勾选且填了名字才替换；不勾时**在原谱师后追加** ` & KeyConverter` |
| 源键数过滤 | 1K ~ 9K，默认全不勾 | 勾了哪些就只转哪些源键数的谱面；**一个都不勾 = 全部转换** |

> Gap 的实际含义：`gap_ms = 29998.8584 × e^(−0.3176 × Gap) + 347.7248`（Gap=0 时无限大）。
> 例如 Gap=10 约等于每 1.6 秒切一块、Gap=20 约 0.4 秒切一块 —— 数字越大，谱面越“碎”。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\osu-key-converter\config.json` | 上面全部参数（改一下自动保存，没有「保存」按钮） |
| 输出 | 与**源谱面同目录**的新 `.osu`（难度名带 `[4To7C]` 前缀、谱师带 ` & KeyConverter`） |

> ⚠️ **文件列表不持久化**：关掉工具 / 切到别的页面后，列表就清空了（参数会保留）。
> 工具**不联网、不读用户目录**，只处理你拖进来的文件。

## 注意

- **只支持低转高**：源 10K、目标键数 ≤ 源键数、或源键数不在勾选的过滤范围里，都会**跳过**并写原因；
  `.osu` 以外的文件会被忽略。
- **可能覆盖同名文件**：新文件名由元数据决定，**如果目标目录里已经有同名文件，会直接覆盖且没有备份**
  （用同一套参数重复转同一张谱时就是覆盖上一次的输出）。重要谱面建议先自己拷一份。
- **打击音效 / 采样会保留**：重建音符时 HitSound / Hitsample 不会丢成默认值。
- **Clean = 0 = 不做去重**（不会误删音符）。
- **支持 1K / 2K 源谱面**（列坐标用通用公式，不会越界）。
- 转出来的音符**按时间重新排序**（同一时刻多个音的顺序不保证，不影响玩法）。
- **解析/写回用 OsuParsers（MIT）**：它只认识标准 `.osu` 段落，写回时**未建模的键值、注释、自定义段落会丢失**；
  拿特别“脏”的谱面前建议先留一份原文件。
- 处理是**串行**的（解析库的编解码内部有静态状态、非线程安全），所以一批几百张就是会比并行的慢一点，
  同时也别同时开两个转换任务跑同一批文件。
- 参数、种子都存在 `Config\` 下；**输出文件本身不自动导入游戏**，要自己双击 `.osz` / 拖进 osu!。
