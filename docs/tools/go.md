# ⚫ 围棋

> 标准围棋：提子、禁自杀、**禁打劫**、停一手；9 / 13 / 19 路可调、贴目可调、中国规则数子。
> **电脑对手四档难度**；**局域网联机**，支持**观战**与**房主安排上场 / 自动换人**。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

> 在主页的 **🎲 棋牌** 类别里点进 围棋（面包屑：`🏠 主页 › 🎲 棋牌 › ⚫ 围棋`）。

## 能做什么

- **完整规则**：落子、提子（对方棋块没气就整块提掉）、**禁自杀**、**禁打劫**、停一手、认输、悔棋（单机）。
- **棋盘**：9 路（快棋）/ 13 路（中盘）/ 19 路（标准），切换后开新局生效。
- **计分**：中国规则数子 —— 自己的子 + 自己围住的空点，**白方加贴目**（可选 5.5 / 6.5 / 7.5）。
  双方连续停一手自动终局；也可以随时点「数子」立即结算。
- **电脑对手**：四档难度，你执黑先手、电脑执白后手。
- **联机**：TCP 房间，最多 16 人；两个人上场对弈，其余人**观战**；
  房主可安排上场、设**自动换人**（手动 / 输的下场 / 全场换人）——跟五子棋、象棋完全一致。

## 打劫怎么判

判劫用的是最严谨的定义：**落完之后如果棋盘跟「上一手之前」完全一样，就是打劫**，
这一手会被拒绝（提示「打劫：不能立刻回提」）。先在别处走一手（或停一手）就能回提了。

## 电脑对手（四档智慧程度）

右侧「设置 → 电脑对手」：勾上「开」就是**你 vs 电脑**（关掉还是同机双人轮流下）。

| 难度 | 说明 |
| --- | --- |
| **入门** | 会在候选里随机挑，会下出明显坏棋，适合练手 |
| **普通** | 纯启发式（提子 / 打吃 / 连接 / 角边优先），正常水平（默认） |
| **困难** | 对前几个候选做随机模拟，挑胜率最高的 |
| **大师** | 模拟次数更多，比较难赢 |

电脑的启发式考虑：能提子就提、自己被叫吃时逃、能连就连、开局靠角靠边、别下在天涯海角、别往虎口里送。

## 怎么玩

1. 点「同机双人」或「开房间」，或直接点「新开一局」单机玩（开了电脑对手就是跟电脑下）。
2. 点棋盘交叉点落子；轮到你时才能下（顶部「轮到 黑棋/白棋」）。
3. 不想下这点就点「停一手」；双方都停一手自动终局并数子。
4. 单机可以「悔棋」；联机时不提供（会跟对方不同步）。

## 联机 + 观战 + 换人

1. 房主填玩家名、端口留 `0`，点「开房间」，把地址复制给朋友。
2. 朋友粘地址点「加入房间」。
3. 房主在「房间成员」里用**席位下拉**安排哪两个人上场，其余人自动是**观战**（能看不能下）。
4. 房主可设**换人方式**：手动安排 / 输的下场换下一位 / 全场换人；补位可选轮流或随机。
5. 一局结束后按设置自动换人，观战者也能顶上来。

## 设置项

存 `Config\go\config.json`：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 棋盘 | 19 路 | 9 / 13 / 19 |
| 贴目 | 7.5 | 白方额外加 |
| 玩家名 | 空 | 联机时对方看到的名字 |
| 开房端口 | 0 | 0 = 自动挑 |
| 换人方式 | 手动安排 | 手动 / 输的下场 / 全场换人 |
| 补位方式 | 轮流上场 | 轮流 / 随机 |
| 电脑对手 | 开 | 同机时是否由电脑接管白方 |
| 电脑难度 | 普通 | 入门 / 普通 / 困难 / 大师 |

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 点棋盘没反应 | 只在轮到你、且你坐在席位上时才能落子 |
| 提示「打劫：不能立刻回提」 | 正常规则：先在别处走一手，或停一手 |
| 提示「禁自杀」 | 下在这里自己这块棋没气，且也没提到对方子 |
| 点「停一手」后直接结束了 | 对方也停了一手 → 双方连续停一手即终局并数子 |
| 联机时悔棋不可用 | 联机不做悔棋（会跟对方不同步） |

## 自检

`go` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/GoChecks.cs`）：落子 / 占位 / 越界 / 回合校验、
提子（单子与整块）、禁自杀、**打劫判定（用自动搜索构造真实劫形验证）**、停一手与双方停一手终局、
中国规则数子（子 + 地 + 贴目）、悔棋 / 认输、快照往返、AI（四档难度合法落点 / 不会自杀 / 终局返回 null / 自我对弈）。
**纯逻辑，不建窗口、不联网。**
