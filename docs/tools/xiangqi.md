# 🀄 联机象棋

> 开一个 TCP 房间，和朋友联机下**中国象棋** —— 局域网直连，外网用**端口映射 / 内网穿透**。
> **一个房间最多 16 人**：只有坐在两个「上场位」上的两个人比赛，其余人**观战**；
> **房主安排谁上场**，也可以开**自动轮换**（输的下场 / 双方都下场）。
> 同一台电脑上也能「同机双人」。除了标准开局，还能**自由摆棋**、**让子**（单马 / 双马 / 单车 / 车马 / 车马炮 / 九子）、
> **让先**（0~5 步），并带**中文记谱**。**不依赖任何第三方服务**，两端都是本程序。

> **界面布局可拖拽**（v0.41.0 起）：棋盘区与右侧栏之间、右侧栏里「信息区 / 房间聊天」之间的区块边界都能拖动
> （拖动时亮蓝线 + ↔ / ↕ 光标），松手自动记住；**双击**某条分隔条只恢复这一处；
> 全部恢复默认在 **主页设置 → 界面布局**。

## 能做什么

- **三种入口**：**同机双人**（一台电脑轮流走）/ **开房间**（房主）/ **加入房间**（客户端）。
- **多人房间（最多 16 人）**：房主 + 最多 15 个客户端。房间里有两种角色：
  - **选手**：坐在「**先手位（红方）**」或「**后手位（黑方）**」上的两个人；
  - **观战者**：其余所有人（包括没坐席位的房主）。
  右侧「**房间成员**」卡列出每个人：身份（房主 / 玩家）、位置（先手位 / 后手位 / 观战）、
  **已打几局**、在线 / 离线；顶部一行显示「你现在是什么身份」。
- **观战**：观战者能看到**实时棋盘**、房间聊天、成员列表和轮次/结果，但**不能走子、不能悔棋 / 求和 / 认输、
  不能开始下一局**；观战者掉线**不会**让对局暂停。
- **房主安排上场**（「**上场安排**」卡）：房主用两个下拉框把任意成员安排到先手位 / 后手位
  （**也可以把房主自己排上去**，或者留空位）；还有「**交换座位**」「**清空座位**」。
  - **对局进行中席位锁定**，等这一局结束才能换人；
  - 房主**不坐席位也能控制房间**（摆棋 / 安排人 / 自动轮换 / 开始下一局 / 结束本局），相当于裁判。
- **自动轮换**（每局结束后自动排好下一局上场的人，**但不会自动开始**——房主点「开始下一局」）：
  - **自动上场方式**：`手动安排`（默认，房主自己挑人）/ `输的下场`（赢家留场、输家下场换人）/
    `双方都下场`（两个人都换）；
  - **补位方式**：`轮流上场`（**没上过场的人优先**，同样场次按进房先后顺序）/
    `随机上场`（没上过场的人里随机挑，同场次的才随机）；
  - **平局**：`输的下场` 不轮换（没有输家）；`双方都下场` 照样换人；
  - **人数不够就回退**：`输的下场` 至少要有 1 个替补、`双方都下场` 至少要有 2 个替补，
    否则维持原上场（不会硬把同一个人排两次）；
  - **上场次数**：完整打完一局才 +1；作废的局、中途退出都不算 —— 补位时场次少的优先。
- **作废本局**（房主）：对局进行中想要重开，点「**结束本局（作废）**」**点两下确认**；
  作废不加分、席位不变，之后可以重新安排再开始。
- **完整中国象棋规则**：9 列 × 10 行，**红先**；**默认红方在下**（执黑 / 观战选黑方视角时黑方在下，见「棋盘朝向」一节）。
  车直行、马走日（**蹩马腿**）、相 / 象走田（**塞象眼**、不过河）、仕 / 士九宫斜走、帅 / 将九宫直走、
  炮隔一子吃 / 平移、兵 / 卒向前（**过河后可横走、不能后退**）。
- **将帅照面**（飞将）非法、**不允许走出「自己被将军」的棋**、被将军必须应将。
- **胜负**：**将死**判负；**困毙**（无合法着法且未被将军）在中国象棋里同样**判负**；
  连续 **120 个半回合**（双方各 60 步）无吃子 → **自然限着判和**。
- **自由摆棋**（用户点名要的自由度）：「摆棋与让子」卡片里
  - **棋子调色板**：红方 `帅仕相马车炮兵`、黑方 `将士象马车炮卒`、`删除` —— 选一个再点棋盘落子（覆盖原格）；
  - **「默认开局」**一键恢复标准布局（摆乱了不用一项项改回来），**「清空棋盘」**从头摆；
  - 摆错了会**实时提示**（见「摆棋校验」），有错时不能开房 / 开始对局；
  - **未开局时房主随时可以摆棋**（即使房主自己不上场）；对局进行中摆棋锁定：
    联机时先点「**房间成员**」卡里的「**结束本局（作废）**」（点两下确认）回到未开始，摆棋解锁，重新摆好再点「开始下一局」；
    同机双人时点「**重新摆棋（会结束本局）**」（先确认：确定结束 / 取消），重新摆好后再开始；
  - 同机双人同样可以先摆再下：调好后点「**应用并开始（同机双人）**」。
- **让子**：选「让子方」（红方 / 黑方），再点预设 —— **让单马 / 让双马 / 让单车 / 让车马 / 让车马炮 / 让九子**。
  「让子方」是**让子的一方**（强者），会从自己那边去掉对应的棋子。
- **让先**：`0~5` 步。被让方（让子方以外那方）在开局阶段可以**连续走 N 步**，N 步走完才恢复正常轮换。
- **对局辅助**：**走法提示**（点自己的棋子高亮它所有能走的位置）、**最后一步标记**、**显示坐标**。
- **棋盘朝向跟着你走**（用户点名要的体验）：**执红时红方在下方、执黑时黑方在下方**，棋盘自动朝向自己，
  不用手动翻转；**棋子文字 / 楚河汉界 / 坐标始终正向绘制**（只镜像落点位置，不会倒字）。
  **观战者（含不下场的房主）可以自由选红方视角还是黑方视角**，见下面「棋盘朝向」一节；
  同机双人 / 离线时也可以手动「翻转棋盘」。
- **中文记谱**：棋谱一行放两个半回合（红、黑各一），如 `1. 炮二平五    马8进7`；可一键复制整份棋谱。
- **悔棋 / 认输 / 求和 / 再来一局**：同机双人随时可悔；**联机只有场上的选手能发起**，
  请求要对方（或房主）点「同意」，同意后由主机应用并同步局面。
- **房间聊天**：所有人都能发文字（观战者也能）；系统提示（谁进来了 / 谁上场了 / 谁掉线了）会混在聊天记录里。
- **掉线不用重开**：**主机是权威**——**席上的选手**断网后主机**不重置棋局、不关房间**，
  显示「对局暂停 · 等席上的玩家重连回来」；掉线的人会**自动重连**（默认每 2 秒一次、最多 60 秒），
  回来时**保留原来的席位与上场次数**，拿到**当前最新局面**（含轮次 / 结果 / 让先剩余 / 棋谱）继续下。
  只有房主关房 / 主动离开才不重连。

## 怎么联机

### 主机：开房间

1. 主页「**棋牌**」类别 → 打开「**联机象棋**」。
2. 先在右栏「**房间**」里填：**玩家名**、**端口**（默认 `5311`，填 `0` 表示让系统自动挑）；
   **房主默认坐席**（先手位红方 / 后手位黑方）在「**摆棋与让子**」卡里改 —— 只影响**下次开房**，
   进房间后会禁用；开房之后要换席位，用「**上场安排**」。
   端口被占用时会提示「开房间失败」，改成 `0` 最省事。
3. 想摆棋 / 让子 / 让先就先在「摆棋与让子」里摆好（标准开局直接点「默认开局」）。
4. 点「**开房间**」。开好后界面列出本机的「**地址:端口**」（IPv4 / IPv6，最多 3 行、更多会折叠），
   可单独复制或「**复制邀请**」。**最多 16 人**，人满后新连接会提示「房间已满」。
5. 大家在「**房间成员**」里出现后，房主在「**上场安排**」里把两个人放到先手位 / 后手位
   （可以放自己；点「交换座位」「清空座位」调整），然后点「**开始对局**」——摆好的棋会一起同步，
   **双方都要等主机开始后才能走子**。

### 客户端：加入房间

1. 把对方发来的地址填进「**加入地址**」。**地址里要带端口**，例如 `192.168.1.5:5311`、
   IPv6 写成 `[fe80::1]:5311`；外网就是内网穿透工具给你的 `域名:端口`。只填 IP / 域名会被提示「请填写端口」。
2. 点「**加入房间**」。加入后默认是**观战**（能看到棋盘但不能走）；等房主把你安排上场、并点开始对局后，
   你会自动执对应的一边（先手位 = 红方、后手位 = 黑方），并且看到房主摆好的开局。

> 一台电脑上两个人轮流走：点「**同机双人**」即可（可以先摆棋再下）。
> 玩完点「**离开房间**」断开：房主离开 = 房间关闭；其他人离开 = 自动从成员表移除、若是选手会清空他的席位。
> 掉线会自动重连，想主动放弃就点「**停止重连**」。

## 自动轮换的排人规则

| 自动上场方式 | 一局结束后 | 平局时 |
| --- | --- | --- |
| 手动安排（默认） | 席位不动，等房主自己选 | 席位不动 |
| 输的下场 | 赢家留原席位，输家下场 → 替补 1 人 | 不轮换（没有输家） |
| 双方都下场 | 两个人都下场 → 替补 2 人 | 照样换人 |

- **替补从哪来**：所有**在线**、且**不在场上**的成员。
- **先补谁**：上场次数少的优先；次数一样时，`轮流上场` 按进房顺序（早进的先），
  `随机上场` 在这些同次数的人里随机挑（随机也**不会**打乱「没上过场的人优先」这条）。
- **排好之后不会自动开局**：聊天里会提示「已自动安排下一局」，房主确认后点「**开始下一局**」。
  下一局按「摆棋与让子」当前的设置重新开局（默认开局 / 让子 / 让先都照旧）。
- 候补不够时**保持原上场**并提示「没有可替换的选手，维持原上场」。

## 摆棋校验（哪些摆法不能开局）

自由摆棋在开房 / 开始对局前会校验，有错时界面会直接给出原因：

- 双方**各必须有且只有一个**帅 / 将；
- 帅 / 将必须在**自己的九宫**里；
- **将帅不能照面**（同一列且中间无子）；
- **不该走棋的一方不能正被将军**（轮到红走时，黑方不能被红方将军）。

## 中文记谱怎么读

- 红方路数从**红方视角由右往左**数 `一~九`，黑方路数从**黑方视角由右往左**数 `1~9`
  （屏幕上就是黑方从左往右数）。
- 格式：**起点路数 + 进 / 退 / 平 + 终点**，例：`炮二平五`（红炮从二路平到五路）、`马8进7`（黑马从 8 路进到 7 路）。
- 同一路上有多个**同种棋子**时用「前 / 后」区分（如 `前车进一`）。
- 棋谱列表**每行放两个半回合**（红、黑各一），复制出来就是一份可以贴给别人的完整棋谱。

## 棋盘朝向（执子方视角 / 观战视角）

棋盘方向由**你在这局里的身份**决定，不用自己翻：

| 你的身份 | 棋盘朝向 | 怎么切换 |
| --- | --- | --- |
| 坐席选手（执红） | 红方在下 | 自动跟随，不用切（棋盘下方有小字提示「视角：红方在下」） |
| 坐席选手（执黑） | 黑方在下 | 自动跟随，不用切 |
| 观战者（含不下场的房主） | 默认红方在下 | 棋盘下方「**观战视角**」下拉：红方视角 / 黑方视角，**切换立即生效并记住** |
| 同机双人 / 离线 | 默认红方在下 | 棋盘下方「**翻转棋盘**」按钮手动翻（再点翻回来） |

- **换座 / 换边后朝向自动变**：房主在「上场安排」里把你从红方换到黑方（或反过来），你的棋盘立刻转成对应视角。
- **坐席选手不要手动翻**：坐席和观战状态下不显示「翻转棋盘」按钮（观战用「观战视角」下拉），
  视角始终跟随「你执哪一方 / 你选的观战视角」，不会被刷新或收到棋局状态重置。
- **只镜像位置、不旋转文字**：翻转只影响格子的上下左右映射，棋子上的汉字、楚河汉界、坐标数字**始终正向**。
- 观战视角存在配置里（`spectatorViewSide`，默认 `red`），下次打开仍是你上次选的视角。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 玩家名 | `玩家` | 别人看到的昵称；同机双人也会显示 |
| 端口 | `5311` | 主机监听端口；`0` = 让系统自动挑一个空闲端口（界面上写「0 = 自动挑」） |
| 加入地址 | （空） | 客户端上次连的地址，下次自动填好（要带端口，如 `192.168.1.5:5311`） |
| 房主默认坐席 | 先手位（红方） | 开房时房主默认坐哪个席位（先手位 = 红方 / 后手位 = 黑方）；进房间后该下拉禁用，可在「上场安排」里改；你的棋盘视角自动跟随所执方 |
| 自动上场方式 | 手动安排 | 手动安排 / 输的下场 / 双方都下场（房主在「上场安排」卡里改） |
| 补位方式 | 轮流上场 | 轮流上场（没上过场优先 + 进房顺序）/ 随机上场（没上过场的人里随机） |
| 走法提示 | 开 | 选中自己的棋子时高亮所有可走点（吃子的位置用另一种圈） |
| 观战视角 | 红方视角 | 红方在下 / 黑方在下；只影响观战者自己的棋盘，切换后自动记住（棋盘下方也能直接切） |
| 最后一步 | 开 | 用方框标出上一步的起点和终点 |
| 显示坐标 | 开 | 棋盘边缘显示路数 / 行数 |

> 所有设置都是**改一下就自动保存**，没有「保存」按钮。设置存在 `Config\xiangqi\config.json`（见下）；
> 上次选的「让子方」「让先步数」也会记住，下次打开接着用。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\xiangqi\config.json` | 上面所有设置 + 上次的让子方 / 让先步数：玩家名 / 上次加入地址 / 端口 / 房主默认坐席 / **自动上场方式 / 补位方式** / 走法提示 / **观战视角** / 最后一步 / 显示坐标 |

- 联机**不开新的数据端口**：所有内容都走主机那一个 TCP 端口（内网穿透只映射它即可）。
- **`Data\xiangqi\` 这版没有用到**（对局不落盘，没有历史记录文件）；关掉工具或程序，这一局就结束了
  （想留棋谱请在「棋谱」卡片里点复制，自己存下来）。

## 注意

- **连接没有加密**（就是普通 TCP）。传敏感内容请只在可信网络里用，或者先套一层加密通道（VPN / 穿透工具的 TLS）。
- **一个房间最多 16 人**（房主 + 15 个客户端）：人满后新的连接会收到「房间已满」并断开，房间里原有的人不受影响。
- **只有席上的选手能走子**：观战者点棋盘不会有反应；房主会忽略非场上玩家的走子动作。
  「悔棋 / 求和 / 认输 / 再来一局」也只有席上的选手能用；房主不下场时作为裁判处理这些请求。
  **「再来一局」联机只有客户端坐席玩家在本局结束后显示「请求再来一局」**；房主不显示这个按钮（用「开始下一局」）；
  同机双人才是点「再来一局」直接重开。
- **对局暂停**：对局进行中如果**席位上有人掉线 / 席位空着**，所有人棋盘只读（「对局暂停」）；
  观战者掉线**不**暂停。席上的人重连回来、或房主换人并重开后恢复。
- **掉线与重连**：掉线的人自动重连（成员保留、席位保留、上场次数保留），棋局（含棋谱 / 轮次 / 让先）原样保留；
  重连中棋盘只读、不会重复加入；「离开房间」按钮会变成「**停止重连**」。
  **房主关房 / 主动离开不会自动重连**。
- **作废本局**要连点两次「结束本局（作废）」确认（3 秒内不点第二下自动取消）；作废**不加分**。
- **开房前摆好棋**：摆棋 / 让子 / 让先在开局时固定；对局进行中这些选项会被锁定。
  联机时房主点「结束本局（作废）」（点两下确认）回到未开始 → 摆棋解锁 → 重新摆好再「开始下一局」；
  同机双人则用「重新摆棋（会结束本局）」（会先确认；该局不计入上场次数）。
- **视角**：坐席选手的棋盘方向自动跟随所执的一边（执黑则黑在下），棋子文字始终正向；
  **观战视角只影响观战者自己**（房主不下场时按观战视角，不受场上选手影响），切换后会记住。
- **悔棋语义**：主机按「撤到请求方该走」处理 —— 如果最后一步是对方走的就撤 2 步、是请求方自己走的就撤 1 步；
  一步都没走时撤不了，会提示。
- **自然限着**按「连续 120 个半回合无吃子」判和，和正式比赛的长将长捉等细则不同，日常对弈够用。
