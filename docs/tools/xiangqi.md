# 🀄 联机象棋

> 开一个 TCP 房间，和朋友联机下**中国象棋** —— 局域网直连，外网用**端口映射 / 内网穿透**。
> 同一台电脑上也能「同机双人」。除了标准开局，还能**自由摆棋**、**让子**（单马 / 双马 / 单车 / 车马 / 车马炮 / 九子）、
> **让先**（0~5 步），并带**中文记谱**。**不依赖任何第三方服务**，两端都是本程序。

## 能做什么

- **三种玩法**：**同机双人**（一台电脑轮流走）/ **开房间**（主机）/ **加入房间**（客户端）。
- **完整中国象棋规则**：9 列 × 10 行，**红先**，红方在下、黑方在上。
  车直行、马走日（**蹩马腿**）、相 / 象走田（**塞象眼**、不过河）、仕 / 士九宫斜走、帅 / 将九宫直走、
  炮隔一子吃 / 平移、兵 / 卒向前（**过河后可横走、不能后退**）。
- **将帅照面**（飞将）非法、**不允许走出「自己被将军」的棋**、被将军必须应将。
- **胜负**：**将死**判负；**困毙**（无合法着法且未被将军）在中国象棋里同样**判负**；
  连续 **120 个半回合**（双方各 60 步）无吃子 → **自然限着判和**。
- **自由摆棋**（用户点名要的自由度）：「摆棋与让子」卡片里
  - **棋子调色板**：红方 `帅仕相马车炮兵`、黑方 `将士象马车炮卒`、`删除` —— 选一个再点棋盘落子（覆盖原格）；
  - **「默认开局」**一键恢复标准布局（摆乱了不用一项项改回来），**「清空棋盘」**从头摆；
  - 摆错了会**实时提示**（见「摆棋校验」），有错时不能开房 / 开始对局；
  - 对局进行中摆棋会锁定；要换摆法点「**重新摆棋（会结束本局）**」（会先弹出确认：确定结束 / 取消）；
  - 同机双人同样可以先摆再下：调好后点「**应用并开始（同机双人）**」。
- **让子**：选「让子方」（红方 / 黑方），再点预设 —— **让单马 / 让双马 / 让单车 / 让车马 / 让车马炮 / 让九子**。
  「让子方」是**让子的一方**（强者），会从自己那边去掉对应的棋子。
- **让先**：`0~5` 步。被让方（让子方以外那方）在开局阶段可以**连续走 N 步**，N 步走完才恢复正常轮换。
- **对局辅助**：**走法提示**（点自己的棋子高亮它所有能走的位置）、**最后一步标记**、**显示坐标**、
  **自动翻转**（执黑时把棋盘转 180°，自己总在下方；也可以点「翻转棋盘」手动翻）。
- **中文记谱**：棋谱一行放两个半回合（红、黑各一），如 `1. 炮二平五    马8进7`；可一键复制整份棋谱。
- **悔棋 / 认输 / 求和 / 再来一局 / 房间聊天**：和五子棋一样，联机时请求需要对方点「同意」。
- **掉线不用重开**：**主机是权威**——客户端断网后主机**不重置棋局、不关房间**，显示「对局暂停 · 等待对方重连」；
  客户端自动重连（默认每 2 秒一次、最多 60 秒），回来时拿到**当前最新局面**（含轮次 / 结果 / 让先剩余 / 棋谱）继续下。
  只有房主关房 / 主动离开才不重连。

## 怎么联机

### 主机：开房间

1. 主页「**棋牌**」类别 → 打开「**联机象棋**」。
2. 右栏「房间」里填：**玩家名**、**端口**（默认 `5311`，填 `0` 表示让系统自动挑）、**房主执棋**（红先 / 黑后）。
   端口被占用时会提示「开房间失败」，改成 `0` 最省事。
3. 想摆棋 / 让子就先在「摆棋与让子」里摆好（标准开局直接点「默认开局」）。
4. 点「**开房间**」。开好后界面列出本机的「**地址:端口**」（IPv4 / IPv6），可单独复制或「复制邀请」。
5. 对方连上后，主机点「**开始对局**」（摆好的棋会一起同步给对方）—— **双方都要等主机开始后才能走子**。
   主机自己的「摆棋与让子」卡里不显示「应用并开始」；那是离线 / 同机双人用的。

### 客户端：加入房间

1. 把对方发来的地址填进「**加入地址**」。**地址里要带端口**，例如 `192.168.1.5:5311`、
   IPv6 写成 `[fe80::1]:5311`；外网就是内网穿透工具给你的 `域名:端口`。
   只填 IP / 域名会被提示「请填写端口」。
2. 点「**加入房间**」。连上后等主机开始，然后按轮次走子。

> 一台电脑上两个人轮流走：点「**同机双人**」即可（可以先摆棋再下）。玩完点「**离开房间**」断开：
> 主机离开 = 房间关闭；客户端离开 = 回离线界面。客户端掉线会自动重连，想主动放弃就点「**停止重连**」。

## 摆棋校验（哪些摆法不能开局）

自由摆棋在开房 / 开始对局前会校验，有错时界面会直接给出原因：

- 双方**各必须有且只有一个**帅 / 将；
- 帅 / 将必须在**自己的九宫**里；
- **将帅不能照面**（同一列且中间无子）；
- **不该走棋的一方不能正被将军**（轮到红走时，黑方不能被红方将军）。

## 中文记谱怎么读

- 红方路数从**红方视角由右往左**数 `一~九`，黑方路数从**黑方视角由右往左**数 `1~9`
  （屏幕上就是黑方从左往右数）。
- 格式：**起点路数 + 进 / 退 / 平 + 终点**，例：`炮二平五`（红炮从二路平到五路）、`马8进7`（黑马从 8 路进到 7 路）。
- 同一路上有多个**同种棋子**时用「前 / 后」区分（如 `前车进一`）。
- 棋谱列表**每行放两个半回合**（红、黑各一），复制出来就是一份可以贴给别人的完整棋谱。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 玩家名 | `玩家` | 联机时对方看到的昵称；同机双人也会显示 |
| 端口 | `5311` | 主机监听端口；`0` = 让系统自动挑一个空闲端口（界面上写「0 = 自动挑」） |
| 加入地址 | （空） | 客户端上次连的地址，下次自动填好（要带端口，如 `192.168.1.5:5311`） |
| 房主执棋 | 红方 | 开房时主机执红（先手）还是执黑（后手）；执黑时自动翻转棋盘（设置里的「自动翻转」）；「再来一局」会交换 |
| 走法提示 | 开 | 选中自己的棋子时高亮所有可走点（吃子的位置用另一种圈） |
| 自动翻转 | 开 | 执黑时自动把棋盘转 180°，自己的子总在下方 |
| 最后一步 | 开 | 用方框标出上一步的起点和终点 |
| 显示坐标 | 开 | 棋盘边缘显示路数 / 行数 |

> 所有设置都是**改一下就自动保存**，没有「保存」按钮。设置存在 `Config\xiangqi\config.json`（见下）；
> 上次选的「让子方」「让先步数」也会记住，下次打开接着用。

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\xiangqi\config.json` | 上面所有设置 + 上次的让子方 / 让先步数：玩家名 / 上次加入地址 / 端口 / 房主执棋 / 走法提示 / 自动翻转 / 最后一步 / 显示坐标 |

- 联机**不开新的数据端口**：所有内容都走主机那一个 TCP 端口（内网穿透只映射它即可）。
- **`Data\xiangqi\` 这版没有用到**（对局不落盘，没有历史记录文件）；关掉工具或程序，这一局就结束了
  （想留棋谱请在「棋谱」卡片里点复制，自己存下来）。

## 注意

- **连接没有加密**（就是普通 TCP）。传敏感内容请只在可信网络里用，或者先套一层加密通道（VPN / 穿透工具的 TLS）。
- **房间最多两人**（主机 + 1 位客户端）：第三个人连进来会收到「房间已满」的提示并被断开，房间里原有的两人不受影响。
- **掉线与重连**：客户端断网会自动重连，主机侧「对局暂停 · 等待对方重连」、棋局（含棋谱 / 轮次 / 让先）原样保留；
  重连中棋盘只读、不会重复加入；「离开房间」按钮会变成「**停止重连**」。
  **房主关房 / 主动离开不会自动重连**（客户端收到「房主关闭了房间 / 房主离开了房间」后回到离线）。
- **开房前摆好棋**：摆棋 / 让子 / 让先 / 房主执棋在开局时固定，对局进行中这些选项会被锁定；
  要换摆法点「重新摆棋（会结束本局）」，会先让你确认一次（确定结束 / 取消）。
- **悔棋语义**：主机按「撤到请求方该走」处理 —— 如果最后一步是对方走的就撤 2 步、是请求方自己走的就撤 1 步；
  一步都没走时撤不了，会提示。
- **自然限着**按「连续 120 个半回合无吃子」判和，和正式比赛的长将长捉等细则不同，日常对弈够用。
