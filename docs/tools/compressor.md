# 🗜️ 压缩器

> 把图片、音频、视频拖进来，选一档压缩程度，批量输出更小的文件。源文件只读，不会覆盖原文件。

## 能做什么

- **拖入即读**：支持一次拖入多个文件或整个文件夹；也可点「添加文件 / 添加文件夹」。
- **自动识别**：按扩展名识别图片 / 音频 / 视频，读取文件大小；音频、视频会额外读取时长和分辨率。
- **压缩程度**：轻度（画质优先）/ 标准（体积与画质平衡）/ 极限（优先减小体积）。
- **图片输出**：JPG（有损压缩）或 PNG（无损重新编码）。
- **音频输出**：MP3 / M4A（AAC）/ OGG。
- **视频输出**：MP4（H.264 + AAC）。
- **批量处理**：逐文件进度、总体进度、失败状态、取消；完成后可自动打开输出目录。
- **安全输出**：默认输出到 `桌面\YuLiangToolkit 压缩输出`，同名文件自动加序号，不覆盖原文件。

## 压缩档位

| 档位 | 图片 | 音频 | 视频 |
| --- | --- | --- | --- |
| 轻度压缩 | JPG 92 | 192 kbps | H.264 CRF 20 + 192 kbps 音频 |
| 标准压缩 | JPG 82 | 128 kbps | H.264 CRF 26 + 128 kbps 音频 |
| 极限压缩 | JPG 70 | 64 kbps | H.264 CRF 32 + 64 kbps 音频 |
| 超糊压缩 | JPG 45 / 长边 1600 | 32 kbps | H.264 CRF 38 / 最高 720p + 32 kbps |
| 全损压缩 | JPG 28 / 长边 1024 | 16 kbps | H.264 CRF 45 / 最高 480p + 16 kbps |
| 随缘压缩 | JPG 12 / 长边 640 | 8 kbps | H.264 CRF 51 / 最高 360p + 8 kbps |

> 后三档是整活用，画面 / 声音会明显变糊、变糙；默认仍是标准压缩。

## 怎么用

1. 打开「文件 → 压缩器」，把图片 / 音频 / 视频拖进左侧区域。
2. 在右侧选择压缩程度、输出格式和输出目录。
3. 点「开始压缩」；列表会显示每个文件的进度和压缩前后体积。
4. 完成后可点「打开」查看输出目录。

## 运行要求

- 图片压缩：Windows 自带 WPF 图像编解码。
- 音频 / 视频压缩：需要系统 FFmpeg；工具会自动查找 PATH / WinGet 常见位置，找不到时可在右侧点「选择 ffmpeg.exe…」。
- 支持格式：JPG / PNG / WebP / GIF（图片首帧）；MP3 / WAV / FLAC / AAC / M4A / OGG / OPUS / WMA / AIFF / APE；MP4 / MKV / MOV / AVI / WebM / FLV / WMV / M4V / TS / MTS。

## 配置位置

- 配置：`Config\compressor\config.json`
- 输出目录：默认 `桌面\YuLiangToolkit 压缩输出`（可在页面修改）
- 源文件：只读，不会删除或修改
