# 🏷️ 批量重命名

> 给一批文件套一组改名规则：**改之前先看预览，改完还能一键撤销**。

[← 工具一览](../../README.md) ｜ [文档索引](../README.md)

## 能做什么

- **规则是一张清单**，不是写死的顺序：
  - 上面选一个类型 → 点「**+ 添加规则**」→ 规则出现在清单里，点标题行展开填参数；
  - **同一种规则可以加多条**（例如两条「查找替换」接力、先「编号」再加「前缀」）；
  - **顺序自己定**：按住每行左边的 **☰** 上下拖动（也可以点 ↑ ↓），
    **清单顺序 = 执行顺序**，换顺序预览立刻跟着变；
  - 不想要的规则去掉勾选就临时停用，点 **✕** 删除，「清空规则」一键清空。
- **每条规则还能选「作用于」哪一部分**：`主名`（默认，不动扩展名）/ `扩展名` / `整个文件名`。
- **预览**：列表里每行显示「原名 → 新名 + 状态」（正常 / 冲突 / 跳过 / 错误），改规则即时重算。
- **冲突会拦下来**：两个文件算成同一个名字、或目标位置已有别的文件 → 标红为「冲突」并跳过，
  不会悄悄覆盖你的东西；想让它自动加 ` (1)`、` (2)` 也有开关。
- **执行是两阶段的**：先把所有要改的文件改成同目录临时名，再改成最终名字。
  所以 `A→B`、`B→A` 互换、只改大小写（`photo.jpg` → `Photo.jpg`）、`A→B→C` 链式改名都不会打架；
  中途失败的那一条会被改回原名，不会留下半个临时文件。
- **撤销**：每次改名都写一份流水账到 `Data\batch-rename\rename-history.json`
  （自动只保留最近 20 批），所以**关掉程序再打开照样能撤销**；列表里列出每批改名，可以挑其中一批单独撤销。

## 界面布局

- 「① 文件列表 / ② 命名规则 / ③④ 执行 + 历史」三块之间可以**拖动调整大小**（蓝线 + ↕），松手自动记住（`Config\layout.json`）；
- **双击**某条分隔线只恢复这一处；全部恢复默认：**主页设置 →「界面布局 → 恢复默认布局」**。

## 规则类型

| 规则类型 | 能做什么 |
| --- | --- |
| 查找替换 | 普通文本（可不区分大小写、可只替换第一处）或**正则**（替换里能用 `$1` 引用捕获组） |
| 清理 | 去首尾空格 / 连续空格合并成一个 / 删掉指定字符（如 `_-`） |
| 截取 / 删除 | 从头删 N 个字符 / 从尾删 N 个字符 / 删掉两个标记之间的内容（可只删标记、保留内容） |
| 大小写 | 全小写 / 全大写 / 每个单词首字母大写 / 仅首字母大写 |
| 加前缀 / 后缀 | 加前缀、加后缀 |
| 自动编号 | 起始 / 步长（可为负）/ 位数补零 / 放在前、后或直接当整个名字，**按列表顺序编号** |
| 扩展名 | 保持 / 转小写 / 转大写 / 统一换成指定扩展名 / 去掉 |

## 怎么用

1. `添加文件…`（多选）/ `扫描文件夹…`（可递归子文件夹、按扩展名过滤：`jpg; png; .bmp`），
   或者直接把文件 / 文件夹**拖进窗口**；列表里每行前面的勾选框可以临时排除某几个文件。
2. 加规则、填参数、拖动排序，看预览。
3. 点「执行重命名」→ 二次确认 → 完成。后悔了就点「撤销上一批」，或者到历史列表里挑一批撤销。
4. 列表可以按名字升序 / 降序排（序号跟着列表走）；排序方式与上次用的文件夹会记住。

## 设置项

| 设置 | 存哪 | 说明 |
| --- | --- | --- |
| 规则清单（整条数组） | `Config\batch-rename\config.json` 的 `rules` | **可以直接用记事本改**，改完重开功能即生效 |
| 冲突时自动加序号、列表排序偏好、上次的文件夹 | 同上 | 改一下就自动保存 |

## 数据与配置

| 位置 | 内容 |
| --- | --- |
| `Config\batch-rename\config.json` | 规则清单 + 偏好 |
| `Data\batch-rename\rename-history.json` | 改名流水账（撤销依据，最多 20 批）。**删了就等于放弃所有撤销记录** |

## 注意

- 只改**名字**，绝不换目录：目标永远是同一个文件夹里的新名字。想「移动到子文件夹」得另外做。
- 撤销依赖那份流水账，所以别删 `Data\batch-rename\rename-history.json`；
  但删了也不会影响已经改好的文件名。
- Windows 上「只改大小写」必须靠两阶段改名才做得到，这个工具已经处理了。
