# 🧮 计算器

> 科学计算器：直接敲表达式（`2(3+4)`、`sin(30)`、`5!`、`2^10`、`sqrt(2)` 都认），边打边出结果；
> 键盘按钮和实体键盘都能用，带角度制 / 弧度制、结果精度、历史记录、Ans 与复制结果。
> **整数和有限小数走任意精度精确计算**：`100!`、`2^1000`、二十位大整数相加都是完整准确的数字。
>
> 另有一个 **辈分计算模式**：从「我」一级一级点出亲戚关系（`爸爸的哥哥`、`妈妈的妈妈的哥哥`），
> 直接告诉你该叫对方什么、对方该叫你什么 —— **北方叫法 / 南方叫法两套**（姥爷 ↔ 外公、大伯 ↔ 伯伯）。

> **界面布局**：左边「主显示 + 键盘」与右边「历史记录 / 设置」之间可左右拖；
> 左边的主显示与键盘之间、右边的历史与设置之间可上下拖，拖完自动记住；
> 双击某条缝只恢复这一处，全部恢复默认在 **主页设置 → 界面布局 → 恢复默认布局**。
> 辈分计算模式同样可拖（结果 / 关系链 / 对照表 / 说明四块各自独立）。

## 两个模式

页头右上角切换，选哪个下次打开还是哪个：

| 模式 | 干什么 |
| --- | --- |
| **标准计算** | 表达式计算（下面「能做什么」到「常见问题」说的都是它） |
| **辈分计算** | 亲属称谓：点关系链 → 出叫法（详见下面的 [辈分计算模式](#辈分计算模式)） |

## 能做什么

- **直接输入表达式**：不用按「几加几」的顺序点按钮，像写公式一样输入 `sin(pi/6)+ln(2)`，
  回车（或 `=` 键）出结果。输入框里也支持粘贴、复制、退格、光标移动。
- **边打边算**：实时预览区跟着输入刷新；写错了只在这一行显示**中文**提示（例如「括号没有闭合」），
  不会弹窗打断你。不想要实时预览可以在设置里关掉。
- **科学函数**：三角 / 反三角（sin cos tan asin acos atan）、双曲（sinh cosh tanh 等，可直接手打）、
  对数（ln / log / log2）、根号（sqrt / cbrt）、乘方 `^`、阶乘 `!`、常量 π / e / τ，以及
  abs / exp / floor / ceil / round / trunc / mod / hypot / min / max / nCr / nPr 等。
- **角度制 / 弧度制**：一个下拉框切换。角度制下 `sin(90)=1`；弧度制下 `sin(pi/2)=1`；
  `asin(1)` 会按当前单位返回 90° 或 π/2。
- **任意精度大数**：整数和有限小数的四则运算、乘方、阶乘、取模用 `BigInteger` 十进制精确计算，
  `100!` 出完整 158 位、`2^1000` 出完整 302 位、`12345678901234567890+1` 一位不差、
  `0.1+0.2` 就显示 `0.3`。这类结果**不截断、不用科学计数法**，Ans 也按精确文本插入。
  除不尽的分数（`1/3`）、函数、`π` / `e`、负指数幂自动回退到普通浮点计算，按下面的有效位数显示。
- **结果精度**：可调有效位数（3 ~ 12，默认 12）—— 只影响**回退到浮点**的那些结果（除不尽、三角函数等）。
  特别大 / 特别小的浮点结果自动用科学计数法（`1.2e+15`）。
- **特殊结果显示**：超出实数范围或除零不崩溃 —— `sqrt(-1)` 显示「无定义」，`1/0` 显示「+∞」。
- **历史记录**：每次求值记下「表达式 = 结果」，新的在最上面；点一条就把表达式填回输入框；
  可以一键清空，条数上限可调（10 ~ 200），关掉工具再打开还在。
- **Ans 与复制**：「Ans」按钮插入上一次的计算结果；「复制」把当前结果复制到剪贴板。

## 怎么用

1. 在输入框里打字（或用下面的键盘按钮），实时预览区就会显示结果。
2. 按 **Enter** 或点 **=**：结果固定下来并写入历史记录；此时「Ans」也更新成这个结果。
3. 按 **Esc** 或点 **C**：清空输入重新算。**⌫** 退格，**±** 切换正负号。
4. 想用上一次的结果继续算：点 **Ans**（会插入格式化后的数字；紧贴数字 / 括号时会自动补乘号，
   例如 `2×Ans` 变成 `2*(…)` 的合法写法）。
5. 想重算历史里的某一条：在右侧历史列表点它，表达式就回到输入框。
6. 点「复制」把结果复制走；历史不需要了点「清空历史」。

## 支持的表达式写法

- 四则运算 `+ - * /`、乘方 `^`（右结合：`2^3^2 = 512`）、取模 `mod`（`7 mod 3 = 1`）、阶乘后缀 `!`（`5! = 120`）。
- **省略乘号**：`2(3+4)`、`2π`、`3sin(30)`、`(x+1)` 这类写法都当乘法（计算器里没有变量，只有函数绘图用 `x`）。
- 括号可以多层嵌套；一元正负号 `-2^2 = -4`（先乘方后取负，和数学惯例一致）。
- 三角函数只写函数名 + 括号，例如 `sin(30)`；反三角 `asin(0.5)`。
- 结果里出现 ∞ 表示溢出 / 除以 0；「无定义」表示数学上没有实数值（例如 `sqrt(-1)`、`ln(0)`）。
- 顺手兼容输入法打出来的 `× ÷ − ² ³`、全角括号和全角数字。

## 设置项

改一下就自动存进 `Config\calculator\config.json`，没有保存按钮。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 模式 | 标准计算 | 「标准计算」或「辈分计算」；页头右上角也能切 |
| 角度单位 | 弧度 | 「弧度」或「角度」；只影响三角与反三角函数 |
| 结果有效位数 | 12 | 3 ~ 12；调小会让结果更「短」，调大保留更多位 |
| 历史记录条数上限 | 50 | 10 ~ 200；超出的旧记录自动丢掉 |
| 实时预览 | 开 | 关掉后只有按 Enter / = 才更新结果区 |
| 叫法地区（辈分） | 北方 | 「北方」或「南方」；只改称呼文字，关系推导不变 |
| 我是（辈分） | 男 | 「男」或「女」；只影响「对方该叫我什么」 |
| 当前关系链（辈分） | 空 | 上次看着的那条链，切走再回来还停在原处 |

## 辈分计算模式

页头切到「辈分计算」，界面是四块（都能拖）：

- **① 结果卡**：大字叫法 + 书面称谓 + `辈分：长一辈` / `支系：母系` + 白话解释 +
  「他 / 她该叫你：外甥」；
- **② 关系链**：从「我」开始点 `爸爸 / 妈妈 / 哥哥 / 弟弟 / 姐姐 / 妹妹 / 老公 / 老婆 / 儿子 / 女儿`，
  可以一直点下去（`妈妈的妈妈的哥哥的女儿`）；`退一级` / `重来` 随时回退；
- **③ 称谓对照表**：一百多条常用亲戚的南北两列叫法，带搜索框；**点一行就把它的关系装到左边**，
  这是「认辈分名」最快的入口（看到「大伯」不认识 → 点一下就知道是「爸爸的哥哥」，比自己点快）；
- **④ 说明**：叫法地区切换、我的性别、小提示。

### 南北叫法

关系推导完全一样，只是最终显示的称呼按地区换一套：

| 关系 | 北方 | 南方 |
| --- | --- | --- |
| `妈妈的爸爸` / `妈妈的妈妈` | 姥爷 / 姥姥 | 外公 / 外婆 |
| `爸爸的哥哥` / `爸爸的弟弟` | 大伯 / 叔叔 | 伯伯 / 叔叔 |
| `爸爸的哥哥的老婆` | 大娘 | 伯母 |
| `爸爸的弟弟的老婆` | 婶子 | 婶婶 |
| `弟弟的老婆` | 弟妹 | 弟媳 |
| `爷爷的哥哥` | 大爷爷 | 伯公 |

叫法一致的（姑姑、舅舅、叔叔、姑父、舅妈、侄子…）两边都显示同一个词。
每个称谓的差异与地区变体都写在对照表和结果卡的说明里（例如「南方也叫阿公」），
**口语叫法本来就有方言差异，工具给的是比较通行的说法，不当作铁律。**

### 它怎么推的

1. **规范化**：先按必然成立的等价规则化简关系链 —— `哥哥的爸爸 → 爸爸`、
   `爸爸的哥哥的爸爸 → 爸爸的爸爸`、`儿子的哥哥 → 儿子`、`老婆的儿子 → 儿子`、
   `老公的老婆 → 我自己`；长幼同向的兄弟姐妹也能合（`哥哥的姐姐 → 姐姐`），
   但 `哥哥的弟弟` 这种说不好是不是本人的保持原样；
2. **查表**：规范化后的链拿去查称谓表（一百多行：直系三辈、伯叔姑舅姨及其配偶、堂表兄弟、
   侄甥、姻亲、孙辈、再上一层的堂伯 / 堂叔 / 表舅 / 表姨…）；
3. **反向**：把链倒过来（`父 ↔ 子/女`、`兄 ↔ 弟/妹`…）再走同一套流程，得到「对方叫我什么」；
4. **兜底**：表里没有的远亲不瞎编称呼 —— 标题写「远房亲戚」，辈分 / 支系 / 关系链照旧讲清楚，
   反向那边给「小一辈的亲戚」这种有信息量的说法。

### 边界

- **长幼看不出时会写一对**：堂 / 表兄弟的关系链里没有年龄，所以结果是「堂哥 / 堂弟」，
  自己按谁大对号（结果卡和小提示都写了）；
- **按血缘与婚姻推导**（一夫一妻的常规理解）：继父母、收养、同父异母这类特殊情形不在范围内；
- **不覆盖方言全谱**：一百多条是常见称谓，方言（阿公 / 阿婆 / 舅公…）在说明里注明；
- 名字之外的东西（对方的名字、排行「二叔」怎么排）不猜。

## 文件放在哪

- 配置：`Config\calculator\config.json`（相对 **exe 所在目录**，不是仓库根目录），历史记录也存在这里。
- 数据：本工具不写 `Data\`、不写 `Cache\`；清缓存 / 重建配置只会把上面这些选项恢复默认。
- 区块大小：和别的工具页一样存在 `Config\layout.json`（键名前缀 `calculator.`）。

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 输入 `x` 报错 | 计算器没有变量；`x` 是「函数绘图」工具用的，那边才需要 |
| 显示「无定义」 | 数学上无实数值，例如 `sqrt(-1)`、`0/0`、`asin(2)` |
| 显示 `+∞` / `-∞` | 除以 0、或浮点结果溢出（例如 `2^100000` 这种精确引擎也撑不住的巨大结果）；可以拆成小步算 |
| `100!` 出来一长串数字 | 这是精确结果（158 位），不是 bug；想短一点可以用 `100!/1e100` 近似 |
| `1/3` 只有十几位 | 除不尽，走的是浮点通道，位数由「结果有效位数」控制 |
| `sin(90)` 结果不是 1 | 当前是弧度制：切到「角度」；或改写成 `sin(pi/2)` |
| 历史越攒越多 | 设置里的「历史记录条数上限」控制保留数量，也可点「清空历史」 |
| 辈分算出来是「远房亲戚」 | 这条关系超出常用称谓表（或长幼说不准，如「哥哥的弟弟」）；卡的说明里解释了原因，关系链本身照样显示 |
| 辈分显示「堂哥 / 堂弟」两个 | 堂 / 表兄弟的长幼要靠实际年龄，关系链里看不出来；自己按谁大对号 |
| 想换地方叫法 | 辈分模式的「说明」里切「北方叫法 / 南方叫法」，改一下自动保存 |

## 自检

`calculator` 组（`tests/YuLiangToolkit.FrameworkSelfCheck/CalculatorChecks.cs`）：纯逻辑断言 ——
表达式解析与求值（运算符优先级 / 右结合乘方 / 一元负号 / 取模）、省略乘号、阶乘、角度制与弧度制、
常量、无定义与 ∞、结果格式化（去尾 0 / 科学计数法 / ±∞ / 无定义）、按键与输入构造（小数点去重 / 退格 /
正负号 / 平方 / 倒数 / Ans）、历史记录规则（新的在前 / 相邻去重 / 上限裁剪 / 清空 / JSON 往返）、
配置默认值与区间夹取，以及**任意精度大数**（`100!` 158 位 / `2^1000` 302 位 / 大整数不丢位 / `0.1+0.2=0.3` /
除得尽才接管 / 结果位数失控回退 +∞）。**不创建窗口、不碰剪贴板、不写真实 Config。**

辈分计算模式由 `tests/YuLiangToolkit.FrameworkSelfCheck/KinCalculatorChecks.cs` 断言（同属 `calculator` 组，
由 `CalculatorChecks.Run` 末尾调用）：关系链规范化（含长幼与配偶的每条替换规则）、
**称谓表与算法一致性**（表里每一行都能解析、且推出来的结果与这一行相同）、南北叫法、辈分与支系、
反向称谓（含**反两次必须回到原链**的对称性）、性别对反向的影响、远亲兜底、关系链文案、配置项与 JSON 往返。

精确大数的轮子在 `src/YuLiangToolkit.Core/`（`Numbers/ExactDecimal.cs` +
`Expressions/ExactMathExpression.cs`），共享的浮点表达式引擎仍在 `src/YuLiangToolkit.Core/Expressions/`
（计算器与函数绘图共用）。改这些都属于跨层改动，按 `docs/dev/verification.md` 走全量自检。
辈分内核（`src/YuLiangToolkit.Tools.Calculator/Core/Kin/`）在本工程内，改它只跑 `calculator` 组。
